    第 6 章 随机过程与随机微积分¶

    来源：quant_guide.md Ch5

    本节要解决的核心问题¶

    从「静态随机变量」进阶到「随时间的随机过程」。量化中期权定价、策略建模都建立在本讲之上。核心：Markov 链、鞅/随机游走、动态规划、布朗运动与 Itô 引理。

    6.1 马尔可夫链（Markov Chain）¶

    • 性质：下一状态只依赖于当前状态，与历史无关。
    • 状态分类：常返态与瞬态、吸收态，以及状态或链的周期性。
    • 核心工具：转移概率矩阵、平稳分布 \(\pi\) 满足 \(\pi P=\pi\)。
    • n 步转移：\(P(X_{t+n}=j\mid X_t=i)=(P^n)_{ij}\)；有限状态链若不可约且非周期，则分布收敛到唯一平稳分布。
    • 吸收链：按瞬态/吸收态分块 \(P=\begin{bmatrix}Q&R\\0&I\end{bmatrix}\)，基本矩阵 \(N=(I-Q)^{-1}\)；\(NR\) 给出最终吸收概率，\(N\mathbf 1\) 给出期望吸收时间。
    • 经典题：Gambler's ruin、掷骰子、硬币三元组、彩色球等。

    常用技巧¶

    • 设 \(p_i\) = 从状态 \(i\) 出发到吸收态的概率，列线性方程组求解（一阶/二阶递推）。

    6.2 鞅与随机游走（Martingale & Random walk）¶

    • 鞅：相对于信息集 \(\mathcal F_n\)，\(E[|X_n|]<\infty\) 且 \(E[X_{n+1}\mid\mathcal F_n]=X_n\)；不能只写成条件于 \(X_n\)，除非状态本身包含全部相关信息。
    • 次鞅/上鞅：条件期望分别 \(\ge X_n\) / \(\le X_n\)，可用来判断策略是否有正漂移。
    • 由鞅可得 Doob 停时定理：在某些条件下 \(E[X_\tau]=E[X_0]\)。
    • 例：Random walk（醉汉、购票队列、骰子博弈）。

    常用技巧¶

    • 若一个随机过程是鞅，则可用停时定理直接得期望，免去繁重的逐层递推。

    6.3 动态规划（Dynamic Programming, DP）¶

    建模四要素（bible 5.3 / guide Ch5）： 1. 离散时间动态系统（状态转移） 2. 随时间的可加成本/收益函数 3. 目标：选定策略最优化总成本/收益 4. Bellman 方程：从终点倒推，\(V(\text{状态})=\max(\text{立即收益}+\text{未来价值})\)

    适用场景：多阶段决策、每一步交互后要重新决策（掷骰子、世界系列赛、动态纸牌等）。

    常用技巧¶

    • 倒推法（backward induction）是核心：从最后一步往前算最优价值。
    • 把握「边界/吸收态」的终值来启动递推。

    6.4 布朗运动与随机微积分（bible 5.4 + guide Ch5）¶

    布朗运动¶

    • 连续时间、连续路径、独立与平稳增量、\(B_0=0\)，\(B_t\sim\mathcal N(0,t)\)。
    • 相关题：\(B_t\) 与 \(B_t^2\) 的相关；\(P(B_1>0\text{ 且 }B_2<0)\) 等。

    二次变差与积分¶

    • 布朗运动的二次变差 \([W]_t=t\)；伊藤规则：\((dW)^2=dt\)、\(dt\cdot dW=0\)、\((dt)^2=0\)。
    • Itô 积分要求被积过程适应于当前信息，不能使用未来信息；平方可积时其期望为 0。
    • 风险中性漂移：定价测度下可交易资产的贴现价格是鞅，真实世界漂移 \(\mu\) 被无风险利率 \(r\) 替代，这是第 7 章无套利定价的桥梁。

    典型过程¶

    • 几何布朗运动解：\(S_t=S_0\exp((\mu-\sigma^2/2)t+\sigma W_t)\)；均值回复 OU：\(dX_t=\kappa(\theta-X_t)dt+\sigma dW_t\)，长期均值 \(\theta\)、回复速度 \(\kappa\)。
    • 停时定理需满足可积性/有界性等条件；无限期赌博题不能无条件套用 \(E[X_\tau]=E[X_0]\)。

    Itô 引理¶

    若 \(dS=\mu S\,dt+\sigma S\,dW(t)\)，对 \(V=V(S,t)\)：

    \[dV=\Big(\frac{\partial V}{\partial t}+\mu S\frac{\partial V}{\partial S}+\frac12\sigma^2S^2\frac{\partial^2 V}{\partial S^2}\Big)dt+\sigma S\frac{\partial V}{\partial S}dW(t)\]
    • Itô 引理是推导 Black-Scholes 微分方程的基础（见第 7 章）。

    Poisson 过程与生成元¶

    • Poisson 过程 \(N_t\)：独立且平稳增量，\(N_t-N_s\sim\operatorname{Poisson}(\lambda(t-s))\)；相邻到达时间服参数 \(\lambda\) 的指数分布。
    • 小时间近似：\(P(\Delta N=1)=\lambda\,\Delta t+o(\Delta t)\)，\(P(\Delta N\ge2)=o(\Delta t)\)。看到“单位时间独立到达”时优先检查这一模型。
    • Markov 过程的生成元描述瞬时变化：对扩散 \(dX=b(X)dt+a(X)dW\)，
    \[\mathcal L f(x)=b(x)f'(x)+\tfrac12a(x)^2f''(x).\]

    它把随机微分方程与定价 PDE/动态规划连接起来；离散链中对应 \(Pf-f\)。 - 二次协变差：独立 Brownian motion 的 \([W^i,W^j]_t=0\ (i\ne j)\)；相关系数为 \(\rho\) 时 \([W^1,W^2]_t=\rho t\)，多资产 Itô 展开会出现交叉项。

    常见题型与套路¶

    题型 套路
    Markov 链吸收概率 列递推方程组
    鞅期望 停时定理 \(E[X_\tau]=E[X_0]\)
    多阶段最优策略 倒推式动态规划
    布朗运动性质 正态增量 + 联合分布
    求随机微分 dV Itô 引理

    易错点 / 面试提示¶

    • DP 题关键在正确写出状态与转移，并从终态倒推。
    • 判断能否用停时定理：确认过程是鞅、停时条件满足。
    • Itô 引理要记得当 \(dW\) 项「平方」成 \(dt\) 时出现的 \(\frac12\sigma^2S^2\partial^2V/\partial S^2\) 项（这是与普通微积分最大的不同）。
    • 先明确过滤信息集、测度（真实/风险中性）和停时条件，再使用鞅结论。
