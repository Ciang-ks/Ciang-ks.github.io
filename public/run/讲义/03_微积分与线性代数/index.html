    第 3 章 微积分与线性代数¶

    来源：quant_guide.md Ch3

    本节要解决的核心问题¶

    量化面试需要快速、准确地进行微积分与线代运算（求导、积分、矩阵分解、特征值等）。本章整理最常用、最高频的数学工具。

    3.1 极限与导数¶

    • 导数定义：\(f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}\)，表示局部线性变化率。
    • 基本规则：
    • \((uv)'=u'v+uv'\)，\((u/v)'=\frac{u'v-uv'}{v^2}\)，\((f\circ g)'=f'(g)g'\)；
    • \((x^a)'=a x^{a-1}\)，\((e^u)'=e^u u'\)，\((\ln|u|)'=u'/u\)；
    • \(\sin'=\cos\)，\(\cos'=-\sin\)，\(\tan'=\sec^2\)。
    • 常用极限/阶数：\(\sin x\sim x\)、\(1-\cos x\sim x^2/2\)、\(\ln(1+x)\sim x\)、\(e^x-1\sim x\)（\(x\to0\)）；指数增长快于任意多项式，多项式快于对数。
    • 极值问题：先找定义域内驻点 \(f'=0\)，再检查不可导点和区间端点；二阶导 \(f''>0/<0\) 只给出局部极小/极大。
    • 隐函数与对数求导：对 \(y=f(x)\) 两边求导并保留 \(y'\)；含乘方/乘积的正值函数先取 \(\ln\)，可把幂变乘积。
    • 洛必达法则：仅适用于 \(0/0\) 或 \(\infty/\infty\)（先确认条件）；\(0\cdot\infty\)、\(\infty-\infty\)、\(1^\infty\) 等需先改写。

    3.2 积分¶

    • 基本积分：幂、指数、三角、对数（\(\int\ln x\,dx=x\ln x-x\)）；不定积分不要忘记常数项 \(+C\)。
    • 换元法：识别复合结构，设新变量。
    • 分部积分：\(\int u\,dv=uv-\int v\,du\)，用于 \(\int\sec x\,dx\)、\(\int\ln x\,dx\) 等。
    • 微积分基本定理：若 \(F(x)=\int_a^x f(t)\,dt\) 且 \(f\) 连续，则 \(F'(x)=f(x)\)；定积分是净面积，需注意上下限方向。
    • 广义/反常积分：无穷区间或端点无界时用极限定义；先判断收敛性再交换积分、求期望或使用数值法。
    • 应用：计算期望 \(E[X]=\int x f(x)\,dx\)、尾概率、面积/体积。量化中常用 \(E[g(X)]=\int g(x)f(x)\,dx\)，不是只对 \(x\) 本身积分。

    3.3 偏导数与多重积分¶

    • 偏导：对单个变量求导，其余视为常数。
    • 全微分/梯度：\(df=\nabla f(x)^\top dx\)，\(\nabla f=(\partial f/\partial x_1,\ldots,\partial f/\partial x_d)^\top\)；链式法则写成 \(J_{f\circ g}=J_fJ_g\)。
    • 多重积分：嵌套积分或 Fubini 定理换序；变量变换要乘 Jacobian，极坐标中 \(dx\,dy=r\,dr\,d\theta\)。
    • Hessian：\(H=\nabla^2f\)。在驻点处 \(H\) 正定/负定分别对应局部极小/极大；不定时是鞍点，半正定时二阶检验不充分。
    • 多元 Taylor：\(f(x+h)\approx f(x)+\nabla f(x)^\top h+\frac12h^\top H(x)h\)，是 Newton 法、delta method 和风险近似的共同基础。

    3.4 重要方法¶

    • 泰勒展开：把函数在一点附近展开为多项式，用于近似与推导。
    • 常用：\(e^x=1+x+x^2/2+\cdots\)，\(\ln(1+x)=x-x^2/2+\cdots\)，\(\sin x=x-x^3/6+\cdots\)，\(\cos x=1-x^2/2+\cdots\)。
    • 虚数单位满足 \(i^2=-1\)；欧拉公式 \(e^{i\theta}=\cos\theta+i\sin\theta\)，故 \(e^{i\pi}+1=0\)。原文中的“\(i'\)”应为笔误。
    • 截断误差可用 Lagrange 余项 \(R_n=f^{(n+1)}(\xi)(x-x_0)^{n+1}/(n+1)!\) 估计。
    • 牛顿法：迭代逼近方程根，\(x_{n+1}=x_n-f(x_n)/f'(x_n)\)。
    • 根附近且 \(f'(\text{root})\ne0\) 时通常二次收敛；初值差或导数接近 0 时可能发散。
    • 二分法要求区间端点异号，收敛慢但有保证；割线法不需要显式导数。
    • 无约束优化：梯度下降 \(x_{k+1}=x_k-\eta_k\nabla f(x_k)\)；步长过大震荡、过小收敛慢。凸函数的任一局部极小都是全局极小。
    • 拉格朗日乘子：带等式约束 \(g(x)=0\) 时 \(\nabla f=\lambda\nabla g\)；多个约束写成 \(\nabla f=\sum_j\lambda_j\nabla g_j\)。不等式约束需结合 KKT 条件（互补松弛）。

    3.5 常微分方程（ODE）¶

    • 可分离变量：\(dy/dx=g(y)h(x)\)，分离后两边积分。
    • 一阶线性：\(y'+p(x)y=q(x)\)，用积分因子。
    • 齐次/非齐次线性方程：齐次解 + 特解（待定系数 / 常数变易）。二阶常系数方程的特征根实/重根/复根分别给指数、指数乘 x、衰减振荡。
    • 稳定性直觉：解中实部为负的特征根对应衰减，实部为正对应爆炸；这是利率/均值回复模型判断长期行为的快速工具。
    • 数值解：Euler \(y_{n+1}=y_n+h f(t_n,y_n)\) 简单但误差 \(O(h)\)；Runge--Kutta 4 阶误差 \(O(h^4)\)，代价更高。

    3.6 线性代数¶

    • 向量：内积、范数、正交、投影。
    • 线性映射：秩 \(\operatorname{rank}(A)\) 是像空间维数，零空间维数满足 \(\operatorname{rank}(A)+\operatorname{nullity}(A)=\text{列数}\)；满列秩时最小二乘解唯一。
    • 投影与最小二乘：\(P=A(A^\top A)^{-1}A^\top\) 是列空间的正交投影，残差 \(r=y-A\hat\beta\) 与列空间正交（\(A^\top r=0\)）。
    • QR 分解：把矩阵正交化/上三角化，是回归、最小二乘的数值工具；实际计算优先 QR，避免显式形成 \((X^\top X)^{-1}\)。
    • 行列式、特征值、特征向量：\(Av=\lambda v\)，判别矩阵性质。
    • 谱定理：实对称矩阵可正交对角化 \(A=Q\Lambda Q^\top\)；特征值是二次型和协方差矩阵的核心。
    • 正定/半正定矩阵：所有特征值 \(>0/\ge0\)，与协方差、凸性相关。
    • LU 分解、Cholesky 分解：求解线性方程组、模拟多元正态。
    • Cholesky：正定矩阵 \(A=LL^\top\)，常用于生成相关随机变量。
    • SVD（奇异值分解）：任意 \(m\times n\) 矩阵 \(X=U\Sigma V^\top\)；奇异值平方是 \(X^\top X\) 的特征值。截断 SVD 给出固定秩下的最佳 Frobenius 范数近似，也是 PCA 的数值基础。
    • 条件数与稳定性：\(\kappa(A)=\|A\|\,\|A^{-1}\|\) 大表示问题病态，小的输入误差可能被放大；回归中强共线性会使 \(X^\top X\) 条件数变大，正则化可缓解。
    • 矩阵微分：\(\partial(a^\top x)/\partial x=a\)，\(\partial(x^\top A x)/\partial x=(A+A^\top)x\)；\(A\) 对称时为 \(2Ax\)。这些公式用于 OLS、风险和优化推导。

    常见题型与套路¶

    题型 套路
    求极值/最值 一阶导数=0 → 二阶导判型
    求积分（含 ln/sec） 分部 / 换元
    期望积分 \(E[X]=\int x f(x)\,dx\)
    泰勒近似 展开至所需阶数
    约束优化 拉格朗日乘子
    梯度优化 梯度下降 / Newton（Hessian）
    解 ODE 判类型 → 选方法
    矩阵性质 特征值 / 分解 / 二次型
    最小二乘数值实现 QR 或 SVD，避免直接求逆
    相关系数上下界 相关矩阵半正定，检查行列式

    易错点 / 面试提示¶

    • 见到 \(\sec\)、\(\ln\)、\(e^x\) 的积分要条件反射想到分部积分。
    • 特征值相关题：问「是否正定」「是否可对角化」时，从特征值符号入手。
    • Cholesky 只适用于正定矩阵；生成相关正态用 \(Lz\)。
    • 相关矩阵必须半正定；三变量题可令行列式 \(\ge0\) 得到相关系数范围。
    • 数值实现中不要把“可逆”误当成“适合求逆”：病态矩阵优先用 QR/SVD，并报告条件数或正则化方案。
    • 二阶导为 0 不能直接判定极值；需看更高阶项或直接比较函数值。

    3.7 面试前最小公式集¶

    1. \(\nabla f=0\) 只给候选点；全局最优还要检查边界、凸性和可行域。
    2. \(\int f(g(x))g'(x)\,dx\) 用换元，\(\int u\,dv=uv-\int v\,du\) 用分部。
    3. \(A^\top A\beta=A^\top y\) 是正规方程，但代码中优先 QR/SVD。
    4. 对称矩阵 \(A=Q\Lambda Q^\top\)；\(A\) 正定当且仅当所有特征值为正。
    5. \(X=U\Sigma V^\top\) 同时解释降维、伪逆和病态性。

    3.8 复杂分析、傅里叶与数值稳定性¶

    量化面试中的数学题不只考机械求导，还会考函数变换、级数和矩阵的结构。遇到复数函数时，先使用欧拉公式将指数形式与正弦、余弦互换；遇到傅里叶题时，先明确变换约定，再利用线性、平移、微分和卷积性质。

    对于矩阵函数（例如 \(e^A\)），优先根据矩阵结构选择方法：对称矩阵使用正交特征分解；一般矩阵使用 Schur 分解、Padé 逼近或缩放平方；直接累加幂级数只适合小矩阵或教学推导。任何数值答案都要说明截断误差、舍入误差和条件数。

    复杂分析与积分题的统一策略是：先确认解析性、边界和收敛性，再决定是否可以交换极限、积分或求和。
