    第 5 章 统计基础¶

    本章主要依据 quant_bible.md Ch3，系统整理 LLN、CLT 与置信区间。

    本节要解决的核心问题¶

    概率与统计的区别：概率 = 已知参数推结果；统计 = 由数据反推未知参数。量化研究中大量「从数据估计 + 给出置信区间」的工作依赖本讲，也是面试中统计/数据题的理论根基。

    5.1 统计建模框架（bible 3.1）¶

    1. 把每个数据事件当作随机变量，假设其服从某分布（Bernoulli、Uniform、Exponential、Poisson…）。
    2. i.i.d. 假设：各事件独立、且服从同一分布（“independent and identically distributed”）。
    3. 建立「待估参数 → 数据统计量」的联系：该统计量即估计量（estimator）。 - 例：数据为 Bernoulli，\(\bar X_n=(X_1+\cdots+X_n)/n\) 收敛到 \(E(X)=p\)，故用 \(\hat p=\bar X_n\) 估计 \(p\)。
    4. 评估置信度：估计到 \(\hat p=0.55\) 后，95% 置信它落在哪个区间？

    5.2 大数定律（LLN）¶

    $$

    \bar X_n\xrightarrow{\mathrm{a.s.}}\mu\quad\text{（强大数定律）}.

    $$

    • 当均值是未知参数的函数时（所有常见分布都如此），LLN 是「理论参数 ↔ 经验数据」的桥梁。
    • 弱大数定律给出依概率收敛，强大数定律给出几乎处处收敛；面试中要先说明采用哪种版本。
    • i.i.d. 不是唯一条件：弱相关、平稳且遍历的时间序列也可能满足 LLN，但不能机械套用独立样本标准误。

    5.3 中心极限定理（CLT）¶

    \[\sqrt{n}\frac{\bar X_n-\mu}{\sigma}\xrightarrow[n\to\infty]{(d)}\mathcal{N}(0,1)\]
    • CLT 说明「样本均值标准化后近似标准正态」，这是构造置信区间的依据。
    • CLT 描述的是分布收敛，并不保证单次样本均值接近正态；小样本、重尾或强依赖时要检查条件。
    • 有限方差是经典 CLT 的关键前提；重尾分布可能需要稳健统计量或稳定分布极限。

    5.4 置信区间（bible 3.2）¶

    定义：置信水平 \(1-\alpha\) 的区间 \(I\) 满足

    \[\mathbb{P}_\theta[I\ni\theta]\ge 1-\alpha,\quad\forall\theta\in\Theta\]

    构造（中心 = LLN 的估计量，宽度 = CLT）：

    \[I_{1-\alpha}=\Big[\hat\theta-\frac{\sigma}{\sqrt n}q_{\alpha/2},\ \hat\theta+\frac{\sigma}{\sqrt n}q_{\alpha/2}\Big]\]

    其中 \(q_{\alpha/2}=\Phi^{-1}(1-\alpha/2)>0\) 是 \(\mathcal N(0,1)\) 的上侧临界值（例如 95% 区间约为 \(1.96\,\operatorname{SE}\)）。

    关键难点：消除对真实参数的依赖¶

    \( \sigma \) 依赖真实参数，需去掉它： - 特殊情形（Bernoulli）：\(\sigma=\sqrt{p(1-p)}\)，且 \(p(1-p)\le1/4\)，得保守区间

    \[I=\Big[\hat p-\frac{1}{2\sqrt n}q_{\alpha/2},\ \hat p+\frac{1}{2\sqrt n}q_{\alpha/2}\Big]\]
    • 一般情况（Slutsky 定理）：把方差中的真实参数替换为估计量，再代入区间。

    假设检验与 p 值¶

    • 原假设 \(H_0\)、备择假设 \(H_1\)、显著性水平 \(\alpha\) 必须在看数据前确定；拒绝 \(H_0\) 不等于证明 \(H_1\) 为真。
    • p 值是在 \(H_0\) 成立时观察到当前或更极端统计量的概率；它不是 \(H_0\) 为真的概率。
    • I 类错误：错误拒绝 \(H_0\)，概率控制为 \(\alpha\)；II 类错误：未拒绝错误的 \(H_0\)，概率为 \(\beta\)；检验功效为 \(1-\beta\)。
    • 多重检验会放大假阳性；可用 Bonferroni 控制 FWER，或 Benjamini--Hochberg 控制 FDR。

    抽样、偏差与自助法¶

    • 估计量要区分偏差 \(E[\hat\theta]-\theta\)、方差和均方误差 \(\operatorname{MSE}=\operatorname{Bias}^2+\operatorname{Var}\)；无偏不代表 MSE 最小。
    • 训练/验证/测试必须按时间或交易日切分，避免未来信息泄漏；时间序列不能随机打乱后声称独立同分布。
    • Bootstrap 通过对样本有放回重采样近似估计量分布；强时间依赖时应使用 block bootstrap。

    常见题型与套路¶

    题型 套路
    判断统计/概率 有无已知参数模型
    构造估计量 让参数 = 统计量期望（LLN）
    给置信区间 估计量居中 + CLT 定宽度
    Bernoulli 区间 用 \(p(1-p)\le1/4\) 去掉参数依赖
    检验功效 给定效应、噪声、样本量与 \(\alpha\)，反推 \(\beta\) 或所需样本量
    时间序列推断 先判断依赖/平稳性，再选 HAC、block bootstrap 或模型化标准误

    5.5 t 检验与标准误（关联计量，bible Ch4.6）¶

    用于「样本均值 vs 已知均值」「两个样本均值是否相等」的检验，是统计基本功的延伸（详见第 8 章 8.6）： - 抽样方差 \(\operatorname{Var}(\bar Y)=\sigma_Y^2/n\)，估计 \(\operatorname{SE}(\bar Y)=S(Y_i)/\sqrt n\)。 - t 统计量 \(t(\mu)=(\bar Y-\mu)/\operatorname{SE}(\bar Y)\)；正态样本且用样本标准差估计方差时服 t 分布，大样本下近似标准正态。显著性应与指定自由度和显著性水平下的临界值比较；\(|t|\approx2\) 只是双侧 5% 检验的经验近似。 - 两独立样本（Welch）：\(\operatorname{SE}(\bar Y^1-\bar Y^0)=\sqrt{s_1^2/n_1+s_0^2/n_0}\)；只有在等方差假设下才使用合并方差版本。

    易错点 / 面试提示¶

    • 置信区间的解读：\(95\%\) 置信表示按同一程序重复抽样时，约 95% 的区间会覆盖真值；对已经算出的固定区间，不能说“真值有 95% 概率落在其中”。
    • 对统计建模：先写「假设 i.i.d.、分布类型」，再写估计量与置信区间。
    • 量化数据题常与第 8 章（数据科学）联动；t/SE/两样本检验的完整推导见第 8 章 8.6。
    • “不拒绝”不是“接受”；显著性也不等同于经济意义，应同时报告效应大小和区间。
    • 先区分标准差 \(\sigma\)、标准误 \(\sigma/\sqrt n\) 与置信区间半宽，三者经常被混淆。
