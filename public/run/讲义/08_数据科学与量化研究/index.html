    第 8 章 数据科学与量化研究¶

    本章主要依据 quant_bible.md Ch4（ESL 概览）与 Ch5（案例研究）。

    本节要解决的核心问题¶

    量化研究/数据科学面试比重越来越高。核心主题：回归建模、偏差-方差取舍、正则化与降维、计量视角、真实案例。素材对应《Elements of Statistical Learning》(ESL) 的核心章节。

    8.1 线性模型与最小二乘（bible 4.1）¶

    线性模型：\(\hat Y=\hat\beta_0+\sum_iX_i\hat\beta_i\)，表示特征与输出的超平面。

    最小二乘（OLS）：最小化残差平方和

    \[RSS(\beta)=\sum_{i=1}^N(y_i-x_i^T\beta)^2\]
    • RSS 是常用误差度量。若条件均值确为线性且满足外生性等条件，OLS 对线性系数无偏；在 Gauss--Markov 条件下，它是线性无偏估计量中方差最小者。

    近邻（Nearest Neighbors）：

    \[\hat Y(x)=\frac1k\sum_{x_i\in N_k(x)}y_i\]
    • 直接对训练数据取平均，不拟合模型，只需记忆训练集。
    • 1-NN 的决策边界形成 Voronoi 镶嵌；k 越大区域越不支离。
    • 对训练点上的 k-NN 平滑器，有效自由度常近似为 \(n/k\)，可解释为何 \(k\) 大时区域更平滑。k-NN 与局部核平滑思想相近：前者对最近的 \(k\) 个点等权，后者通常让权重随距离平滑递减。

    两种模型对比¶

    线性模型（最小二乘） 近邻（k-NN）
    低方差、高偏差 高方差、低偏差
    依赖「线性正确」的假设 基本不依赖数据假设
    适用「情形1」：单高斯、分量不相关 适用「情形2」：高斯混合、可重叠
    高维高效准确 低维多数据占优，受维数灾难影响

    8.2 直觉：偏差-方差与维数灾难（bible 4.2）¶

    偏差-方差权衡¶

    • 偏差 \( \approx \) 模型中的假设/约束程度（我们可控）；方差 \( \approx \) 模型对数据变化的敏感度（观察到的结果）。
    • 模型复杂度（有效自由度 df）与偏差负相关、与方差正相关。df 越高 → 偏差越小、方差越大。
    • 1-NN 的训练误差通常很低、局部偏差较小，但方差很大（单点扰动即可改变预测区域）。
    • 线性回归假设更强 → 偏差更大、方差更小。
    • 平方损失下的期望预测误差可分为不可约噪声、偏差平方与方差；当降低方差的收益超过新增偏差时，加约束可降低总误差。

    维数灾难（Curse of Dimensionality）¶

    • 高维下任意两点距离增大、点更易落在边界，近邻难以找到邻近训练点 → 预测变差。
    • 低维且数据充足时近邻占优；维度稍高近邻就迅速失灵，线性回归（靠线性假设）相对抗维数灾难。

    8.3 回归技术细节（bible 4.3）¶

    核心闭式解（必须背）：

    \[\hat\beta=(X^TX)^{-1}X^Ty\]
    • Hat 矩阵：\(H=X(X^\top X)^{-1}X^\top\)，\(\hat y=Hy\)，即 \(y\) 在 \(X\) 列空间上的正交投影。
    • 推导：\(\partial\operatorname{RSS}/\partial\beta=-2X^\top(y-X\beta)=0\)。
    • 非满秩（如 \(x_2=3x_1\)）：\(X^\top X\) 奇异，\(\beta\) 不唯一，但 \(\hat y\) 仍是投影。

    样本方差：

    \[\hat\sigma^2=\frac{1}{N-p-1}\sum_{i=1}^N(y_i-\hat y_i)^2\]

    单系数检验（t 检验 / Z-score）¶

    \[z_j=\frac{\hat\beta_j}{\hat\sigma\sqrt{v_j}},\quad v_j=(X^TX)^{-1}_{jj}\]
    • 在经典正态误差假设下，\(z_j\) 服从自由度 \(N-p-1\) 的 t 分布；大样本时近似标准正态，\(|z|>2\) 只是经验阈值。单个系数区间写作 \(\hat\beta_j\pm t_{1-\alpha/2,\,df}\hat\sigma\sqrt{v_j}\)。

    成组系数检验（F 统计量）¶

    \[F=\frac{(RSS_0-RSS_1)/(p_1-p_0)}{RSS_1/(N-p_1-1)}\]
    • t 检验只能测单个系数；F 检验能测一组系数的联合显著性，可检测「单个不显著但成组显著」。

    多元回归 = 逐次正交化¶

    • 把 \(x_j\) 对之前已选变量回归取残差 \(z_j\)，再对 \(y\) 回归，\(\hat\beta_p=\langle z_p,y\rangle/\langle z_p,z_p\rangle\)。
    • 意义：每个 \( \beta_j \) 代表 \( x_j \) 剔除其它变量影响后的额外贡献。

    回归解剖 / 标准误（关联计量，见 8.6）¶

    • 双变量时 \(\beta=\operatorname{Cov}(Y,X)/\operatorname{Var}(X)\)，\(\alpha=E[Y]-\beta E[X]\)。
    • 标准误 \(\operatorname{SE}(\hat\beta)=\sigma_\varepsilon/(\sqrt n\,\sigma_X)\)：残差方差越小越好，输入方差越大越好。
    • 该式假设同方差；异方差时要用稳健标准误。

    验证、泄漏与时间序列¶

    • 先划分训练/验证/测试，再做标准化、缺失值填补和特征选择；所有预处理参数只能在训练集拟合，避免数据泄漏。
    • 随机交叉验证适用于近似 i.i.d. 数据；金融时间序列应使用 walk-forward / expanding-window 验证，训练窗口必须早于验证窗口。
    • 评估指标要匹配目标：回归可用 MSE/MAE/Huber，分类可用 log-loss/AUC；交易策略还要报告换手、交易成本、最大回撤和风险调整收益。
    • 只在测试集上做一次最终评估；反复看测试结果会把测试集变成训练信号。

    8.4 正则化与降维（bible 4.4）¶

    动机：① 降低测试误差（引入约束减方差的收益 > 增偏差的代价）；② 提高可解释性。

    子集选择（Subset selection / 逐步回归）¶

    基于「逐次正交化」构建，常见三种： - 前向（Forward stepwise）：空模型起，每步加入「最优拟合」的那个参数，再正交化。共 k 步。 - 后向（Backward stepwise）：全模型起，每步删除「贡献最小」的参数，再正交化。共 k 步。 - 前向分段（Forward stagewise）：零模型起，每步找与当前残差相关最大的参数，逐步累加系数。相比前两种需更多步，但在极高维度下更精确有效。 - leaps-and-bounds：维度 \( \le 30 \) 时的子集选择高效算法。

    岭回归（Ridge）¶

    \[\hat\beta^{ridge}=\arg\min_\beta\Big\{\sum_i(y_i-\beta_0-\sum_jx_{ij}\beta_j)^2+\lambda\sum_j\beta_j^2\Big\}\]
    \[\hat\beta^{ridge}=(X^TX+\lambda I)^{-1}X^Ty\]
    • 在特征已中心化、截距不参与惩罚的写法下，\(\lambda>0\) 时特征系数部分有唯一解；岭惩罚也能缓解共线性导致的病态性。
    • 对有效自由度 df 的影响：\(df(\lambda)\) 是 \(\lambda\) 的单调递减函数，\(df(0)=p\)，\(df(\infty)\to0\)。\(\lambda\) 越大 → df 越小 → 偏差越大。
    • 岭回归本质上是对主成分按比例收缩（收缩尾部主成分）。

    套索回归（Lasso）¶

    \[\hat\beta^{lasso}=\arg\min_\beta\Big\{\sum_i(y_i-\beta_0-\sum_jx_{ij}\beta_j)^2+\lambda\sum_j|\beta_j|\Big\}\]
    • 用 L1 惩罚替代 L2；一般没有闭式解，可用坐标下降、近端梯度或等价的凸优化形式求解。
    • 产生稀疏性：当 L1 约束收紧时，部分系数恰好归零（整变量被剔除），ridge 不会。
    • 可解释性差异：lasso 用于变量选择/稀疏模型；ridge 用于压缩但不置零。
    • 使用 ridge/lasso 前通常先中心化并标准化特征，否则惩罚会偏向量纲较大的变量；截距一般不惩罚。

    三种方法对照¶

    子集选择（stepwise） Ridge Lasso
    硬阈值：完全丢弃超出子集大小的特征 比例收缩：重要特征收缩更少 软阈值：每系数按同一因子收缩并在 0 截断

    在正交、标准化设计这一便于理解的特殊情形下，best-subset 表现为硬阈值，ridge 为比例收缩，lasso 为软阈值；一般相关设计下不能逐坐标直接套用这些标量公式。

    广义：\( L_q \) 正则化与 elastic-net¶

    • lasso/ridge 分别是 L1/L2（\(q=1\) 或 \(q=2\)）。\(q\to0\) 可视作变量子集选择的极限；\(q\in(1,2)\) 是连续的折中惩罚。
    • Elastic-net：lasso 与 ridge 的加权平均，正则项 \(\lambda\sum_j(\alpha\beta_j^2+(1-\alpha)|\beta_j|)\)，兼顾稀疏与压缩。

    逐角回归（LAR, Least Angle Regression）¶

    • 类似前向，但系数连续增加，始终跟踪「与残差相关最高的多个参数」并同步增加。
    • 贪婪、易算，且结果与 lasso 几乎一致（直到某系数跨 0）。在系数跨 0 时丢弃并重算，可得到完整 lasso 路径。
    • 第 k 次迭代后拟合有 k 个自由度。

    主成分回归（PCR）与 PCA（bible 4.4）¶

    • SVD：对中心化数据矩阵 \(X=UDV^\top\)，有 \(X^\top X=VD^2V^\top\)。\(V\) 的列是特征方向，\(z_i=Xv_i\) 是第 \(i\) 个主成分得分，\(d_i\) 是相应奇异值；若样本协方差按 \(X^\top X/(n-1)\) 定义，则该主成分的样本方差为 \(d_i^2/(n-1)\)。
    • PCR：直接在主成分上回归（它们正交 → 简化为一个个单变量回归），只用前 M 个主成分，丢弃尾部。
    • 与 ridge 区别：PCR 直接截断尾部主成分；ridge 按比例收缩所有主成分。
    • PCA 是更通用的降维：可在建模前对输入做无监督降维，不限于回归。

    8.5 回归脑经急转弯（bible 4.5）¶

    • 线性回归的主要假设：① 目标与输入有线性条件均值（误差条件均值为 0）；② 少多重共线性（输入间不过度相关）；③ 同方差（误差方差恒定）；④ 无自相关（误差间不相关）。误差正态分布并非 OLS 无偏的必需条件，但小样本精确 t/F 推断通常需要它。
    • \( \beta_1 = 1/\beta_2 \) 吗？ 否。两个回归分别最小化垂直与水平残差，\( \beta \) 不会恰好互为倒数。
    • 输入线性相关、设计矩阵不满列秩时？ OLS 系数解不唯一，但拟合值仍由对列空间的投影唯一确定。
    • 三特征高度相关、其中一个高标准误？ 多重共线性信号。最简：删掉该变量；也可做特征变换（多项式、中心化、线性组合）、或改用 ridge/lasso/PCA。
    • 数据翻倍（每点重复一次）？ \(\beta\) 不变（闭式解 \((X^\top X)^{-1}X^\top y\) 中矩阵与向量同步加倍）。
    • lasso vs ridge 谁偏差更低/方差更高？ 没有脱离数据生成机制和调参强度的统一排序。相关特征成组、信号稠密时 ridge 往往更稳定；真实信号稀疏时 lasso 的变量选择可能更合适。比较时必须说明惩罚强度如何选择。

    8.6 计量视角（bible 4.6）¶

    计量目标：从数据推断因果，而非仅预测。核心概念：选择性偏差、随机试验、回归控制、遗漏变量偏差。

    选择偏差与随机试验¶

    • 直观例子：健康保险 → 健康状况。若直接比较「参保 vs 未参保」人群的平均健康，会混入教育/收入/年龄等混杂因素，即选择偏差。
    • 以二元处理 \(D\) 为例，观测均值差可分解为处理组平均处理效应与选择偏差：

    $$

    =E[Y_1-Y_0\mid D=1]+{E[Y_0\mid D=1]-E[Y_0\mid D=0]}.

    $$

    • 随机分配处理/控制组极大缓解选择偏差（LLN 使两组的其它特征平均趋向相等）。随机化后应检查平衡（各特征样本均值是否大致相等）。

    统计基础（t 检验 / 标准误）¶

    • 样本均值无偏 \(E[\bar Y]=E[Y_i]\)；抽样方差 \(\operatorname{Var}(\bar Y)=\sigma_Y^2/n\)，估计 \(\operatorname{SE}(\bar Y)=S(Y_i)/\sqrt n\)。
    • t 统计量 \(t(\mu)=(\bar Y-\mu)/\operatorname{SE}(\bar Y)\)，CLT 下渐近标准正态；\(|t|>2\) 常视为显著，也可构造置信区间。
    • 两独立样本均值检验：Welch 标准误为 \(\sqrt{s_1^2/n_1+s_0^2/n_0}\)；等方差假设下可改用合并方差。t 值的绝对值取决于效应相对标准误的大小；绝对值小可能是效应小，也可能是样本不足、估计不精确。

    回归推断因果与 CIA¶

    • 无随机分配时用回归控制变量，依赖条件独立假设（CIA / selection on observables）：控制相同可观察变量后，平均因果效应无选择偏差。
    • 处理/控制变量编码：连续用原始值，分类用 one-hot（哑变量）。
    • 模型：\(Y_i=\alpha+\beta X_i+\gamma A+\varepsilon\)，OLS 最小化 RSS。

    遗漏变量偏差（OVB）¶

    • 回归只能消除「已编码控制变量」上的选择偏差；控制变量不充分 → OVB 残留。
    • OVB 公式（短回归 vs 长回归）：
    \[OVB=\beta^s-\beta^l=\pi_1\times\gamma\]

    其中 \(\pi_1\) = 遗漏控制对处理变量的回归系数，\(\gamma\) = 遗漏控制在长回归中的系数。 - 即使无遗漏数据，也可定性推断 OVB 的符号方向。 - 稳健性：若加入新控制变量后处理效应几乎不变（OVB 小），则模型可信。

    CEF 分解与 ANOVA¶

    • CEF 分解：\(Y_i=E[Y_i\mid X_i]+\varepsilon_i\)，其中 \(\varepsilon\) 均值独立于 \(X\)（\(E[\varepsilon_i\mid X_i]=0\)）。CEF 是均方误差最小预测器。
    • ANOVA 定理：
    \[Var(Y_i)=Var(E[Y_i|X_i])+E[Var(Y_i|X_i)]\]
    • 若 \(X\) 表示列向量，总体线性投影系数为 \(\beta=E[XX^\top]^{-1}E[XY]\)；样本 OLS 为 \(\hat\beta=(\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y\)。在常规正则条件下，\(\hat\beta\) 渐近正态。
    • 分组数据：只有保留正确组权重和足够统计量时，聚合回归才可能复原微观 OLS；随意对组均值等权回归通常会改变结果。

    抽样权重 / 饱和回归（进阶）¶

    • 加权最小二乘：非随机抽样、抽样权重 w=抽样概率的倒数时使用；宏经济惯例常做不加权聚合分析。
    • 饱和回归：所有输入为离散时，可为每个联合取值单元设置哑变量（等价于包含所需的全阶交互项），从而完整表示样本中的条件均值；参数量会快速膨胀，稀疏单元的估计噪声也很大。

    计量 vs ML 的视角¶

    • 计量重因果与推断（CIA、OVB、稳健性）；ML 重预测精度（偏差-方差、正则化）。两者互补。

    8.7 量化研究案例（bible Ch5）¶

    真实数据科学题目，训练完整流程。

    通用案例套路¶

    1. 明确目标变量 & 特征（业务问题 → 建模问题）
    2. 数据预处理与编码（连续保留 / 分类 one-hot / 对数变换）
    3. 归一化（量纲；右偏如房价平方英尺、收入用 log 后再归一化）
    4. 相关性 & 共线性诊断（连续-离散用 Spearman；分类-连续用 point-biserial / logistic）
    5. 选模型（线性 vs 近邻/树）与验证
    6. 处理共线性（子集选择 / ridge / lasso / elastic-net / PCA）
    7. 解释与权衡（t/F 检验、偏差-方差、可解释性）

    8.7.1 Two Sigma · 纽约房价¶

    • 预处理：sqft/year_built 连续保留；beds/baths 离散；borough 分类 → one-hot。
    • 归一化：先检查 sqft 的分布；若明显右偏且取值为正，可尝试 log 变换，再在训练集上标准化。右偏本身并不能证明变量服从对数正态。
    • 相关性：sqft 连续、beds 为有序计数时，可同时查看 Pearson 与 Spearman；后者对单调非线性和异常值更稳健，但不是由变量类型自动决定的唯一选择。
    • 共线性：sqft 与 beds/baths 高相关 → 用 ridge/lasso/逐步/正交化；t 检验定哪些显著。

    8.7.2 QuantCo · 剧院¶

    • 近邻：席位有 2D/3D 空间关系（距舞台距离、视角），相邻席位应定价相近；可用核加权、边界席位加大窗口。
    • 回归：row/column/section 作输入；把 row 换成「到舞台的欧氏距离」更贴合；利用左右对称配对。
    • 共线性：row/column/section 高度相关 → lasso/子集选择删除，或 ridge/正交化保留。
    • 进阶（时间与行为因素）：随时间临近的需求近似指数增长、供给指数下降 → 价格也指数对应 → 加入 \(\log(\text{演出日期}-\text{售票日期})\) 作为输入。
    • 稀缺（scarcity）：剩余席位越少，FOMO/损失厌恶提高支付意愿 → 加入「已售出数量」变量。可解释后排座位反常高价。
    • 消费经济学：可把收入的对数正态形状作为支付意愿分布的候选假设，但必须用购票数据检验，不能直接推出两者分布相同；最终应建模支付意愿并据此最大化利润。

    8.7.3 Two Sigma · CitiBikes【进阶】¶

    • 开放性：无预设输入，需先头脑风暴再迭代「引入变量 ↔ 预处理/调参/评估」。
    • 第一批变量：时间、地点/街区、季节、温度、天气。
    • 循环变量（时间/季节）：naive 用数值会引入不连续。可 one-hot（或分桶为 morning/afternoon/evening/night、四季）以降低维度并恢复顺序；或用三角函数 / 循环样条直接捕捉周期。
    • 地点/街区：不规则 → 假设街区内部/邻近均匀 → one-hot；或用经纬度连续坐标 + 多项式/样条基变换近似非线性。
    • 温度/天气：温度归一化，天气 one-hot；温度-天气高相关可用 point-biserial / logistic、或合并。
    • 温度-季节共线性：用「与前一日同时刻的温度差」归一化，去除周期共线性。
    • 第二批变量：星期几、节假日、交通、地铁、雨量、空气质量、房价、商业活跃度（处理方式类似）。
    • 最终调参：十个变量 → 逐变量算 z-score，对不显著且相关的成组变量算 F 统计量；降维用 lasso/ridge/elastic-net（高维互相关时 elastic-net 常最有效）；大视角用 前向/后向逐步。

    易错点 / 面试提示¶

    • 闭式解 \((X^\top X)^{-1}X^\top y\) 与 hat 矩阵是必背。
    • 分清 t 检验（单系数）与 F 检验（成组）。
    • ridge（比例收缩、不置零）vs lasso（软阈值、稀疏）vs 子集选择（硬阈值）三者区别要能说清。
    • 「有效自由度 = \(n/k\)」是理解 k-NN 复杂度的关键；\(df(\lambda)\) 单调递减可解释 ridge 的偏差增加。
    • 案例题考察完整流程思维，缺一步（如共线性诊断、归一化、循环编码）都显得不完整。
