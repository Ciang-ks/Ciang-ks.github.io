    第 9 章 做市与交易（Market Making）¶

    本章主要依据 quant_bible.md Ch6，介绍做市机制与案例。

    本节要解决的核心问题¶

    做市商（Market Maker）的核心职责是持续给出可执行的双边报价，并在风险限额内承接订单流，从而提供流动性。面试中常以「模拟做市 + 连续交易」的形式考察你的理论估值、报价宽度、仓位与信息不对称处理。

    9.1 做市是什么（bible 6.1）¶

    • 交易所需要流动性，做市商持续提供报价；具体报价义务、激励和可获得的信息取决于交易场所规则。
    • 报出 bid-ask spread（x@y，\(x\)=买价/出价，\(y\)=卖价/叫价），常限制 \(ask-bid<k\)。
    • 承担风险：买到的标的可能跌价。价差理论上用于补偿承担风险的代价；也可用期权等工具对冲。
    • 原则：通过对冲后的「受控下注」来管理风险。

    9.2 报价三大决定因素（bible 6.2）¶

    1. 理论价值（Theoretical Value）：你认为它值多少。确定性强（如骰子 \( =3.5 \)）可报窄；不确定性大（如帝国大厦能装多少乒乓球）要报宽。
    2. 上一成交价（Last Price Traded）：市场价格。若偏离你的理论值，要在「信任市场」与「信任模型」间权衡。
    3. 当前持仓（Current Position）：净多/净空。理想是 flat（无暴露）。仓位大了要不对称报价降低暴露。 - 例：极度做多一只值 0.50 的资产，可报价 0.43@0.53（更愿卖、价差偏向）。flat 时应对称报价。

    9.3 置信区间（bible 6.2 + 关联第 5 章）¶

    • 置信区间是由估计量构造的随机区间：重复抽样时约 95% 的区间覆盖参数真值；单次观测后不要说“真值有 95% 概率在区间内”。若讨论的是随机结果而非未知参数，例如 \(X\sim N(100,10^2)\)，\([80,120]\) 是约 95% 的中央覆盖区间，不是参数置信区间。
    • 不确定性越大 → 区间越宽，报价也越宽。
    • 但报价要现实：0@1e9 虽涵盖真值，却永远不会成交。

    9.4 信息不对称与报价策略¶

    • 若你确信对方估值与你不同（如认为 windows 至少 600），可上移报价 550@600；虽高于你的理论值，但对方更可能买入 → 获更多补偿。
    • 关键洞察：即使你 100% 知道真值，也应报你预计对方仍会成交的最宽报价。

    库存与 adverse selection¶

    • 报价中心价不一定等于理论价值。净多时把中心价下移、卖价更积极；净空时把中心价上移、买价更积极，目标是降低库存风险。
    • 逆向选择：知情交易者更可能在你报价错误时成交；连续亏损可能来自信息优势而非 spread 太窄。遇到异常订单流应扩大 spread、降低报价数量或暂时撤价。
    • 一个简化的库存惩罚目标是 \(U\approx\mathbb E[\mathrm{PNL}]-\gamma I^2\sigma^2\Delta t\)；\(\gamma\) 越大或波动率越高，报价越宽、库存越快归零。
    • 必须把手续费、tick size、最小成交量和订单延迟纳入报价；理论上的无风险套利可能在成本后变成亏损。

    9.5 做市案例（bible 6.3）¶

    做市游戏是多回合的，核心是根据每次成交动态调整报价。

    通用交易流程（案例 1/2/3 共同套路）¶

    1. 给出理论值：说明假设（数据、常识、迭代修正）。
    2. 报出市场（含宽度要求/规则，如 ask 最多 \( 1.5\times \) bid）。
    3. 对方交易后调整：对上移/下移报价做决策。
    4. 追踪持仓与 PNL：配对多空头寸，算盈亏、剩余敞口。
    5. 回答终局问题：当前仓位？若真值为 X 赚/赔多少？盈亏平衡点？

    案例要点¶

    • Case 1 体育博彩（Red Sox 胜场）：用 \(\operatorname{Bin}(162,p)\) 近似正态，\(\sigma=\sqrt{162\cdot0.5\cdot0.5}\approx6.36\)，50%/90% CI 用 \(z\approx0.67/1.64\)。随成交上移报价（对方买入→你短仓→想买回→报价上行），并利用交易边界缩小真实值区间，制造无风险 PNL（低买高卖配对）。
    • Case 2 国家人口（Tanzania）：首报用粗略常识（25M→20@30）。首个买成交 → 大幅上移（信息少、上移风险小于下移）；后续用前后成交限制出的区间中点逐步收窄，每次移动递减小。最终可能亏损（正常，考的是应变而非猜对答案）。
    • Case 3 Trade or Tighten：博弈场景 = 你的理论值 vs 对方未知理论值，在「收紧报价」与「成交」之间抉择，偏向对你不利的对手博弈。

    做市成功的关键习惯（"trader memory"）¶

    • 记住每次成交的价格、你的持仓、以及累计 PNL。
    • 成交告诉你对手的估值倾向 → 用它逐步逼近真值。

    易错点 / 面试提示¶

    • 别想猜对——做市题考的是「如何从交易中学习并报价」，允许犯错。
    • 报价要动态：对方买入 → 上移；对方卖出 → 下移；对称市场要对称报价。
    • 明确谈出你的假设与置信区间，这是被考察的要点。
    • 分清 PNL 计算（配对买卖）与 当前敞口（剩余裸头寸）。
    • 不要把“成交概率高”误当成“策略有利”；同时检查成交方向、条件期望 PNL 和库存尾部风险。
