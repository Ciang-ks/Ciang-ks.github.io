    一、位运算与二进制编码¶

    位运算（异或交换、判断 2 的幂、乘 7）与二进制编码（毒酒、毒鼠问题）用比特级的对应关系解决问题。核心是把对象编码为比特串，再用编码容量给出下界。

    Q1154 · 判断 2 的幂¶

    难度：★｜题型：位运算与编码｜副题型：二进制最低位消除

    题目：如何判断一个整数是 2 的幂？

    解答

    \( x = 2^n \)（\( n \ge 0 \)）的二进制只有右起第 \( n+1 \) 位为 1（如 \( 8 = 2^3 \) 为 \(0\ldots 01000\)）；而 \( 2^n - 1 \) 的右起 \( n \) 位全为 1（如 7 为 \(0\ldots 00111\)）。所以 \( 2^n \) 与 \( 2^n-1 \) 没有任何公共的 1 位：

    bool isPowerOfTwo(int x) { return x > 0 && (x & (x-1)) == 0; }

    Q1155 · 常数乘法的移位加减分解¶

    难度：★｜题型：位运算与编码｜副题型：二进制分解与有符号数字表示

    题目：不用乘法运算符计算整数 \(7x\)。再说明如何为一般已知整数常数 \(c\) 构造移位加减式，并明确C++中的有效数值范围。

    解答

    因为 \(7=2^3-1\)，有 \(7x=(x\ll3)-x\)。一般把 \(c\) 展开为 \(\sum_jb_j2^j\)，得到 \(cx=\sum_{j:b_j=1}(x\ll j)\)。若 \(c\) 的二进制有长串1，可改用差，例如 \(31=32-1\)，减少加法次数；对负常数再变号。

    这些等式首先是整数代数恒等式。实际代码须避免移位和中间运算溢出，移位计数也必须小于类型位宽。跨语言标准的稳妥实现可对无符号类型操作，接受按模 \(2^w\) 结果；若要有符号精确结果，应先检查范围并使用足够宽的类型。编译器通常也会为常数乘法自动选择合适指令，手写移位未必更快。

    Q1156 · 无暂存变量交换¶

    难度：★★｜题型：位运算与编码｜副题型：可逆运算与别名分析

    题目：如何在不使用额外存储空间的情况下交换两个整数 \(i\) 和 \(j\)？

    解答

    比较与交换是许多算法的基本操作；常规做法用临时变量，本题禁止。数学方法：先存和、再逐一提取：

    void swap(int &i, int &j) {
    i = i + j;  // 存 i 与 j 之和
    j = i - j;  // j 变为原 i
    i = i - j;  // i 变为原 j
}

    实际 C++ 中优先使用 std::swap：加减法可能发生有符号整数溢出，异或写法在两个引用指向同一对象时会把值清零。

    替代方案（异或）：利用 \(x\oplus x = 0\)、\(0\oplus x = x\)：

    void swap(int &i, int &j) {
    i = i ^ j;
    j = j ^ i;  // j = j ^ (i^j) = i
    i = i ^ j;  // i = (i^j) ^ i = j
}

    Q1157 · 任意概率 \(p\) 的游戏¶

    难度：★★｜题型：概率构造｜副题型：二进制展开与首次差异

    题目：给你一枚公平硬币，能否设计一个简单游戏使你获胜的概率是任意给定的 \( p \)（\( 0 < p < 1 \)）？

    解答

    关键：\(p\) 可以写成二进制小数，每一位都可由公平硬币模拟。把 \(p\) 表示为

    \[ p = 0.p_1p_2\cdots = p_12^{-1} + p_22^{-2} + \cdots,\qquad p_i\in\{0,1\} \]

    掷公平硬币，正面记 1、反面记 0；设第 \( i \) 次结果为 \( s_i \)。逐位比较 \( p_i \) 与 \( s_i \)：

    • \( s_i < p_i \)：获胜，停止；
    • \( s_i > p_i \)：失败，停止；
    • \( s_i = p_i \)：继续掷下一位。

    某些 \( p \)（如 \( 1/3 = 0.010101\ldots \)）的二进制展开是无穷级数——随着 \( i \) 增大，出现 \( s_i \neq p_i \) 的概率趋于 1。若序列有限（如 \( 1/4 = 0.01 \)）且走到最后仍相等（\( s = p \)），判负（对 \( 1/4 \)，只有 00 判胜，01、10、11 都判负）。此模拟的获胜概率恰为 \( p \)。

    令 \(U=\sum_{i\ge1}s_i2^{-i}\)，独立公平比特使 \(U\sim U(0,1)\)。首次不同的二进制位决定 \(U<p\)，故中奖概率为 \(p\)；无限完全相同的概率为0。若 \(T\) 为首次不同的位置，\(P(T>k)=2^{-k}\)，所以 \(ET=\sum_{k\ge0}2^{-k}=2\)。有限展开时可更早结束；一般无限展开算法还要求能够取得 \(p\) 的所需二进制位。

    Q1158 · 毒酒问题¶

    难度：★★｜题型：位运算与编码｜副题型：多进制编码与信息容量｜公司：Two Sigma

    题目：生日派对备有 1000 瓶酒。派对前 20 小时酒厂紧急通知：其中一瓶被下毒。你有 10 只小白鼠可用于测试。毒药极强：任何剂量都会在恰好 18 小时后杀死小鼠，18 小时之前没有任何症状。能否在派对前用 10 只小鼠确保找出毒酒？

    解答

    若可以顺序测试（每次淘汰一半），10 只小鼠用二分搜索能从多达 \( 2^{10} = 1024 \) 瓶中找出毒酒。不幸的是症状 18 小时后才显现、只剩 20 小时，无法顺序测试。但二进制编码思想仍然适用：

    1 到 1000 的所有整数都可写成 10 位二进制。例如

    \[ 1000 = 2^9 + 2^8 + 2^7 + 2^6 + 2^5 + 2^3 \]

    让小鼠 1 喝所有第 1 位（最低位）为 1 的酒；小鼠 2 喝所有第 2 位为 1 的酒；……；小鼠 10 喝所有第 10 位为 1 的酒。18 小时后，把小鼠按位从高到低排列：活 \(= 0\)、死 \(= 1\)，即得毒酒标号的二进制。例如第 6、7、9 只小鼠死亡、其余存活，则序列为 0101100000，毒酒为 \( 2^8 + 2^6 + 2^5 = 352 \)。

    一次测试即可（信息论下界 \( 2^{10} = 1024 \ge 1000 \)）。

    扩展（多轮观察）：若毒药 1 小时后死亡，\( n \) 只鼠一次可区分 \( 2^n \) 瓶；两小时（两轮观察）用三进制编码可区分 \( 3^n \) 瓶；一般地 \( k \) 小时可区分 \( (k+1)^n \) 瓶。信息论视角：每只鼠有 \( k+1 \) 种可区分结局（存活或第 \( 1\ldots k \) 个观察时点死亡），\( n \) 只鼠共 \( (k+1)^n \) 种结局。

    二、数组、查找与数据结构¶

    数组与数据结构的核心是选择合适结构（哈希、滑动窗口、堆、树）并说明复杂度。查找题（行列递增矩阵、首个非零）、去重、移动平均、滚动最小值与树遍历都在本节。

    Q1159 · 有序数组去重¶

    难度：★｜题型：数组与查找｜副题型：有序扫描与双指针

    题目：给定有序数组，写代码提取其中的唯一元素。例如 [1, 1, 3, 3, 3, 5, 5, 5, 9, 9, 9, 9] 应得 [1, 3, 5, 9]。

    解答

    设 \( a \) 为 \( n \) 元有序数组 \( a_0 \le a_1 \le \ldots \le a_{n-1} \)。有序数组中，某元素是新元素（首次出现）当且仅当它与前一个元素不同（\( a_i \neq a_{i-1} \)）。利用这一性质即可线性扫描提取：

    template <class T> vector<T> unique(T a[], int n) {
    vector<T> vec;
    if (n <= 0) return vec;
    vec.reserve(n);            // 预留空间避免重分配
    vec.push_back(a[0]);
    for (int i = 1; i < n; ++i) {
        if (a[i] != a[i-1])
            vec.push_back(a[i]);
    }
    return vec;
}

    复杂度 \(\Theta (n)\)。（注：C++ STL 已有通用算法 unique / unique_copy。）

    Q1160 · 判断 \(0..N-1\) 中的重复元素¶

    难度：★★｜题型：数组与查找｜副题型：原地置换与归位不变量

    题目：整数向量 \(v\) 有 \(N\) 个元素、每个都在 0 到 \(N-1\) 的闭区间内。写一个判断是否存在重复数的算法（无需保留数组、可只给思路）。

    • 如果元素值域为 \(0\) 到 \(M\)，且 \(M>N\)，应如何处理？

    • 在实际系统中，时间和内存哪一个更重要？答案取决于哪些条件？

    解答

    本题有多种解法，各有优缺点。选择时主要考虑时间、空间之间的权衡，以及 \(N\) 很大时实现是否仍然可靠。

    最简单的方法是先排序，再检查位置 \(i\) 上是否为 \(i\)。但通用排序没有利用元素限定在 \(0\) 到 \(N-1\) 这一特殊结构，时间复杂度为 \(O(N\log N)\)。

    另一种简单方法是分配一个初值全为 false 的布尔向量，遍历输入时把相应下标设为 true；若再次遇到已经为 true 的位置，就发现了重复值。该方法的时间和额外空间复杂度均为 \(O(N)\)。

    下面的方法除少量整数变量外不使用额外内存，且运行很快，但它强烈依赖输入值域恰为 \([0,N-1]\)，并会修改原数组：

    bool hasDuplicate(std::vector<int>& input) {
    const int n = static_cast<int>(input.size());
    for (int value : input)
        if (value < 0 || value >= n)
            throw std::invalid_argument("元素超出 [0,N-1] 范围");

    for (int i = 0; i < n; ++i) {
        while (input[i] != i) {
            const int target = input[i];
            if (input[target] == target) return true;
            std::swap(input[i], input[target]);
        }
    }
    return false;
}

    遍历每个位置 \(i\)。若 input[i] != i，就把该元素与它本应位于的位置交换；若目标位置已经放着正确的同值元素，则存在重复。每次成功交换至少让一个元素归位，因此交换总数不超过 \(N\)，总时间复杂度为 \(O(N)\)。若不存在重复，结束时数组会被整理为升序。

    由于至少需要查看 \(N\) 个输入元素，任何确定性算法的时间下界都是 \(\Omega(N)\)，所以上述线性时间已达到渐近最优。

    扩大值域为 \([0,M]\) 后，原地归位算法的数组下标可能越界，不能原样使用。可选哈希集合（期望线性时间、\(O(N)\)存储）、排序后比较相邻项（\(O(N\log N)\)时间），或 \(M+1\) 位的位图。选择取决于 \(M/N\)、是否可改输入、可用内存、缓存和I/O成本，以及需不需要最坏时间保证；并不存在独立于场景的“时间总比内存重要”。

    Q1161 · 万中缺一¶

    难度：★★｜题型：数组与查找｜副题型：异或消去与整数求和

    题目：给定前 10000 个数中的 9999 个，写一个内存与计算都高效的程序找出缺失的数。

    • 如何证明前 \(N\) 个正整数的求和公式？（可用首尾配对法。）
    • \(N\) 大到什么程度时，这段程序会因整数溢出而失效？
    • 排序、布尔数组、异或等其他方法各有什么优缺点？
    解答

    这道题有多种解法。最直观的方法是先排序，再顺序扫描寻找缺口，但排序耗时 \(O(n\log n)\)。另一种方法是建立一个初值全为 false 的布尔数组，以读到的数字作为下标把对应位置设为 true，最后寻找唯一仍为 false 的位置；其时间复杂度为 \(O(n)\)，空间复杂度也是 \(O(n)\)。

    若输入本应包含 \(1,2,\ldots,N\)，可以先求完整序列的总和，再减去输入数组之和；差值就是缺失数。该方法时间复杂度为 \(O(n)\)、额外空间复杂度为 \(O(1)\)：

    int FindMissingInt(const std::vector<int>& numbers)
{
    int N = numbers.size() + 1;
    int total = N * (N + 1) / 2;

    int x = 0;

    for (unsigned long j = 0; j < numbers.size(); ++j)
        x += numbers[j];

    int r = total - x;

    return r;
}

    完整和公式可由正序、倒序相加得到 \(2\sum_{i=1}^Ni=N(N+1)\)。若按代码先计算32位有符号 \(N(N+1)\)，\(N=46341\) 时中间乘积已溢出，尽管最后除2后的和仍可能可表示；使用64位中间量或先把偶因子除2可延后溢出。32位最终和在 \(N=65536\) 时也超界。

    不依赖和的方案是把 \(1,\ldots,N\) 与输入全部异或：每个已出现值成对抵消，剩下缺失值。时间 \(O(N)\)、额外空间 \(O(1)\)，且不发生加法溢出。这要求输入确实互异且只缺一个；任意脏数据不能仅凭异或检出。

    Q1162 · 未知大小数组找首个非零¶

    难度：★★｜题型：数组与查找｜副题型：指数扩张与二分边界

    题目：给定数组：从开始到某位置全为 0，其后全为非零。若不知道数组大小，如何找到第一个非零元素的位置？

    解答

    指数跳跃 + 二分。从第 1 个元素开始：若为 0 查第 2 个；若第 2 个为 0 查第 4 个……第 \( i \) 步查第 \( 2^i \) 个元素，直到 \( 2^i \) 处元素非零。然后取中点 \( (2^i + 2^{i-1})/2 \) 处：若为 0，搜索范围缩至 \( [(2^i+2^{i-1})/2, 2^i] \)；否则缩至 \( [2^{i-1}, (2^i+2^{i-1})/2] \)……每次把范围减半——本质是二分搜索。若第一个非零元素在位置 \(n\)，复杂度 \(\Theta (\log n)\)。

    边界语义不可省略：有限数组必须提供可识别的“越界”结果，或保证非零元素最终存在且探测安全。一般化为单调谓词 \(P(i)\) 从假变真，先检查 \(i=0\)，再在 \(1,2,4,\ldots\) 探测；首次真点为 \(2^k\) 时，答案在 \((2^{k-1},2^k]\) 内，用保持“左假右真”的二分查找即可。扩张和二分各 \(O(\log(n+1))\) 次探测。

    Q1163 · 行列递增矩阵查找¶

    难度：★★｜题型：数组与查找｜副题型：单调矩阵的行列排除

    题目：一个 \( n\times n \) 数字方阵：每行从左到右递增，每列从上到下递增。设计算法在方阵中查找给定数字 \( x \)，复杂度是多少？

    解答

    设 \( A \) 为 \( n\times n \) 方阵。从右上角开始蛇形搜索：

    1. 从最后一列自上而下搜：\( A_{1,n}, \ldots, A_{n,n} \)。找到则停；若 \( A_{n,n} < x \)，\( x \) 不在方阵中，停止；
    2. 若 \( A_{i,n} < x < A_{i+1,n} \)，则第 \( 1,\ldots,i \) 行的所有数都小于 \( x \)，全部消去；在第 \( i+1 \) 行从右向左搜。若在第 \( i+1 \) 行找到则停；若 \( A_{i+1,j+1} > x > A_{i+1,j} \)，则第 \( j+1,\ldots,n \) 列（第 \( i+1 \) 行以下）全部消去；
    3. 再沿第 \( j \) 列从 \( A_{i+1,j} \) 向下搜……如此交替"沿列向下、沿行向左"。

    每一步都消去一整行或一整列。搜索至多 \(2n\) 步，复杂度 \(O(n)\)。

    同一方法适用于 \(m\times n\) 矩形矩阵。从右上角 \((0,n-1)\) 出发：当前值大于目标则整列在下方都更大，左移一列；小于目标则整行在左侧都更小，下移一行；相等则找到。每次至少排除一行或一列，最多 \(m+n-1\) 次比较，故时间 \(O(m+n)\)、额外空间 \(O(1)\)。非严格单调和重复值也不影响存在性查找。

    Q1164 · 找 \(k\) 个最大元素¶

    难度：★★｜题型：排序与搜索｜副题型：分区选择与有界最小堆｜公司：Citadel

    题目：如何在大小为 \(n\) 的数组中找出 \(k\) 个最大元素？最高效的算法是什么？

    解答

    三种方案与取舍：

    1. 完整排序：用 \(O(n \log n)\) 的归并/快排排好后取前 \(k\) 个。简单可靠。
    2. 大小为 \(k\) 的最小堆：先放入 \(k\) 个元素；随后每遇到比堆顶大的元素，就替换堆顶并下沉。时间 \(O(n \log k)\)，额外空间 \(O(k)\)，结束后堆中即为前 \(k\) 大元素。
    3. Quickselect：围绕枢轴分区，定位第 \( k \) 大元素；平均时间 \( O(n) \)、最坏 \( O(n^2) \)。采用 median-of-medians 可保证最坏 \(O(n)\)，但常数较大。若还要按降序输出这 \(k\) 个值，再加 \(O(k \log k)\) 排序。
    4. 最大堆：\( O(n) \) 建堆后弹出 \( k \) 次，时间 \( O(n+k\log n) \)，适合还需按从大到小依次取得结果的情形。

    结论：只求无序的前 \(k\) 大时，Quickselect 的平均时间最优；流式数据或内存受限时，大小为 \(k\) 的最小堆最实用。

    Q1165 · 和为 \(m\) 的元素对¶

    难度：★★｜题型：数据结构｜副题型：频数哈希与无序对除重｜公司：Citadel

    题目：如何找出大小为 \(n\) 的数组中，元素之和等于某数 \(m\) 的元素对的个数？

    解答

    线性时间两趟哈希：

    1. 第一趟：建字典，枚举每个唯一值及其在数组中出现的次数（\(O(n)\)）；
    2. 第二趟：遍历字典（\(O\)(唯一值数)）。只在 \(k<m-k\) 时累加 \(cnt[k]cnt[m-k]\)；在 \(k=m-k\) 时累加 \(\binom{cnt[k]}2\)。这样不会把同一对重复计算。

    总体 \(O(n)\) 时间、\(O(n)\) 空间。

    也可一趟完成：扫描到 \(x\) 时，先把历史频数 \(\mathrm{cnt}[m-x]\) 加入答案，再执行 \(\mathrm{cnt}[x]++\)。因为只与先前位置配对，每个无序下标对恰在较晚位置被访问时计入一次，自动处理重复值和 \(2x=m\) 的情况。结果可能达到 \(N(N-1)/2\)，计数类型要足够宽；哈希线性时间是期望界。

    Q1166 · 日期加 \(n\) 天¶

    难度：★★｜题型：数组与查找｜副题型：序数日转换与周期分解

    题目：写一个把日期增加 \(n\) 天的算法（须稳健处理闰年与非闰年世纪）。

    如果要求更快，应做哪些改动？

    如果要求高速且允许使用大量内存，可以怎样用预计算或查表来实现？

    解答

    开始作答前，应先确认题目要求高效实现，还是只要求正确可用。下面先给出逻辑清楚、但时间复杂度为 \(O(n)\) 的逐日推进法。

    本题最容易出错的地方是 2 月 29 日。规则是：

    • 只有闰年才有 2 月 29 日；

    • 年份能被 4 整除时通常是闰年；但若能被 100 整除，则还必须能被 400 整除。

    因此 2000 年是闰年，而 2100 年不是。

    在不强调效率时，可以连续执行 \(n\) 次“日期加一天”。若当前日期不是月末，直接把日加一；若到了月末，则把日重置为 1 并推进月份，必要时再推进年份。2 月末需要额外判断闰年。

    bool IsLeapDayNext(int y, int m, int d)
{
    if (m!=2)
        return false;

    if (d!=28)
        return false;

    if (y % 4 > 0)
        return false;

    if (y % 100 > 0)
        return true;

    if (y % 400 == 0)
        return true;

    return false;
}

void AddOneToDate(int &y, int &m, int&d)
{

static int lengths[] = { 31, 28, 31, 30, 31, 30,
                         31, 31, 30, 31, 30, 31 };
if (d < lengths[m-1]) { ++d; return; }
if (IsLeapDayNext(y,m,d))
{
    ++d;
    return;
}
d=1;
if (m == 12) { m = 1; ++y; }
else { ++m; }
}

void AddToDate(int &y, int &m, int& d, int N)
{
    for (int i=0; i < N; ++i)
        AddOneToDate(y,m,d);
}

    加速为序数日运算。 对公历正年份，把日期映射为自基准起的天数：完整年份部分为 \(365(y-1)+\lfloor(y-1)/4\rfloor-\lfloor(y-1)/100\rfloor+\lfloor(y-1)/400\rfloor\)，再加此前月份长度和 \(d-1\)。序数日直接加上偏移，再反解年月日。可先跳过400年周期（每周期146097天），然后在周期内二分年份并查累计月表。若仅改原逐日算法，也可先跳整年、整月。大量重复查询可预存一个400年周期的日期映射，用 \(O(146097)\) 存储实现固定次查表。负偏移需使用数学向下取整并先定义支持的年份范围。

    Q1167 · 直方图程序¶

    难度：★★｜题型：数据结构｜副题型：区间分桶与在线矩更新

    题目：实现一个直方图（histogram）生成程序。

    • 能否提出更合理的分桶边界选择算法？

    • 如果允许不等宽分桶，如何确定一个数属于哪一桶？

    • 修改程序，使其除记录每桶元素数外，还记录桶内元素的均值。

    • 实现二维直方图。

    解答

    下面给出一个简单的 C++ 实现：

    void MakeHistogram(std::vector<double>& bucketLeft,
                   std::vector<int>& bucketContents,
                   const std::vector<double>& values,
                   int numberOfBuckets) {
    if (values.empty() || numberOfBuckets <= 0)
        throw std::invalid_argument("直方图输入无效");

    const auto [minIt, maxIt] =
        std::minmax_element(values.begin(), values.end());
    const double minValue = *minIt;
    const double maxValue = *maxIt;

    bucketLeft.resize(numberOfBuckets);
    bucketContents.assign(numberOfBuckets, 0);
    if (minValue == maxValue) {
        bucketLeft.assign(numberOfBuckets, minValue);
        bucketContents[0] = static_cast<int>(values.size());
        return;
    }

    const double bucketSize =
        (maxValue - minValue) / numberOfBuckets;
    for (int i = 0; i < numberOfBuckets; ++i)
        bucketLeft[i] = minValue + i * bucketSize;

    for (double value : values) {
        int k = static_cast<int>((value - minValue) / bucketSize);
        if (k == numberOfBuckets) --k; // 最大值归入最后一桶
        ++bucketContents[k];
    }
}

    关键在于选择分桶边界，并正确处理最大值端点。代码采用等宽的左闭右开区间，只有最后一桶额外包含全局最大值。

    对任意数值，用它到最小值的距离除以桶宽即可算出桶下标，因此单个元素的归桶耗时为 \(O(1)\)；这一点依赖于所有桶等宽。遍历全部样本的总时间复杂度为 \(O(n)\)。

    追问的统一表示。 对递增边界 \(b_0<\cdots<b_K\)，以 \([b_j,b_{j+1})\) 分桶，最后一个桶包含右端点。非等宽桶用二分定位，单个样本 \(O(\log K)\)。每桶维护计数 \(c\) 和和 \(s\)，均值为 \(s/c\)；也可在线更新 \(\mu\leftarrow\mu+(x-\mu)/(c+1)\)，空桶均值需单独约定。二维直方图分别定位两坐标，累加二维计数矩阵。

    等宽桶宽可参考 \(h=2\operatorname{IQR}(x)n^{-1/3}\) 的Freedman–Diaconis规则，若IQR为0应退到其他规则。分位数边界能使各桶样本数接近；画非等宽密度直方图时高度应除以桶宽，确保柱面积而非高度之和反映概率。

    Q1168 · 移动平均¶

    难度：★★｜题型：数组与查找｜副题型：窗口和的增量更新

    题目：给定长度为 \( m \) 的大数组 \( A \)，设计高效算法构造 \( n \) 元移动平均数组：\( B_i = (A_{i-n+1} + \cdots + A_i)/n \)，\( \forall i = n, \ldots, m \)。

    解答

    计算下一个 \(n\) 元移动平均时复用上一次的窗口和。维护总和 \(S\)：减去滑出窗口的首元素、加上新进窗口的元素，再除以 \(n\)。伪代码：

    S = A[1] + ... + A[n];  B[n] = S/n;
for (i = n+1 to m) {
    S = S - A[i-n] + A[i];
    B[i] = S/n;
}

    复杂度 \(O(m)\)（朴素做法 \(O(mn)\)）。

    一般固定窗口可加统计量 \(S_i=\sum_{j=i-n+1}^iw_j\) 都满足 \(S_i=S_{i-1}-w_{i-n}+w_i\)，因此不仅均值，窗口计数、平方和也能增量维护。窗口方差可由和与平方和组合，但两大数相减可能损失精度，应视数据尺度使用稳定的更新公式。

    Q1169 · 30 分钟滚动最小值¶

    难度：★★★｜题型：数据结构｜副题型：单调队列与摊还分析｜公司：Virtu

    题目：设计一个算法为 SPX 价格数据维护一个滚动 30 分钟最小值：代码会在随机时刻被查询最小值，同时会在随机时刻收到完全随机的价格数据。如何设计高效算法？

    解答

    维护一个按价格单调递增的双端队列，元素为 (timestamp, price)：

    1. 插入新价格前，从队尾删除所有价格不小于新价格的元素；它们更旧且更贵，以后不可能成为窗口最小值。随后把新点压入队尾。
    2. 每次插入或查询时，从队首删除所有时间戳早于“当前时刻 \(- 30\) 分钟”的元素。
    3. 清理后，队首价格就是滚动窗口最小值；若队列为空，则窗口内没有数据。

    每个点最多入队、出队各一次，所以插入和查询的合计摊还时间均为 \(O(1)\)，空间为 \(O(w)\)；单次清理可能删除多个元素。时间戳相同、重复价格以及乱序到达需要预先规定语义；若数据会乱序到达，应改用平衡树或先做事件时间缓冲。

    复杂度与时间语义。 上述结论假定数据按时间戳非递减到达，查询时刻也不倒退，窗口内最小值仅针对已收到的样本。价格可以完全随机，但不能因此推断时间顺序也随机。以闭窗口 \([t-30\text{ 分钟},t]\) 为例，应删除时间戳严格小于左端点的项。

    每个点入队一次，随后从队尾被支配删除或从队首过期删除一次。因此 \(n\) 次插入、\(q\) 次查询合计 \(O(n+q)\)，两种操作合起来是摊还 \(O(1)\)。单次插入可能清空队尾，长时间无查询后的第一次查询也可能清掉整条队列，所以单次操作最坏可达 \(O(w)\)；只有在完成过期清理后读取队首是严格 \(O(1)\)。空间 \(O(w)\) 中 \(w\) 是窗口内样本数；若采样率无上限，它不是固定常数。

    若确实允许迟到事件，一条刚到达的旧低价不能永久删除更新的高价：旧点可能更早过期。因此需先规定迟到容忍时间，用水位线缓冲成有序流；或用按时间索引、子树存价格最小值的平衡树，支持插入与区间最小值查询，各 \(O(\log n)\)。

    Q1170 · 树节点求和¶

    难度：★★★｜题型：数据结构｜副题型：树遍历与RAII深复制

    题目：写一个对树节点上的数求和的程序：节点可以有两个、一个或零个分支。

    • 修改解法，使其能处理空树。

    • 上述解法使用递归，能否改用显式栈实现迭代遍历？

    • 编写完整的树类，正确实现创建、销毁、复制和赋值。

    • 什么是红黑树？

    解答

    最直接的做法是递归，具体实现取决于树的表示方式。下面把树表示为一组节点：每个节点含一个数据项以及指向左右子节点的指针；子节点不存在时，相应指针为空。

    典型的树节点头文件如下：

    #ifndef TREE_NODE_H
#define TREE_NODE_H

class TreeNode
{
    public:
        TreeNode* Left;
        TreeNode* Right;
        double data;

};

double GetSum(const TreeNode& top);

#endif

    完整工程还需要处理节点的创建、销毁、复制与所有权；这里只保留足以回答面试题的最小结构。

    下面的接口以根节点引用为参数，因而没有处理空树。可以改为接收指针，或把根节点封装进负责处理空状态的树类。

    递归遍历整棵树时，节点对应子树的总和等于当前节点值，加上存在的左、右子树之和：

    double GetSum(const TreeNode& top)
{
    double value = top.data;

    if (top.Left !=0)
        value += GetSum(*top.Left);

    if (top.Right !=0)
        value += GetSum(*top.Right);

    return value;
}

    用值语义树配合独占指针，可实现创建、销毁、深复制、赋值及空树处理。下面是完整可编译的 C++17 示例：

    #include <memory>
#include <utility>
#include <vector>
class Tree {
public:
    struct Node {
        double value;
        std::unique_ptr<Node> left, right;
        explicit Node(double v) : value(v) {}
    };
    std::unique_ptr<Node> root;
    Tree() = default;
    Tree(const Tree& other) : root(clone(other.root.get())) {}
    Tree(Tree&&) noexcept = default;
    Tree& operator=(Tree other) noexcept {
        root.swap(other.root);
        return *this;
    }
    static std::unique_ptr<Node> clone(const Node* p) {
        if (!p) return {};
        auto q = std::make_unique<Node>(p->value);
        q->left = clone(p->left.get());
        q->right = clone(p->right.get());
        return q;
    }
    double sum() const {
        double result = 0;
        std::vector<const Node*> pending;
        if (root) pending.push_back(root.get());
        while (!pending.empty()) {
            const Node* p = pending.back();
            pending.pop_back();
            result += p->value;
            if (p->left) pending.push_back(p->left.get());
            if (p->right) pending.push_back(p->right.get());
        }
        return result;
    }
};

    空树返回0，遍历每个节点一次，时间 \(O(n)\)、显式栈空间 \(O(h)\)，退化树可达 \(O(n)\)。unique_ptr 确保节点只有一个所有者，自动递归销毁；深复制逐节点新建，赋值先完成参数副本再交换，复制失败不损坏原树。极深退化树的复制和析构仍有递归栈限制，若需支持任意深度应额外改成迭代版本。

    红黑树是保持近似平衡的二叉搜索树：节点红/黑、根黑、空叶黑、红节点无红子节点、任意节点到后代空叶的黑节点数相同。最短路径全黑，最长路径至多交替红黑，故高至多 \(2\log_2(n+1)\)，查询、插入、删除最坏 \(O(\log n)\)；更新用旋转和重染色维持不变量。它不是“任意二叉树都自动平衡”。

    Q1171 · 二叉树：深度与最大元素¶

    难度：★★★｜题型：数据结构｜副题型：后序遍历与子树聚合

    题目：用 C++ 实现每个节点含一个整数的二叉树数据结构（讨论空树情形）；写出返回树深度的函数（空树深度为 0），以及返回非空树最大元素的函数。

    • 增加可用于常量树的只读迭代器类。

    • 把树改写为可存放任意数据类型的类模板。

    用节点和指针的传统方式重新实现这棵树，并明确所有权管理。

    解答

    二叉树由一组节点构成，每个节点包含一个数据项，并有零、一个或两个子节点。除根节点外，每个节点恰有一个父节点；结构中不能有环，因此每个节点到根的距离都有明确定义，其子节点的深度比它大 1。

    C++ 中有多种表示方法。传统做法是每个节点保存数据以及左右子节点指针，不存在的子节点用空指针表示。这种结构直观，但若用拥有型裸指针，插入、复制、赋值、构造和析构都涉及繁琐的内存管理，而且节点可能分散在内存中。现代实现可用 std::unique_ptr 明确所有权。

    下面的方法把所有节点集中存入向量，用下标表示节点关系，再通过辅助迭代器遍历树。

    int rightDepth = TreeDepth(tmp);

    return 1+std::max(leftDepth, rightDepth);
}

    需要注意的是，遍历时会复制迭代器。迭代器只含一个引用和一个整数下标，复制成本很低，与节点数据类型的复杂程度无关。之所以必须复制，是因为 Left() 与 Right() 会修改迭代器位置，而递归访问另一子树时仍需保留原位置。深度函数对空树返回 0；最大值函数只对非空树有定义，接口应明确以异常、可选值或前置条件处理空树。

    泛型所有权表示与只读遍历。 以下是另一种完整表示：Tree<T> 支持空树、深拷贝和移动；父节点通过 unique_ptr 独占左右子树，迭代器只借用节点，不拥有它们。只读迭代器按“根、左、右”先序遍历，从常量树也能取得，解引用仅返回 const T&。

    #include <algorithm>
#include <cstddef>
#include <iterator>
#include <memory>
#include <stdexcept>
#include <utility>
#include <vector>

template<class T>
class Tree {
    struct Node {
        T value;
        std::unique_ptr<Node> left, right;
        Node(T v, std::unique_ptr<Node> l = {},
             std::unique_ptr<Node> r = {})
            : value(std::move(v)), left(std::move(l)), right(std::move(r)) {}
    };
    std::unique_ptr<Node> root_;
    static std::unique_ptr<Node> clone(const Node* n) {
        if (!n) return {};
        return std::make_unique<Node>(n->value, clone(n->left.get()),
                                      clone(n->right.get()));
    }
    static std::size_t depth_of(const Node* n) {
        return n ? 1 + std::max(depth_of(n->left.get()),
                               depth_of(n->right.get())) : 0;
    }
public:
    Tree() = default;
    explicit Tree(T value) : root_(std::make_unique<Node>(std::move(value))) {}
    Tree(T value, Tree left, Tree right)
        : root_(std::make_unique<Node>(std::move(value),
                    std::move(left.root_), std::move(right.root_))) {}
    Tree(const Tree& other) : root_(clone(other.root_.get())) {}
    Tree(Tree&&) noexcept = default;
    Tree& operator=(Tree other) {
        root_.swap(other.root_);  // 先完成副本构造，再交换，提供强异常保证
        return *this;
    }
    bool empty() const { return !root_; }
    std::size_t depth() const { return depth_of(root_.get()); }

    class const_iterator {
        const Tree* owner_ = nullptr;
        std::vector<const Node*> pending_;
        const_iterator(const Tree* owner, const Node* n) : owner_(owner) {
            if (n) pending_.push_back(n);
        }
        friend class Tree;
    public:
        using iterator_category = std::forward_iterator_tag;
        using value_type = T;
        using difference_type = std::ptrdiff_t;
        using pointer = const T*;
        using reference = const T&;
        const_iterator() = default;
        reference operator*() const { return pending_.back()->value; }
        pointer operator->() const { return &pending_.back()->value; }
        const_iterator& operator++() {
            const Node* n = pending_.back();
            pending_.pop_back();
            if (n->right) pending_.push_back(n->right.get());
            if (n->left) pending_.push_back(n->left.get());
            return *this;
        }
        const_iterator operator++(int) { auto old = *this; ++*this; return old; }
        bool operator==(const const_iterator& other) const {
            return owner_ == other.owner_ && pending_ == other.pending_;
        }
        bool operator!=(const const_iterator& other) const { return !(*this == other); }
    };
    const_iterator begin() const { return const_iterator(this, root_.get()); }
    const_iterator end() const { return const_iterator(this, nullptr); }
    const T& maximum() const {
        if (empty()) throw std::out_of_range("empty tree has no maximum");
        auto it = begin();
        const T* best = &*it;
        for (++it; it != end(); ++it)
            if (*best < *it) best = &*it;
        return *best;
    }
};

    例如 const Tree<int> t(3, Tree<int>(-2), Tree<int>(8)); 的深度为 2，最大值为 8，遍历顺序为 \(3,-2,8\)。空树深度为 0，begin()==end()，求最大值抛异常。泛型最大值只要求 T 支持严格弱序 <；拷贝树还要求 T 可拷贝。比较时不应把初始最大值设为 0，否则全负树会出错。

    每个节点只有一个拥有者，销毁树会自动销毁所有后代；clone 防止两棵树共享拥有型指针，复制失败时已构造节点也会自动释放。移动或销毁原树、修改结构或赋值后，不应继续使用原迭代器和元素引用。深度、最大值、深拷贝均访问全部 \(n\) 个节点，耗时 \(O(n)\)；递归栈及先序迭代器的待访问栈占 \(O(h)\)。此处迭代器复制会复制栈，成本 \(O(h)\)，前置递增遍历全树总成本 \(O(n)\)。高度极大的退化树还需考虑递归析构和递归函数的调用栈限制。

    Q1172 · 固定锚点后的斜率分组¶

    难度：★★★｜题型：排序与搜索｜副题型：锚点枚举与最大公因数斜率

    题目：\(n\)个平面点，哈希均摊\(O(1)\)，怎样求通过最多输入点的直线，复杂度是多少？

    解答

    依次选每个点\(i\)作锚点，遍历所有其他点\(j\)，把向量\((dx,dy)\)约成同一个无向斜率键：用\(\gcd (|dx|,|dy|)\)除尽公因子，再统一符号（\(dx>0\)，或\(dx=0\)时\(dy>0\)）。哈希统计同键最大数量，加锚点即这条线上点数；遍历所有\(i\)取最大。重复坐标单独计数并加到每个斜率桶。整数坐标用约分键可避浮点斜率误差；一般实坐标需规定可靠的相等判定。 每个锚点\(O(n)\)哈希操作，共\(O(n^{2})\)，附加空间\(O(n)\)。在给定选项中选\(O(n^{2})\)；整数位长若也计复杂度，还须计gcd的位运算开销。 方法：把两两关系压成“固定一个点后的同类项”，把三点共线检验的立方枚举降为平方分组。

    排序题关注比较次数下界与快排最坏情形；随机算法（洗牌、随机排列）与在线抽样（蓄水池抽样）强调均匀性与无偏性证明。

    Q1173 · 均匀随机洗牌¶

    难度：★★｜题型：随机与在线算法｜副题型：Fisher–Yates与蓄水池抽样

    题目： (a) 有一个可生成离散或连续均匀分布随机数的生成器，如何洗一副 52 张的牌使每种排列等可能？ (b)（见 Q762 · 未知长度序列的均匀抽样）文件逐字符可读、长度未知，如何等概率抽取一个字符？

    解答

    (a) 方法一：随机排序法。给每张牌赋一个随机数，再按随机数排序。由对称性，\(n!\) 种顺序等可能。复杂度取决于排序：\(\Theta (n \log n)\)——\(n = 52\) 时足够好。

    方法二：Knuth 洗牌（大 \(n\) 时更快）：

    for (i = 1 to n) swap(A[i], A[Random(i, n)])

    其中 \( \operatorname{Random}(i, n) \) 是 \( i \) 到 \( n \) 之间的离散均匀随机数。复杂度 \( \Theta(n) \)，且有直观解释：第一步每张牌以 \( 1/n \) 等概率成为第 1 张；第二步剩余 \( n-1 \) 张等概率竞争第 2 位；……所以每种有序序列的概率恰为 \( 1/n! \)。

    均匀性与在线推广。 对任意指定排列，Fisher–Yates依次选择各剩余位置的条件概率为 \(1/n,1/(n-1),\ldots,1\)，乘积为 \(1/n!\)。随机键排序要求键为独立连续变量，或对有限精度键的并列再均匀打破；否则稳定地按原次序处理并列会引入偏差。

    未知长度流抽一个元素时，保留第一个，第 \(i\) 个以概率 \(1/i\) 替换当前保留项。旧项在第 \(i\) 步仍被保留的概率是 \([1/(i-1)](1-1/i)=1/i\)，新项也是 \(1/i\)，归纳得到最终均匀。若抽 \(k\) 个元素，先装满前 \(k\) 个；第 \(i>k\) 项以概率 \(k/i\) 入选，并均匀替换池中一项。每项最终边际入选率为 \(k/n\)，且全部 \(k\) 元子集等可能。

    Q1174 · 排序算法的实现与优化¶

    难度：★★｜题型：排序与搜索｜副题型：插入不变量与归并排序

    题目：写出一种排序算法的代码；讨论程序的速度与内存，并说明如何改进。

    你认为有必要在工程中手写已有的 STL 算法吗？

    • 实现归并排序。

    • 如何对链表排序？（链表内存不连续，不能使用随机访问迭代器。）

    • 如果对象复制和赋值的成本很高，这会怎样影响排序算法的选择与实现？

    • 哪些场景需要稳定排序？

    解答

    实际工程中，数组排序应优先使用标准库：

    #include <algorithm>

MyArray // 使用 STL 的排序算法
STLSort(const MyArray& input // 待排序数组
                )
{
    MyArray tmp(input);
    std::sort(tmp.begin(), tmp.end());
    return tmp;
}

    该版本先复制输入，所以不是原地排序。若不需要保留原数组，可以把参数改为非常量引用、返回类型改为 void，直接对输入排序。

    不过，面试官通常还希望考查算法实现能力。应知道 std::sort 不保证稳定性，也就是可能改变等价元素的原有相对次序；若需要稳定排序，应使用 std::stable_sort。

    下面是插入排序的一个简单实现：

    template<class T>
void InsertSort(T start, T end)
{
    for(T i=start; i<end; ++i)
    {
        typename std::iterator_traits<T>::value_type value = *i;
        T dec = i;

        while(dec > start && *(dec-1) > value)
        {
            *dec=*(dec-1);
            --dec;
        }

        *dec=value;
    }
}

    模板参数 T 是迭代器类型（也可以是指针），因此代码可用于任何支持所需比较和赋值操作的元素序列。插入排序简单但一般不够快，其步骤如下：

    • 保持前 \(j\) 个元素有序；

    • 取第 \(j+1\) 个元素，向前寻找适当位置；

    • 把更大的元素依次后移，将该元素插入正确位置，使前 \(j+1\) 个元素有序；

    • 重复直到处理完整个序列。

    其重要性质是：

    • 它是稳定排序；

    • 它可原地执行，只需常数额外空间；

    • 平均与最坏时间复杂度为 \(O(n^2)\)；

    • 速度取决于输入原有的有序程度；若数组已经有序，时间复杂度为 \(O(n)\)。

    插入排序还能增量工作：数字逐个到来时即可维持已有部分有序，不必先看到全部输入。

    更快的通用比较排序可达到 \(O(n\log n)\)。例如归并排序把序列分成两半，递归排序后再合并；其主要缺点是常规数组实现需要 \(O(n)\) 临时空间。实际实现常在子序列很小时切换到插入排序，例如长度小于 20 时，以降低递归和分治的常数开销。

    其他常见选择包括堆排序和快速排序。比较算法时应说明平均/最坏复杂度、稳定性、额外空间、缓存局部性以及对近乎有序数据的表现。

    归并实现。 对随机访问区间，可用如下稳定的自顶向下版本；实际高性能实现可复用一份辅助缓冲，避免每层分配：

    template<class It>
void merge_sort(It first, It last) {
    const auto n = last - first;
    if (n <= 1) return;
    It middle = first + n / 2;
    merge_sort(first, middle);
    merge_sort(middle, last);
    using T = typename std::iterator_traits<It>::value_type;
    std::vector<T> buffer;
    buffer.reserve(static_cast<std::size_t>(n));
    It a = first, b = middle;
    while (a != middle && b != last) {
        if (*b < *a) buffer.push_back(std::move(*b++));
        else buffer.push_back(std::move(*a++));
    }
    while (a != middle) buffer.push_back(std::move(*a++));
    while (b != last) buffer.push_back(std::move(*b++));
    std::move(buffer.begin(), buffer.end(), first);
}

    相等时先取左半，保证稳定性。链表可按快慢指针分半，再通过重连节点稳定归并；不需要随机访问，标准 std::list::sort 已提供成员排序。昂贵对象宜用移动、交换、排序索引或指针；仅当键值相等时仍需保留已有排序或输入先后关系，才需要稳定排序。

    Q1175 · 三种排序算法¶

    难度：★★｜题型：排序与搜索｜副题型：分治递推与随机主元

    题目：解释插入、归并和快速排序，比较平均与最坏复杂度；进一步解释快排最坏分区如何产生、随机主元能保证什么，以及如何取得最坏复杂度保证。

    解答

    插入排序（incremental）：假设 \( A[1,\ldots,i-1] \) 已排好，把 \( A_i \) 插入合适位置得 \( A[1,\ldots,i] \)；\( i \) 从 1 增到 \( n \)。每步期望比较 \( i/2 \) 次、最坏 \( i \) 次：

    \[ A(n) = \Theta\Big(\sum_{i=1}^n i/2\Big) = \Theta(n^2),\qquad W(n) = \Theta\Big(\sum_{i=1}^n i\Big) = \Theta(n^2) \]

    归并排序（分治）：数组分成两个 \( n/2 \) 子数组分别排序，再合并；子数组足够小则直接返回。合并两个有序子数组需 \(\Theta (n)\)：

    \[ T(n) = 2T(n/2) + \Theta(n) \]

    由主定理（\( a=2, b=2, f(n) = \Theta(n^{\log_2 2}\log^0 n) \)）：\( T(n) = \Theta(n\log n) \)；\( A(n) \) 与 \( W(n) \) 相同。

    快速排序（分治）：选一个基准 \( A_i \)，比它小的放左子数组、大的放右子数组，对两个子数组递归。最坏情形与插入排序同阶：如总选第一个元素做基准且数组已有序，每步一个子数组为空、另一个 \( n-1 \) 元，只缩减 1：\( W(n) = \Theta(n^2) \)。

    平均情形：设初始次序随机（可疑时可先以 \(\Theta (n)\) 随机打乱）。排序后第 \( p \)、\( q \) 个元素 \( \tilde A_p \)、\( \tilde A_q \)（\( p < q \)）被比较的概率：\( \tilde A_p \) 与 \( \tilde A_q \) 在 \( \tilde A_{p+1},\ldots,\tilde A_{q-1} \) 中的任何一个之前先被比较（否则二者被分进不同子数组、不再比较），由对称性 \( P(p,q) = 2/(q-p+1) \)。期望比较总数：

    \[ A(n) = \sum_{q=2}^n\sum_{p=1}^{q-1}\frac{2}{q-p+1} = \Theta(n\lg n) \]

    尽管理论最坏情形慢于归并排序，实践中快排通常不慢于（甚至快于）归并排序。

    最坏分区的防护。 若每次划分为0项与 \(n-1\) 项，比较次数为 \(\sum_{j=1}^{n-1}j=n(n-1)/2\)。随机主元或先随机洗牌可使每个固定输入的期望成本为 \(O(n\log n)\)，也有适当的高概率界，但不排除极小概率的二次时间。若需要确定的最坏保证，可使用introsort：递归深度超过 \(O(\log n)\) 后切换堆排序，保证总时间 \(O(n\log n)\)。大量重复键还可用三路分区避免相等元素造成无效递归。

    Q1176 · 证伪 \(O(n)\) 排序的声称¶

    难度：★★★｜题型：排序与搜索｜副题型：比较决策树与信息下界

    题目：假设我声称有一个 \(\mathcal{O}(n)\) 时间内给 \(n\) 个数排序的程序，请证明我说错了。

    • 你知道哪些 \(O(n\log n)\) 排序算法？

    • 还能为哪些算法问题证明复杂度下界？

    • 什么是堆？如何在内存中表示它？堆与排序有什么关系？

    解答

    需要区分交换与比较两类操作。下面证明：在只通过元素比较获取次序信息的模型中，最坏情形至少需要 \(\Omega(n\log n)\) 次比较。

    关键是计算可能的初始排列数，并分析一次比较最多能排除多少种排列。若 \(n\) 个元素互不相同并可按任意顺序出现，就有 \(n!\) 种可能排列。

    对尚存的 \(k\) 种可能性做一次二元比较，会把它们分成两个子集，其中至少一个子集含有 \(k/2\) 种可能。因此，做完 \(M\) 次比较后，决策树中必有一个分支至少还对应

    \[ \frac{n!}{2^{M}} \]

    种排列。要唯一确定答案，该数必须不大于 1。取对数得

    \[ \log(n!)-M\log2\leq\log1=0. \]

    整理得

    \[ M\ge\frac{\log(n!)}{\log2}. \]

    最后需要估计 \(\log(n!)\)。使用 Stirling 公式：

    \[ \log\Gamma(z)\sim\frac{1}{2}\log(2\pi)+\left(z-\frac{1}{2}\right)\log z-z+\mathcal{O}(z^{-1}). \]

    \(\Gamma\) 函数与阶乘的关系为

    \[ \Gamma(n+1)=n!. \]

    当 \(n\) 很大时，主导项为 \(n\log_2 n\)。因此，基于比较的通用排序不可能在最坏情况下达到 \(O(n)\)；其比较次数下界为 \(\Omega(n\log n)\)。计数排序等线性算法依赖键值范围等额外结构，并不违背该结论。

    追问：常见排序算法。 归并排序的递推为 \(T(n)=2T(n/2)+O(n)\)，最坏 \(O(n\log n)\)，数组实现通常用 \(O(n)\) 辅助空间，并可保持稳定。堆排序最坏 \(O(n\log n)\)，可原地进行但通常不稳定。快速排序一次分区为 \(O(n)\)，随机选主元时平均 \(O(n\log n)\)，普通实现最坏仍为 \(O(n^2)\)；不能把其平均界当作最坏界。Introsort 在分区过深时改用堆排序，可保证最坏 \(O(n\log n)\)。

    堆的表示和排序过程。 最大二叉堆是一棵完全二叉树，满足父节点的键不小于两个孩子。用零基数组存储时，节点 \(i\) 的孩子在 \(2i+1,2i+2\)，父节点在 \(\lfloor(i-1)/2\rfloor\)。堆只保证局部偏序，并不是有序数组。自最后一个非叶节点向根依次下沉可在 \(O(n)\) 建堆：高度为 \(h\) 的节点至多约 \(n/2^{h+1}\) 个，因此总成本由 \(n\sum_{h\ge0}h/2^{h+1}=O(n)\) 控制。随后把堆顶与当前末尾交换、缩小堆并下沉，做 \(n-1\) 次，每次至多 \(O(\log n)\)，就得到升序数组。

    其他下界及其模型。 比较查找一个已排序数组中的目标，需要区分至少 \(n+1\) 个插入位置，故最坏需要 \(\Omega(\log n)\) 次比较。找 \(n\) 个数的最大值至少需 \(n-1\) 次比较，因为除胜者外，每个元素必须至少输过一次；线性扫描达到该界。无序数组精确查找的最坏输入需要访问全部 \(n\) 项，否则未读项可能就是目标。每个下界都依赖计算模型及输入假设，不能据此否定整数计数排序等利用额外结构的线性算法。

    Q1177 · 同时求最大最小¶

    难度：★★｜题型：排序与搜索｜副题型：成对比较与胜负分组

    题目：如何用不超过 \( 3n/2 \) 次比较同时找出无序数组的最大值和最小值？

    解答

    对无序 \( n \) 元数组，单找最大或最小需 \( n-1 \) 次比较；但同时找两者最多只需 \( 3n/2 \) 次：

    1. 把元素分成 \( n/2 \) 对，每对内比较一次，较小者放入组 \(A\)、较大者放入组 \(B\)（\( n/2 \) 次比较）；
    2. 全数组的最小值必在 \(A\) 中、最大值必在 \(B\) 中；
    3. 在 \(A\) 中找最小（\( n/2 - 1 \) 次比较）、在 \(B\) 中找最大（\( n/2 - 1 \) 次）。

    总计最多 \( n/2 + 2(n/2 - 1) = 3n/2 - 2 \le 3n/2 \) 次比较。

    若 \(n\) 为奇数，先以一个元素同时初始化当前最小值和最大值，再把余下 \(n-1\) 项配对；每对用一次分大小，再分别与当前两极值比较，共 \(3(n-1)/2\) 次。偶数时第一对初始化两极值用一次，其余对各用三次，共 \(3n/2-2\)。统一为 \(\lceil3n/2\rceil-2\)（\(n\ge2\)），比单独做两趟扫描节省约四分之一比较。

    动态规划用状态定义加递推求解（最大子数组、斐波那契）；算法设计题（同时求最大最小、命中潜艇、机器人相撞）先想不变量与下界，再构造策略。

    Q1178 · Fibonacci的递归成本、滚动递推与快速幂¶

    难度：★★｜题型：动态规划｜副题型：子问题复用、滚动数组与快速倍增

    题目：采用 \(F_0=0,F_1=1,F_n=F_{n-1}+F_{n-2}\)。

    1. 朴素递归在某个大 \(n\) 上耗时100秒，求计算 \(F_{n+1}\) 的近似耗时并解释重复子问题。
    2. 写出线性时间、常数额外空间的迭代程序；说明多次查询如何避免重复分配。
    3. 用矩阵快速幂或快速倍增降到对数次算术运算，解释递归何时有用、Binet公式为何不自动给出精确常数时间算法。若以 \(1,1\) 为初值，答案如何对应？
    解答

    1. 朴素递归没有复用。 调用次数满足 \(T(n)=T(n-1)+T(n-2)+1\)，\(T(0)=T(1)=1\)。令 \(U(n)=T(n)+1\)，则 \(U(n)=U(n-1)+U(n-2)\)，从而 \(T(n)=2F_{n+1}-1\)。Binet公式为

    \[ F_n=\frac{\varphi^n-\psi^n}{\sqrt5},\quad\varphi=\frac{1+\sqrt5}2,\quad\psi=\frac{1-\sqrt5}2. \]

    由于 \(|\psi|<1\)，大 \(n\) 时耗时比趋于 \(\varphi\)，下一项约 \(100\varphi\approx162\) 秒，复杂度为 \(\Theta(\varphi^n)\)。

    2. 每个子问题只算一次。

    #include <cstdint>
#include <stdexcept>
std::uint64_t fibonacci(unsigned n) {
    if (n > 93) throw std::overflow_error("超出 uint64_t 精确范围");
    if (n == 0) return 0;
    std::uint64_t a = 0, b = 1;
    for (unsigned i = 1; i < n; ++i) {
        const auto next = a + b;
        a = b; b = next;
    }
    return b;
}

    循环不变量是 \(a=F_{i-1},b=F_i\)。时间 \(O(n)\)，无动态分配、额外空间 \(O(1)\)。若查询重复且范围已知，可一次预存所有项；若只递增查询，保留最后两项即可。

    3. 快速幂与精确成本。 矩阵 \(A=\begin{pmatrix}1&1\\1&0\end{pmatrix}\) 满足 \(A^n=\begin{pmatrix}F_{n+1}&F_n\\F_n&F_{n-1}\end{pmatrix}\)（\(n\ge1\)），归纳乘一次 \(A\) 即可证明。二进制快速幂每次把指数减半，只需 \(O(\log n)\) 次固定维矩阵乘法。也可递归求 \((a,b)=(F_k,F_{k+1})\)，用

    \[ F_{2k}=a(2b-a),\qquad F_{2k+1}=a^2+b^2 \]

    返回偶数或奇数所需的一对。

    递归适合分治和树结构；问题在于重复计算而非递归语法本身。精确 \(F_n\) 有 \(\Theta(n)\) 个二进制位，输出和大整数运算都不是常数成本；Binet公式使用固定浮点精度在大 \(n\) 时会舍入错误。若初值改成 \(G_0=G_1=1\)，则 \(G_n=F_{n+1}\)，算法与复杂度相同。

    Q1179 · 最大连续子数组¶

    难度：★★｜题型：动态规划｜副题型：前缀和最小值与Kadane递推

    题目：一维数组 \( A \)（长 \( n \)）含正负数。设计算法求连续子数组 \( A[i, j] \) 的最大和 \( V(i,j) = \sum_{x=i}^{j}A[x] \)，\( 1 \le i \le j \le n \)。

    解答

    几乎所有交易系统都需要此算法计算最大涨幅（run-up）或最大回撤（drawdown）——对冲基金与交易台的面试最爱。

    朴素算法 \( O(n^2) \)：用 \( V(i,i) = A[i] \)、\( V(i,j) = V(i,j-1) + A[j] \) 逐个计算 \( V(i,j) \)，同时记录最大值及下标。

    高效算法 \( O(n) \)（前缀和/递推）：定义 \( T(i) = \sum_{x=1}^{i}A[x] \)、\( T(0) = 0 \)，则 \( V(i,j) = T(j) - T(i-1) \)。对固定的 \( j \)，\( T(i-1) \) 最小时 \( V(i,j) \) 最大：以 \( j \) 结尾的最大子数组和为 \( V_{\max} = T(j) - T_{\min} \)，\( T_{\min} = \min(T(0),\ldots,T(j-1)) \)。随 \( j \) 递增同时维护 \( V_{\max} \) 与 \( T_{\min} \)：

    T = A[1]; Vmax = A[1]; Tmin = min(0, T);
for j = 2 to n {
    T = T + A[j];
    if (T - Tmin > Vmax) Vmax = T - Tmin;
    if (T < Tmin) Tmin = T;
}
return Vmax;

    例：\( A = \{1.0, 2.0, -5.0, 4.0, -3.0, 2.0, 6.0, -5.0, -1.0\} \Rightarrow V_{\max} = 9 \)（\( i=4 \)、\( j=7 \)），子数组 \( [4.0, -3.0, 2.0, 6.0] \)。

    等价的Kadane状态为 \(D_j=\max(A_j,D_{j-1}+A_j)\)：以 \(j\) 结尾的非空最优子数组，要么从当前元素重新开始，要么延长此前最优后缀。以 \(D_1=A_1\) 初始化，并随时更新 \(\max_jD_j\)，可正确处理全负数组。若允许空子数组，才把状态与答案再和0取最大。记录“重新开始”的位置及最佳终点即可恢复区间。

    Q1180 · 单笔交易最大利润¶

    难度：★★｜题型：数组与查找｜副题型：前缀最小值与差分子数组｜公司：Citadel

    题目：给定半小时的股价数据，如何求"单笔交易"能获得的最大利润？不许卖空——交易必须是先买后卖。

    解答

    这是经典的“单笔股票买卖最大利润”问题，一趟线性扫描即可。正向遍历时维护“截至当前的最低买入价”；在每个卖出时刻用当前价减最低买入价来更新最大利润，再更新最低买入价。若反向遍历，则应维护“未来见过的最高卖出价”，用最高卖出价减当前价来更新利润。

def cross(a,b,p):
    return (b[0]-a[0])*(p[1]-a[1])-(b[1]-a[1])*(p[0]-a[0])
def ccw(points):
    return points if cross(*points)>0 else [points[0],points[2],points[1]]
def clip(poly, bounds):
    poly = [(F(x),F(y)) for x,y in poly]
    for a,b in zip(bounds,bounds[1:]+bounds[:1]):
        out = []
        if not poly: break
        for s,e in zip(poly[-1:]+poly[:-1],poly):
            fs,fe = cross(a,b,s),cross(a,b,e)
            if (fs>=0)!=(fe>=0):
                t=fs/(fs-fe)
                out.append((s[0]+t*(e[0]-s[0]),s[1]+t*(e[1]-s[1])))
            if fe>=0: out.append(e)
        poly = out
    return poly

def overlap(a,b):

    return bool(poly) and sum(x*v-y*u for (x,y),(u,v) in
                             zip(poly,poly[1:]+poly[:1])) != 0

    R S L
O A T
I N E
    它能拼出词表前十词，其长度和\(7+7+6+5+5+5+5+4+4+5=53\)；后三词不满足邻接。所有排列中恰8个达最高值，对应这个棋盘的旋转、镜像。枚举覆盖所有排列给出上界，展示棋盘给出下界。

    from itertools import permutations

pairbit=[[1 << (min(i,j)*9+max(i,j)) for j in range(9)] for i in range(9)]
requirements=[]
for word in words:
    mask=0
    for a,b in zip(word,word[1:]):
        mask |= pairbit[index[a]][index[b]]
    requirements.append((mask,len(word)))
neighbours=[(a,b) for a in range(9) for b in range(a+1,9)
            if max(abs(a//3-b//3),abs(a%3-b%3))==1]
best=-1

    for a,b in neighbours:
        adjacency |= pairbit[board[a]][board[b]]
    score=sum(length for mask,length in requirements if adjacency & mask == mask)
    if score>best:
        best=score;boards=[board]
    elif score==best:
        boards.append(board)

    Q1183 · 同形块的加权不相交打包¶

    难度：★★★★｜题型：排序与搜索｜副题型：位掩码动态规划与加权打包

    题目：\(6\times 6\)数表如下，值均1至5。任选一个\(n\)格连通方块形\(T\)，用若干个旋转或镜像副本覆盖互不重叠的格，可留空；每块内不能重复数值，该块得分为数值乘积。所有块形、\(n\)和放法中求总分最大值。

    4 3 2 3 1 4
2 1 4 1 5 5
3 5 4 2 2 1
2 2 5 1 1 3
5 5 1 1 4 3
4 1 3 1 1 1
    解答

    每块值不得重复，所以\(n\le 5\)。依次生成全部自由\(n\)连通方块形：给已有形状加一个边邻格，再对平移、八种旋转镜像归一，\(n=1\)至5的形状数为1、1、2、5、12，不会漏掉任意连通形状。对固定形状枚举所有合法摆放\(P\)，权重\(w_{P}\)为格值乘积，二元变量\(z_{P}\)表示是否使用。 最大化 \(\sum_Pw_Pz_P\)，约束为每个棋盘格 \(s\) 上 \(\sum_{P\ni s}z_P\le1\)。每种形状独立求整数最优，再取最大。\(n=1,2,3,4,5\) 的最优分数分别为96、140、208、344、600；所有整数优化均达到最优，非只取得一个可行值。 最大600由一个\(L\)形五格块的五副本达到，每块都含1至5、得120。以下格坐标为(行,列)，从1起：

    • {(3,3),(4,3),(5,3),(6,3),(3,4)}；
    • {(1,3),(1,4),(1,5),(1,6),(2,6)}；
    • {(1,1),(1,2),(2,2),(3,2),(4,2)}；
    • {(3,1),(4,1),(5,1),(6,1),(6,2)}；
    • {(2,5),(3,5),(4,5),(5,5),(5,6)}。

    五块形状互为旋转或镜像、没有重叠，故确达600。 方法：形状去重与摆放优化分两层，不能先混用不同形状的副本，也不能仅从“有六个5”猜测上界可达。

    形状生成为什么完整。 任意有限共边连通格形的邻接图有生成树，删去该树一个叶格后，剩余格仍连通。按大小归纳，原形状必能由某个已生成的 \(n-1\) 格形加一邻格得到。每步对八种正方格对称变换、再平移到最小坐标0，取字典序最小元去重，恰对应题目允许旋转镜像的自由格形，不会把不同形状的副本混在一次打包中。

    有限最优性的另一种精确递推。 对固定形状，先枚举所有在棋盘内且数值互异的摆放 \(P\)，每个带整数权 \(w_P\)。用位掩码 \(S\) 表示仍可使用的格，\(F(\varnothing)=0\)。选 \(v\in S\)，则

    \[ F(S)=\max\left\{F(S\setminus\{v\}), \max_{P\subseteq S,\,v\in P}\bigl(w_P+F(S\setminus P)\bigr)\right\}. \]

    第一分支表示该格留空，后面分支枚举覆盖它的唯一那一块。任何可行最优放法恰落入某分支，而每分支拼出的放法又可行，故递推严格等价于整数最优。全部权为正，仍不能删掉“留空”分支：强制覆盖每格可能牺牲更大总分。

    若改用整数规划，应对全部21种形状分别求出最优值并证明相应上界，再比较最高值。五个L形副本给出总分600的可行摆放；完整优化给出上界600，两者结合证明最优。单块至多120这一松界，对六格块只给出720的上界，不能据此证明600最优。

    Q1184 · 三点铺放的奇偶障碍与覆盖构造¶

    难度：★★★★｜题型：排序与搜索｜副题型：染色不变量与铺放构造

    题目：三角点阵\(T_{N}\)第\(r\)行有\(r\)个点，邻接为三角格网；三点小三角形可向上或向下，要求每点恰用一次。可用已知工具：若可铺，\(\text{向上块数}-\text{向下块数}=\lceil N/3\rceil\)。求\(1\le N\le 50\)中可铺\(N\)之和；不能只检验工具给出的必要条件。

    解答

    总点数\(M=N(N+1)/2\)。若向上、向下块数分别\(u,d\)，则\(u+d=M/3\)，\(u-d= \lceil N/3\rceil\)。因此\(M\)必须被3整除，且\(M/3\)与\(\lceil N/3\rceil\)同奇偶。逐个模12代入，只有\(N\equiv 0,2,9,11(\operatorname{mod} 12)\)可能。 有限范围的候选为2,9,11,12,14,21,23,24,26,33,35,36,38,45,47,48,50。对每个候选确实构造精确覆盖：坐标用\((r,c)\)，\(0\le c\le r<N\)。所有向上块是\(\{(r,c),(r+1,c),(r+1,c+1)\}\)，向下块是\(\{(r,c),(r,c+1),(r+1,c+1)\}\)且\(c<r\)。为每个块设二元变量，每个点的相邻块变量之和强制为1。对这17个候选都找到满足所有等式的铺法，故此有限范围没有额外不可铺的候选。 答案是这些\(N\)之和474。 方法：先用不变量缩小候选，再为所有剩余有限实例提供可检查构造。

    必要条件的代数检查。 设 \(q=M/3\)、\(c=\lceil N/3\rceil\)，则必须有 \(u=(q+c)/2,d=(q-c)/2\) 为非负整数。将 \(N\) 模12分情况（模3控制 \(M\) 可除性，模4控制 \(q,c\) 奇偶）便得到四类余数0、2、9、11。此步只排除不可能的 \(N\)，不证明剩余可铺。

    无需整数规划库的完整构造算法。 把每点赋一位，枚举所有合法三点块的位掩码。对尚未覆盖集合 \(S\)，任取一个未覆盖点 \(v\)，枚举所有包含它且完全在 \(S\) 内的块 \(T\)，递归覆盖 \(S\setminus T\)。合法铺法必须选择其中一块，所以分支既不漏解也不会误报；空集合是成功边界。实际选候选块最少的点以减少分支。下面代码返回具体铺法并逐点检查所有17个候选：

    def triad_tiling(n):
    cells = [(r,c) for r in range(n) for c in range(r+1)]
    index = {p:i for i,p in enumerate(cells)}
    tiles = []
    for r in range(n-1):
        for c in range(r+1):
            tiles.append(((r,c),(r+1,c),(r+1,c+1)))
            if c < r:
                tiles.append(((r,c),(r,c+1),(r+1,c+1)))
    by = [[] for _ in cells]
    masks = {}
    for t in tiles:
        mask = sum(1 << index[p] for p in t)
        masks[mask] = t
        for p in t:
            by[index[p]].append(mask)
    def search(left):
        if left == 0:
            return []
        best = None
        rest = left
        while rest:
            bit = rest & -rest
            rest -= bit
            choices = [t for t in by[bit.bit_length()-1] if t & left == t]
            if not choices:
                return None
            if best is None or len(choices) < len(best):
                best = choices
            if len(best) == 1:
                break
        for t in best:
            answer = search(left ^ t)
            if answer is not None:
                return [masks[t]] + answer
        return None
    return search((1 << len(cells))-1)

possible = []
for n in range(1,51):
    M = n*(n+1)//2
    if M % 3 or (M//3 - (n+2)//3) % 2:
        continue
    tiles = triad_tiling(n)
    assert tiles is not None
    flat = [p for t in tiles for p in t]
    expected = {(r,c) for r in range(n) for c in range(r+1)}
    assert len(flat) == len(set(flat)) == len(expected) and set(flat) == expected
    possible.append(n)
assert sum(possible) == 474

    这是有限问题的构造性证明：不合必要条件者被严格排除；合条件者每个都生成覆盖并逐点验证。不需要假定这些同余类对所有 \(N>50\) 也一定可铺。递归最坏复杂度可指数增长，候选最少优先是加速而非改变正确性。

    Q1185 · 正五边形链的坐标化有限枚举¶

    难度：★★★★｜题型：排序与搜索｜副题型：坐标递推与有限路径枚举

    题目：单位边长正五边形拼两臂发夹，底片向下，右臂先接底片顶边，之后在“向上片的右上边、向下片的左上边”交替接，共\(2k+1\)片；左臂先接底片左上边，再在“向上片的左上边、向下片的顶边”交替接，共\(2j+1\)片。总片数\(2k+2j+3\le 15\)，已知片内部不重叠。求两端顶片之间最小正距离，接触距离0须排除。

    解答

    取底片中心原点、顶边水平。设内切半径\(\rho =1/(2\tan 36^{\circ})\)，外接半径\(R=1/(2\sin 36^{\circ})\)，记\(v\theta =2\rho (\cos \theta ,\sin \theta )\)。共享一整边的相邻两片中心差是该边外法向的\(2\rho\)倍。两端片都向上，因此中心分别为

    \[ C_R=v_{90}+k(v_{54}+v_{162}),\qquad C_L=v_{162}+j(v_{126}+v_{90}). \]

    任一向上顶片的五顶点为\(C+R(\cos (90^{\circ}+72^{\circ}i),\sin (90^{\circ}+72^{\circ}i))\)，\(i=0,\ldots ,4\)。这给出不依赖图形测量的准确坐标模型。 约束是\(k,j\ge 0\)且\(k+j\le 6\)，只有28对。每对计算两个凸五边形的距离：若接触则0，否则取一方各顶点到另一方各边线段距离及反向的最小值。点\(p\)到边ab的最近参数是\(t=clip((p-a)\cdot (b-a)/||b-a||^{2},0,1)\)，距离\(||p-a-t(b-a)||\)。 排除0后，最小值在\((k,j)=(2,1)\)，为\(\sqrt{5-2\sqrt{5}}/2\approx 0.3632712640\)，七位小数0.3632713。该实例总共9片，已满足至多15片。随后较小的正值为\((k,j)=(2,2)\)的\(\sin 36^{\circ}\approx 0.5877852523\)，故不能把接触的(1,1)错误作为“最小正”答案。

    方法：规则链先压成中心位移向量之和，再以凸多边形点到边距离求有限全局最小。

    中心式由交替位移相加得到。 右臂最初位移 \(v_{90}\)，之后每两次连接重复位移 \(v_{54}+v_{162}\)，故 \(k\) 对连接后为 \(C_R\)；左臂同理。相邻片中心位于公共边两侧且各距该边 \(\rho\)，中心距 \(2\rho\)，因此位移向量不是外接半径 \(R\)，也不是单边长1。

    最小值的精确来源。 在 \((k,j)=(2,1)\)，最近点为右顶片的第2顶点（顶点从0计、角度为 \(90+72i\) 度），到左顶片第4边的垂足；线段投影参数恰为1/2，落在边中点，不能把它当成两顶点距离。此边外法向为 \(n=(\cos54^\circ,\sin54^\circ)\)，因此距离为

    \[ (C_R-C_L)\cdot n-R-\rho =\rho(4-\sqrt5)-R =\frac{\sqrt{5-2\sqrt5}}2. \]

    其中用 \(C_R-C_L=2v_{54}+v_{162}-v_{126}\) 和 \(\cos72^\circ=(\sqrt5-1)/4\) 可先求点积，再以 \(\rho=1/(2\tan36^\circ),R=1/(2\sin36^\circ)\) 化简。距离平方为 \((5-2\sqrt5)/4\)，可避免从小数反猜根式。

    为什么28种枚举能给全局最优。 \(k+j\le6\) 的非负整数对数为 \(7+6+\cdots+1=28\)。对两个不相交凸多边形，最近点必落在边界；若两最近点都在边内部而平行，则可把其中一点滑到某条边的端点而不增加距离，所以检查双向“顶点到边”足够。相交或接触先由凸多边形分离轴检验识别，距离记0并按题意排除。28对中零距离者为(0,0)、(1,1)、(3,2)，最小三个正值分别来自(2,1)、(2,2)、(4,2)，约为0.363271264、0.587785252、0.726542528；其余正值至少1。有限检查与上述达到最小值的精确计算合起来才排除更小正距离，单画一个近似发夹图不足以证明。

    Q1186 · 有限回合命中潜艇¶

    难度：★★★★｜题型：动态规划｜副题型：可达集合递推与奇偶覆盖

    题目：潜艇从整数轴上某点出发、每回合移动固定整数个单位；你每回合可向整数轴上某点发射一枚导弹。能否给出有限回合内必中潜艇的算法？

    • 如果 \(a,b\) 可以是有理数而不必是整数，结论是否仍成立？

    • 如果 \(a,b\) 可以是实数，但导弹有半径为 \(\epsilon>0\) 的爆炸范围，是否仍能保证命中？

    解答

    先把问题数学化。对某一对整数 \(a,b\)，潜艇在第 \(n\) 回合的位置为

    \[ a+nb. \]

    所有可能的 \((a,b)\) 构成 \(\mathbb Z\times\mathbb Z\)，这是可数集。因此可以把所有整数对排成序列 \((a_n,b_n)\)，保证每一对最终都会出现；例如按以原点为中心、边长逐渐增大的正方形边界依次枚举。

    在第 \(n\) 回合，把导弹射向

    \[ a_{n}+n b_{n}. \]

    若此时恰有 \(a_n=a\) 且 \(b_n=b\)，导弹就会命中潜艇。由于枚举覆盖所有可能的整数对，这一回合最终一定会到来。

    有理数位置与速度。 \(\mathbb Q^2\) 仍可数：依次增加分子、分母的绝对值上界，分母取正并约分，去重枚举所有有理数对。在它被枚举的回合射击 \(a_n+nb_n\)，同一证明成立。“有限回合”指每个固定潜艇参数都有有限命中时刻，没有对全部无界参数统一的最迟回合数。

    实数参数与正爆炸半径。 可数枚举实数对不成立，但 \(\epsilon>0\) 仍能构造保证策略。分阶段 \(M=1,2,\ldots\)，在每个阶段覆盖参数方形 \([-M,M]^2\)。用有限多个 \(a_0\) 网格点使任何 \(|a|\le M\) 距某点不超过 \(\epsilon/2\)。对每个 \(a_0\)，在连续回合 \(n\) 用斜率区间覆盖 \([-M,M]\)：第 \(n\) 回合选一个长度 \(\epsilon/n\) 的区间，中点 \(b_0\)，射向 \(a_0+nb_0\)。该次命中所有满足 \(|a-a_0|\le\epsilon/2\)、\(|b-b_0|\le\epsilon/(2n)\) 的轨道，因为位置误差不超过 \(\epsilon\)。

    把这些斜率区间首尾相接；\(\sum_{n\ge n_0}\epsilon/n=\infty\)，所以有限回合便能覆盖长度 \(2M\)，然后处理下一个 \(a_0\)。每阶段网格有限，因此阶段有限结束。真实 \((a,b)\) 总落在某个整数 \(M\) 的方形中，该阶段结束前必中。这给出了实数情形的构造，而非仅靠“稠密有理点”的错误推断：逼近误差会乘以时间 \(n\)，必须同步控制。

    Q1187 · 让两个机器人相撞¶

    难度：★★★★｜题型：算法设计与证明｜副题型：有限状态轨迹与标记触发的快慢追赶

    题目：两个机器人同时空投到整数轴上，落地后各自扔下降落伞并执行你编写的同一段代码；每行代码执行 1 秒，可用指令：左移 1 单位；右移 1 单位；GOTO 某行；若当前位置有降落伞则 GOTO 某行。写出让它们相撞的代码。

    先在方向一致、机器人与自己的伞同点落地的模型下构造程序。再分析下列变体：说明这一构造及其证明是否仍适用，并区分有限指令模型与允许无界内存的扩展模型。

    • 如果两台机器人对“左”的理解可能相反，有限程序能否保证相撞？

    • 如果机器人与自己的降落伞分开落地呢？可假设机器人离自己的降落伞比离另一台机器人及其降落伞更近。

    • 二维版本是否可解？更高维又如何？

    • 本题与判断链表是否含环有什么联系？

    解答

    这道题有很多变体。核心思路是：机器人先以较慢的净速度向一个方向搜索；一旦踩到另一台机器人留下的降落伞，就知道对方位于前方，随后持续快速追赶。下面任意选择左方作为初始搜索方向；每轮“左、右、左”使机器人净向左移动一步：

    0 向左移动 1 向右移动 2 向左移动 3 若当前位置有降落伞，则跳到第 5 行 4 跳到第 0 行 5 向左移动 6 跳到第 5 行

    主程序的追赶证明。 搜索循环每5秒净向左1格，周期内位置只在相邻格摆动；追赶循环“左移、GOTO”每2秒净向左1格。若两机器人初始距离 \(d>0\)，左侧机器人沿相同程序永远不会碰到右侧的降落伞，仍维持搜索；右侧机器人最终走到左侧的降落伞并切换追赶。此时目标在前方有限距离，追赶者平均速度 \(1/2\) 大于 \(1/5\)，相对距离最终降至零，故有限时间相撞。GOTO 与条件判断也耗1秒，不能把追赶误算成每秒1格。默认移动沿线连续进行，途中相遇也算相撞。

    方向相反：按题给的有限指令语言，不能保证。 程序没有变量、计数器或随机源，有限行号就是有限内部状态。单机器人只与自己的固定降落伞交互时，若无限次回到原点，某个“原点加行号”会重复，从此轨迹周期循环、范围有界；若只有限次回原点，之后条件检测永远为假，有限状态指令流最终周期，轨迹不是有界就是沿一个方向线性漂移。因此它至少有一侧的最大探测距离有限。

    将两台机器人镜像放置，令各自可能的无界漂移都朝外，初始距离大于其有限的朝内探测距离之和。两者永远碰不到对方降落伞，也不会相撞，看到的情形恰与各自单独运行相同。这给出对任意有限程序的反例。若额外允许无界计数器，则可编写不断加长、返回起点的左右搜索，镜像朝向的两者会在某次朝内搜索相遇；这个构造依赖扩展语言提供的无界计数能力。

    降落伞偏移：主程序不再保证。 取机器人初始位置为0、10，自己的伞分别在-1、9，都满足“离自己的伞更近”。两者执行同一搜索循环，均在首个搜索循环中检测到自己的伞，随后完全同步地切换追赶循环，始终相距10。因此不能直接把同点落地的保证推广到此变体。

    若扩展语言以允许记忆坐标和无界计数，可以先从原点逐步扩大双向搜索。第一次找到伞时记录距离 \(D\)，再搜完半径 \(D\) 内的所有位置；在“自己的伞严格最近”条件下，可确定自己的伞。这个步骤只解决识别问题：两者走到各自伞的时刻可能不同，后续还需设计可处理异步启动的会合协议。同点落地的七行程序与同步证明本身不提供这种协议；题给四种有限指令也不直接支持上述无界搜索。

    二维与更高维的有限程序障碍。 即使补上上下移动指令并共享坐标方向，也不能直接照搬一维方案。考察机器人独自与原点降落伞交互的轨迹：它要么有界，要么最终是一个有限步周期反复平移，所访问位置包含在有限多条平行格点射线上。二维总可选择一个不在该轨迹及其反射中的初始位移。两机器人在遇到对方降落伞前始终执行相同程序、保持该位移，因此永远不相撞也不产生打破对称的新观测。更高维同理。允许无界内存、不同标识、随机化或更丰富传感器时需另建模型，以上不可能性只针对题给的确定性有限指令模型。

    与链表环的联系。 主构造利用“同轨迹上的快者追上慢者”，与 Floyd 快慢指针相似。但链表在有限环上使相对步数按环长取模，必然相遇；机器人在无限轴上没有这种周期空间保证，必须先用降落伞确认追赶方向与谁在前方，不能只让两个相同程序无条件跑不同速度。

    Q1188 · 用二分交换读出真假币数量¶

    难度：★★★★｜题型：排序与搜索｜副题型：二分交换与称重信息

    题目：32枚同外观硬币，重金币重量相同，轻假币重量相同，且至少一枚是假币。只能用两盘天平，可否在15次内确定金币总数？不要求指出每枚身份。

    解答

    可以。先处理一般\(2^{k}\)枚，金币数\(d\)。将币任意分为各\(m=2^{k-1}\)枚的\(A\)、\(B\)，比较一次。若平衡，两边金币数都为\(d/2\)，记最低位为0并留任一半。 若不平衡，令\(A\)较重。把两边各固定一个顺序，定义配置\(t\)为交换前\(t\)对币后的两盘，\(t\)从0至\(m\)。配置0左重，配置\(m\)右重；每增加\(t\)一步只互换一对，金币数差变化只能是\(-2\)、0、2。用二分查找保留异号端点：中点平衡就得到\(d\)偶数的等分；否则替换同号端点，最多再用\(\log _{2}m\)次比较，找到相邻的左重与右重配置。它们的金币差只能是\(+1\)和\(-1\)，所以\(d\)奇数，取金币少的一盘就有\(\lfloor d/2\rfloor\)枚，记录最低位1。这里符号不必随\(t\)单调，二分只要求端点异号且单步跳幅至多2。 递归在保留的一半继续，规模依次32、16、8、4、2，各最多5、4、3、2、1次，共15。每层得到\(d=2d_{next}+bit\)。最后剩一枚的金币数是\(\lfloor \text{原}d/32\rfloor =0\)，因为已知原\(d\le 31\)；从底向上重建全部二进制位即可得到准确金币数。 方法：通过可控的等量交换把计数差压到0或1，逐位读取未知数量。15次足够确定数量，不等于15次逐枚鉴别所有身份。

    二分时实际怎样配置天平。 固定原两半各自的顺序，配置 \(t\) 表示“前 \(t\) 对已互换、后面的未互换”，每次称量前按这个定义重置两盘。可以撤销先前交换，操作次数不限，限制的只有称量次数。设 \(D(t)\) 为左盘金币数减右盘金币数，因为两盘硬币总数始终相等、真币比假币重，天平的符号就是 \(D(t)\) 的符号。

    若 \(D(0)>0,D(m)<0\)，二分区间始终只保留一个正端点和一个负端点。中点若为零立即找到等分，否则替换同号端点；即使中间曲线来回振荡，新的两端仍异号。区间长为1时，\(D(t)>0,D(t+1)<0\)，且一次换对使差值至多改变2，所以只可能 \(D(t)=1,D(t+1)=-1\)。由 \(d=L+R\)、\(D=L-R\) 可知 \(d\) 奇，较轻盘含 \((d-1)/2\) 枚金币。

    每层记下 \(b=d\bmod2\)，保留半盘含 \(\lfloor d/2\rfloor\) 金币。依次得到低位 \(b_0,\ldots,b_4\)，最后剩一枚的金币数为 \(\lfloor d/32\rfloor\)。已知至少一枚是假币，所以 \(d\le31\)，这最后一位必为0，无需额外鉴别单币。最终 \(d=\sum_{j=0}^4b_j2^j\)。若没有“至少一枚是假币”条件，全真和全假的所有等数量称量都会平衡，二者无法区分；该条件正是算法终止解码所需的信息。

    Q1189 · 诚实多数的成组消去与询问下界¶

    难度：★★★★｜题型：排序与搜索｜副题型：多数消去与对抗下界

    题目：10人中至多4人会任意说谎，其余必说真话，每人知道所有人的身份。一次只可问\(i\)“\(j\)是否诚实”，可自适应。保证指出一个诚实者最少几问？

    解答

    答案7。上界先任意舍去一人，剩9人仍诚实过半。每个人最初是大小1的组与其代表，保持“若代表是坏人，则全组都是坏人”。每次选两个同大小组，问\(A\)代表\(B\)代表是否诚实：答是则合并，代表取\(B\)；若\(B\)坏，诚实\(A\)不可能答是，所以\(A\)也坏，合并不变量成立。答否则丢掉两组，因至少一个代表坏，至少一整个组坏；丢掉的坏人不少于好人，所以余者仍诚实过半。 重复至各剩余组大小互异（均为2的幂）。最大组大于其他组总大小；其代表若坏，则全组坏，违背余者诚实过半。因此最大组代表诚实。一次合并使组数减1，一次丢弃使组数减2。若无丢弃，9的二进制分解最终为 \(8+1\)，需要7问；若有丢弃，最终至少1组，且丢弃次数至少1，问数为 \(9-\text{最终组数}-\text{丢弃次数}\le7\)。 下界只需考虑坏人始终说谎这一允许子类。每次回答就相当于确定两人的类型相同或相反。已连通的问答分量有两个互补阵营，人数记\((a,b)\)，\(a\le b\)。当前最少坏人数\(M=\sum a\)。若某分量\(b-a>4-M\)，则它的大阵营不可能全坏，才可确定其中诚实者；否则每个人都仍可在某个不超过4坏人的世界中为坏。 以下遍历所有有信息的新询问与两种可行回答的精确minimax给出7，因此6问不足。分量内部问题不会增信息，可略去；跨分量只有两种合并方式，所以没有遗漏。 

    from functools import lru_cache
@lru_cache(None)
def f(state):
    M = sum(a for a, b in state)
    if any(b-a > 4-M for a, b in state):
        return 0
    best = 99
    for i, (a, b) in enumerate(state):
        for j in range(i):
            c, d = state[j]
            rest = [v for k, v in enumerate(state) if k not in (i, j)]
            next_cost = []
            for x, y in ((a+c, b+d), (a+d, b+c)):
                s = tuple(sorted(rest + [tuple(sorted((x, y)))]))
                if sum(u for u, v in s) <= 4:
                    next_cost.append(f(s))
            best = min(best, 1+max(next_cost))
    return best
assert f(((0, 1),)*10) == 7
    这也符合Wildon 的一般询问界\(2s-\)popcount\((s)\)，\(s=4\)给7；本题上下界已分别给出构造和有限检验。 方法：保留单向证据不变量作消去；证明最少次数时必须另给对抗下界，不能只数一个算法的步数。

    下界状态为什么足够。 在“坏人每次都说谎”子类中，用1代表诚实、0代表坏。问 \(i\)“\(j\)是否诚实”时，答是等价于二者类型相同，答否等价于类型不同。每条回答就是同/异约束，连通分量内所有人的类型都由一个根类型决定，所以整个分量只有互补的两种指派，压成两阵营大小 \((a,b)\) 丢掉的只是对未来可行性无关的身份排列。

    各分量最少要放 \(a\) 个坏人，故 \(M=\sum a\)。若要让某分量大阵营全坏，额外需 \(b-a\) 人；当且仅当 \(M+b-a>4\)，这个方向被排除，该大阵营才被强制诚实。若没有分量满足这个条件，则每个人都至少在一个不超过4坏人的合法世界中为坏，算法还不能保证输出任何人。

    跨两个分量的回答只可能令其两个阵营同向合并成 \((a+c,b+d)\)，或交叉合并成 \((a+d,b+c)\)；分量内部的询问结果已确定，不提供新信息。合并后最少坏人数超过4的回答不合法，应从对抗者动作中删掉。于是上述代码的“对回答取 max、对所问分量对取 min”恰是穷尽全部自适应决策树的 minimax，而不是只检查某类固定询问顺序。它返回7，结合7问构造，才证明“最少”。最坏深度不超过9，代码中的99只作足够大的初始哨兵。

    Q1190 · 连续摆绳动作转成有限最短路¶

    难度：★★★★｜题型：排序与搜索｜副题型：几何事件离散化与Dijkstra

    题目：粒子从棋盘\(a_{1}\)格中心到对角目标，每次向可见柱系绳，顺或逆时针转；可见指连接段上没有其他柱。绳扫到比粒子更近的柱时绕该柱继续，余绳长减去两柱距离；同射线多柱时绕最远的，允许多次绕柱与绳自交。粒子不能撞柱或越过棋盘外缘，可在任何无柱格中心结束一次摆动（包括碰柱瞬间），一次费用为投绳时长度\(D\)的\(1/D^{2}\)。格宽1、外缘距最外格中心半格。求两例的最小总费：\(6\times 6\)从\(a_{1}\)到\(f_{6}\)，柱\(a_{5},e_{1},e_{3},e_{4},f_{1}\)；\(7\times 7\)从\(a_{1}\)到\(g_{7}\)，柱\(d1,f_{1},a_{5},c_{5},g_{5},b6\)。

    解答

    停止状态只有无柱格的中心，因而分别只有31与43个图节点。对每个节点枚举可见初始柱与两种转向，按角度推进至下一个事件：绳碰到新柱、粒子撞柱或轨迹离开外缘。记录此前和事件瞬间经过的所有格中心，分别加一条费用\(1/D^{2}\)的有向边；绕柱后用新圆心与缩短的余绳继续，费用仍由最初\(D\)决定。每次绕柱至少消耗1单位绳长，所以单摆事件枚举有限；没有其他事件时转一整圈已覆盖该圆所有候选停止点。 这样每条合法路线都对应图中一条路径，图边又都是可实现的摆动，最小费用恰是正权图的Dijkstra距离。初始柱与格中心均在整数格点，\(D^{2}\)整数，所以所有边费与最后总费用有理数精确累加。 \(6\times 6\)答案\(21/208\)：\(a_{1}\)先向\(e_{1}\)投绳，顺时针绕到\(e_{4}\)柱后停\(f_{4}\)，费用\(1/16\)；再向\(a_{5}\)投绳，逆时针到\(f_{6}\)，费用\(1/26\)。总和\(1/16+1/26=21/208\)。 \(7\times 7\)答案\(69/592\)：\(a_{1}\)向\(a_{5}\)投绳、逆时针绕\(c_{5}\)后到\(c_{7}\)，费用\(1/16\)；\(c_{7}\)向\(d1\)投绳、顺时针到\(e_{7}\)，费用\(1/37\)；\(e_{7}\)向\(f_{1}\)投绳、顺时针到\(g_{7}\)，费用\(1/37\)。总和\(1/16+2/37=69/592\)。

    方法：动作途中可以连续运动，但只有离散的合法停止位置时，先枚举动作可达关系，再套有限图最短路。

    动作事件的方程。 当前转轴 \(P\)、余绳长 \(R\)、粒子 \(X=P+R(\cos\theta,\sin\theta)\)。对另一个柱 \(Q\)，绳扫到它的候选角度为 \(\arg(Q-P)\)。若 \(|Q-P|<R\)，到该角时绕轴变成 \(Q\)，余绳长改为 \(R-|Q-P|\)，粒子位置不跳变；若两距离相等，粒子撞柱，该方向在此终止；柱更远则不构成本段事件。下一事件取顺/逆方向角度增量最小者；同角多个较近柱按题设选择距离最远的一个。

    棋盘边界 \(x=-1/2,n-1/2\)、\(y=-1/2,n-1/2\) 与当前圆的交点可由 \(\cos\theta=(x_\mathrm{edge}-P_x)/R\)、\(\sin\theta=(y_\mathrm{edge}-P_y)/R\) 求出。只在轨迹从内到外时终止，纯相切不越界；候选停止格心 \(Z\) 还必须满足 \(|Z-P|=R\) 且角度位于本段可扫范围。绕柱瞬间符合这些条件的格心也要记录，不能只记录事件前严格小于的角度。

    每次绕柱至少扣除不同整数柱之间的距离1，初始绳长有限，因此连续摆动只有有限次换轴；一段无新事件时转一整圈就重复，停止枚举。每次重新投绳才重新计算费用 \(1/|Z-P_0|^2\)，摆动中途换轴不改变本次费用。图上每条边记录初始轴、方向、全部中间换轴，便能把最短路还原为可执行动作，而不是只给抽象节点序列。

    最短路上下界的对应。 任意合法方案的每次停摆在格心，故能逐步替换为所枚举的一条边，路径费用不变；每条枚举边又确由合法扫角事件生成，反向也成立，所以 Dijkstra 距离不是一个松弛下界，而是原问题的最优值。费用可用有理数精确累加；几何事件计算若使用浮点，仍须对近乎共线、相切、相等半径情况作稳健判定，不能因费用精确就声称所有几何判定也自动精确。所给两条路线的合法性及费用均可由上述扫角方程和边长公式计算。

    Q1193 · Adam首步偏差校正¶

    难度：★｜题型：有限差分与数值方法｜副题型：指数滑动矩与偏差校正

    题目：Adam 零初始化，\(\beta _{1}=0.9\)、\(\beta _{2}=0.999\)、\(\eta =0.01\)、\(\epsilon =0\)，首次梯度 3.7。求首步更新幅度。

    Adam首步\(m_{1}=.37\)、\(v_{1}=.01369\)，偏差校正后\(\hat{m}_{1}=3.7\)、\(\hat{v}_{1}=13.69\)，所以幅度\(\eta \hat{m}_{1}/\sqrt{\hat{v}_{1}}=.01\)。\(\epsilon =0\)且非零梯度时首步幅度为学习率，与梯度绝对值无关。

    Q1194 · 递归链式导数的衰减¶

    难度：★｜题型：有限差分与数值方法｜副题型：链式法则与雅可比乘积

    题目：\(h_{t}=0.9h_{t-1}+x_{t}\)，各输入独立于 \(h_{0}\)，求 \(\partial h_{100}/\partial h_{0}\)。

    解答

    递归链式求导逐步乘.9，得\(0.9^{100}\approx 0.0000265613988875875\)；输入的加法不影响对\(h_{0}\)的导数。

    一般递推 \(h_t=ah_{t-1}+x_t\) 展开为 \(h_t=a^th_0+\sum_{j=1}^ta^{t-j}x_j\)，对 \(h_0\) 求导得到 \(a^t\)。\(|a|<1\) 时梯度指数衰减，\(|a|>1\) 时增长；矩阵递推对应雅可比矩阵连乘。这里实际要求把输入视为不随 \(h_0\) 变化，概率独立只是充分的建模说明。

    Q1196 · Horner 算法¶

    难度：★｜题型：有限差分与数值方法｜副题型：嵌套乘法与同时求导

    题目：写一个算法计算 \( y = A_0 + A_1x + A_2x^2 + A_3x^3 + \cdots + A_nx^n \)。

    解答

    朴素做法逐项计算再相加，需要 \( O(n^2) \) 次乘法。Horner 算法把多项式改写为

    \[ y = \Big(\big(\cdots((A_nx + A_{n-1})x + A_{n-2})x + \cdots + A_2\big)x + A_1\Big)x + A_0 \]

    并依次计算 \( B_n = A_n \)、\( B_{n-1} = B_nx + A_{n-1} \)、…、\( B_0 = B_1x + A_0 \)，则 \( y = B_0 \)。最多 \( n \) 次乘法，复杂度 \( O(n) \)。

    逐项重新从1乘到 \(x^j\) 才需要 \(O(n^2)\) 乘法；若复用相邻幂，本来也可做到 \(O(n)\)。Horner的优势是固定只需 \(n\) 次乘加且额外空间常数。还可同时求导：从 \(y=A_n,d=0\) 开始，按 \(j=n-1,\ldots,0\) 依次更新 \(d\leftarrow dx+y\)、\(y\leftarrow yx+A_j\)，导数更新必须使用旧的 \(y\)。这是对每一层嵌套乘法使用乘积法则，最终得到 \(p(x),p'(x)\)。

    Q1197 · 计算 \(n\) 阶乘¶

    难度：★★｜题型：归纳与递推｜副题型：乘积递推与任意精度

    题目：写一个计算 \(n\) 阶乘的程序。

    • 如何高效计算二项式系数？（可考虑 Pascal 三角形或约分后的乘法公式。）

    • 你更倾向使用递归还是循环？为什么？

    • 哪一种通常运行得更快？

    • 什么是 Stirling 公式？

    如果要求精确结果，但它超过了最大的内建整数类型，应怎样处理？

    解答

    下面给出循环与递归两种解法：

    double FactorialLoop(int n)
{
    double answer =1.0;
    for (int j=2; j <=n; ++j)
        answer*=j;

    return answer;
}

double FactorialRecursion(int n)
{
    if (n ==0)
        return 1.0;

    return n*FactorialRecursion(n-1);
}

    第一种是简单循环；第二种使用递归，形式简洁，但有函数调用开销，而且递归过深可能导致栈溢出。

    返回类型使用 double 而不是 int，是因为常见 32 位 int 的上限约为 \(2\times10^9\)，不大的 \(n\) 就会使阶乘越界。不过 double 只能扩大数值范围，不能保证大阶乘的整数精确性。

    若会在一个较小的固定范围内反复调用，可预先缓存所有可表示的阶乘值。若需要精确计算大阶乘，应使用任意精度整数，而不是 double。

    二项式系数可先令 \(k\leftarrow\min(k,n-k)\)，再由 \(c_0=1\)、\(c_j=c_{j-1}(n-k+j)/j\) 逐项计算。精确整数实现可先约分以防中间乘积溢出；任意精度整数仍需计入位运算成本。若要同一 \(n\) 附近的许多值，Pascal递推 \(\binom nk=\binom{n-1}k+\binom{n-1}{k-1}\) 可复用计算。Stirling公式为 \(n!\sim\sqrt{2\pi n}(n/e)^n\)，对数形式适合极大 \(n\) 的量级估计。循环无调用栈开销，通常比朴素递归快；两者算术运算次数同为 \(O(n)\)。

    Q1198 · Newton平方根：尺度归一化、收敛与浮点停止¶

    难度：★★｜题型：有限差分与数值方法｜副题型：Newton二次收敛与二进制尺度分解

    题目：不用现成的开方函数，写一个计算非负有限 \(x\) 平方根的C++程序。推导Newton迭代、说明收敛速度，并设计对极大数、极小数和浮点停滞都合理的停止条件。再与二分法比较。

    解答

    对 \(f(y)=y^2-x\) 用Newton公式，得到

    \[ y_{j+1}=y_j-\frac{y_j^2-x}{2y_j}=\frac12(y_j+x/y_j). \]

    记真根 \(r=\sqrt x\)，误差满足 \(y_{j+1}-r=(y_j-r)^2/(2y_j)\)，因此进入根附近后每次迭代大致把有效位数翻倍。

    直接计算 \(y^2-x\) 会在极大尺度上溢出；用固定绝对残差又可能过早接受极小数。先写 \(x=m2^e\)，把 \(e\) 调成偶数，使 \(m\in[1/2,2)\)。只在这个固定尺度求根，再乘 \(2^{e/2}\)。frexp和ldexp只做二进制尺度转换，不调用平方根。

    #include <cmath>
#include <cstdlib>
#include <iostream>
#include <limits>
#include <stdexcept>
double square_root(double x) {
    if (!std::isfinite(x) || x < 0)
        throw std::invalid_argument("需要非负有限数");
    if (x == 0) return x;
    int exponent;
    double m = std::frexp(x, &exponent);
    if (exponent % 2 != 0) { m *= 2; --exponent; }
    double y = 1;
    for (int i = 0; i < 32; ++i) {
        const double next = 0.5 * (y + m / y);
        const double difference = next > y ? next - y : y - next;
        y = next;
        if (difference <= 4 * std::numeric_limits<double>::epsilon() * y)
            return std::ldexp(y, exponent / 2);
    }
    throw std::runtime_error("迭代未达到停止条件");
}
int main(int argc, char** argv) {
    if (argc != 2) return 1;
    char* end;
    const double x = std::strtod(argv[1], &end);
    if (end == argv[1] || *end != '\0') return 1;
    try { std::cout.precision(17); std::cout << square_root(x) << '\n'; }
    catch (const std::exception& e) { std::cerr << e.what() << '\n'; return 1; }
}

    相邻迭代值的相对变化接近机器精度时停止，也覆盖舍入后不再变化的情形。该实现获得接近double精度的结果，不声称满足正确舍入的全部标准库保证。二分法只需保持区间夹住正根，线性收敛、每次约增加一位二进制精度；Newton在合理初值下更快。若输入解析发生下溢，应按接口需求另检查 errno，避免把无法表示的正输入当成0。

    Q1199 · 处处数值稳定的 sinc 函数¶

    难度：★★★｜题型：有限差分与数值方法｜副题型：Taylor局部展开与消减误差

    题目：设 \( f(x)=\sin(x)/x \)，写出返回 \( f(x) \) 值的代码，要求处处行为良好（包括 \( x=0 \) 附近）。

    • 补全 \(\phi\) 的具体构造。

    • 如何稳定地计算 \(\left(\cos(x)-1\right)/x^{2}\)？

    • 计算机通常如何实现 sin 函数？

    解答

    问题在于 \(f(x)=\sin(x)/x\) 在零点有一个可去奇点。由

    \[ \sin(x)=\sum_{j=0}^{\infty}(-1)^{j}\frac{x^{2j+1}}{(2j+1)!}. \]

    可得

    \[ f(x)=\sum_{j=0}^{\infty}(-1)^{j}\frac{x^{2j}}{(2j+1)!}. \]

    这是一个性质良好的收敛幂级数，因此在零点附近可以直接用它计算。

    但当 \(|x|\) 较大时，级数可能需要很多项，浮点舍入误差也会损害精度。实用方案是：当 \(|x|<10^{-4}\) 时使用级数，此时四次以上的幂通常小到不会影响结果；其他位置使用标准库的 sin(x)/x。切换阈值附近可能因两种近似各自的浮点误差而出现极小的不连续。

    若希望平滑过渡，可以引入光滑截断函数（bump function）\(\phi\)：它在零点附近等于 1，取值始终位于 0 与 1 之间，并在离零点超过某个距离后等于 0。

    然后计算

    \[ \phi(x)f(x)+(1-\phi(x))\frac{\sin(x)}{x}. \]

    这样的 \(\phi\) 可以由更简单的函数构造。令

    \[ g(x)=\begin{cases}e^{-1/x},&x>0,\\0,&x\le 0.\end{cases} \]

    函数 \(g\) 光滑，在 \(x>0\) 时为正，在 \(x\le 0\) 时为零。对 \(g\) 做平移、缩放与归一化即可构造所需的 \(\phi\)。

    稳定的可执行版本与余项。

    #include <cmath>
double sinc(double x) {
    if (std::abs(x) < 1e-4) {
        const double z = x*x;
        return 1.0 + z*(-1.0/6.0 + z/120.0);
    }
    return std::sin(x)/x;
}
double cosm1_over_x2(double x) {
    const double y = sinc(x/2.0);
    return -0.5*y*y;
}

    小区间截断误差不超过 \(|x|^6/7!<2\times10^{-28}\)，低于双精度舍入水平；零点直接由多项式返回1。恒等式 \((\cos x-1)/x^2=-\tfrac12[\sin(x/2)/(x/2)]^2\) 避免两个接近1的数相减，零点延拓为 \(-1/2\)。

    若确需光滑混合，选 \(0<a<b\)，令 \(\phi(x)=g(b^2-x^2)/[g(b^2-x^2)+g(x^2-a^2)]\)。则 \(|x|\le a\) 时为1，\(|x|\ge b\) 时为0，分母不会同时为零。数值实现应在两个端区直接分支，不能先求 sin(0)/0 再乘零，NaN不会被零权重消除。

    标准 sin 通常先高精度约化到很小角度（大参数需 Payne–Hanek 等约化避免丢失相位），再用 minimax 多项式或有理逼近，结合象限还原。直接对很大的 \(x\) 累加 Taylor 级数会出现巨大中间项和消减误差，不能作为通用实现。

    Q1200 · 面积蒙特卡洛、离散骰坐标与误差分解¶

    难度：★★｜题型：蒙特卡洛｜副题型：面积指示变量、进制网格与大数律

    题目：希望用随机抽样估计 \(\pi\)。

    1. 从单位正方形与四分之一圆的面积关系构造估计量，求无偏性、方差和标准误。
    2. 若只有公平 \(n\) 面骰，\(n\ge2\)，且各掷独立，如何生成有限分辨率的均匀坐标？
    3. 区分固定分辨率下增加样本量与提高分辨率，说明如何同时控制两种误差。
    解答

    1. 指标的期望就是面积。 取独立均匀点 \((U_i,V_i)\in[0,1]^2\)，令 \(I_i=\mathbf1_{\{U_i^2+V_i^2\le1\}}\)。圆内区域面积为 \(p=\pi/4\)，故 \(EI_i=p\)。定义

    \[ \hat\pi_M=\frac4M\sum_{i=1}^MI_i. \]

    独立性给 \(E\hat\pi_M=\pi\)、\(\operatorname{Var}\hat\pi_M=16p(1-p)/M\)，标准误可用 \(4\sqrt{\hat p(1-\hat p)/M}\) 估计。大样本近似区间为估计值加减1.96倍标准误。把标准误减半通常需四倍样本量。

    2. 骰子生成等概率格点。 将每次点数减一得到独立数字 \(D_j\in\{0,\ldots,n-1\}\)，令

    \[ U_k=\sum_{j=1}^kD_jn^{-j}. \]

    每个数字串概率为 \(n^{-k}\)，且与 \(\{0,1/n^k,\ldots,(n^k-1)/n^k\}\) 的格点一一对应。因此 \(U_k\) 在该网格均匀。用另一组独立掷骰生成 \(V_k\)，重复面积判定。

    3. 双重极限。 固定 \(k\)，估计均值趋于 \(4p_k\)，其中 \(p_k\) 是有限网格内圆点的比例，它一般不等于 \(\pi/4\)。当 \(k\to\infty\)，Riemann和给 \(p_k\to\pi/4\)。于是总误差分为 \(4(\hat p_{k,M}-p_k)\) 的抽样误差与 \(4p_k-\pi\) 的网格偏差。圆边界只经过 \(O(n^k)\) 个小格，网格偏差为 \(O(n^{-k})\)，抽样标准误为 \(O(M^{-1/2})\)。同时令 \(k,M\) 增大即可使二者趋零；有限次离散骰不产生精确的连续均匀变量。

    Q1201 · 蒙特卡洛定价欧式看涨¶

    难度：★★｜题型：蒙特卡洛｜副题型：风险中性终值抽样与标准误

    题目：解释如何用蒙特卡洛模拟为欧式看涨期权定价。

    解答

    背景：MC 模拟在风险中性测度下模拟大量标的价格路径，计算每条路径的贴现 payoff 并平均；其有效性依赖大数定律。payoff 只依赖终值的衍生品（及路径依赖衍生品）都能处理；美式期权等含提前行权的衍生品不能直接用 MC。

    若股价服从几何布朗运动，把 \( [t, T] \) 均分为 \( N \) 步：\( \Delta t = (T-t)/N \)、\( t_i = t + i\Delta t \)。在风险中性测度下逐步模拟：

    \[ S_i = S_{i-1}\,e^{(r-\sigma^2/2)\Delta t + \sigma\sqrt{\Delta t}\,\varepsilon_i},\qquad \varepsilon_i \sim \text{iid } N(0,1) \]

    模拟 \( M \) 条路径，得到到期价 \( S_{T,k} \)（\( k = 1,\ldots,M \)）。欧式 call 的估计价格即期望 payoff 的现值：

    \[ C = e^{-r(T-t)}\cdot\frac{1}{M}\sum_{k=1}^M \max(S_{T,k}-K,\ 0) \]

    对于只依赖终值的欧式看涨，无须切分路径：直接生成 \(S_T=S_te^{(r-\sigma^2/2)(T-t)+\sigma\sqrt{T-t}Z}\)，\(Z\sim N(0,1)\)，即可避免无用的时间步成本。记贴现收益为 \(Y_k\)，价格估计 \(\bar Y\) 的标准误为样本标准差 \(s_Y/\sqrt M\)。路径依赖或非精确可模拟模型才另需时间离散，并应区分时间步偏差与抽样误差。美式期权需要条件继续价值估计，例如最小二乘蒙特卡洛，而不能只平均固定到期收益。

    Q1202 · 蒙特卡洛方差缩减的恒等式与适用条件¶

    难度：★★★｜题型：蒙特卡洛｜副题型：对偶、控制变量、条件期望与重要性权重

    题目：目标是估计 \(\mu=EX\)，单次样本二阶矩有限。

    1. 推导独立平均的标准误，说明计算量与精度的关系。
    2. 分别推导对偶变量、控制变量和条件期望降方差的依据。
    3. 写出重要性抽样的无偏条件和方差公式。
    4. 说明矩匹配和低差异序列为何不能无条件套用独立无偏均值的公式。
    解答

    1. 基准成本。 独立样本平均满足 \(E\bar X=\mu\)、\(\operatorname{Var}\bar X=\sigma_X^2/M\)，故标准误为 \(\sigma_X/\sqrt M\)。将误差尺度降低为原来的 \(c\) 倍，需要约 \(1/c^2\) 倍样本。

    2. 保持均值而减少随机波动。 若 \(X'\) 与 \(X\) 同分布，对偶样本 \((X+X')/2\) 的方差为 \(\sigma_X^2(1+\rho)/2\)。与两份独立样本的平均相比，只有 \(\rho<0\) 才改善；正态输入取 \(Z,-Z\) 并不对所有收益都保证负相关。

    已知 \(EY=m_Y\) 时，控制变量 \(X_c=X-c(Y-m_Y)\) 保持均值不变。其方差为 \(\sigma_X^2-2c\operatorname{Cov}(X,Y)+c^2\operatorname{Var}Y\)，最优

    \[ c^*=\frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}Y},\qquad\operatorname{Var}X_{c^*}=\sigma_X^2(1-\rho_{XY}^2). \]

    系数可由独立先导样本估计，避免同样本拟合带来的有限样本偏差问题。

    对可计算条件均值 \(H=E(X\mid Z)\)，全方差公式给 \(\operatorname{Var}X=\operatorname{Var}H+E\operatorname{Var}(X\mid Z)\)，故直接模拟 \(H\) 保持均值且方差不增。

    3. 改变抽样权重。 若目标为 \(\int h(x)f(x)dx\)，从 \(g\) 抽样后使用 \(W=h(X)f(X)/g(X)\)。必须在 \(hf\ne0\) 的区域有 \(g>0\)，并有相应可积性，才保证 \(E_gW=\mu\)。二阶矩为 \(\int h^2f^2/g\)，方差是该积分减 \(\mu^2\)。把更多质量放到重要区域常有帮助，但选错 \(g\) 也可增大方差或造成无限方差。

    4. 样本设计不是自动无偏。 矩匹配会让重缩放后的样本相关，并可能改变目标分布，对一般非线性收益不保证无偏；误差公式要重新分析。低差异序列是确定性求积，收敛率依赖维数、函数变差和光滑性，不能对任意不连续收益宣称 \(1/M\) 误差。随机化准蒙特卡洛可通过独立随机化批次估计标准误。

    解答

    下面给出一个简单的 C++ 实现。uniform_int_distribution 可以避免 rand() 常见的端点错误和取模偏差：

    #include <algorithm>
#include <numeric>
#include <random>
#include <stdexcept>
#include <vector>

double SimulateGrandma(int passengers, int simulations,
                       std::mt19937& rng) {
    if (passengers < 2 || simulations <= 0)
        throw std::invalid_argument("模拟规模无效");
    int successes = 0;

    for (int run = 0; run < simulations; ++run) {
        std::vector<int> freeSeats(passengers);
        std::iota(freeSeats.begin(), freeSeats.end(), 0);

        for (int person = 0; person < passengers - 1; ++person) {
            auto own = std::find(freeSeats.begin(), freeSeats.end(), person);
            auto chosen = own;
            if (own == freeSeats.end()) {
                std::uniform_int_distribution<int> pick(
                    0, static_cast<int>(freeSeats.size()) - 1);
                chosen = freeSeats.begin() + pick(rng);
            }
            freeSeats.erase(chosen);
        }
        if (freeSeats.front() == passengers - 1) ++successes;
    }
    return static_cast<double>(successes) / simulations;
}

    算法维护当前仍空闲的座位编号。第 0 位乘客均匀随机选座；此后的乘客若自己的座位仍空闲便直接入座，否则从剩余座位中均匀随机选择。直接使用向量的实现易于检查，但 find 和 erase 都是线性操作，故最坏时间复杂度为二次；改用支持按序号选择和删除的数据结构可进一步优化。

    这份实现每轮有 \(O(n)\) 次向量查找或删除，总时间为 \(O(Rn^2)\)、额外空间 \(O(n)\)，\(R\) 为模拟次数。若仅需最后一人是否成功，可只模拟由错误占座产生的链：每遇到一个被挤出的乘客，在尚未决出的座位中继续均匀抽取，直到座位1或座位 \(n\) 首先被选中。两座位对称，所以成功概率恰为1/2；若只需这个指标，直接掷公平比特可得同分布 \(O(1)\) 一次模拟，但不再重建完整入座过程。

    原模拟可用小 \(n\) 枚举所有选择路径核对，再检查每轮没有重复占座、总人数与座数守恒。估计标准误为 \(\sqrt{\hat p(1-\hat p)/R}\)，近似95%半宽约 \(0.98/\sqrt R\)。观察到若干次小数不变并不是误差已受控的依据。

    Q1204 · 深虚值数字期权的蒙特卡洛改进¶

    难度：★★★｜题型：蒙特卡洛｜副题型：正态均值平移与似然比

    题目：已知 \(T\) 时刻股价服从 \(N(100,1)\)，要用蒙特卡洛为行权价 110 的数字看涨期权定价：直接模拟会发生什么？如何改进？

    • 你认为 \( \mu=10 \) 是最优的平移参数吗？如何选择方差最小的参数？

    • 能否推导该期权价格的解析公式？

    • 这里能否使用分层抽样？

    解答

    根本困难是几乎所有路径到期时都处于虚值状态。十个标准差上涨的概率极小，约为 \(7\times10^{-24}\)。因此该期权价值几乎为零；用任何现实可行的路径数做朴素蒙特卡洛，估计结果几乎必然是零。

    可以用方差缩减技术解决，最简单的是重要性抽样。目标是计算

    \[ \int f(S_{0}+z)\phi(z)dz \]

    当 \(z<10\) 时，收益函数 \(f\) 为零。令 \(\psi\) 为均值 10、方差 1 的正态密度，把积分改写为

    \[ \int f(S_{0}+z)\frac{\phi(z)}{\psi(z)}\psi(z)d z. \]

    现在从 \(N(10,1)\) 抽取 \(z\)，并把每条路径的收益乘以似然比

    \[ \frac{\phi(z)}{\psi(z)}. \]

    该似然比可化简为

    \[ \frac{e^{-\frac{z^{2}}{2}}}{e^{-\frac{(z-\mu)^{2}}{2}}}=e^{\frac{\mu^{2}}{2}-\mu z} \]

    其中 \(\mu=10\)。这样会显著增加落入实值区域的样本数，同时通过似然比保持估计无偏。

    解析价与最优平移。 若该分布已是风险中性分布且利率为 \(r\)，价格为 \(e^{-rT}\overline\Phi(10)\)，\(\overline\Phi(10)\approx7.6198530\times10^{-24}\)。若仅给历史分布，还不足以唯一推出无套利价格。

    令 \(Z\sim N(\mu,1)\)，不计贴现的无偏样本 \(Y=\mathbf1_{Z>10}e^{-\mu Z+\mu^2/2}\)。配方可得二阶矩

    \[ E_QY^2=e^{\mu^2}\overline\Phi(10+\mu). \]

    均值不随 \(\mu\) 改变，所以最小方差等价于最小此式。对数求导给

    \[ 2\mu=\frac{\phi(10+\mu)}{\overline\Phi(10+\mu)}. \]

    用稳定的正态尾函数和 Mills 比求根，解略大于10，约 \(10.05\)；\(\mu=10\) 只是把一半样本移到尾部的近最优选择。直接计算 \(1-\Phi(20)\) 会舍入为零，应使用 survival/log-survival 函数。

    可以对生成 \(Z\) 的均匀变量分层，使高尾所在层获得样本，并按各层概率加权。若直接条件于 \(Z>10\) 采样，权重恰为已知 \(\overline\Phi(10)\)，得到零方差；但这个例子的答案也已被用来构造采样器，主要用于解释理想重要性分布，复杂衍生品通常无法预先知道归一化常数。

    Q1205 · 热方程的统一差分格式、稳定性与网格选择¶

    难度：★★★｜题型：有限差分与数值方法｜副题型：中心空间差分与Fourier放大因子

    题目：考虑 \(u_t=\nu u_{xx}\)、\(\nu>0\)，在均匀网格求解，初值与两端边界已知。令 \(\alpha=\nu\Delta t/(\Delta x)^2\)。

    1. 写出显式、后向Euler与Crank–Nicolson三种格式，并统一成 \(\vartheta\) 格式。
    2. 推导显式格式的稳定性条件，解释为什么固定时间步下加密空间网格会不稳定。
    3. 比较三种格式的精度、每层成本与稳定性；说明Crank–Nicolson为何仍可能出现振荡。
    解答

    记 \(\delta_{xx}u_j^n=(u_{j-1}^n-2u_j^n+u_{j+1}^n)/(\Delta x)^2\)。\(\vartheta\) 格式为

    \[ \frac{u_j^{n+1}-u_j^n}{\Delta t}=\nu\{(1-\vartheta)\delta_{xx}u_j^n+\vartheta\delta_{xx}u_j^{n+1}\}. \]

    \(\vartheta=0,1,1/2\) 分别是显式、后向Euler和Crank–Nicolson。显式展开为 \(u_j^{n+1}=\alpha u_{j-1}^n+(1-2\alpha)u_j^n+\alpha u_{j+1}^n\)。隐式两种需移项解三对角线性系统；边界值进入首末方程右侧，每层可在线性时间求解。

    稳定性。 对周期或无限均匀网格，把误差写成 \(e^{ij\xi}\)，空间二阶差分给因子 \(-4\sin^2(\xi/2)\)。于是

    \[ G(\xi)=\frac{1-4(1-\vartheta)\alpha\sin^2(\xi/2)}{1+4\vartheta\alpha\sin^2(\xi/2)}. \]

    显式时要求所有 \(|G|\le1\)，最不利频率给 \(0\le\alpha\le1/2\)。此时三个更新权重也非负。固定 \(\Delta t\) 而把 \(\Delta x\) 减半，\(\alpha\) 变成四倍，可能越过稳定界；空间加密需配合 \(\Delta t=O((\Delta x)^2)\)。更多时间步意味着更小 \(\Delta t\)，通常改善稳定性，但增加成本和累计舍入机会。

    当 \(\vartheta\ge1/2\) 时该线性热方程格式无条件稳定；当 \(\vartheta<1/2\) 时需 \(\alpha\le1/[2(1-2\vartheta)]\)。前后向Euler时间一阶、空间二阶；Crank–Nicolson在光滑解下时间、空间均二阶。后者高频放大因子可接近-1，稳定并不意味着不振荡；不光滑期权终值常先做若干后向Euler半步来平滑，再切换Crank–Nicolson。

    在Black–Scholes模型下，可先作变量变换得到热方程，再按支付结构设置终值和空间边界。其他模型可能改变算子、自由边界或障碍条件，不能只改边界便套用同一PDE。

    Q1206 · 无解析公式的希腊字母¶

    难度：★★｜题型：蒙特卡洛｜副题型：共同随机数与中心差分

    题目：若某期权没有闭式定价公式，如何估计它的 delta 和 gamma？

    解答

    用 MC 给三个初始价格分别定价：把当前标的价格从 \( S \) 微调为 \( S \pm \delta S \)（\( \delta S \) 为小的正数），对 \( S-\delta S \)、\( S \)、\( S+\delta S \) 各跑一次 MC，得 \( f(S-\delta S) \)、\( f(S) \)、\( f(S+\delta S) \)：

    \[ \hat\Delta = \frac{f(S+\delta S) - f(S-\delta S)}{2\delta S}\ \text{（中心差分）},\qquad \hat\Gamma = \frac{\big(f(S+\delta S)-f(S)\big)-\big(f(S)-f(S-\delta S)\big)}{\delta S^2} \]

    降方差要点：三个价格必须使用同一组随机数序列（common random numbers），否则差分噪声会淹没信号。

    设三个价格估计的单独方差均约 \(\sigma_f^2/M\)。若独立抽样，中心差分Delta的方差约 \(\sigma_f^2/(2Mh^2)\)，Gamma更可能按 \(1/(Mh^4)\) 放大噪声。共同随机数使相邻价格样本高度相关，差分中共同噪声抵消；是否有效仍取决于收益连续性。中心差分截断偏差为 \(O(h^2)\)（相应导数存在时），所以不能把 \(h\) 无限制缩小。光滑收益可考虑逐路径求导，不连续收益可用似然比或平滑技术。

    难度：★★｜题型：有限差分与数值方法｜副题型：求积误差阶与自适应细分

    题目：写出数值积分算法，并说明如何优化。

    • 该方法的收敛阶是多少？

    • 如何判断数值结果已经收敛？

    • 对哪些函数，该方法可能失效或表现很差？

    • 实现梯形公式。

    • 你最常用哪一种数值积分方法？它如何工作？

    • 如何设计接口，才能避免把被积函数名硬编码在程序中？

    解答

    下面给出一个 C++ 实现，用来对给定函数 \(F\) 做数值积分。

    double F(double x)
{
    // 在这里定义被积函数

    return x*x;
}

double IntegrateF(double a, double b, int N)
{

double result=0.0;
double length=(b-a)/N;

for (int i=0; i<N; ++i)
    result +=F(a+(i+0.5)*length);

result *= length;

return result;
}

    这是最简单的数值积分方法之一：把积分区间等分为 \(N\) 段，在每个子区间的中点计算函数值，求和后再乘以子区间长度。这就是中点公式。

    注意，代码把乘以区间长度的操作放到了循环结束后，而不是每次循环都做。一般优化循环时，应尽量把不随迭代变化的计算移到循环外。还可以预先计算起始中点，并逐次累加 length，从而避免循环中反复计算 \( a+(i+0.5)*length \) 这个表达式。

    对足够光滑的被积函数，复合梯形误差为 \(O(h^2)\)，复合Simpson为 \(O(h^4)\) 且需偶数个小区间；这些阶依赖相应导数存在和有界。自适应Simpson比较一个区间结果与两个半区间结果，差约为细网格误差的15倍，因此用差除15估计误差，再把容差按子区间分配。端点奇异、振荡和不连续处应先分段或变量替换，不能机械套用平滑误差阶。多维积分则需考虑网格点数随维数指数增长，可能改用蒙特卡洛。

    Q1208 · 线性插值程序¶

    难度：★★｜题型：有限差分与数值方法｜副题型：分段一次基函数插值

    题目：写一个做线性插值的程序。

    • 如何自行实现 lower_bound？

    • 如果横坐标等间距，能否在 \(O(1)\) 时间内直接定位区间？

    • 当 \(x\) 超出范围时，外推一定是合理策略吗？还可以采用哪些接口约定？

    • 实现双线性插值算法。

    解答

    假设给定两个等长数组：xs 存放严格递增的横坐标，foxx 存放函数 \(f\) 在这些点上的值。还需明确查询点超出数据范围时的语义；下面选择线性外推。

    问题分为两步：先找出夹住查询点的两个相邻横坐标，再利用这两个点的函数值做线性插值。由于横坐标已经有序，可用二分查找在 \(O(\log n)\) 时间内定位区间。

    下面给出使用 STL 算法与容器的 C++ 实现：

    #include <vector>
#include <algorithm>

double Interpolate(const std::vector<double>& xs,
                           const std::vector<double>& foxx,
                           double x)
{
    std::vector<double>::const_iterator it
        = std::lower_bound(xs.begin() + 1
                                 ,xs.end(), x);

    if (it == xs.end())
        --it;

    --it;

    std::vector<double>::const_iterator it2 = foxx.begin() + (it - xs.begin());

    double xl = *it;
    double fxl = *it2;
    ++it;
    ++it2;
    double xr = *it;
    double fxr = *it2;

    double theta = (x - xl) / (xr - xl);
    double fx = (1.0 - theta) * fxl + theta * fxr;

    return fx;
}

    STL 的 lower_bound 使用二分查找，返回有序区间中第一个大于等于给定值的元素。因为需要查询点两侧的一对相邻元素，搜索从第二个横坐标开始，并把结果向前移动一位。若 \(x\) 大于数组中所有元素，返回的是尾后迭代器，还需额外向前移动。正式实现还应检查数组至少含两个元素、两数组等长且 xs 严格递增。

    找到端点后，计算查询点在区间中的相对位置 \(\theta=(x-x_l)/(x_r-x_l)\)，再用 \((1-\theta)f(x_l)+\theta f(x_r)\) 得到插值或外推结果。

    一般 \(x\in[x_i,x_{i+1}]\) 时，令 \(t=(x-x_i)/(x_{i+1}-x_i)\)，插值为 \((1-t)y_i+ty_{i+1}\)。两权重非负且和为1，故区间内不超出两端值范围。节点严格递增是分母非零的前提；先用二分找到所在区间，复杂度 \(O(\log n)\)。若真函数二阶导有界，误差满足 \(f(x)-L(x)=f''(\xi)(x-x_i)(x-x_{i+1})/2\)，绝对值不超过 \(\|f''\|_\infty h_i^2/8\)。外推不享有区间内凸组合保证。

    Q1209 · 生成正态随机变量¶

    难度：★★｜题型：蒙特卡洛｜副题型：Box–Muller与极坐标拒绝

    题目：若计算机只能生成 \( [0,1] \) 之间的连续均匀随机数，如何生成 \( N(\mu, \sigma^2) \) 随机变量？

    解答

    两步：① 由均匀随机数生成 \( x \sim N(0,1) \)；② 缩放 \( x \to \mu + \sigma x \)。第二步平凡，第一步有两种方法：

    方法一：逆变换法。对任意连续随机变量 \( X \)（cdf 为 \( F \)），令 \( U = F(X) \)，则 \( X = F^{-1}(U) \) 服从该分布（\( U \in [0,1] \) 均匀）。步骤：抽 \( u \sim U(0,1) \)；解 \( u = F(x) \) 得 \( x \)。要求 \( F^{-1} \) 可计算。对标准正态 \( F(x) = \int (1/\sqrt{2\pi})e^{-x^2/2}\,dx \) 没有解析逆——理论上可用数值积分（Euler 法，从 \( F(0) = 0.5 \) 起步迭代 \( F(x_i+h) = F(x_i) + f(x_i)h \)）逼近，但效率低于：

    方法二：接受-拒绝法。用有解析逆的密度 \( g(y) \)（如指数分布 \( \lambda=1 \)：\( u = 1 - e^{-x} \Rightarrow x = -\ln(1-u) \)）作辅助。设常数 \( M \) 满足 \( f(y)/g(y) \le M \) 对一切 \( y \)。步骤：

    1. 从 \( g(y) \) 抽 \( y \)、从 \( U(0,1) \) 抽 \( v \)；
    2. 若 \( v \le f(y)/(Mg(y)) \)，接受 \( x = y \)；否则回到第 1 步。

    （接受概率 \( \propto f(y)/g(y) \)，保证被接受的样本服从目标密度。）先在 \(x>0\) 上生成半正态变量，再用一个独立公平比特随机赋予正负号。对半正态密度与指数辅助分布：

    \[ \frac{f(x)}{g(x)} = \sqrt{\frac{2}{\pi}}e^{x - x^2/2} \le \sqrt{\frac{2}{\pi}}e^{1/2} \approx 1.32,\quad \forall x > 0 \]

    取 \( M = 1.32 \)，接受后独立随机取正负号，便得到 \( N(0,1) \) 变量，再缩放为 \( N(\mu, \sigma^2) \)。

    Q1210 · 每个高斯抽样消耗多少均匀抽样¶

    难度：★★★｜题型：蒙特卡洛｜副题型：接受概率与几何抽样成本

    题目：给出的 C++ 代码从标准高斯分布（均值 0、标准差 1）中抽样。估计每个高斯抽样平均消耗多少个均匀抽样。

    #include <cmath>

// 返回一个均匀随机数，并更新种子
double drawUniform(long& seed);

// 生成一个标准正态随机数
double drawGaussian(long& seed)
{
    static bool drawNotDone=true;
    static double otherDraw;
    double factor, rSquared, x, y;
    if (drawNotDone)
    {
        do
        {
            x = 2.0 * drawUniform(seed) - 1.0;
            y = 2.0 * drawUniform(seed) - 1.0;
            rSquared = x * x + y * y;
        }
        while (rSquared >= 1.0 || rSquared == 0.0);
        factor = sqrt(-2.0 * log(rSquared) / rSquared);
        otherDraw = x * factor;
        drawNotDone=false;
        return y * factor;
    }
    else
    {
        drawNotDone=true;
        return otherDraw;
    }
}
    • 如何只用两个均匀随机数直接生成单位圆内的均匀点，而不使用接受—拒绝法？
    • 该方法适合直接配合低差异序列吗？拒绝步骤会带来什么问题？
    • 你还知道哪些生成正态随机数的方法？
    • 实际应用中你会选哪种方法？依据是什么？
    解答

    这段代码采用 Marsaglia 极坐标法，把一对独立均匀随机数变换成两个相互独立的标准正态样本。它先把均匀数映射到 \([-1,1]^2\)；若点落在单位圆外或恰在原点，就拒绝该点并重新抽取。

    在原始 \([0,1]^2\) 坐标中，接受区域等价于以 \((0.5,0.5)\) 为圆心、半径 \(0.5\) 的圆；方形面积为 1，因此一对均匀样本被接受的概率是

    \[ \pi\left(\frac{1}{2}\right)^{2}=\frac{\pi}{4}. \]

    每次尝试消耗 2 个均匀样本，接受后产生 2 个正态样本。每个正态样本平均消耗的均匀样本数因此为

    \[ \frac{4}{\pi}\sim1.27. \]

    为什么该变换给出独立正态。 接受后 \((x,y)\) 在单位圆内按面积均匀，所以 \(R^2=x^2+y^2\) 在 \((0,1)\) 均匀，角度 \(\Theta\) 在 \([0,2\pi)\) 均匀且与 \(R^2\) 独立。乘以代码中的因子后，新半径为 \(\sqrt{-2\log R^2}\)，其径向密度为 \(re^{-r^2/2}\)。配上均匀角度，平面密度为 \((2\pi)^{-1}e^{-(z_1^2+z_2^2)/2}\)，正好分解成两个标准正态密度。\(4/\pi\) 是包含缓存配对后的长期均值；刚好调用一次且缓存为空，期望消耗是 \(8/\pi\)。

    不拒绝的圆内抽样。 对独立 \(U,V\sim U(0,1)\)，令

    \[ R=\sqrt U,\quad\Theta=2\pi V,\quad (X,Y)=(R\cos\Theta,R\sin\Theta). \]

    有 \(P(R\le r)=r^2\)，所以圆内按面积均匀；若误用 \(R=U\)，点会在圆心附近过密。再作同一径向变换就成为 Box–Muller：

    \[ Z_1=\sqrt{-2\log U}\cos(2\pi V),\quad Z_2=\sqrt{-2\log U}\sin(2\pi V). \]

    每对恰用两个均匀数；实现时应保证用于对数的 \(U\) 严格大于零。

    低差异序列。 接受—拒绝消耗的坐标数量随机变化，会打乱“某一维对应某个因子或时点”的固定映射，不能直接继承原序列的低差异保证。固定维度的逆正态分布函数变换常更适合准蒙特卡洛；Box–Muller 也保持固定的二维映射，但端点奇异性及被积函数的平滑性仍影响效果，并非换一个变换就保证误差更低。

    方法选择与随机流状态。 常见方法还包括逆 CDF、有理函数近似、Ziggurat 分层拒绝法以及库提供的正态分布生成器。大批量普通 Monte Carlo 可基于准确度和目标硬件实测选择极坐标法或 Ziggurat；准 Monte Carlo 通常优先考虑逆 CDF，并结合 Brownian bridge/PCA 调整有效维数。题给代码的 static 缓存由所有调用者共享：切换种子会取出另一条随机流的缓存值，并发调用还会产生数据竞争。应把种子及缓存放进同一个独立生成器对象，使每条随机流拥有自己的状态，再测试尾部精度、可复现性和吞吐量。

    Q1211 · 用均匀随机数抽取任意离散分布¶

    难度：★★★｜题型：随机与在线算法｜副题型：逆CDF抽样与重要性权重

    题目：设资产取离散值 \(v_j\)、对应概率 \(p_j\)。写一个从均匀分布随机变量生成该资产随机变量的算法。

    假设 \(N\) 很大，如何得到更快的算法？

    • 如何测试这个抽样算法？

    • 给出一种利用整数随机数生成器产生均匀分布随机变量的算法。

    • 你倾向使用哪一种整数随机数生成器？为什么？

    • 使用随机数生成器时可能遇到哪些问题？

    解答

    下面给出一个 C++ 实现。示例使用 xlw 项目中的简单数组类，也可以换成任何合适的向量容器。

    double Simulate(const MyArray& p,
                           const MyArray& v,
                           double u)
{
    int i=0;

    while (u >= p[i])
    {
        u-= p[i];
        ++i;
    }

    return v[i];
}

    本质上，要找的是第一个使累计概率超过 \(u\) 的下标 \(i\)。代码没有显式保存所有累计概率，而是依次从 \(u\) 中减去各事件概率，直到剩余值落入当前事件对应的区间。

    若可能事件数为 \(N\)，该算法的时间复杂度为 \(O(N)\)，额外空间复杂度为 \(O(1)\)。实现时还应校验 p、v 长度一致、概率非负且总和为 1，并防止下标越界。

    大 \(N\) 与边界实现。 预计算累计和 \(F_j=\sum_{i\le j}p_i\) 用 \(O(N)\) 时间和空间，每次用二分查第一个 \(F_j>u\)（\(u\in[0,1)\)），采样 \(O(\log N)\)。严格大于可避开 \(u=0\) 时抽到零概率类别。需大量重复抽同一分布时，用 alias 表作 \(O(N)\) 预处理，再用均匀桶号和桶内一次比较，均摊每样本 \(O(1)\)；分布频繁改变时则可用前缀和树支持 \(O(\log N)\) 更新与抽样。

    验证与随机源。 先检查概率和、零概率项、单点分布及 \(u=0\)、接近1、恰好等于累计边界等输入；对固定种子作可复现实验，再以经验频率及卡方检验检查分布，期望频数过小的桶要合并或采用精确方法。频率接近不能证明随机数独立，还应检查自相关和不同流的相关性。

    均匀 \(b\) 位整数 \(J\in\{0,\ldots,2^b-1\}\) 可构造 \(U=J/2^b\)，它是 \([0,1)\) 上的均匀离散网格；连续均匀只能在有限精度意义近似。双精度可取53个随机位。生成有界整数不能随意 J % N，除非 \(N\mid2^b\)，否则要拒绝超出最大整倍数区间的值以消除模偏差。

    一般仿真可选经过统计检验、周期充足且支持独立子流的 PCG 或 counter-based Philox；std::mt19937 可作可复现基线，安全用途应另选密码学随机源。记录种子与生成器版本，避免每次抽样重新播种；并行时明确分流，拒绝采样与有限周期也会影响质量。

    Q1212 · 高效计算矩阵指数¶

    难度：★★★｜题型：有限差分与数值方法｜副题型：缩放平方与Padé逼近

    题目：如何高效地计算矩阵指数 \(e^A\)？

    • 什么是最小多项式？它与特征多项式有什么关系？

    • 如何计算 \(\sin(A)\)？

    • 对一般矩阵 \(A\)，证明

    \[ \cos^{2}(A)+\sin^{2}(A)=I. \]
    解答

    这道题比表面上复杂，矩阵指数的高效、稳定计算至今仍有丰富研究。这里给出定义、基本方法以及实际计算时的重要注意点。

    先从定义出发。矩阵的解析函数可由幂级数定义；对矩阵 \(A\)，有

    \[ \exp(A)=\sum_{j=0}^{\infty}\frac{A^{j}}{j!}. \]

    这个级数总是收敛。利用算子范数 \(\|A\|\) 可作如下估计：

    \[ \left|\left|\sum_{j=M}^{N}\frac{A^{j}}{j!}\right|\right|\leq\sum_{j=M}^{N}\frac{||A||^{j}}{j!}. \]

    由于标量级数 \(\exp(\|A\|)\) 收敛，上式的部分和构成 Cauchy 序列，因而矩阵级数收敛。有限维空间中的范数彼此等价，所以选用哪一种矩阵范数都不影响收敛结论。

    因此，最朴素的方法是不断计算 \(A\) 的幂并累加各项，直到严格的余项上界足够小。但当矩阵范数较大时，直接求和既低效又可能数值不稳定；实际数值库通常采用“缩放与平方”结合 Padé 逼近，或采用基于 Schur 分解的方法。

    如果矩阵可对角化，还可以写成

    \[ A=PDP^{-1}. \]

    其中 \(P\) 的列构成一组特征向量基，\(D\) 为对角矩阵。于是

    \[ A^{j}=PD^{j}P^{-1}, \]

    以及

    \[ \exp(A)=P\exp(D)P^{-1}. \]

    \(D\) 的指数很容易计算：只需分别对每个对角元取指数。并非所有矩阵都可对角化，但每个实对称矩阵都可以；此时 \(P\) 可取为正交矩阵，故 \(P^{-1}=P^T\)。若特征向量矩阵病态，直接对角化也可能放大数值误差。

    另一条思路是使用 Cayley–Hamilton 定理：矩阵满足自身的特征多项式 \(p\)。特征多项式定义为

    \[ p(\lambda)=\det(\lambda I-A), \]

    它是 \(n\) 次多项式，其根就是矩阵的特征值。由于

    \[ p(A)=0, \]

    必有

    \[ A^{n}=\sum_{j<n}c_{j}A^{j}. \]

    因此，所有不低于 \(n\) 次的矩阵幂都能化为低次幂的线性组合，\(\exp(A)\) 也可写成关于 \(A\) 的次数低于 \(n\) 的多项式；其系数由 \(A\) 的谱及其重数结构决定。可以直接求这些系数，也可以针对具体矩阵推导。

    可实施的缩放与平方。 选 \(s\ge0\)，使 \(B=A/2^s\) 的范数落在所用 Padé 阶数的可靠区间；用有理逼近 \(r_m(B)=p_m(B)q_m(B)^{-1}\) 近似 \(e^B\)。实现时解线性方程 \(q_m(B)X=p_m(B)\)，不要显式求逆。然后重复 \(X\leftarrow X^2\) 共 \(s\) 次，利用 \(e^A=(e^B)^{2^s}\)。阶数和缩放量应按误差界选择，过度缩放也会积累舍入误差。大型稀疏问题若只需 \(e^Av\)，可用 Krylov 子空间计算其对向量的作用，避免生成稠密的整个指数矩阵。

    最小多项式。 \(m_A\) 是使 \(m_A(A)=0\) 的最低次数首一多项式。Cayley–Hamilton 保证它存在。用多项式带余除法 \(p_A=q m_A+r\)，\(\deg r<\deg m_A\)；代入 \(A\) 得 \(r(A)=0\)，由最小性只能有 \(r=0\)。故 \(m_A\mid p_A\)。它含有所有特征值，但每个特征值的指数等于该特征值最大 Jordan 块的大小，而非其代数重数。例如 \(A=\lambda I\) 时 \(m_A(z)=z-\lambda\)，特征多项式却是 \((z-\lambda)^n\)。

    若 \(m_A(z)=\prod_\lambda(z-\lambda)^{s_\lambda}\)，解析函数 \(f(A)\) 等于唯一的次数小于 \(\deg m_A\) 的多项式 \(r(A)\)，其中

    \[ r^{(j)}(\lambda)=f^{(j)}(\lambda),\qquad 0\le j<s_\lambda. \]

    这是 Hermite 插值；导数条件解释了为什么有非平凡 Jordan 块时，仅在特征值上匹配函数值还不够。

    \(\sin A\) 和恒等式。 可以用绝对收敛级数

    \[ \sin A=\sum_{k\ge0}\frac{(-1)^kA^{2k+1}}{(2k+1)!},\qquad \cos A=\sum_{k\ge0}\frac{(-1)^kA^{2k}}{(2k)!}, \]

    也可用 Schur 分解或上述 Hermite 插值；实对称阵可直接正交对角化。令 \(E=e^{iA}\)、\(F=e^{-iA}\)，绝对收敛与 \(iA,-iA\) 可交换给出 \(EF=FE=I\)。于是

    \[ \cos A=\tfrac12(E+F),\quad \sin A=\tfrac1{2i}(E-F),\quad \cos^2A+\sin^2A =\tfrac14[(E+F)^2-(E-F)^2]=I. \]

    这里从未要求 \(A\) 可对角化；一般不同矩阵的指数不能直接这样相乘，但同一矩阵的函数彼此可交换。

    Q1213 · 测度变换及其在蒙特卡洛中的用途¶

    难度：★★★★｜题型：蒙特卡洛｜副题型：Radon–Nikodym与Girsanov变换

    题目：解释什么是测度变换（change of measure），并举例说明它在蒙特卡洛中何时有用。

    • 在上例中，直接计算说明新测度下的期望仍给出正确结果。

    • 能否把一个正态分布测度变换成 Poisson 分布？为什么？

    • 把正态分布变换成 Cauchy 分布所需的 Radon–Nikodym 导数是什么？

    • 为什么测度变换通常只能改变 Itô 过程的漂移，而不能改变其扩散项？

    • 把随机微分方程

    \[ d X_{t}=\mu(X_{t})d t+\sigma d W_{t} \]

    变换为

    \[ d X_{t}=\alpha(X_{t})d t+\sigma d W_{t} \]

    所需的 Radon–Nikodym 导数是什么？要使测度变换适用于这两个过程，该导数需要满足什么条件？

    解答

    测度变换是以新的概率权重描述同一可测事件。它可强调某些收益或路径，但必须保持同一可测空间，并使原测度下不可能的事件在新测度下仍不可能。

    数学上，设概率空间 \((\Omega,\mathcal F,\mathbb P)\) 上有正随机变量 \(X\) 且 \(\mathbb E[X]=1\)，定义新测度 \(\mathbb Q\)：

    \[ \mathbb{Q}(A)=\mathbb{E}[\mathbb{1}_{A}X]=\int_{A}X d P, \]

    对 \(A\in\mathcal F\)。则 \(\mathbb Q\) 关于 \(\mathbb P\) 绝对连续：

    \[ \mathbb{P}(A)=0\Rightarrow\mathbb{Q}(A)=0. \]

    \(X\) 称为 Radon–Nikodym 导数，常记为 \(dQ/dP\)。Radon–Nikodym 定理表明，任意关于 \(\mathbb P\) 绝对连续的测度都可用这种（几乎处处唯一的）导数表示。

    若 \(P,Q\) 互相绝对连续，则称二者等价，且有

    \[ \frac{d\mathbb{P}}{d\mathbb{Q}}=\left(\frac{d\mathbb{Q}}{d\mathbb{P}}\right)^{-1} \]

    衍生品定价中，Girsanov 定理用于改变布朗运动漂移。设 \(X_t\) 为正鞅且 \(\mathbb E[X_T]=1\)，则在 \(\mathcal F_t\) 上定义

    \[ \mathbb{Q}_{t}(A)=\mathbb{E}_{\mathbb{P}_{t}}[\mathbb{1}_{A}X(t)], \]

    其中 \(A\in\mathcal F_t\)，而 \(X_t=d\mathbb Q_t/d\mathbb P_t\)。Girsanov 定理的核心如下：

    （Girsanov 定理）设 \(\gamma\) 是满足一定条件的适应过程，定义

    \[ X_{t}=\exp\left(-\frac{1}{2}\int_{0}^{t}|\gamma(u)|^{2}d u+\int_{0}^{t}\gamma(u)d W(u)\right). \]

    若 \( \mathbb{E}_{\mathbb{P}}[X_{T}]=1 \)，则 \( X_{t} \) 是鞅，并定义新测度 \( \mathbb{Q} \)，其中

    \[ \frac{d\mathbb{Q}}{d\mathbb{P}}=X(T). \]

    在 \(Q\) 下，过程

    \[ W_{t}^{\mathbb{Q}}=W_{t}-\int_{0}^{t}\gamma(u)d u \]

    为标准布朗运动。

    即测度变换可把漂移移入密度过程，使 \(W_t^{\mathbb Q}\) 无漂移。

    作为测度变换在蒙特卡洛中的一个应用，我们来看重要性抽样（importance sampling）。这里的目标是用测度变换降低样本方差。基本想法是：有些生成的路径对最终结果（通常是某个期望）影响很小，花时间生成这些路径基本是浪费；重要性抽样让影响更大的路径更可能被抽到。

    下面看一个简单（其实无需蒙特卡洛也能直接算出期望）但足以说明问题的例子。

    设在适当的风险中性测度下（利率为零），股票终值在区间 \((0,1)\) 上均匀分布，即 \(S_T \sim U(0,1)\)，记该测度为 \(P\)。考虑该股票上的一个数字期权：若 \(T\) 时刻股价高于水平 \(a\in(0,1)\) 则支付 1，否则支付 0。记该期权价值为 \(C\)，则

    \[ C=\mathbb{E}_{\mathbb{P}}\big(\mathbb{1}_{\{S_{T}>a\}}\big)=\int_{0}^{1}\mathbb{1}_{\{z>a\}}d z. \]

    标准蒙特卡洛方法是模拟 \(n\) 个 \(U(0,1)\) 随机变量，数出其中大于 \(a\) 的个数再除以 \(n\)。若 \(\hat{C}\) 是这个蒙特卡洛估计量，则

    \[ \hat{C}=\frac{1}{n}\sum_{k=1}^{n}\mathbb{1}_{\{U_{k}>a\}}, \]

    其中 \( U_{k} \) 是独立同分布的 \(U(0,1)\) 随机变量。

    其方差可由 \(\mathbf1_{\{U_k>a\}}^m=\mathbf1_{\{U_k>a\}}\)（对任意正整数 \(m\)）得到：\(\operatorname{Var}(\hat C)=a(1-a)/n\)。

    现在考虑改变所用测度。在当前测度下模拟，只有终值落在区间 \( (a,1) \) 内时结果才非零，所以把测度改为更强调分布中“期权有价值”的重要部分。用如下密度定义新测度：

    \[ f(x)=\begin{cases}\frac{\alpha}{a},&0\leq x\leq a,\\\frac{1-\alpha}{1-a},&a\leq x\leq1,\end{cases} \]

    其中 \( 0 < \alpha < 1 \)。它把概率 \( 1 - \alpha \) 放到期权有价值的区域。新测度 \(Q\) 关于 \( \mathbb{P} \) 的 Radon–Nikodym 导数为 \(f(x)\)（因为旧密度为 1）。于是

    \[ \begin{aligned}{C=\mathbb{E}_{\mathbb{P}}\big(\mathbb{1}_{\{S_{T}>a\}}\big)}&{{}=\mathbb{E}_{\mathbb{Q}}\left(\mathbb{1}_{\{S_{T}>a\}}\frac{d\mathbb{P}}{d\mathbb{Q}}\right)}\\ {}&{{}=\frac{1-a}{1-\alpha}\mathbb{E}_{\mathbb{Q}}\big(\mathbb{1}_{\{S_{T}>a\}}\big).}\\ \end{aligned} \]

    在模拟中使用这个测度变换，得到估计量

    \[ \hat{C}_{2}=\frac{1-a}{1-\alpha}\frac{1}{n}\sum_{k=1}^{n}\mathbb{1}_{\{U_{k}^{*}>a\}}, \]

    其中 \( U_{k}^{*} \) 的密度为 \( f(x) \)。其方差为

    \[ \mathrm{Var}(\hat{C}_{2})=\frac{1}{n}\frac{(1-a)^{2}}{1-\alpha}\alpha, \]

    当

    \[ \frac{1-a}{a}<\frac{1-\alpha}{\alpha} \]

    即 \(\alpha<a\) 时，它小于 \(\hat{C}\) 的方差（这为什么并不意外？为什么不能取 \(\alpha = 1\)？）。

    虚值期权的重要性抽样。 设

    \[ S_T=S_0e^{(r-\sigma^2/2)T+\sigma\sqrt T Z},\qquad Z\sim N(0,1). \]

    看涨期权实值的条件为 \(Z>z_K\)，其中

    \[ z_K=\frac{\log(K/S_0)-(r-\sigma^2/2)T}{\sigma\sqrt T}. \]

    改为在 \(Q\) 下抽取 \(Z\sim N(z_K,1)\)，恰有一半样本落入实值区域。收益乘以密度比

    \[ \frac{dP}{dQ}(Z)=e^{-z_KZ+z_K^2/2} \]

    后保持原期望，再乘贴现因子即可估计期权价格。改变的是标准化正态变量的抽样均值；在股价过程上，对应的对数漂移增量为 \(\sigma z_K/\sqrt T\)。

    分布之间的测度变换。 正态实随机变量在原测度下落在整数集的概率为零，绝对连续换测度后该事件仍概率零，因此不能把同一个变量改成整数上全质量的 Poisson 分布。用逆 CDF 把正态变量变换为 Poisson 变量是改变随机变量的映射，属于另一种操作。

    标准正态密度为 \(\phi(x)\)，标准 Cauchy 密度为 \(c(x)=1/[\pi(1+x^2)]\)，二者在实轴均正，故

    \[ \frac{dQ}{dP}(X)=\frac{c(X)}{\phi(X)} =\frac{\sqrt{2\pi}e^{X^2/2}}{\pi(1+X^2)}, \qquad E_P[dQ/dP]=\int c(x)dx=1. \]

    若用于重要性抽样，\(Q\) 下估 \(P\) 的期望需乘相反方向的 \(dP/dQ=\phi/c\)，不可把方向写反。

    对 \(dX=\mu(X)dt+\sigma dW^P\)，\(\sigma\ne0\)，令 \(\gamma_t=[\alpha(X_t)-\mu(X_t)]/\sigma\)，则

    \[ Z_T=\frac{dQ}{dP}\bigg|_{\mathcal F_T} =\exp\!\left(\int_0^T\gamma_t dW_t^P-\frac12\int_0^T\gamma_t^2dt\right). \]

    若 \(\gamma\) 可预测、局部平方可积且 \(Z\) 是期望1的真鞅，例如满足 Novikov 条件 \(E_Pe^{\frac12\int_0^T\gamma_t^2dt}<\infty\)，则 \(W^Q=W^P-\int\gamma dt\) 为 \(Q\)-Brownian，代回即得漂移 \(\alpha\)。扩散不能随意改变，因为同一条连续路径的二次变差 \([X]_t=\int_0^t\sigma^2ds\) 是路径性质，等价测度不能改变它几乎处处的值。局部指数鞅若严格局部、期望小于1，就不能直接充当概率密度。

    重要性抽样的均值与方差。 \(Q(U>a)=1-\alpha\)，样本值是 \((1-a)\mathbf1_{U>a}/(1-\alpha)\)，其均值 \(1-a\)，方差 \((1-a)^2\alpha/(1-\alpha)\)。比朴素方差 \(a(1-a)\) 更小当且仅当 \(\alpha<a\)，应把更多质量移到尾区，而不是增大 \(\alpha\)。\(\alpha=1\) 完全不采尾区，丢失目标贡献且权重分母为零；\(\alpha\downarrow0\) 的条件尾抽样可达零方差，这个简单例子本来已知道精确尾概率，不能把它当普遍可实施的免费方法。

    难度：★｜题型：C++ 语言｜副题型：工具链比较与项目证据

    Q1217 · 子对象构造、逆序析构与作用域时机¶

    难度：★★｜题型：C++ 语言｜副题型：子对象依赖、声明顺序与栈展开

    题目：对含继承与成员对象的类型，先给出一般构造、析构顺序，再分析代码。

    1. 若派生类继承基类、又含多个成员，子对象顺序由什么决定，为什么不能由初始化列表任意改变？
    2. 说明下列程序的六行输出；删除 Gamma c 外的内层花括号后，析构输出在什么时候发生？
    3. 说明构造中途失败或构造/析构期间调用虚函数时，哪些完整对象性质尚不成立。
    #include <iostream>
using namespace std;

class Alpha
{
public:
    Alpha()
    {
        cout << "创建 Alpha" << endl;
    }
    ~Alpha()
    {
        cout << "销毁 Alpha" << endl;
    }
};

class Beta
{
public:
    Beta()
    {
        cout << "创建 Beta" << endl;
    }
    ~Beta()
    {
        cout << "销毁 Beta" << endl;
    }
};

class Gamma : public Alpha
{
public:
    Gamma()
    {
        cout << "创建 Gamma" << endl;
    }
    ~Gamma()
    {
        cout << "销毁 Gamma" << endl;
    }
private:
    Beta b;
};

int main()
{
    {
        Gamma c;
    }

    char d;
    cin >> d;
    return 0;
}
    解答

    1. 顺序由依赖确定。 最派生对象先构造虚基类（按规定的遍历顺序），再按基类列表构造直接基类，再按类内声明顺序构造成员，最后执行派生类构造函数体。析构依次执行派生类析构函数体、逆序成员析构、逆序基类析构。写初始化列表时调换名字不会调换声明顺序，应避免成员初始化依赖尚未完成的后继成员。

    2. 具体输出。 代码依次输出创建Alpha、创建Beta、创建Gamma、销毁Gamma、销毁Beta、销毁Alpha。进入Gamma函数体前，Alpha基类与Beta成员已经存在；执行Gamma析构体时二者仍然可用。内层块使 c 在读取字符之前销毁；移除内层块后，c 存活到main退出，三行销毁信息会在输入完成后输出。

    3. 未完成对象与虚分派。 构造抛异常时，完整对象没有建立，因此不会调用它自身的析构函数；仅逆序销毁已经构造成功的子对象。构造或析构期间，虚调用不会进入尚未构造或已经销毁的更派生覆盖函数。逆序销毁正是为使较晚构造对象在清理时仍可依赖较早构造的基础部分。

    Q1218 · 构造函数中抛异常¶

    难度：★★｜题型：C++ 语言｜副题型：构造不变量与RAII展开

    题目：C++ 中允许在构造函数里抛异常吗？说明理由。

    • 类的基类和数据成员按什么顺序构造？

    • 若尝试分配超过可用内存的数组，会发生什么？

    解答

    可以在构造函数中抛出异常，而且这是报告对象无法成功建立不变量的标准方式。回答时应把重点放在对象生命周期、已构造成员的清理和 RAII，而不是简单地说“可以”或“不可以”。

    关键事实是：若构造过程中抛出异常，完整对象从未构造成功，所以不会调用该对象自身的析构函数；但已经成功构造的基类子对象和数据成员会按逆序自动析构。如果异常发生在构造函数体内，则此前完成构造的成员都能正常清理。

    真正的风险来自手工取得但尚未交给 RAII 对象管理的资源：由于外层对象的析构函数不会运行，这些裸资源可能泄漏。

    因此，只要保证异常路径上所有资源都能释放，就可以安全抛出。最稳妥的做法是让标准容器、智能指针、锁守卫等 RAII 类型直接充当数据成员，避免用裸指针表示所有权。

    构造函数没有返回值，若禁止抛异常，报告构造失败会很别扭。工厂函数可以返回携带错误的结果类型；普通构造函数则通常用异常表示失败，并依靠 RAII 清理已经完成的子对象。

    普通 new T[n] 无法分配内存时通常抛 std::bad_alloc，长度无效还可能抛 std::bad_array_new_length；new(std::nothrow) 的分配失败返回空指针，但构造函数自身抛出的异常仍会传播。多个子对象先按虚基类、直接基类、成员声明次序构造，异常时只逆序销毁已完成的部分。

    Q1219 · 析构函数中抛异常¶

    难度：★★｜题型：C++ 语言｜副题型：noexcept与栈展开

    题目：C++ 中允许在析构函数里抛异常吗？说明理由。

    • 数据成员与基类按什么顺序析构？为什么这样安排？

    • 代码具备异常安全性是什么意思？基本保证、强保证和不抛保证分别是什么？

    解答

    析构函数不应让异常逸出。现代 C++ 中析构函数通常隐式为 noexcept，违反这一约定会终止程序。

    根本原因是：已有异常传播时，栈展开会销毁当前作用域中的自动对象；如果其中某个析构函数又抛出异常，就会在处理一个异常的同时出现第二个未处理异常，程序将调用 std::terminate。

    因此，析构函数应捕获并在内部处理可能失败的清理操作，或把可能失败的动作放到可显式调用、能报告错误的成员函数中；不得让异常越过析构函数边界。

    异常安全的基本保证是失败后没有资源泄漏、对象仍满足有效不变量；强保证是在失败时可观察状态不变，如“先构造副本、成功后交换”；不抛保证是该操作不向外传播异常。它们不等同于“有catch语句”。析构时先执行派生类函数体，再逆序销毁成员与基类，保证较晚构造的对象销毁时仍能依赖较早构造的子对象。

    Q1220 · 捕获代码中抛出的所有异常¶

    难度：★★｜题型：C++ 语言｜副题型：异常传播与重新抛出

    题目：如何编写代码来捕获一段代码中抛出的所有异常？

    • 什么是异常安全？

    如何保留原异常对象并重新抛出？throw; 与 throw e; 有什么区别？

    • 若在处理 X 类型异常时又抛出 Y 类型对象，哪些处理器可能捕获 Y？
    解答

    把可能抛出异常的代码放入 try 块，并在最后添加 catch (...)，即可捕获任意 C++ 异常：

    try {
    // 可能抛出异常的代码
} catch (...) {
    // 统一处理，或使用 throw; 保留原异常重新抛出
}

    通常应先捕获能够有意义处理的具体异常类型，并按 const 引用接收，把 catch (...) 作为最后防线。它不能捕获进程崩溃、未定义行为或操作系统层面的所有故障。

    在处理器中单独写 throw; 会重新抛出当前异常，保留其动态类型；写 throw e; 会构造一个新的异常对象，若 e 的静态类型为基类，可能发生切片。某个 catch(X) 内抛出的 Y 不会交给与它并列的后续catch处理，而是继续向包围该处理器的外层try传播；若处理器内部再建嵌套try，才可先由内层处理。跨作用域保存当前异常可用 std::exception_ptr 与 std::current_exception()。

    Q1221 · 内联函数与宏的区别¶

    难度：★★｜题型：C++ 语言｜副题型：预处理展开与ODR内联

    题目：C++ 中内联函数与宏有什么区别？

    • 哪些场景确实需要宏？

    • 什么时候适合把函数或方法定义为内联？

    • 使用宏有哪些危险？

    解答

    这道题容易让人误以为二者很相似，实际上它们只是在某些场景下都能减少显式函数调用；其语义和处理阶段完全不同。

    inline 关键字的主要语言语义，是允许同一定义按单一定义规则出现在多个翻译单元中。编译器可以展开带或不带 inline 的函数调用；是否内联展开属于优化决定，并非关键字作出的保证。

    还需注意：

    • 对是否展开调用而言，它至多是提示，不是命令；

    • 过度展开可能增大机器码体积；

    • 定义通常放在头文件中供各翻译单元使用，修改后可能触发大范围重新编译，并把其编译期依赖传给调用方；

    • 好处是编译器看到调用上下文后，可能继续做常量传播、消除分支等优化。

    在符合规则的程序中，增加或删除函数调用的内联展开不应改变可观察行为，只可能影响性能与代码体积。

    宏由预处理器在正式编译前按记号进行替换，不具备普通函数的类型检查、作用域和参数求值语义，因此更容易出现重复求值、运算符优先级、名称冲突等问题。能用 constexpr、模板或普通函数解决时，通常应避免函数式宏。

    二者有限的共同点是：都能把短小逻辑写在一个地方，并有机会避免运行时函数调用开销，而不必在源代码中手工复制逻辑。

    宏的具体风险如 #define SQUARE(x) ((x)*(x))：调用 SQUARE(i++) 重复求值，括号也不能解决副作用。确需预处理的场景包括头文件保护、条件编译、字符串化和记号拼接；普通常量宜用 constexpr，泛型逻辑宜用模板。短小且定义适合放在头文件的函数可标inline，但性能取舍仍应由剖析决定，不能用关键字保证机器码展开。

    Q1222 · 函数指针的声明语法¶

    难度：★★｜题型：C++ 语言｜副题型：声明优先级与成员函数指针

    题目：写出 C++ 声明函数指针的语法。

    • 如果 MyFunction 接收 const B&，还能赋给上述函数指针吗？

    • 若目标是类的非静态成员函数，函数指针语法是什么？

    你认为函数指针在 C++ 中有哪些用途？

    解答

    若要声明名为 MyPointer 的函数指针，使其指向“接收一个 B 类型参数并返回 A 类型对象”的函数，语法是

    A (*MyPointer)(B);

    指针名和星号外的括号不可省略。若要让它指向函数 MyFunction，可以写成

    A MyFunction(B);

void f()
{
    A (*MyPointer)(B);
    MyPointer = &MyFunction;
}

    现代 C++ 还可用 using FunctionPtr = A (*)(B); 简化声明；若需要保存捕获型 lambda 或其他可调用对象，可考虑 std::function。

    若目标函数参数是 const B&，指针类型必须相应为 A (*)(const B&)，不能赋给接收 B 值的函数指针。非静态成员函数需保留所属类，如 A (Owner::*p)(B) = &Owner::method;，调用为 (obj.*p)(arg) 或 (ptr->*p)(arg)；常量成员函数类型还要在括号后加 const。静态成员函数没有隐式对象参数，可作为普通函数指针。常见用途是回调、策略分派和与C接口交互。

    Q1223 · C++ 函数的 \(C\) 链接语法¶

    难度：★★｜题型：C++ 语言｜副题型：语言链接与符号名称

    题目：让 C++ 函数采用 \(C\) 语言链接约定的语法是什么？

    • 为什么需要 extern "C"？它影响名称改编、类型系统与调用约定中的哪些部分？

    解答

    语法如下：

    extern "C"
{
    // 需要采用 C 语言链接约定的函数声明
}

    例如 extern "C" int price(double); 为函数声明C语言链接，主要用于与C编译模块或按C符号查找的动态库互操作。它通常使链接名不采用C++重载名称改编，但不把函数体切换为C语法，也不自动使所有C++类型跨ABI安全。不同平台的调用约定仍取决于目标ABI和附加声明。C语言链接函数不能靠C++参数重载区分同一外部名。普通 extern 还可声明在其他翻译单元定义的变量或函数；它和语言链接的双引号语法属于不同用途。

    Q1224 · 复制类型未知的多态对象¶

    难度：★★｜题型：C++ 语言｜副题型：虚拟clone与所有权转移

    题目：如何复制一个类型未知的多态对象？

    • 返回类型应使用智能指针还是裸指针？

    • 如何管理新对象的生命周期？

    • 为什么不能直接按值返回基类对象放在栈上？这会涉及什么对象切片问题？

    解答

    这是经典的多态复制问题。普通构造函数不能声明为虚函数，但可以在基类中定义虚拟的克隆成员函数，从而达到“虚构造”的效果。

    在基类中声明虚拟克隆操作，并由每个派生类覆盖；现代 C++ 应返回表示所有权的智能指针：

    virtual std::unique_ptr<Base> clone() const = 0;

std::unique_ptr<Base> clone() const override {
    return std::make_unique<Inherited>(*this);
}

    关键在于派生类知道自身的具体类型，因此可用拷贝构造函数复制自己。调用方只知道基类接口，所以通过指向基类的拥有型指针接收堆上的副本。

    若使用裸指针或引用作为返回类型，C++ 允许覆盖函数使用协变返回类型，即返回更具体的派生类指针或引用；但 std::unique_ptr<Derived> 与 std::unique_ptr<Base> 不属于语言层面的协变类型，因此示例中的覆盖函数仍应声明返回 std::unique_ptr<Base>。

    按值返回 Base 只保留基类子对象，派生类字段与覆盖行为会被切掉，且抽象基类根本不能实例化。unique_ptr<Base> 明确副本由调用方独占并负责销毁；基类应有虚析构。若API返回裸拥有指针，调用方必须知道释放规则，容易泄漏；借用引用则不能表达新副本的所有权。

    Q1225 · 派生类是否需要赋值运算符¶

    难度：★★｜题型：C++ 语言｜副题型：逐成员赋值与可复制性

    题目：C++ 中若基类定义了赋值运算符，派生类还需要吗？

    • 对拷贝构造函数，结论是否相同？

    如果某个数据成员有用户自定义赋值运算符，包含它的类是否也必须自行定义赋值运算符？

    解答

    不一定需要。若派生类的逐成员赋值正是所需语义，编译器生成的赋值运算符通常已经正确；若类直接管理资源、要求深拷贝、需要保持额外不变量，或某成员不可赋值，则需要显式定义、默认化或删除相应操作。

    若类 X 继承自 Y，并写出

    \(X a\); \(X b\); \(a = b\);

    若 X 没有自行声明赋值运算符，且其生成条件满足，编译器会生成一个，并依次调用每个基类子对象和数据成员的赋值操作。基类 Y 的赋值运算符是用户定义还是隐式生成，并不会因此强迫 X 再写一个。

    拷贝构造的逻辑类似：隐式生成的派生类拷贝构造会拷贝构造基类和每个成员，不是简单“继承基类构造函数”。某成员已有正确的自定义赋值或拷贝操作时，外层逐成员操作会调用它，通常无需再手写外层版本；若成员不可复制，外层相应操作也可能被删除。是否定制应取决于整个类的不变量和所有权。

    Q1226 · 每个类自带的成员¶

    难度：★★｜题型：C++ 语言｜副题型：特殊成员生成与零法则

    题目：每个类都自带（编译器自动生成）哪些东西？

    • 从拥有动态内存的裸指针类出发，解释默认浅拷贝、赋值覆盖、自赋值与分配失败的风险，再说明“三法则”“五法则”和“零法则”。

    • 你使用过哪些智能指针？它们的所有权语义有何不同？

    • 若要禁止某类对象被复制，应怎样声明？多态对象经基类指针删除时还需什么条件？

    解答

    编译器可能隐式声明默认构造、拷贝构造、移动构造、拷贝赋值、移动赋值和析构函数，但具体成员以及类已声明的特殊成员函数，可能使其中一些不生成或被定义为删除。自动生成的拷贝操作按基类和数据成员逐一执行。

    因此，隐式拷贝构造函数会调用每个基类与成员的拷贝构造函数，隐式赋值运算符会调用各自的赋值操作。对值类型成员，这通常就是正确语义；对拥有资源的裸指针，逐成员复制只会复制地址，形成危险的浅拷贝。

    如果所有成员的拷贝语义都正确，编译器生成的操作即可使用。若数据成员是拥有资源的裸指针，复制后两个对象会指向同一资源，析构时可能重复释放；赋值也有同类问题。

    当类需要在对象销毁时释放自有资源，才需要非平凡析构逻辑。若对象可能通过基类指针删除，基类还需要虚析构函数，无论析构函数体本身是否为空。

    更好的做法是用标准容器和智能指针表达资源所有权，使编译器生成的特殊成员自然正确，这就是“零法则”。只有确实需要定制资源管理或拷贝语义时，才自行编写相关成员。

    三法则对应析构、拷贝构造、拷贝赋值；五法则再加入移动构造与移动赋值。它们是资源语义的设计提示，并非“每个类都必须实现五个函数”。禁止复制可显式写 T(const T&) = delete; T& operator=(const T&) = delete;。unique_ptr 表示独占所有权、可移动不可复制；shared_ptr 共享引用计数所有权；weak_ptr 借用共享控制块且不增加强计数，用于打破环或检测对象存活。资源型裸指针若确需深拷贝，应先取得新资源再替换旧状态，并处理自赋值、分配失败和基类删除。

    Q1227 · delete 与 delete[] 的区别¶

    难度：★★｜题型：C++ 语言｜副题型：分配释放配对与数组析构

    题目：delete 与 delete[] 有什么区别？

    • 删除空指针会发生什么？

    • 可以重载 operator new 与 operator delete。是否能靠重载安全弥补 delete/delete[] 混用？为什么不应依赖这种做法？

    • 为什么语言要区分单对象与数组两种删除形式？

    解答

    delete 用来销毁并释放由单对象形式 new 创建的对象；delete[] 则对应数组形式 new[]，会对数组元素执行所需的析构并释放整块存储。

    混用二者会产生未定义行为，可能表现为内存泄漏、析构次数错误、堆损坏或崩溃。现代 C++ 应尽量用标准容器和智能指针，避免手写 new/delete 配对。

    删除空指针是合法空操作。数组删除需要正确定位分配块、调用每个元素析构，再交还与分配方式匹配的存储；单对象和数组的元数据布局可能不同。自定义 operator delete 只接收到释放阶段的信息，无法普遍挽回此前已发生的错误析构或错误指针调整，因此不应试图靠重载弥补混用。unique_ptr<T> 对应单对象，unique_ptr<T[]> 对应数组；标准容器通常更适合动态序列。

    Q1228 · 什么是虚函数¶

    难度：★★｜题型：C++ 语言｜副题型：动态分派与静态多态

    题目：什么是虚函数？解释主流实现的虚表、对象开销与ABI约定，再比较静态多态。

    • 编译器通常如何实现虚函数？静态成员能否是虚函数，纯虚函数何时可有定义或被显式调用？

    • 虚函数的运行时开销有多大？

    • 模板实现的静态多态与虚函数实现的动态多态有什么区别？

    • C++ 标准是否规定虚函数必须采用虚函数表实现？

    解答

    虚函数是 C++ 运行时多态的核心机制。基类声明统一接口，派生类提供不同实现；当通过基类指针或引用调用时，程序会依据对象的动态类型选择最终覆盖函数。例如，可在普通期权基类中把 PayOff 声明为虚函数，再让看涨与看跌期权分别实现其收益逻辑。

    调用方无需知道对象究竟是哪一种期权，通过基类接口调用 PayOff 时会自动执行正确的派生类版本。若基类只定义接口而不提供实现，可把函数声明为纯虚函数。

    主流实现以虚表和对象中的隐藏指针找到最终覆盖函数，但C++标准只规定动态分派行为，不强制表布局。每个对象的额外指针、间接访存和难以内联是常见成本。模板静态多态在编译期选择目标，易内联但可能增加代码体积，也不直接提供同一基类接口下的运行时异构对象集合。没有实例的静态成员函数不能同时是虚函数，因为动态分派需要对象的动态类型。

    纯虚函数可以另行定义函数体，并通过 obj.Base::f() 显式限定调用；限定调用关闭虚分派。若缺少该定义而作这种调用，通常无法链接。抽象类仍不能因函数体存在而直接实例化。纯虚析构函数也必须有定义，因为派生类析构后仍要执行基类析构。构造或析构期间的虚分派停在当前构造/析构的类；对纯虚函数作虚调用不能当成安全调用更派生实现的办法。

    因此，含虚函数的对象通常会多占一个指针大小的空间。虚函数表由哪个翻译单元发出、如何合并，属于编译器和 ABI 的实现问题。旧编译器有时会把表放在定义关键虚函数（常是析构函数）的翻译单元中；若所有虚函数都在头文件内联定义，可能产生多个待链接器合并的副本。

    virtual ~MyClass(){}

    因此传统建议之一，是在源文件中为多态类提供一个非内联的虚析构函数定义。现代编译器与链接器通常能妥善处理重复表项，但理解 ABI 与链接行为仍有价值。

    Q1229 · 虚析构函数与使用时机¶

    难度：★★｜题型：C++ 语言｜副题型：基类删除与虚析构链

    题目：什么是虚析构函数？何时需要它？

    • 把析构函数声明为虚函数有什么成本或限制？

    你认为 C++ 是否应默认把所有析构函数都设为虚函数？

    解答

    如果派生类对象经动态分配，并通过基类指针销毁，就必须确保调用完整的派生类析构链。基类析构函数为虚函数时，delete 会先调用派生类析构函数，再逐级调用基类析构函数。

    若基类析构函数不是虚函数，通过基类指针删除派生类对象会产生未定义行为，派生类资源通常无法正确释放。

    一般规则是：凡是准备作为多态基类使用、可能经基类指针删除的类型，都应有虚析构函数，通常写成 virtual ~Base() = default;。若类型明确禁止经基类指针删除，也可把非虚析构函数设为受保护成员。没有多态用途的值类型通常不需要虚析构函数。

    为没有多态需求的每个值类型都加虚析构，会引入多态对象布局和潜在间接调用，影响平凡性、布局约束与优化，因此不默认强加。若类本来已经多态，额外对象空间常已存在，但仍须考虑析构异常契约和删除方式。成本应与“允许经基类销毁”这一接口能力一起判断。

    Q1230 · 虚拟化对优化的影响¶

    难度：★★｜题型：C++ 语言｜副题型：间接调用成本与去虚拟化

    题目：从优化角度看虚函数有什么问题？当函数不是虚的时候，编译器能做什么？

    • 用函数指针替代虚函数是否有助于优化？为什么它通常仍是间接调用？

    • 改用模板实现静态多态是否有帮助？代价是什么？

    你认为虚函数带来的灵活性是否值得其成本？应如何判断？

    解答

    虚函数可能影响优化。首先，虚调用通常需要一次或多次指针间接访问，处理器跳转到运行时取得的地址，而不是编译期已知的固定地址，因此会增加少量指令和分支预测压力。

    更重要的是，若编译器和链接器无法确定调用目标，就难以基于被调用函数做内联、常量传播等跨函数优化。不过，当动态类型可被证明时，现代编译器可以去虚拟化，把虚调用还原为直接调用。

    此外，每个多态对象通常需要保存虚表指针。若系统中有大量很小的对象，这部分空间开销可能不可忽略。

    如果函数本身工作量很大，这些开销往往微不足道；若被调用的是极短、位于热点循环中的访问器，间接调用和无法内联的代价就可能明显。是否采用虚函数应以剖析结果和设计需求为依据。

    不同动态类型还可能访问分散的代码和虚表，降低指令缓存、数据缓存及分支预测的局部性，在异构对象密集遍历时尤其明显。

    用函数指针替换虚函数通常仍是运行时间接调用，未必改善目标预测或内联。模板/CRTP把实现绑定在编译期，可优化短小热点，但增加实例化与编译成本，也不适合所有运行时插件架构。是否采用动态分派，应根据异构扩展需求、对象数量、热点函数的工作量与性能剖析决定。

    Q1231 · 虚函数与多态的输出分析¶

    难度：★★｜题型：C++ 语言｜副题型：动态类型追踪与智能指针

    题目：阅读给出的代码（基类 Alpha、派生类 \(\operatorname{Beta} /\operatorname{Gamma}\)、虚函数与指针/引用调用）：说明程序输出及原因。

    #include <iostream>
#include <memory>
using namespace std;

class Alpha
{
public:
    Alpha() : ptrAlpha(new int) {}
    virtual ~Alpha() { delete ptrAlpha; }

    virtual void MyFunction()
    {
        cout << "位于 Alpha" << endl;
    }

private:
    int* ptrAlpha;
};

class Beta : public Alpha
{
public:
    Beta() : ptrBeta(new int) {}
    ~Beta() override { delete ptrBeta; }

    void MyFunction() override
    {
        cout << "位于 Beta" << endl;
    }

private:
    int *ptrBeta;
};

class Gamma : public Alpha
{
public:
    Gamma() : ptrGamma(new int) {}
    ~Gamma() override { delete ptrGamma; }

    void MyFunction() override
    {
        cout << "位于 Gamma" << endl;
    }

private:
    int *ptrGamma;
};

int main()
{
    unique_ptr<Alpha> alpha1(new Beta());
    Gamma gamma;
    Alpha& alpha2 = gamma;
    alpha1->MyFunction();
    alpha2.MyFunction();

    char d;
    cin >> d;
    return 0;
}

    该程序会输出什么？你认为程序正确吗？若不正确，应如何修复？

    • 为什么 C++ 不把所有析构函数都默认设为虚函数？

    • auto_ptr 有哪些问题，为什么已被废弃并移除？

    • unique_ptr、shared_ptr 与 weak_ptr 分别适合什么所有权场景？

    解答

    本题考查虚函数与虚析构。MyFunction 在基类中一旦声明为虚函数，在派生类中即使省略 virtual 也仍然是虚函数。alpha1 指向动态类型为 Beta 的对象，第一次调用输出“位于 Beta”；alpha2 引用动态类型为 Gamma 的对象，第二次调用输出“位于 Gamma”。

    作为多态基类的 Alpha 必须有虚析构函数，因为程序会通过基类指针销毁派生类对象。题面代码中的析构函数为虚函数，因此基类删除会调用完整析构链。

    若基类析构函数不是虚函数，当智能指针离开作用域时，通过 Alpha* 删除实际的 Beta 对象会产生未定义行为，Beta 的资源可能泄漏。正确做法是把基类析构函数声明为 virtual ~Alpha()，并使用已经取代 auto_ptr 的 std::unique_ptr<Alpha>；题面代码采用的正是这一写法。

    题面代码的两次调用均正确；但它的类各拥有一个裸指针，隐式复制会浅拷贝并造成重复释放，若需复制还必须实现相应语义，或把所有权成员改为 unique_ptr<int> 并明确不可复制。auto_ptr 复制会转移所有权，违反容器和普通值复制的直觉，C++11弃用、C++17移除。此处独占所有权使用 unique_ptr；跨多个拥有者共享才用 shared_ptr，观察共享对象但不延长其寿命用 weak_ptr。没有多态删除需求的类型不必默认承担虚析构成本。

    Q1232 · 多态/抽象类/指针的定义¶

    难度：★★｜题型：C++ 语言｜副题型：纯虚接口与引用语义

    题目：定义以下术语：什么是多态？什么是抽象类？什么是指针？

    • 什么是多态？

    • 什么是抽象类？

    • 什么是指针？

    • 什么是引用？

    你认为引用为语言增加了什么能力或接口表达力？

    • 什么是智能指针？

    • 能否调用没有函数体定义的纯虚函数？请讨论不同调用场景。

    • 若纯虚函数另有定义，如何显式调用它？构造和析构期间调用又有什么风险？

    解答

    多态意为“多种形态”。在 C++ 的运行时多态中，基类声明虚函数，派生类覆盖它；客户端通过基类指针或引用使用对象，而实际行为随对象的动态类型变化。模板与重载还可提供编译期多态。

    例如，收益基类可只规定统一的 PayOff 接口，由看涨和看跌收益类分别实现。计算程序只依赖基类接口，无需为每种收益类型编写不同控制流程。其他常见例子包括“汽车是一种交通工具”并实现 drive，以及“圆是一种图形”并实现 draw。

    抽象类是至少含一个最终未被覆盖的纯虚函数的类。纯虚函数在声明末尾写 = 0。抽象类不能直接实例化，只能作为接口或基类，由已经实现全部纯虚函数的具体派生类创建对象。纯虚函数也可以另行提供函数体，但类仍因其纯虚声明而保持抽象。

    指针是保存对象或函数地址的值，可重新赋值，也可为空；现代 C++ 用 nullptr 表示空指针。引用是已有对象的别名，初始化后不能重新绑定，通常也不允许为空。虽然实现常以地址完成引用语义，但语言层面不应简单把引用定义为另一种指针。

    引用让接口直接表达“对象必须存在且不重新绑定”，也使运算符重载和泛型代码能像普通对象一样使用别名；它不提供自动生命周期延长的一般保证，仍可能悬空。智能指针在对象访问之外编码所有权，不能把裸指针、引用与拥有型智能指针的生命周期语义混为一谈。未定义的纯虚函数不能作需要函数体的限定调用；有定义时可用 obj.Base::f() 调用，但纯虚声明仍使类抽象。

    Q1233 · 实现 strcmp¶

    难度：★★｜题型：C++ 语言｜副题型：终止符扫描与无符号字节比较

    题目：实现 strcmp 函数。

    • 如何实现不区分大小写的字符串比较？应注意哪些区域设置与字符编码问题？

    如何把 std::string 转为 \(C\) 风格字符串？使用 c_str() 得到的指针有哪些生命周期和失效风险？

    解答

    strcmp 比较两个 \(C\) 风格字符串：若第一个按字典序较小则返回负值，相等返回 0，较大返回正值。

    这里的大小按字典序定义，也就是比较两字符串第一次不同的字符；若一方先结束，则较短者更小。

    函数签名为

    int strcmp( const char *str1, const char *str2 );

    实际项目应直接使用标准库 <cstring> 中的 std::strcmp；面试题要求的是自行实现，以检查对指针、终止符和字典序比较的理解。

    关键事实是 \(C\) 风格字符串以空字符 \0 结尾。简单实现如下：

    int mystrcmp( const char *str1, const char *str2 )
{
    while (*str1 != '\0' && *str2 != '\0' && *str1 == *str2)
    {
        ++str1;
        ++str2;
    }
    if (*str1 < * str2)
        return -1;
    if (*str1 > * str2)
        return 1;
    return 0;
}

    两个形参是“指向常量字符的指针”，指针自身并非常量，因此可以递增。循环持续到某个字符串结束或出现不同字符。严格仿照标准库时应按 unsigned char 比较，以避免带符号 char 对非 ASCII 字节造成次序差异；还应明确输入空指针属于非法前置条件。

    完全遵循字节顺序时，可把比较处改为：

    const auto a = static_cast<unsigned char>(*str1);
const auto b = static_cast<unsigned char>(*str2);
return (a > b) - (a < b);

    不区分大小写的简单单字节版本可逐字节应用 std::tolower(static_cast<unsigned char>(ch)) 后比较；不能把负的有符号char直接传入。locale会影响转换，UTF-8的Unicode大小写折叠也不能靠逐字节tolower完成。s.c_str() 返回以零结尾的只读缓冲指针；不能释放它，字符串销毁或可能重分配的修改后不能继续使用。

    Q1234 · 字符串反转的两个版本¶

    难度：★★｜题型：C++ 语言｜副题型：对称交换与移动语义

    题目：写一个 C++ 函数：输入字符串、返回反转后的新字符串；再写一个原地反转、不做任何内存分配的变体。

    • 如果处理的是以 \0 结尾的 \(C\) 风格字符数组，代码应如何修改？

    • 你更倾向使用返回副本还是原地修改的版本？这取决于哪些接口语义？

    如果向量中的对象复制成本很高，应如何利用移动或交换高效反转？

    解答

    先给出一个使用反向迭代器、返回新字符串的解法：

    std::string reverse_string(const std::string& input)
{
    std::string output;
    output.reserve(input.size());

    for (std::string::const_reverse_iterator
        it = input.rbegin();
        it != input.rend(); ++it)
        output.push_back(*it);

    return output;
}

    反向迭代器让程序可以从尾到头遍历，而不必手工计算下标。预先用 reserve 保留足够容量，可避免字符串增长过程中多次重新分配。

    原地反转需要交换关于中点对称的字符，直接实现如下：

    void reverse_string_inplace(std::string& input) {
    for (std::size_t i = 0; i < input.size() / 2; ++i)
        std::swap(input[i], input[input.size() - 1 - i]);
}

    注意末元素下标是字符串长度减 1，因此右侧下标必须写成 input.size() - 1 - i。两种算法的时间复杂度都是 \(O(n)\)；原地版本只需 \(O(1)\) 额外空间。

    C风格数组先找终止符得到长度，再对称交换前半与后半；终止符留在原位置。返回副本适合保留输入或函数式接口，原地版本适合调用方允许修改且希望省分配的场景。一般对象向量可用 std::reverse，内部交换可利用移动构造与移动赋值，或类型自定义的高效swap，避免昂贵深复制。这些操作反转的是字节/元素顺序；UTF-8用户可见字符需先正确分段。

    Q1235 · 按值/按引用/按指针传参¶

    难度：★★｜题型：C++ 语言｜副题型：参数别名与值类别

    题目：按值、按引用与按指针传参有什么区别？

    • 已有指针，为什么还需要引用？

    • 形参为常量引用时，函数是否仍可能间接观察或造成底层对象变化？mutable、别名和 const_cast 分别意味着什么？

    解答

    从语法上看，形参类型含 & 表示按引用传递，含 * 表示传入指针；普通对象形参则按值传递。

    按值传递会构造一个独立形参，通常涉及复制或移动；函数内对它的修改不影响调用方对象。对整数、指针等小型类型，按值往往最自然高效。

    按引用传递让形参与调用方对象表示同一对象，不发生对象复制；非常量引用允许函数修改调用方状态，适合输入输出参数。若只读且对象复制成本较高，通常使用 const T&，既避免复制，又向调用方明确承诺不通过该引用修改对象。

    传指针与传引用相似之处是都可间接访问原对象，但实际按值复制的是一个指针。指针可以为空、可以重新指向其他对象，并可分别限定“指针本身是否可变”和“所指对象是否可变”；每次访问还需显式解引用。接口用指针通常暗示“允许为空”或需要指针语义，用引用通常暗示参数必须存在且不重新绑定。

    const T& 限制的是该访问路径，不冻结整个对象。其他可写别名可能修改同一底层对象，mutable成员也可在const函数内修改；因此两次读取未必永远相同。const_cast移除限定后，仅当底层对象原本不是const时才可合法修改。真正const对象经转换写入仍是未定义行为；并发读写还需独立满足数据竞争规则。

    Q1236 · 关于 const 的知识¶

    难度：★★｜题型：C++ 语言｜副题型：访问路径限定与const重载

    题目：谈谈你对 const 的了解。

    • 对 volatile 重复上述讨论；它与线程同步有什么区别？

    你认为 const 为 C++ 带来了哪些价值与复杂性？

    • 能否仅凭返回类型或返回值的常量性重载函数？成员函数末尾的 const 为什么可以参与重载？
    解答

    关键字 const 表示通过相应名字或访问路径不允许修改对象，但其具体含义取决于修饰位置。常见用法包括：

    • 修饰变量声明；

    • 修饰函数或成员函数的参数；

    • 放在成员函数参数列表之后，声明常量成员函数；

    • 修饰类的数据成员；

    • 修饰指针本身或指针所指对象。

    变量声明中的 const 表示对象初始化后不能通过该名字修改，因此常量对象必须完成初始化。

    为避免复制成本，函数参数常按引用传递。非常量引用允许修改调用方对象；const T& 则禁止通过该引用修改对象，并向调用方表达只读意图。

    const 修饰成员函数时，函数不能通过 this 修改非 mutable 数据成员，也只能调用其他常量成员函数。mutable 缓存仍可在逻辑常量操作中更新，但不应改变对象对外可观察的逻辑状态。

    常量数据成员必须在构造阶段初始化，之后不能赋新值。这通常会使编译器生成的赋值运算符被删除，因为赋值无法改变该成员；只有在类确实不需要可赋值语义时才应这样设计。

    指针有两层常量性：const T* 表示不能通过指针修改所指对象，T* const 表示指针本身不能改指向，二者还可组合。引用初始化后本来就不能重新绑定，因此所谓“常量引用”实际是对所引用对象的只读访问。

    const_cast 可以移除访问路径上的常量限定；但若底层对象原本就被声明为常量，再经转换去修改它会产生未定义行为。此转换主要用于兼容缺乏常量正确性的旧接口，不应作为常规手段。

    良好的常量正确性可以明确接口契约、帮助编译器检查误修改，并允许常量对象安全使用相应接口。

    不能仅靠返回类型或按值返回类型的顶层const区别重载；调用者无法由实参唯一选择。成员函数末尾const却改变隐式对象参数的限定，因此 T::f() 与 T::f() const 可重载。volatile表示某些访问具有不可随意省略的可观察语义，常用于设备寄存器，不保证原子性、线程可见性或先后顺序；线程间共享状态应使用原子或锁。const与volatile也可组合，它们回答不同问题。

    Q1237 · \(A\) 类型到 \(B\) 类型的自动转换¶

    难度：★★｜题型：C++ 语言｜副题型：转换构造与显式转换

    题目：C++ 中 \(A\) 类型对象自动转换为 \(B\) 类型对象有哪两种方式？

    • explicit 关键字有什么作用？

    你认为单参数构造函数是否应默认是显式的？现有语言规则为何如此设计？

    • 给出一个使用类型转换运算符的非平凡例子。
    解答

    第一种方式是在类 B 中声明非 explicit 的转换构造函数：

    B( const A& myObject);

    构造函数声明中必须写明参数类型；B(myObject); 不是合法的构造函数声明。

    第二种方式是在类 A 中定义类型转换运算符。当无法修改 B，例如 B 是 double 这样的内建类型时，可以在 A 的类声明中加入

    operator B() const;

    定义时写成

    A::operator B() const
{
    // 构造并返回 B 类型对象
}

    类型转换运算符的声明和定义都不在行首另写返回类型。现代 C++ 可把转换构造函数或转换运算符声明为 explicit，以禁止容易误触发的隐式转换。

    例如范围受限的句柄类可声明 explicit operator bool() const，允许在 if(handle) 中检测有效性，却阻止意外参与整数运算。转换构造通常在容易引入隐式语义变化时应标explicit；但语言保留隐式转换构造以支持自然的值转换和既有代码，不能简单把所有单参数构造都判错。一个隐式转换序列通常至多含一次用户定义转换，因此连锁的 \(A\to B\to C\) 不能无限自动串接。

    Q1238 · int 与 float 递增作图¶

    难度：★★｜题型：C++ 语言｜副题型：浮点间距与整数溢出

    题目：编程题：若 \(x\) 是 int 型，不断增大 \(x\) 并作图，图形是什么样的？若 \(x\) 是 float 型呢？

    • C++ 的 double 能表示的最大有限值是多少？

    • double 能表示的最小正规格正数与最小非正规格正数分别是什么？

    • 在 C++ 中可采用哪些策略减小浮点舍入误差？

    • 如何取得数值类型的最大有限值常量？

    解答

    C++ 中的 int 通常为 32 位，但有符号整数溢出属于未定义行为；标准并不保证它回绕，也不能据此断言图像必为锯齿。无符号 \(N\) 位整数则按模 \(2^N\) 运算，图像会周期性回绕。

    对 float 或 double，随着数值增大，相邻可表示浮点数之间的间距也会增大；当间距大于 1 后，继续加 1 会因舍入而不再改变数值，图像最终变为水平线。还应考虑无穷大以及不同循环写法的终止条件。

    对IEEE754 binary32，精确有效位数24，\(2^{24}\) 处向上间距为2，按最近偶数舍入不断加1会停在该量级；binary64对应53位。IEEE binary64最大有限数为 \((2-2^{-52})2^{1023}\approx1.7976931348623157\times10^{308}\)，最小正规格正数 \(2^{-1022}\approx2.2250738585072014\times10^{-308}\)，最小非正规格正数 \(2^{-1074}\approx4.9406564584124654\times10^{-324}\)。

    可分别用 std::numeric_limits<double>::max()、min()、denorm_min() 查询；min()不表示最负数，最负有限数用 lowest()。减小误差可采用尺度归一化、避免接近大数相减、补偿求和、成对求和和融合乘加，并以误差传播分析选择精度。这些具体数值依赖类型实现，代码应查询特性而不假定所有平台相同。

    Q1239 · static的链接、存储期、类共享状态与并发¶

    难度：★★｜题型：C++ 语言｜副题型：存储期、链接属性与初始化顺序

    题目：从局部变量、命名空间变量/函数、类成员三个层次解释 static。

    1. 列出它在各位置的含义，并区分静态存储期与内部链接。
    2. 说明初始化、销毁顺序及跨翻译单元依赖的风险；举例局部静态缓存或类计数器。
    3. 说明初始化线程安全与后续并发访问的区别，并解释“弃用”是否等于立即不可用。
    解答

    1. 同一个关键字表达不同属性。 函数内的局部static具有静态存储期，首次控制流到达声明时初始化，之后各次调用共享同一对象。命名空间作用域的static变量或函数具有内部链接，名称只在该翻译单元内可见；命名空间变量本来通常已有静态存储期。静态数据成员由类的全部实例共享，静态成员函数没有 this，可经类名调用。静态成员函数调用仍可写对象语法，但不意味着它绑定对象。

    2. 存储与生命周期。 静态存储期贯穿程序运行；实现常把已初始化对象放数据段、零初始化部分放BSS，但标准不强制具体布局。局部动态对象通常在作用域结束销毁，new对象须由相应拥有者释放。成功构造的函数局部static在正常退出时销毁；在可保证顺序的范围内按完成构造的逆序销毁。不同翻译单元的动态初始化与退出依赖可能造成“某对象使用尚未初始化或已销毁的另一个对象”。可用按需构造的局部static管理初始化，但仍需设计销毁依赖。

    例如类的静态原子计数器可统计活跃对象，构造时加一、析构时减一；局部static可缓存只构造一次的只读查表。

    3. 线程安全与语言演进。 C++11起局部static的初始化由语言保证并发只完成一次；初始化失败抛异常后，后续调用可以重试。但初始化后的修改仍须原子或互斥同步，不能因为对象是static就安全。

    弃用表示标准建议迁移、未来可能移除，通常仍可编译并可能发警告；移除后则不再属于对应版本标准。命名空间作用域static并未被普遍移除，也可使用匿名命名空间表达内部链接。

    Q1240 · ?: 是否冗余（condif 函数）¶

    难度：★★★｜题型：C++ 语言｜副题型：thunk惰性求值与值类别保留

    题目：一个学生声称 C++ 的 ?: 结构是冗余的，可以用其他语言特性实现，并建议用 condif(condition,\(i, j\)) 函数替代。对整数而言两者真的没有区别吗？你是否同意该学生？

    • 如何用接收可调用对象的函数正确模拟整数分支的惰性求值行为？

    • 把该实现推广到一般类型，并正确处理返回类型推导与值类别。

    解答

    C++ 规定条件运算符 ?: 只对第二、第三操作数中的一个求值；普通函数 condif(condition, i, j) 则必须在进入函数前对两个实参都求值。二者在性能、异常和副作用方面都可能不同。

    若两个分支的计算很昂贵，函数版本会浪费一半工作；若分支表达式会修改状态、抛异常或进行 \(I/O\)，函数版本还会同时触发两边的行为，而 ?: 只执行被选中的分支。

    普通函数还可能有调用开销，不过现代编译器可能将其内联；真正无法由普通按值参数函数复现的是惰性求值语义。可以用 lambda、可调用对象或模板封装延迟计算。

    用 thunk 保留惰性与值类别。

    #include <functional>
#include <utility>
template<class F, class G>
decltype(auto) condif(bool condition, F&& yes, G&& no) {
    return condition
        ? std::invoke(std::forward<F>(yes))
        : std::invoke(std::forward<G>(no));
}
// condif(ok, [&]{ return costly_a(); }, [&]{ return costly_b(); });

    两个 lambda 对象会先创建，但函数体只执行所选的一个。整数版本中两分支都返回 int 即可。一般版本让真正的条件运算符完成公共类型和值类别规则：若两可调用对象都返回相同类型左值引用，则 decltype(auto) 保留引用；若组合产生纯右值，则按值返回。两分支仍必须在编译期具有兼容的条件表达式类型；运行时没有选中某分支不等于其语法可以非法。

    例如引用版本要显式写 [&]() -> int& { return a; }，否则 lambda 通常按值推导返回；也不能返回指向局部或临时对象的悬空引用。lambda 的捕获初始化本身仍会执行，所以 [x=costly()] 不属于延迟计算。该包装把惰性要求转给调用者，并未证明语言内置 ?: 冗余。
