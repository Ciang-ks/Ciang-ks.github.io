    第 18 讲 · 最短路径¶

    阅读起点：第 15 讲：BFS；第 12 讲：最小堆。

    首读范围：先理解松弛，再看 Dijkstra；Bellman–Ford 与限步快照一起读，全源选读。

    先看一张只有三个顶点的图：A —1— B —1— C，同时 A —3— C。然后问：

    1. 从 A 出发做 BFS，它认为 A 到 C 的最短路是什么？
    2. 把权重考虑进去呢？
    3. 你会怎么设计求加权最短路的算法？能改造 BFS 吗？

    答案是：BFS 说距离 1（因为只有一条边）；按权重算是 A → B → C，代价 2；而 BFS 不能直接改造，因为它的正确性建立在"每条边代价相同"这个假设上。

    这一讲要补上的，正是"边有权重"时的算法。

    从一对顶点到全部顶点¶

    本讲用 δ(s,v) 表示从 s 到 v 的最小边权总和，不可达记为 ∞。这是第 15 讲距离的推广：所有边权都是 1 时，总权重恰好等于边数，才退回 BFS 的最少步数。

    问题 输入 输出
    单对可达性 G, s, t s 能否到 t
    单对最短路 G, s, t δ(s,t) 与一条最短路径
    单源最短路（SSSP） G, s 对所有 v，δ(s,v) 与最短路径树
    全源最短路（APSP） G 对所有 u,v，δ(u,v)

    只要能解决单源，就能解决前两个。所以重心在 SSSP，最后再扩展到全源。

    顺带说一句工程上的巧思：最短路径树只需要每个顶点一个父指针，就能为每个可达顶点编码一条最短路径——比"把每条路径都存下来"（可能要 Θ(V²) 空间）聪明得多。

    橙色路线 CoDa→Packard→CS161→Old Union 的代价为 1+1+4=6。弯曲边上的 25 是 CoDa—Dish 这一条边的权重。下面的 s/a/b/t 图另演示 Dijkstra 的逐轮更新。

    先明确后面函数的接口：n 个顶点编号为 0..n−1，边表中 (u,v,w) 表示从 u 到 v 的一条有向边，代价为 w。若要表示无向边，应加入两个方向。源点 s 必须存在。返回 dist[v] 表示最短距离，不可达为无穷大；parent[v] 记录路径上 v 的前一个顶点。

    先手推一次“松弛”¶

    初始化 dist[s]=0，因为留在起点不用走边；其余位置为无穷大，表示还没有找到到达它们的路径。后面不断改进这些记录。

    dist[v] 是已找到的路径里从 s 到 v 的最小长度，不是未经证明的真实最短距离。∞ 表示尚未找到路径。“松弛 u→v”就是比较：走到 u 再付 w，是否比旧 dist[v] 更便宜？

    例如图中边为 s→a(4), s→b(1), b→a(2), a→t(5), b→t(8)：先从 s 得到 a=4、b=1；弹出 b 后把 a 改为 3，堆中同时有 (4,a) 与 (3,a)。3 那份先处理，4 那份后来因过期被跳过。图里的距离更新应按这样的中间状态来读。

    Dijkstra：把队列换成优先队列¶

    本节先限定边权非负，例如路程或耗时。枚举所有可能路线会重复探索大量共同路段；我们希望保留 BFS“按距离从小到大扩展”的思路，但队列不够用了：一条权重 0.1 的边和一条权重 100 的边，它们到达的顶点应该被插到完全不同的位置。需要的是"按当前已知距离取最小"的容器——最小堆。

    import heapq
from collections import defaultdict

def dijkstra(n, edges, s):
    """要求所有边权 >= 0"""
    graph = defaultdict(list)
    for u, v, w in edges:
        graph[u].append((v, w))
    dist, parent = [float('inf')] * n, [None] * n
    dist[s] = 0
    heap = [(0, s)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:
            continue                       # 过期条目
        for v, w in graph[u]:
            if d + w < dist[v]:            # 松弛
                dist[v] = d + w
                parent[v] = u
                heapq.heappush(heap, (d + w, v))
    return dist, parent

    if d > dist[u]: continue 这一行不能省。 同一个顶点可能被多次压入堆（每次距离被改进就压一次），在非负权前提下，跳过过期条目后首次有效弹出可确定最短距离。若不跳过，仍可能得到正确距离，但会重复扫描邻接表，失去原本的效率保证。

    图的弹出记录包含过期项：(0,s)、(1,b)、(3,a)、(4,a旧)、(8,t)、(9,t旧)。图中“距离从小到大确定”只说有效记录；旧项弹出后直接continue，不能再当作新的定型。数组dist记录当前最好值，堆记录“曾经发现的候选”，所以两者不是一份永远同步的数据。

    每次成功松弛最多新压入一项，共O(E)项；含初始化，本实现在简单图上时间O((V+E)log(V+1))、额外空间O(V+E)。如果输入允许大量平行边，更直接的堆大小界是O(E)，对数项应写log(E+1)。

    为什么第一次弹出的一定正确？这就是全部的正确性所在，值得完整写一遍。

    以下“弹出”仅指跳过旧项后的首次有效弹出。任意有限dist都是一条已找到路径的长度，所以不可能比真实最短距离更小。设u是第一个此时距离仍偏大的顶点，即 dist[u] > δ(s,u)。取从 s 到 u 的一条真实最短路径 P，设 P 上第一个尚未被弹出的顶点是 x，y 是 x 在 P 上的前驱（y 已被弹出）。

    • 由 u 的选取，dist[y] = δ(s,y)；
    • 松弛边 (y,x) 之后，dist[x] ≤ δ(s,y) + w(y,x) = δ(s,x)；
    • 因为 x 还没被弹出，而 u 要被弹出（堆里取最小），所以 dist[u] ≤ dist[x]；
    • 由边权非负，δ(s,x) ≤ δ(s,u)；
    • 串起来得 dist[u] ≤ δ(s,u) < dist[u]，矛盾。∎

    注意"边权非负"出现在第四步。 如果允许负权，δ(s,x) ≤ δ(s,u) 就不成立——后面的负权反例会展示这一保证怎样失效。

    Bellman-Ford：允许负权¶

    负权可以表示一段路线带来的返还或抵扣。例如 s→a 费用 3，a→t 费用 −2，整条路线费用为 1。若有可从 s 到达的负权环，就可以反复绕它让费用继续降低；受它影响的顶点不再有有限的最短距离。下面的函数一旦发现可达负环，便返回 (None,None) 报告这一情况。

    在没有负环的情况下，我们仍然要找到各点的最短距离。负边使“最近的候选可以立即定型”的理由失效，因此换成反复松弛所有边：先把源点的信息传出去，随后继续向更远处传播，直到没有改进或达到规定轮数。

    def bellman_ford(n, edges, s):
    dist, parent = [float('inf')] * n, [None] * n
    dist[s] = 0
    for _ in range(n - 1):                 # 最多松弛 n-1 轮
        updated = False
        for u, v, w in edges:
            if dist[u] != float('inf') and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                parent[v] = u
                updated = True
        if not updated:
            break                          # 已收敛
    for u, v, w in edges:                  # 第 n 轮：还能松弛说明有负环
        if dist[u] != float('inf') and dist[u] + w < dist[v]:
            return None, None
    return dist, parent

    为什么要 n−1 轮？ 无可达负环时，可删除路径上的非负环，得到至多 n−1 条边的一条最短路径。第 k 轮结束后，所有能用至多 k 条边达到的最优距离都已被传播到；就地更新还可能在同一轮传播更多边，所以不能说数组“恰好等于限 k 边的最优值”。要表达严格限边数的状态，必须使用下一节的快照。

    Bellman–Ford 的时间为 O(V+VE)，距离与父指针额外 O(V)，输入边表另计；限 k 个中转的快照版做 k+1 轮，时间 O(V+(k+1)(V+E))，两份距离数组共 O(V)。

    为什么第 n 轮还能松弛就说明有从 s 可达的负环？ 若不存在负环，所有最短路在 n−1 轮内就确定了，第 n 轮不该有任何改进。反过来若还能改进，说明存在一条"越来越短"的路径——那必然是绕着一个负环打转。

    限步数的变体¶

    这里的任务是：给定 n 个城市、有向航班 (u,v,票价)、起点 src、终点 dst，以及非负整数 k，返回至多经过 k 个中转城市的最低票价；无可行路线返回 −1。起终点不算中转，所以 k=0 只允许直达，k=1 最多允许两段航班。

    例如 0→1 票价 100、1→2 票价 100、0→2 票价 500，从 0 到 2：k=0 时只能花 500，k=1 时可以花 200。这里每一轮必须恰好只多允许一段航班，因此要用上一轮的快照来更新。

    def cheapest_within_k(n, flights, src, dst, k):
    INF = float('inf')
    dist = [INF] * n
    dist[src] = 0
    for _ in range(k + 1):                 # 最多 k+1 段航班
        nxt = dist[:]                      # ← 关键：基于上一轮快照
        for u, v, w in flights:
            if dist[u] != INF and dist[u] + w < nxt[v]:
                nxt[v] = dist[u] + w
        dist = nxt
    return dist[dst] if dist[dst] != INF else -1

    dist[:] 复制出一张独立的列表，初值与 dist 相同；若写 nxt=dist，两个变量仍指向同一张表，写 nxt 也会改变本轮仍要读取的 dist。

    为什么必须用副本？ 如果就地更新，同一轮里可能连续松弛多条边（比如 0→1→2→3 在一轮内全部完成），那就等于用了三段却只算一轮，跨越了 k 的限制。这是这题最容易错的地方。

    选读：全源最短路 Floyd–Warshall¶

    下面会把中间计算结果存成一张表，这种方法将在第 20 讲系统介绍。首次学习只需先掌握单源算法，之后再回来读。

    令 D[k][i][j] 表示“只允许编号 0..k−1 的顶点作中转”时 i 到 j 的最短距离。最初 D[0] 只考虑直接边与自己到自己的空路径。放开下一个顶点 k 时，最短路径要么不用 k，要么经 k 分成两段：

    D[k+1][i][j] = min(D[k][i][j], D[k][i][k] + D[k][k][j])

    这里先假定无负环，最短路径可去掉绕圈，因此不需要反复经过 k。

    把阶段 k 这一维省掉，就得到下面的二维实现。[[INF]*n for _ in range(n)] 每轮新建一行；不能写 [[INF]*n]*n，后者各行会引用同一个列表，改一格就会同时改其他行。

    def floyd_warshall(n, edges):
    INF = float('inf')
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for u, v, w in edges:
        dist[u][v] = min(dist[u][v], w)        # 处理平行边：取最小
    for k in range(n):                         # k 必须在最外层！
        for i in range(n):
            if dist[i][k] == INF:
                continue
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist

    无负环时，本轮 dist[k][k]=0，经过 k 再到 k 不会改进距离，所以本轮使用的第 k 行与第 k 列不会因更新而改变；这才允许在同一张表上原地更新，而无需保留上一张表。

    k 必须在最外层——它对应 DP 的"阶段"：我们一轮一轮地放宽"允许中转的顶点集合"。把它写到内层得到的就不是最短距离了。

    若 dist[i][i]<0，说明从 i 出发再返回 i 可获得负权闭合游走，其中含负环；它不必是恰好经过 i 的简单环。

    选读：稀疏图上的全源 Johnson¶

    Floyd-Warshall 是 O(V³)，稀疏图（E = O(V)）上太慢。Johnson 的思路分四步：

    1. 加一个虚拟源点 q，连 n 条权为 0 的边到所有顶点，用 Bellman-Ford 求 q 到各点的距离 h(v)
   （若检测到负环直接报错）
2. 给每条边重新赋权：w' = w + h(u) − h(v)     ← 这一步保证所有边权非负
3. 对每个顶点用一次 Dijkstra，得到重权后的最短路 d'(u,v)
4. 还原：d(u,v) = d'(u,v) − h(u) + h(v)

    为什么重权不破坏最短路？ 沿任意路径 s → ⋯ → t 求和，h 项两两抵消：

    w'(p) = Σ [w(u,v) + h(u) − h(v)] = w(p) + h(s) − h(t)

    也就是说，对固定的 s、t，所有路径的 w' 与 w 只差同一个常数，路径之间的相对大小完全不变。至于 w' ≥ 0：由 Bellman-Ford 的三角不等式 h(v) ≤ h(u) + w(u,v) 直接得到。

    按本讲堆实现，可写为 O(V(V+E)log(V+1))，还含 Bellman–Ford 的预处理；常在 E≥V 的稀疏图讨论中简写 O(VE log V)。

    一个容易忽略的最快情形¶

    如果图是 DAG，那么按拓扑序做一次松弛就能求出单源最短路——时间 O(V + E)，而且允许负权。因为拓扑序保证"处理一个顶点时，所有能到达它的顶点都已处理完"。

    利用无环结构，这里比一般带权图少了反复松弛或堆维护的开销。

    选读：把“求和”换掉¶

    Swim in Rising Water 给一个方形高度网格，水位随时间 t 上升；只有高度不超过 t 的格子才能进入。任务是从左上走到右下，只能上下左右移动，求最早到达时间。一条固定路线需要等到它经过的最高格子被淹没，因此路径代价是沿途格子高度的最大值。用 Dijkstra 时，起点代价为左上格高度，进入高度 x 的下一格时，新代价为 max(t,x)。

    与累加边权的普通最短路相比，这里把“加法”换成“取最大值”，而 max(t,x) ≥ t 仍然单调不减，所以 Dijkstra 的"第一次弹出即最优"依然成立。这个变体除了“延长路径不会让代价变小”，还满足“原来更好的路径在接同一条边后仍不会更差”：a≤b 时 max(a,w)≤max(b,w)。这些性质共同允许保留每个顶点的一个最优标签，不能只凭单调不减就推广到任意代价定义。

    最大概率路径则输入每条边的成功概率，假定沿途成功事件独立，目标是使整条路线的概率乘积最大。概率在 [0,1] 时，接一条边不会增大乘积，且同乘一个非负概率不会颠倒两个候选的优劣。因此可把“取当前最小距离”改成“取当前最大概率”。

    从讲义走到代码¶

    边权表示非负传播时间时可以用 Dijkstra；限制航班中转数还需要记录轮次。

    先对正文 s/a/b/t 图运行 dijkstra，得到距离 [0,3,1,8]（按 s,a,b,t 编号）。记录堆中过期的 (4,a) 为何应跳过。再做 Network Delay Time，先把 1..n 编号转成 0..n−1。

    对 times=[[1,2,1],[2,3,2]]、n=3、起点 1，答案为 3；缺少通向 3 的边时为 −1。接着做 Cheapest Flights，用 0→1→2 的链与 k=0 检查同一轮是否误用了两段航班。

    练习¶

    1. BFS 与按权重算，A 到 C 的最短路分别是什么？能改造 BFS 吗？

    BFS 说 1 条边；按权重是 A→B→C 代价 2。不能直接改 BFS，因为它的正确性依赖"先入队的一定更近"。改造方向是"把队列换成能按当前距离取最小的容器"，也就是最小堆——那就是 Dijkstra。

    2. 如果允许负权，Dijkstra 还成立吗？举反例。

    首次有效弹出即定型的结论不成立。正确反例是 s→a(1), s→b(2), b→a(−5)：先弹出 a 得 1，但真实最短距离是 s→b→a=−3。若弹出 a 就作为终点提前返回，会给错答案。

    本讲代码没有永久 settled 标记，后来可把 a 以 −3 再压回堆，因此它在这个反例上会修正结果。这不挽救非负权的正确性证明与复杂度保证；若有可达负环，还可能一直更新。学习反例时必须说明反驳的是哪项性质。

    3.（学完第 20 讲再做） 为什么朴素递归求斐波那契是指数级的？怎么改进？它和 Bellman-Ford 有什么共同点？

    递归式 T(n) = T(n−1) + T(n−2) + O(1) 的解是 Θ(φⁿ)，因为同一个子问题被反复求解。改进方式是记忆化或自底向上递推。Bellman-Ford 也可以看成 DP：状态是"从 s 出发、最多用 k 条边到达顶点 v 的最短距离"，阶段就是允许的边数 k，一共 n−1 个阶段。这与斐波那契"状态空间有限、转移只依赖更小的阶段"完全同构。

    4. 实现 network_delay_time(times, n, k)：从 k 广播，求所有节点收到信号的最短时间，不可达返回 −1。

    Dijkstra，答案是 max(dist) 而不是总和——信号是并行传播的，最慢的那个决定总时间。有 inf 就返回 −1。

    5. 实现 min_effort_path(heights)：输入非空矩形高度网格，从左上走到右下，每步上下左右移动。一步的体力消耗是相邻格高度差的绝对值，一条路线的消耗取其中最大的一步。返回所有路线里最小的这种消耗。例如一行 [[1,3,2]] 只有一条路线，消耗为 max(2,1)=2。

    Dijkstra 变体，堆里存 (当前最大高度差, r, c)，扩展时 新代价 = max(旧代价, |高度差|)。与 Swim in Rising Water 是同一个模板。

    6. 给定一个 DAG 和源点，求单源最短路（允许负权），要求 O(V + E)。

    先拓扑排序，再按拓扑序对每个顶点松弛它的出边。因为拓扑序保证处理某点时"所有能到达它的点都已处理完"，一次遍历就够了。
