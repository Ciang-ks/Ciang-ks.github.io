    1. 643 Maximum Average Subarray I¶

    LeetCode 643 ｜ Easy

    题目：找出长度恰好为 k 的连续子数组的最大平均值。

    为什么放这里：固定长度窗口的最简形态，用来建立"进一个、出一个"的肌肉记忆。

    思路提示：求最大平均值等价于求最大和。维护一个长度为 k 的窗口和，每轮 += nums[r]、-= nums[r-k]，全程 \(\mathcal{O}(1)\) 更新。

    方法辨析：所有候选长度都相同，除以 k 不改变大小顺序，因此只比较窗口和即可；若长度可变，最大和不再等于最大平均值。初始窗口必须确有 k 项，之后每移一格只需替换一个出入元素，负值也不影响这种固定长度更新。

    class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        cur = sum(nums[:k])
        best = cur
        for r in range(k, len(nums)):
            cur += nums[r] - nums[r - k]      # 进一个、出一个
            best = max(best, cur)
        return best / k

    易错点：结果是浮点数，最后再除以 k（不要每轮都除，避免精度累积）；k == len(nums) 时循环不执行，直接返回。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(1)\)。

    2. 209 Minimum Size Subarray Sum¶

    LeetCode 209 ｜ Medium

    题目：给定正整数数组和 target，找出和 不小于 target 的最短连续子数组长度，不存在返回 0。

    为什么放这里：最短窗口的标准题，专门用来练习"答案在收缩循环内部更新"。

    思路提示：右指针扩张累加和；一旦 \(\mathrm{sum} \ge \mathrm{target}\) 就进入收缩循环，每次收缩前更新答案，直到条件不再满足。

    方法辨析：正数让扩张只增和、收缩只减和；合法时记录并试着缩短，直到不合法，便覆盖了该右端的最短候选。含负数时缩短可能反而增和，标准移动依据失效；这不是“最短子数组”四个字就能决定的模板。

    class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        l = 0
        cur = 0
        best = float('inf')
        for r, x in enumerate(nums):
            cur += x
            while cur >= target:                  # 可以收缩
                best = min(best, r - l + 1)       # 在循环内部更新
                cur -= nums[l]
                l += 1
        return 0 if best == float('inf') else best

    易错点：题目保证元素是正整数——这是滑动窗口成立的前提（有负数就不能用）；答案更新必须在 while 内部；返回值要处理"无解"。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(1)\)。

    3. 438 Find All Anagrams in a String¶

    LeetCode 438 ｜ Medium

    题目：找出 s 中所有是 p 的异位词的子串的起始下标。

    为什么放这里：567 的直接推广——把"返回 True"换成"收集下标"，其余逻辑完全一致。

    思路提示：固定长度窗口 + 26 长度计数数组，窗口长度等于 len(p) 时比较两个计数数组。

    方法辨析：与 Permutation in String 共用固定长度、频次相同的判定，区别是要收集全部起点而非首次成功即停。长度必须与 p 相同，计数比较才同时验证字符及次数；出现匹配后仍按一进一出推进。

    class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        n, m = len(s), len(p)
        if m > n:
            return []
        need = [0] * 26
        window = [0] * 26
        for c in p:
            need[ord(c) - ord('a')] += 1

        res = []
        for r in range(n):
            window[ord(s[r]) - ord('a')] += 1
            if r >= m:
                window[ord(s[r - m]) - ord('a')] -= 1
            if r >= m - 1 and window == need:
                res.append(r - m + 1)
        return res

    易错点：起始下标是 \(r - m + 1\)；窗口长度判断用 \(r \ge m - 1\)；比较的是完整计数数组。

    复杂度：时间 \(\mathcal{O}(26n)\) = \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(1)\)。

    4. 1004 Max Consecutive Ones III¶

    LeetCode 1004 ｜ Medium

    题目：给定 0/1 数组和 k，最多可以把 k 个 0 翻转成 1，求最长连续 1 的长度。

    为什么放这里：424 的结构化翻版——"窗口长度 - 窗口内 1 的个数 不大于 k"，用 if 收缩的技巧也一样。

    思路提示：窗口内维护 0 的个数（或 1 的个数）。当 \(窗口长度 - 1的个数 > k\) 时收缩左边界。

    方法辨析：目标字符固定为 1，零的数量就是准确替换成本，不需要像字符替换题那样求窗口多数派。扩张若使零超过 k，就不断移左端；保留全部合法窗口的最大长度即可。k=0 时退化为最长连续一段 1。

    class Solution:
    def longestOnes(self, nums: List[int], k: int) -> int:
        l = 0
        ones = 0
        best = 0
        for r, x in enumerate(nums):
            ones += x
            if (r - l + 1) - ones > k:            # 0 的个数超过 k
                ones -= nums[l]
                l += 1
            best = max(best, r - l + 1)
        return best

    易错点：ones += x 利用了 0/1 数组的特性；收缩时要从 ones 里减去 nums[l]。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(1)\)。

    5. 713 Subarray Product Less Than K¶

    LeetCode 713 ｜ Medium

    题目：给定正整数数组和 k，统计乘积严格小于 k 的连续子数组个数。

    为什么放这里：滑动窗口的"计数"用法——不只求最长/最短，还要累计区间数量。

    思路提示：窗口内维护乘积。每轮扩张后，若乘积 \(\ge k\) 就收缩左边界。收缩完成后（窗口 \([l, r]\) 合法），以 r 结尾的合法子数组个数恰好是 \(r - l + 1\)（分别是 \([l,r]\)、\([l+1,r]\)、…、\([r,r]\)）。

    这个"以右端点计数"的技巧在子数组计数类题目里非常常用。

    方法辨析：数组元素为正整数，缩短窗口不会增大乘积，所以合法窗口的每个后缀都合法，才可一次贡献 r-l+1。k不大于1 时没有任何非空正整数乘积能小于 k；若允许零或负数，除法恢复与后缀合法性的证明都需重新处理。

    class Solution:
    def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:
        if k <= 1:
            return 0                          # 正整数乘积至少为 1
        l = 0
        cur = 1
        count = 0
        for r, x in enumerate(nums):
            cur *= x
            while cur >= k:
                cur //= nums[l]
                l += 1
            count += r - l + 1                # 以 r 结尾的合法子数组个数
        return count

    易错点：\(k \le 1\) 要特判（否则死循环或除零）；计数公式是 \(r - l + 1\) 不是 r - l。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(1)\)。

    6. 340 Longest Substring with At Most K Distinct Characters¶

    LeetCode 340（会员题） ｜ Medium

    题目：找出最多包含 k 个不同字符的最长子串长度。

    为什么放这里：3 题的推广——把"无重复"（每个字符最多出现一次）换成"种类数 不大于 k"。

    思路提示：窗口内维护字符频次字典。当 len(window) > k 时收缩左边界，并在计数归零时删除该键（否则 len(window) 不会变小）。

    方法辨析：频次字典只保存正计数键，len 才等于不同字符数。移走一个重复字符未必减少种类，只有计数降到零才删除；k=0 只能得到空窗口，与“恰好 k 种字符”的计数问题也不同。

    class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        count = {}
        l = 0
        best = 0
        for r, c in enumerate(s):
            count[c] = count.get(c, 0) + 1
            while len(count) > k:
                d = s[l]
                count[d] -= 1
                if count[d] == 0:
                    del count[d]              # 关键：删除零计数键
                l += 1
            best = max(best, r - l + 1)
        return best

    易错点：忘记 del count[d] 会让 len(count) 永远不变，导致死循环；\(k = 0\) 时返回 0。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(k)\)。

    7. 1438 Longest Continuous Subarray With Absolute Diff 不大于 Limit¶

    LeetCode 1438 ｜ Medium

    题目：找出最长的连续子数组，使其中任意两个元素之差的绝对值不超过 limit。

    为什么放这里：239 的进阶应用——同时维护窗口最大值和最小值，两个单调队列一起用。这是滑动窗口与单调队列结合的高频题型。

    思路提示：窗口内的"最大差"等于 窗口最大值 - 窗口最小值。所以要维护一个递减队列（取最大）和一个递增队列（取最小）。当 max - min > limit 时收缩左边界，两个队列同步弹出过期下标。

    方法辨析：窗口内任意两数最大绝对差恰是 max-min，所以两条单调队列足以检验全部数对。扩张不能减小该差，删除不能增大，故可按最长合法窗口收缩；队列存下标使边界移过时能同时让两个结构过期。

    from collections import deque

class Solution:
    def longestSubarray(self, nums: List[int], limit: int) -> int:
        maxq, minq = deque(), deque()        # maxq 递减，minq 递增，存下标
        l = 0
        best = 0
        for r, x in enumerate(nums):
            while maxq and nums[maxq[-1]] <= x:
                maxq.pop()
            maxq.append(r)
            while minq and nums[minq[-1]] >= x:
                minq.pop()
            minq.append(r)

            while nums[maxq[0]] - nums[minq[0]] > limit:
                l += 1
                if maxq[0] < l:
                    maxq.popleft()
                if minq[0] < l:
                    minq.popleft()

            best = max(best, r - l + 1)
        return best

    易错点：两个队列的单调方向相反（一个递减一个递增）；过期判断用 \(< l\)；收缩是 while 而不是 if。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(n)\)。

    变体：如果题目要求的是"窗口内元素的和"而不是差，那就换回简单的累加变量。
