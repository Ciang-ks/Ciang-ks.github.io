    253. Meeting Rooms II · 会议室 II¶

    Medium ｜ Intervals ｜ LeetCode 253（会员题） ｜ NeetCode

    题目大意¶

    给定一组会议时间区间，求最少需要多少间会议室才能安排所有会议（即"最多有多少场会议同时进行"）。

    输入: intervals = [[0,30],[5,10],[15,20]]     输出: 2
输入: intervals = [[7,10],[2,4]]              输出: 1

    思路¶

    这个问题有两个经典解法，两种都要会。

    方案 A：扫描线（最直观）¶

    把每个区间拆成两个"事件"：

    • 开始 → \((\mathrm{start}, +1)\)；
    • 结束 → (end, -1)。

    把所有事件按时间排序，然后扫一遍累加 cur，cur 的最大值就是答案。

    关键细节：同一时刻，"结束"事件必须排在"开始"事件之前。 因为题目约定半开区间 \([\mathrm{start}, \mathrm{end})\)——一场会议在 10 点结束，另一场 10 点开始，是可以共用同一间会议室的。

    实现上很简单：把事件存成 (time, delta) 元组，直接 sort() 就会让 -1 排在 \(+1\) 前面。

    方案 B：最小堆（也推荐）¶

    按开始时间排序，用一个最小堆存放"当前正在进行的会议的结束时间"：

    对每个会议 [s, e]：
    把堆顶所有 <= s 的结束时间弹出（这些会议已经结束了，会议室可以释放）
    把 e 压入堆
    堆的大小就是"此刻同时进行的会议数"，用它更新答案

    堆里存的都是"还没结束的会议"，所以堆的大小就是同时进行的会议数。 这个视角非常直观。

    解法推导与模式辨析¶

    同一时刻有 c 场会议在进行，至少需要 c 个房间，这是答案下界；按开始时间处理，每次复用已结束房间，否则增开，最多同时使用峰值数量的房间，说明该下界能达到。因此“最大重叠数”与“最少房间数”相等并非纯粹的定义替换。

    扫描线只需保留同时进行的数量，适合求最少数量；若还需输出每场分配到哪间房，应使用带房间编号的结束时间堆。当前堆思路弹出全部结束项并维护峰值；另一种只弹一个以记录已开房间的写法，堆就不再表示“全部正在开会的场次”，两种不变式不能混写。

    代码¶

    解法一：扫描线（推荐，代码最短）¶

    class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        events = []
        for start, end in intervals:
            events.append((start, 1))         # 开始
            events.append((end, -1))          # 结束

        events.sort()                         # 同一时刻，-1 排在 +1 之前
        cur = ans = 0
        for _, delta in events:
            cur += delta
            ans = max(ans, cur)

        return ans

    解法二：最小堆（思路最直观）¶

    import heapq

class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        intervals.sort()                      # 按开始时间排序
        heap = []                             # 正在进行的会议的结束时间
        ans = 0

        for start, end in intervals:
            while heap and heap[0] <= start:  # 已经结束的会议，释放会议室
                heapq.heappop(heap)
            heapq.heappush(heap, end)
            ans = max(ans, len(heap))

        return ans

    解法三：分别排序开始时间和结束时间（双指针，最巧妙）¶

    class Solution:
    def minMeetingRooms(self, intervals: List[List[int]]) -> int:
        starts = sorted(s for s, _ in intervals)
        ends = sorted(e for _, e in intervals)

        i = j = rooms = ans = 0
        while i < len(starts):
            if starts[i] < ends[j]:           # 有新会议开始但上一场还没结束
                rooms += 1
                i += 1
            else:                             # 有会议结束，释放一间
                rooms -= 1
                j += 1
            ans = max(ans, rooms)

        return ans

    这个版本把"开始时间"和"结束时间"分别排序后用双指针比较，空间更省、常数更小。面试中能写出来很出彩，但扫描线版更容易讲清。

    复杂度¶

    解法 时间 空间
    扫描线 \(\mathcal{O}(n \log n)\) \(\mathcal{O}(n)\)
    最小堆 \(\mathcal{O}(n \log n)\) \(\mathcal{O}(n)\)
    双指针 \(\mathcal{O}(n \log n)\) \(\mathcal{O}(n)\)

    易错点与面试追问¶

    • 扫描线里"结束"必须排在"开始"之前（半开区间约定）。如果把结束的优先级写反，答案会偏大。
    • 堆解法里的判断是 heap[0] <= start（结束时间 不大于 开始时间就可以复用），带等号。
    • 空数组返回 0。
    • 追问：如果区间是闭区间 [start, end]？ → 堆解法改成 heap[0] < start；扫描线里把 \((\mathrm{time}, +1)\) 排在 (time, -1) 之前（可以给 delta 取反或者用 (time, -delta) 排序）。
    • 追问：如果要求"输出具体的会议室分配"？ → 用堆存 (结束时间, 会议室编号)，每次分配弹出的编号，没有可复用的就新建一间。
    • 追问：这题和 252 的关系？ → 252 判断"能不能只用 1 间"，253 求"最少要几间"。253 的答案是 1 时，252 就是 True。
    • 追问：这题和 435 的关系？ → 435 求"最多保留几个不重叠区间"，253 求"最多同时重叠几个区间"。前者按右端点排序贪心，后者用扫描线/堆——两个问题的结构完全不同。
