    416. Partition Equal Subset Sum · 分割等和子集¶

    Medium ｜ 1-D DP / 0-1 背包 ｜ LeetCode 416 ｜ NeetCode

    题目大意¶

    给定正整数数组，判断能否把它分成两个和相等的子集。

    输入: nums = [1,5,11,5]
输出: true            # [1,5,5] 和 [11]

    思路¶

    问题的转化¶

    设数组总和为 total。分成两个和相等的子集，等价于：能否从数组中选出一部分，使它们的和恰好等于 \(\mathrm{total} / 2\)。

    于是问题变成"子集和"问题，也就是 0/1 背包（每个元素最多用一次）。

    快速特判¶

    • total 是奇数 → 不可能，直接返回 False；
    • 目标变成 target = total // 2。

    状态定义¶

    dp[j] = 能否从已处理的元素中选出和为 j 的子集。（布尔值）

    转移方程与遍历顺序¶

    对每个 x，从大到小枚举 j：

    for x in nums:
    for j in range(target, x - 1, -1):
        dp[j] = dp[j] or dp[j - x]

    为什么内层必须倒序？ 因为倒序时 dp[j-x] 还没被本轮更新过，保证每个元素最多只用一次（0/1 背包）。如果正序，就会变成"元素可以重复使用"（完全背包），得到错误的答案。

    这是本题最重要的一点，也是"0/1 背包 vs 完全背包"的分水岭。

    初始化¶

    dp[0] = True（不选任何元素就能凑出和 0）。

    解法推导与模式辨析¶

    选中一部分后，另一部分就是补集；总和为偶数且选中和为一半时，两边才同时满足目标。这里无需枚举如何给每个数贴左右标签，只判定某个子集和是否可达。相同值在不同位置仍是独立物品，各可使用一次。

    倒序的含义是读到的 dp[j-x] 仍属于“未加入当前元素”的旧层。例如只有一个 2 时，正序会先让 2 可达，再据此让 4 可达，相当于重复用了同一位置。当前数组全为正数，所以只存 0..target 足够；若包含负数，不能用这张非负容量表直接截断。\(\mathcal{O}(n\cdot \mathrm{target})\) 随数值大小增长，是伪多项式代价，并不等于按输入位数计的线性算法。

    代码¶

    解法一：一维 DP（0/1 背包，推荐）¶

    class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total % 2:                       # 奇数直接排除
            return False
        target = total // 2

        dp = [False] * (target + 1)
        dp[0] = True

        for x in nums:
            # 倒序：保证每个元素只用一次
            for j in range(target, x - 1, -1):
                if dp[j - x]:
                    dp[j] = True
            if dp[target]:                  # 已经达成，提前返回
                return True

        return dp[target]

    解法二：用集合记录"可达的和"（写法更简洁）¶

    class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total % 2:
            return False
        target = total // 2

        reachable = {0}
        for x in nums:
            # 关键：用"上一轮的快照"生成新集合，避免同一轮内重复使用 x
            reachable |= {s + x for s in reachable if s + x <= target}
            if target in reachable:
                return True

        return target in reachable

    reachable |= {...} 这一行是"用推导式先生成新集合，再合并"，天然避免了"同一轮里重复使用 x"，效果和倒序枚举一样。这个写法很 Pythonic，但要说清原理。

    解法三：二维 DP（最标准的背包写法）¶

    class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total % 2:
            return False
        target = total // 2
        n = len(nums)

        # dp[i][j] = 只看前 i 个元素，能否凑出和 j
        dp = [[False] * (target + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = True

        for i in range(1, n + 1):
            for j in range(target + 1):
                dp[i][j] = dp[i - 1][j]
                if j >= nums[i - 1]:
                    dp[i][j] = dp[i][j] or dp[i - 1][j - nums[i - 1]]

        return dp[n][target]

    二维版最贴近"背包"的标准形式，理解它之后再看一维版的空间压缩会很自然（把 i 这一维压掉，就得到了倒序枚举的写法）。

    复杂度¶

    解法 时间 空间
    一维 DP \(\mathcal{O}(n \cdot \mathrm{target})\) \(\mathcal{O}(\mathrm{target})\)
    集合版 \(\mathcal{O}(n \cdot \mathrm{target})\) \(\mathcal{O}(\mathrm{target})\)
    二维 DP \(\mathcal{O}(n \cdot \mathrm{target})\) \(\mathcal{O}(n \cdot \mathrm{target})\)

    易错点与面试追问¶

    • total 是奇数时直接返回 False，这是最容易被忘掉的剪枝。
    • 一维 DP 必须倒序枚举 j（0/1 背包）。正序会变成完全背包，答案错误。
    • dp[0] = True 不能省，它是所有转移的起点。
    • 集合版要用"先生成新集合再合并"（reachable |= {...}），不能写成逐个 add 的循环——后者会在同一轮内连锁使用同一个元素。
    • 追问：如果要求"输出具体的两个子集"？ → 记录每个状态的来源，最后回溯。
    • 追问：如果允许重复使用元素？ → 那就是完全背包（正序枚举），变成另一道题。
    • 追问：如果要求"分成 k 个和相等的子集"？ → 698 Partition to K Equal Sum Subsets，回溯 + 剪枝（因为背包 DP 的状态维度会爆炸）。
    • 追问：为什么这题是 NP 问题还能多项式求解？ → 因为这里的"和"是数值范围，所以 DP 的复杂度 \(\mathcal{O}(n \cdot \mathrm{target})\) 是"伪多项式"的；如果数值极大（比如用二进制表示），问题就是 NP-完全的。这个观察非常能体现算法理论功底。
