    1. 26 Remove Duplicates from Sorted Array¶

    LeetCode 26 ｜ Easy

    题目：给定已排序数组，原地删除重复元素，使每个元素只出现一次，返回新的长度。要求 O(1) 额外空间。

    为什么放这里：快慢指针最纯粹的形态——slow 指向"下一个可写位置"。

    思路提示：数组已排序，所以重复元素一定相邻。slow 指向"已去重部分的末尾 + 1"，fast 一路扫描；当 nums[fast] 与"最后一个被保留的值"不同时，把它写到 slow 位置。

    方法辨析：有序保证所有相同值相邻，因此只需与已保留前缀的最后一项比较。写指针后面的内容不属于有效结果，返回的是前缀长度；若输入无序，同值可能隔开，此判断就不足以全局去重。

    class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        if not nums:
            return 0
        slow = 1                              # nums[0] 必然保留
        for fast in range(1, len(nums)):
            if nums[fast] != nums[slow - 1]:  # 和"上一个保留的值"比较
                nums[slow] = nums[fast]
                slow += 1
        return slow

    易错点：比较对象是 nums[slow - 1]（上一个保留值），不是 nums[fast - 1]；slow 从 1 开始，因为第一个元素一定保留。

    复杂度：时间 O(n)，空间 O(1)。

    变体：80 Remove Duplicates from Sorted Array II 允许每个元素最多出现两次，只需把判断改成 slow < 2 or nums[fast] != nums[slow - 2]。

    2. 27 Remove Element¶

    LeetCode 27 ｜ Easy

    题目：原地移除数组中所有等于 val 的元素，返回新长度。元素顺序可以改变。

    为什么放这里：与第 1 题同一个模板，用来固化"slow 是写指针"这个心智模型。

    思路提示：fast 扫描全数组，遇到不等于 val 的元素就写到 slow 位置并前移。

    方法辨析：循环开始时 [0,slow) 恰好是已读部分中所有不等于 val 的值。读到应保留项就覆盖 slow，不必逐项删除并搬动整个后缀；若题目不要求保留相对顺序，也可考虑与末尾交换的另一写法。

    class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != val:
                nums[slow] = nums[fast]
                slow += 1
        return slow

    易错点：题目说"元素顺序可以改变"，所以也可以用"与末尾元素交换"的写法减少赋值次数——面试时提一句说明你在读题。

    复杂度：时间 O(n)，空间 O(1)。

    3. 283 Move Zeroes¶

    LeetCode 283 ｜ Easy

    题目：把所有 0 移动到数组末尾，同时保持非零元素的相对顺序。

    为什么放这里：快慢指针 + "扫描后补零"的组合，是原地重排类问题的标准收尾方式。

    思路提示：先用快慢指针把所有非零元素"压缩"到前面，剩余位置统一填 0。注意不能只做压缩而忘记补零。

    方法辨析：本题保留数组原长度，并要求非零元素相对顺序不变；先稳定压缩非零，再填零，满足的约束比 Remove Element 多。写入非零前缀不会覆盖尚未读取元素，因为写指针始终不超过读指针。

    class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow] = nums[fast]
                slow += 1
        for i in range(slow, len(nums)):      # 剩下的补 0
            nums[i] = 0

    易错点：不能只做"压缩"而忘记补 0；题目要求原地修改，不要返回新数组。

    复杂度：时间 O(n)，空间 O(1)。

    4. 977 Squares of a Sorted Array¶

    LeetCode 977 ｜ Easy

    题目：给定非递减数组（可能含负数），返回每个元素平方后仍然非递减的数组。

    为什么放这里：对撞指针的经典变体——不从两头往中间填，而是从中间往两头读、从后往前填。

    思路提示：平方后的最大值一定出现在两端：要么是最负的数，要么是最大的正数。于是用左右指针比较绝对值，谁大就把谁的平方放到结果数组的末尾。

    方法辨析：非负平方与绝对值同序，排序数组中绝对值最大者必在两端；拿走它后，剩余候选仍是一段有序区间，故可重复比较。输出从右往左填，是因为每轮确定的是最大剩余平方，不是最小值。

    class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        n = len(nums)
        res = [0] * n
        l, r = 0, n - 1
        for k in range(n - 1, -1, -1):
            if abs(nums[l]) > abs(nums[r]):
                res[k] = nums[l] ** 2
                l += 1
            else:
                res[k] = nums[r] ** 2
                r -= 1
        return res

    易错点：结果必须从后往前填（拿到的是当前最大值）；比较的是绝对值，而不是平方前的原值。

    复杂度：时间 O(n)，空间 O(n)（输出）。

    5. 680 Valid Palindrome II¶

    LeetCode 680 ｜ Easy

    题目：给定字符串 s，判断最多删除一个字符后能否变成回文串。

    为什么放这里：Valid Palindrome 的容错版本，考察"遇到不匹配时如何分支"。

    思路提示：依然左右对撞。当 s[l] != s[r] 时只有两种可能——删掉左字符后检查 s[l+1..r]，或删掉右字符后检查 s[l..r-1]；任一成立即可。不需要真的删字符，用区间上的回文检查即可。

    方法辨析：第一次失配后，保留两端字符不可能使它们互相匹配，所以若只删一个，必须删这两端之一。分别检查两个剩余区间已穷尽可能，不必在整串每个位置尝试；后续不能再允许删除，否则就改变了预算。

    class Solution:
    def validPalindrome(self, s: str) -> bool:
        def is_pal(i: int, j: int) -> bool:
            while i < j:
                if s[i] != s[j]:
                    return False
                i += 1
                j -= 1
            return True

        l, r = 0, len(s) - 1
        while l < r:
            if s[l] != s[r]:
                return is_pal(l + 1, r) or is_pal(l, r - 1)
            l += 1
            r -= 1
        return True

    易错点：不能用"不匹配的字符对数量 ≤ 2"这种简化判断来代替真正的区间检查，否则会在 "abc" 这类用例上出错。

    复杂度：时间 O(n)，空间 O(1)。

    6. 16 3Sum Closest¶

    LeetCode 16 ｜ Medium

    题目：找出三个数，使其和最接近 target，返回这个和。

    为什么放这里：3Sum 的"目标函数替换"版本——双指针框架完全不变，只是把"相等判定"换成"更新最近值"。用它检验你是否真的理解 3Sum 的骨架。

    思路提示：排序后固定第一个数，左右双指针搜索，每一步记录 |cur - target| 最小的和。本题不需要去重（只返回一个值），这也说明"去重"是 3Sum 的题目需求，而不是双指针本身的性质。

    方法辨析：求最接近不再要求命中 target 才记录，因此每次计算当前和都要更新差值。和偏小时，当前右端已提供该左端能得到的最大和，继续缩右端只会更远，可安全丢弃此左端；和偏大时对称。

    class Solution:
    def threeSumClosest(self, nums: List[int], target: int) -> int:
        nums.sort()
        best = nums[0] + nums[1] + nums[2]     # 用一个真实存在的三元组初始化
        n = len(nums)
        for i in range(n - 2):
            l, r = i + 1, n - 1
            while l < r:
                cur = nums[i] + nums[l] + nums[r]
                if abs(cur - target) < abs(best - target):
                    best = cur
                if cur == target:
                    return cur                 # 已经最优，可提前返回
                elif cur < target:
                    l += 1
                else:
                    r -= 1
        return best

    易错点：best 用真实存在的三元组初始化，比用 inf 更容易推理；cur == target 时可以直接返回。

    复杂度：时间 O(n²)，辅助空间 O(n)（Python 排序）。

    7. 18 4Sum¶

    LeetCode 18 ｜ Medium

    题目：找出所有和为 target 的不重复四元组。

    为什么放这里：kSum 的泛化。理解了"固定一层 + 降维"，4Sum、5Sum 就没有区别。

    思路提示：3Sum 是"固定 1 个数 + 2Sum 双指针"，4Sum 就是"固定 2 个数 + 2Sum 双指针"，再往上就是"固定 k-2 个数 + 双指针"。去重规则完全一致：每一层固定值都要跳过与前一个相同的值，最内层命中后也要跳重复值。

    方法辨析：两层固定位置都只向右取后续元素，因此四个下标必互异。结果按值去重仍需每层跳过等值固定点，并在内层命中后跳过重复端点；只对最终结果做 set 会保留大量重复搜索。

    class Solution:
    def fourSum(self, nums: List[int], target: int) -> List[List[int]]:
        nums.sort()
        res = []
        n = len(nums)

        for i in range(n - 3):
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            for j in range(i + 1, n - 2):
                if j > i + 1 and nums[j] == nums[j - 1]:
                    continue
                l, r = j + 1, n - 1
                while l < r:
                    total = nums[i] + nums[j] + nums[l] + nums[r]
                    if total == target:
                        res.append([nums[i], nums[j], nums[l], nums[r]])
                        l += 1
                        r -= 1
                        while l < r and nums[l] == nums[l - 1]:
                            l += 1
                        while l < r and nums[r] == nums[r + 1]:
                            r -= 1
                    elif total < target:
                        l += 1
                    else:
                        r -= 1
        return res

    易错点：内层去重条件是 j > i + 1（不是 j > 0），因为 j 的第一项是 i + 1，必须允许它取到。

    复杂度：时间 O(n³)，辅助空间 O(n)（Python 排序，输出另计）。

    通用写法：写一个 kSum(nums, target, k, start) 递归函数，当 k == 2 时切换成双指针，这样 4Sum、5Sum 可以共用一份代码。
