    Two Pointers · 解题手册¶

    双指针的核心不是"用两个变量"，而是利用单调性让指针只朝一个方向移动。写之前必须能回答一句："我要移动这一边，凭什么不会漏掉答案？"——答不上来就是在碰运气。

    一、从题面提出候选，再核对条件¶

    已学基础：05-双指针与滑动窗口。下面将讲义中的结构性质用于选择解法。

    双指针的理由是一次移动能安全排除一批候选，或能维护已读与已写区间。仅有两个下标不是正确性依据。

    题目特征 需要验证的依据 迁移边界与反例
    有序数组找两数之和 固定左值时，当前右值已是最大候选；和仍小时可排除该左值 一般乘积或差值约束未必支持相同移动规则
    判断回文 两端有效字符必须相等，匹配后向内缩 允许删除时出现分支，需要另推
    原地去重或压缩 读指针扫描输入，写指针表示已保留前缀 只要求返回新长度，尾部通常不是有效答案
    容器或接雨水 分别证明面积候选的支配关系或逐格水位可确定 容器求一对边的最大值，雨水求全格总量

    先写清每轮前 [0,slow) 或 [l,r] 代表什么，再解释移动后丢掉了哪些候选。3Sum 的排序会改变原下标，若题目要求原位置须额外保留映射。

    二、三种形态与它们的"移动依据"¶

    形态 1 对撞指针（相向）¶

    def two_sum_sorted(nums, target):
    left, right = 0, len(nums) - 1
    while left < right:
        cur = nums[left] + nums[right]
        if cur == target:
            return [left, right]
        elif cur < target:
            left += 1            # 和太小 → 需要更大的数
        else:
            right -= 1           # 和太大 → 需要更小的数
    return []

    移动依据必须能证明。以 Two Sum II 为例：当 \(\mathrm{nums}[l] + \mathrm{nums}[r] < \mathrm{target}\) 时，由于数组有序，nums[l] 与任何 \(\le r\) 的位置相加都不会更大，所以 nums[l] 不可能出现在任何可行解里，可以安全丢弃。

    形态 2 快慢指针（同向）¶

    def remove_element(nums, val):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != val:
            nums[slow] = nums[fast]
            slow += 1
    return slow              # slow 就是新长度

    slow 的语义是"下一个待写位置"，一旦想清楚这一点，所有"原地删除/压缩"题都是同一个模板。

    形态 3 分离双指针（两个序列）¶

    def merge_sorted(a, b):
    i = j = 0
    res = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            res.append(a[i])
            i += 1
        else:
            res.append(b[j])
            j += 1
    res.extend(a[i:])
    res.extend(b[j:])
    return res

    三、"移动依据"四种常见来源¶

    来源 典型题 移动规则
    有序数组两端的和 Two Sum II、3Sum 和偏小左移、偏大右移
    面积由较矮的一侧决定 Container With Most Water 移动较矮的一边
    水位由对侧更高柱保证 Trapping Rain Water 移动较矮的一边并立刻结算
    字符是否字母数字 Valid Palindrome 跳过非法字符后再比较

    四、常用模板与使用条件¶

    模板 1 kSum 通用骨架（3Sum / 4Sum 都是它）¶

    def three_sum(nums):
    nums.sort()
    res = []
    n = len(nums)
    for i in range(n - 2):
        if nums[i] > 0:                                  # 剪枝：最小数都是正的
            break
        if i > 0 and nums[i] == nums[i - 1]:             # 去重 1：固定值
            continue
        left, right = i + 1, n - 1
        target = -nums[i]
        while left < right:
            cur = nums[left] + nums[right]
            if cur == target:
                res.append([nums[i], nums[left], nums[right]])
                left += 1
                right -= 1
                while left < right and nums[left] == nums[left - 1]:     # 去重 2
                    left += 1
                while left < right and nums[right] == nums[right + 1]:
                    right -= 1
            elif cur < target:
                left += 1
            else:
                right -= 1
    return res

    两处去重都不能少。第一处防"相同的固定值重复开分支"，第二处防"命中后左右指针停在相同值上"。

    模板 2 前缀极值 + 双指针（蓄水类）¶

    def trap(height):
    if not height:
        return 0
    l, r = 0, len(height) - 1
    left_max, right_max = height[l], height[r]
    water = 0
    while l < r:
        if left_max < right_max:
            l += 1
            left_max = max(left_max, height[l])
            water += left_max - height[l]     # 水位由 left_max 决定
        else:
            r -= 1
            right_max = max(right_max, height[r])
            water += right_max - height[r]
    return water

    注意比较的是 left_max 与 right_max，不是 height[l] 与 height[r]——这是本题最大的坑。

    五、逐题推演：从题面到思路¶

    1. Valid Palindrome（125）¶

    题面信号："只考虑字母数字、忽略大小写，判断是否回文"。

    候选思路：回文 → 对撞指针。多出来的规则只是"跳过非字母数字"。

    走一遍示例："A man, a plan, a canal: Panama"

    l 指向 'A'（字母，保留）；r 指向 'a'（字母，保留）→ 比较 lower 后相同，l++ r--
l 指到空格 → 跳过；r 指到 'm' → 比较 A/m？继续推进
... 一直推进到中间相遇 → True

    关键细节：两个跳过循环都必须带 \(l < r\) 条件，防止越界；" "、".,"、"" 都应返回 True（跳过之后 \(l \ge r\) 天然正确）。

    追问准备："允许删除一个字符？" → 680，遇到不匹配时分两支验证 \([l+1, r]\) 或 \([l, r-1]\)。

    2. Two Sum II（167）¶

    题面信号：数组已排序；要求 \(\mathcal{O}(1)\) 额外空间；返回 1-based 下标。

    候选思路：有序 + 求一对 → 对撞指针。哈希也能做，但用了 \(\mathcal{O}(n)\) 空间，题目给了"有序"就是在暗示双指针。

    走一遍示例：numbers = [2,7,11,15]，target = 9

    • \(l=0(2), r=3(15)\)：和 17 > 9 → r--（15 太大，它配最小的 2 都超了）
    • \(l=0(2), r=2(11)\)：和 13 > 9 → r--
    • \(l=0(2), r=1(7)\)：和 9 → 返回 [1, 2]

    关键细节：返回 [l + 1, r + 1]；循环写 \(l < r\) 而不是 \(\le\)（同一元素不能用两次）。

    3. 3Sum（15）¶

    题面信号："找出所有和为 0 的三元组，且不能重复"。

    候选思路：kSum 降维 —— 排序 + 固定第一个数 + 对剩下的做 Two Sum II。排序还顺带解决了去重。

    走一遍示例：\(\mathrm{nums} = [-1,0,1,2,-1,-4]\)，排序后 [-4,-1,-1,0,1,2]

    固定的 i nums[i] 目标 双指针结果
    0 -4 4 无（最大 2，凑不出 4）
    1 -1 1 命中 (-1,0,1)；继续移动后命中 (-1,-1,2)
    2 -1 1 与 i=1 同值 → 跳过（否则会重复输出）
    3 0 0 只剩 [1,2]，和为 3，不行

    答案 [[-1,-1,2],[-1,0,1]]。

    关键细节：i 从 1 开始时判断 \(\mathrm{nums}[i] = \mathrm{nums}[i-1]\) 才跳过；\(\mathrm{nums}[i] > 0\) 时可以直接 break（后面全是正数）。

    4. Container With Most Water（11）¶

    题面信号："两端竖线围成容器，求最大水量"。

    候选思路：面积 = min(高) * 宽，两端决定 → 对撞指针，每次移动较矮的一边。

    为什么移动较矮的？ 假设 \(\mathrm{height}[l] < \mathrm{height}[r]\)，那么所有"以 l 为左端点"的容器：宽度最大就是当前值，高度上限被 height[l] 锁死。当前这个已经是 l 能给出的最大值，所以 l 可以永久丢弃。

    走一遍示例：\(\mathrm{height} = [1,8,6,2,5,4,8,3,7]\)

    l=0(1), r=8(7)：min=1，宽 8 → 面积 8，移动 l（较矮）
l=1(8), r=8(7)：min=7，宽 7 → 面积 49，移动 r
l=1(8), r=7(3)：min=3，宽 6 → 面积 18，移动 r
... 最大值 49

    关键细节：面积公式里的 min 不能省；两边相等时移动哪边都可以（新的一侧高度不可能超过当前值）。

    5. Trapping Rain Water（42）¶

    题面信号："柱子之间能存多少水"。

    候选思路：单点水量 = min(左侧最高, 右侧最高) - height[i]。直接算需要前后缀数组（\(\mathcal{O}(n)\) 空间）；双指针版本可以省掉数组：当 left_max < right_max 时，左侧水位已经被 left_max 锁死，可以立刻结算。

    走一遍示例：\(\mathrm{height} = [0,1,0,2,1,0,1,3,2,1,2,1]\)

    关键看 i=2（高 0）：左侧最高 1，右侧存在高度 3 的柱子
→ 水位 = min(1, 3) = 1，存水 1 - 0 = 1

    逐格累加得到 6。

    关键细节：比较的是 left_max 和 right_max（不是 height[l] 和 height[r]）；移动指针 → 更新 max → 累加，顺序不能乱。

    面试节奏建议：先讲清公式，再给"前缀/后缀最大值数组"版本（好写），最后提出双指针优化空间；单调栈作为备选方案提一句。

    六、复杂度速查¶

    题目 形态 时间 空间
    Valid Palindrome 对撞 \(\mathcal{O}(n)\) \(\mathcal{O}(1)\)
    Two Sum II 对撞 \(\mathcal{O}(n)\) \(\mathcal{O}(1)\)
    3Sum 排序 + 对撞 \(\mathcal{O}(n^{2})\) Python 排序最坏 \(\mathcal{O}(n)\)，输出另计
    Container With Most Water 对撞 \(\mathcal{O}(n)\) \(\mathcal{O}(1)\)
    Trapping Rain Water 对撞 + 前缀极值 \(\mathcal{O}(n)\) \(\mathcal{O}(1)\)

    七、易错点速查¶

    1. 去重的比较对象：\(\mathrm{nums}[i] = \mathrm{nums}[i-1]\)（和前一个已选值比），不是和后一个比。
    2. 命中后的去重顺序：先记录答案 → 再移动指针 → 再跳过重复值。
    3. while l < r 还是 \(\le\)：两数之和不能取同一元素，用 \(<\)。
    4. 容器问题漏掉 min。
    5. Valid Palindrome 的跳过循环漏掉 \(l < r\)。
    6. 3Sum 返回的是值，Two Sum II 返回的是 1-based 下标。
    7. 排序会改变下标：若题目要求返回原下标，要先把 (值, 下标) 配对再排序。
    8. 有序数组不要习惯性用哈希：先想想双指针能不能把空间降到 \(\mathcal{O}(1)\)。

    八、面试话术¶

    "我先排序，然后固定第一个数，剩下部分用左右双指针。因为数组有序，和偏小时只能移动左指针让和变大——这是安全的，因为右指针左移只会让和更小。总复杂度 \(\mathcal{O}(n^{2})\)，空间 \(\mathcal{O}(1)\)（不计排序）。去重需要在固定值和双指针命中两处各做一次。"
