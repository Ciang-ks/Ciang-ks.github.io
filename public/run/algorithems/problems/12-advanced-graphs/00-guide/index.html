    Advanced Graphs · 解题手册¶

    上一个模块解决"连通性"，这个模块解决"代价"：最短路径、最小生成树、欧拉路径。主要工具包括 Dijkstra、分层松弛、Kruskal/Prim、Hierholzer 以及依赖关系的拓扑排序；先判断目标和约束，再选算法。

    一、从题面提出候选，再核对条件¶

    已学基础：17-并查集与最小生成树、18-最短路径、19-欧拉路径与网络流。下面将讲义中的结构性质用于选择解法。

    同样是带权图，最短路优化一条路线，生成树优化连接全图的边集合；欧拉路径则约束每条边恰好使用一次，目标各不相同。

    题目特征 需要验证的依据 迁移边界与反例
    非负代价单源最短路 Dijkstra，确认当前状态足以支配较差路径 有航段限制时需增加已用段数或分层
    限制最多若干边 分层松弛读取上一层快照 就地更新会在一轮内连走多条边
    最低总成本连通全部点 MST，借割边交换论证选择安全 最短路树不一定是最小生成树
    用完全部机票 在存在合法欧拉行程的前提下用 Hierholzer 机场可重复经过，机票实例不能重复使用

    先写路径代价如何扩展、何时确定最优以及过期状态如何识别。瓶颈 max、概率乘积等变体要重新检查保序与扩展不改善的条件，不能机械替换运算符。

    二、Dijkstra 模板与它的三种变形¶

    import heapq
from collections import defaultdict

def dijkstra(n, edges, src):
    graph = defaultdict(list)
    for u, v, w in edges:
        graph[u].append((v, w))

    dist = [float("inf")] * n
    dist[src] = 0
    heap = [(0, src)]

    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:
            continue                     # 过期条目，跳过
        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(heap, (nd, v))
    return dist

    三个关键点：

    1. if d > dist[u]: continue 不能省——同一个节点可能被多次入堆，只有第一次弹出的才是最优的；
    2. 只能处理非负权边（有负权时贪心性质失效）；
    3. 复杂度 O((V + E) log V)。

    变形 1 瓶颈路径（代价取 max）¶

    def min_max_path(grid):
    n = len(grid)
    best = [[float("inf")] * n for _ in range(n)]
    best[0][0] = grid[0][0]
    heap = [(grid[0][0], 0, 0)]
    while heap:
        cost, r, c = heapq.heappop(heap)
        if r == n - 1 and c == n - 1:
            return cost
        if cost > best[r][c]:
            continue
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < n and 0 <= nc < n:
                nxt = max(cost, grid[nr][nc])     # 关键：取 max 而不是相加
                if nxt < best[nr][nc]:
                    best[nr][nc] = nxt
                    heapq.heappush(heap, (nxt, nr, nc))
    return -1

    为什么取 max 之后 Dijkstra 仍然正确？ 因为 max 扩展既不降低已有代价，也保持两条路径的优劣关系，所以较小状态可支配较大状态，最小候选出堆时可确定最优。这是本题型最有价值的讨论点。

    变形 2 最大概率 / 最大值（取 min 或乘法）¶

    def max_probability(n, edges, succ_prob, start, end):
    graph = defaultdict(list)
    for (u, v), p in zip(edges, succ_prob):
        graph[u].append((v, p))
        graph[v].append((u, p))

    best = [0.0] * n
    best[start] = 1.0
    heap = [(-1.0, start)]               # 大顶堆（存负数）
    while heap:
        negp, u = heapq.heappop(heap)
        p = -negp
        if u == end:
            return p
        if p < best[u]:
            continue
        for v, edge_p in graph[u]:
            np_ = p * edge_p
            if np_ > best[v]:            # 注意是大于
                best[v] = np_
                heapq.heappush(heap, (-np_, v))
    return 0.0

    变形 3 限制步数（787）¶

    def cheapest_within_k(n, flights, src, dst, k):
    INF = float("inf")
    dist = [INF] * n
    dist[src] = 0
    for _ in range(k + 1):                       # 最多 k+1 段航班
        nxt = dist[:]                            # 关键：基于上一轮快照
        for u, v, w in flights:
            if dist[u] + w < nxt[v]:
                nxt[v] = dist[u] + w
        dist = nxt
    return dist[dst] if dist[dst] < INF else -1

    nxt = dist[:] 这一行是本题的核心：如果就地更新，同一轮里可能连续松弛多条边（0→1→2→3 在一轮内完成），跨越了 k 的限制。

    三、最小生成树：Prim 与 Kruskal¶

    import heapq

def prim(n, points):
    """以曼哈顿距离为例：适合"距离需要现算"的稠密图"""
    visited = [False] * n
    heap = [(0, 0)]
    total = 0
    used = 0
    while used < n:
        d, u = heapq.heappop(heap)
        if visited[u]:
            continue
        visited[u] = True
        total += d
        used += 1
        for v in range(n):
            if not visited[v]:
                w = abs(points[u][0] - points[v][0]) + abs(points[u][1] - points[v][1])
                heapq.heappush(heap, (w, v))
    return total

    def kruskal(n, edges):
    """适合"边已经以列表形式给出"的稀疏图"""
    parent = list(range(n))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    edges.sort(key=lambda e: e[2])       # 按权重升序
    total = 0
    count = 0
    for u, v, w in edges:
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            total += w
            count += 1
            if count == n - 1:
                break
    return total

    Prim 和 Dijkstra 的代码几乎一样，需要区分堆中代价的含义以及更新规则：

    算法 堆里存的量
    Dijkstra 从起点到该点的累计距离
    Prim 该点到当前生成树的最近距离（单边权重）

    选型：边少（稀疏图）用 Kruskal；边多（稠密图，或需要现算距离）用 Prim。

    四、欧拉路径：Hierholzer¶

    def find_itinerary(tickets):
    from collections import defaultdict
    graph = defaultdict(list)
    for src, dst in tickets:
        graph[src].append(dst)
    for src in graph:
        graph[src].sort(reverse=True)    # 倒序排，配合 pop() 取到字典序最小的

    route = []

    def dfs(node):
        while graph[node]:
            nxt = graph[node].pop()      # 用掉这条边
            dfs(nxt)
        route.append(node)               # 后序：无路可走时才记录

    dfs("JFK")
    return route[::-1]

    为什么是"后序 + 反转"？ 直观理解：如果某条路走进去是死胡同，那段应该被安排在行程的最后面；后序遍历正好让"最晚走投无路"的节点最先被记录，反转后就对了。

    五、从读题到写码：四步流程¶

    1. 判断问题类型：最短路 / 最小生成树 / 欧拉路径？
    2. 看边权的性质：非负 → Dijkstra；有负权或限制步数 → Bellman-Ford。
    3. 看边怎么给出：边列表 → Kruskal；点坐标或稠密图 → Prim。
    4. 看是否有额外约束：限制步数 → 状态加维度；瓶颈路径 → 代价取 max。

    六、逐题推演：从题面到思路¶

    1. Min Cost to Connect All Points（1584）¶

    题面信号："用最小总费用把所有点连通"。

    候选思路："连通所有点、总代价最小"就是最小生成树的定义，和"最短路"是两个完全不同的问题——MST 保证总权重最小，但不保证任意两点间路径最短。

    为什么用 Prim 而不是 Kruskal？ 因为点两两之间的边有 O(n²) 条，显式构造所有边会占用 O(n²) 空间；数组版 Prim 按需计算边权，额外空间 O(n)；本页堆模板保留大量候选边，最坏占 O(n²)。

    走一遍示例：points = [[0,0],[2,2],[3,10],[5,2],[7,0]]

    从点 0 出发：到各点距离 4, 13, 7, 7 → 选最近的点 1（距离 4）
生成树 {0,1}：点 2 到树的最近距离 min(13, 9) = 9；点 3：min(7, 4)=4；点 4：min(7, 5)=5
→ 选点 3（距离 4），生成树 {0,1,3}
继续：点 2 → min(9, 8, 11)=8；点 4 → min(7,5,4)=4 → 选点 4（距离 4）
最后选点 2（距离 8）
总费用 = 4 + 4 + 4 + 8 = 20

    关键细节：Prim 堆里存的是"到生成树的距离"，不是"从起点的累计距离"——这是和 Dijkstra 关键区别之一；跳过过期条目 if visited[u]: continue 不能省。

    2. Network Delay Time（743）¶

    题面信号："从节点 k 广播，求所有节点都收到信号的时间"。

    候选思路：非负权单源最短路 → Dijkstra。答案是所有 dist 的最大值（信号并行传播，最慢的那个决定总时间），不是求和。

    走一遍示例：times = [[2,1,1],[2,3,1],[3,4,1]]，k = 2

    dist[2] = 0
松弛出边：dist[1] = 1，dist[3] = 1
从 3 继续：dist[4] = 2
所有节点可达，答案 = max(0,1,1,2) = 2

    关键细节：有节点不可达时返回 -1（检查 max(dist.values()) 是否为 inf）；节点编号是 1..n（开 n+1 大小的数组或直接用字典）；有向图只加一条边。

    3. Cheapest Flights Within K Stops（787）¶

    题面信号："最多 k 个中转站的最便宜航班"。

    候选思路：普通 Dijkstra 只管"价格最低"，这里多了一个"步数上限"的约束，最便宜的路径可能步数超标。所以状态要带上"已用段数"。

    Bellman-Ford 的轮数语义正好对应步数：第 i 轮结束后 dist[v] 表示"最多用 i 条边到达 v 的最低价格"，所以做 k+1 轮即可。

    走一遍示例：n = 4，flights = [[0,1,100],[1,2,100],[2,0,100],[1,3,600],[2,3,200]]，src=0, dst=3, k=1

    第 1 轮（最多 1 段）: dist = [0, 100, inf, inf]
第 2 轮（最多 2 段）: 从 1 出发 → dist[2] = 200, dist[3] = 700
答案 = 700（0 → 1 → 3，共 2 段 = 1 个中转站）✓

    关键细节：k 是中转站数量，所以最多 k+1 段航班（写成 range(k) 会少一轮）；必须用副本更新 nxt = dist[:]，否则同一轮内会连续松弛多条边，跨越 k 的限制。

    4. Reconstruct Itinerary（332）¶

    题面信号："用完所有机票恰好一次，返回行程；多种走法时取字典序最小"。

    候选思路："用完所有的边恰好一次"就是欧拉路径。朴素回溯枚举所有走法是指数级的，必须用 Hierholzer。

    走一遍示例：tickets = [["MUC","LHR"],["JFK","MUC"],["SFO","SJC"],["LHR","SFO"]]

    邻接表（倒序存）: JFK→[MUC], MUC→[LHR], LHR→[SFO], SFO→[SJC]
dfs(JFK) → 走到 MUC → 走到 LHR → 走到 SFO → 走到 SJC（无出边，记录 SJC）
回溯记录 SFO、LHR、MUC、JFK
route = [SJC, SFO, LHR, MUC, JFK] → 反转 → [JFK, MUC, LHR, SFO, SJC] ✓

    关键细节：必须后序记录再反转；邻接表要倒序排序（配合 pop() 才能取到字典序最小的目的地），或者直接用小顶堆；有重复机票时 pop() 天然处理。

    5. Swim in Rising Water（778）¶

    题面信号："时刻 t 只能走高度 ≤ t 的格子，求从左上到右下所需的最小时间"。

    候选思路：把每个格子的高度看成"边权"，问题变成"最小化路径上的最大值"（最小瓶颈路径）。Dijkstra 的框架不变，只把"代价相加"换成"代价取 max"。

    为什么取 max 之后仍然正确？ 因为 max(t,x)≥t，且 t₁≤t₂ 时 max(t₁,x)≤max(t₂,x)，扩展不降价且保序，故最小候选首次出堆即可确定最优。

    走一遍示例：grid = [[0,2],[1,3]]

    起点 t = 0
邻居 (0,1) 高度 2 → 代价 max(0,2) = 2；(1,0) 高度 1 → 代价 1
弹出代价 1 的 (1,0)，从它到 (1,1) 高度 3 → 代价 max(1,3) = 3
弹出终点 (1,1)，代价 3 → 返回 3 ✓

    另一种解法：二分答案 t + BFS 判断连通性，O(n² log(maxH))。第三种解法：按高度升序"激活"格子并用并查集合并，起点终点第一次连通时的高度就是答案（和 Kruskal 同源）。

    6. Alien Dictionary（269）¶

    题面信号："给定按外星字典序排好序的单词，推导字母顺序"。

    候选思路：难点在建图，不在排序。相邻两个单词的第一个不同字符确定了一条先后关系；把这些关系建成有向图后，拓扑排序就是答案。

    走一遍示例：words = ["wrt","wrf","er","ett","rftt"]

    "wrt" vs "wrf" → 前两个字符相同，第 3 个 t≠f → 边 t → f
"wrf" vs "er"  → 第 1 个字符 w≠e → 边 w → e
"er"  vs "ett" → 第 2 个字符 r≠t → 边 r → t
"ett" vs "rftt"→ 第 1 个字符 e≠r → 边 e → r
拓扑序（一种）: w → e → r → t → f，即 "wertf"

    三种必须处理的边界情况：

    1. 前缀冲突：["abc","ab"] → 短词本应在前，顺序矛盾 → 返回 ""（判断条件：w1[:L] == w2[:L] and len(w1) > len(w2)）；
    2. 有环：拓扑序长度 < 字母总数 → 返回 ""；
    3. 只有一个单词 / 所有单词相同：提取不到任何关系，但答案不是空串——所有出现过的字母都可以任意排列（解法一天然处理）。

    关键细节：只能从相邻单词提取关系；只取第一个不同字符就要 break；建图时要收集所有出现过的字母（包括没参与比较的），否则长度检查会出错。

    七、复杂度速查¶

    题目 算法 时间
    Min Cost to Connect All Points MST（Prim / Kruskal） O(n² log n)
    Network Delay Time Dijkstra O(E log V)
    Cheapest Flights Within K Stops 快照分层松弛 O((k+1)(E+V))
    Reconstruct Itinerary Hierholzer O(E log E)
    Swim in Rising Water Dijkstra 变体 / 二分 + BFS O(n² log n)
    Alien Dictionary 拓扑排序 O(总字符数)

    八、易错点速查¶

    1. Dijkstra 忘记跳过过期条目。
    2. 在有负权的图上用 Dijkstra。
    3. 限制步数的 Bellman-Ford 忘了用副本更新。
    4. Prim 与 Dijkstra 混淆（堆里存的量不同）。
    5. Kruskal 忘记并查集，产生环。
    6. Hierholzer 忘记反转结果。
    7. 787 的 k 少算一轮（最多 k+1 段航班）。
    8. 269 漏掉前缀冲突这个边界。

    九、面试话术¶

    "这是一个非负权单源最短路问题，我用 Dijkstra。维护一个距离数组和一个优先队列，每次弹出当前距离最小的节点，用它去松弛邻居。因为边权非负，节点第一次被弹出时距离一定最优。复杂度 O((V+E) log V)。"
