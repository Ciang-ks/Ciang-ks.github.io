    21. Merge Two Sorted Lists · 合并两个有序链表¶

    Easy ｜ Linked List ｜ LeetCode 21 ｜ NeetCode

    题目大意¶

    合并两个升序链表，返回合并后的升序链表（复用原有节点即可）。

    输入: 1 → 2 → 4,  1 → 3 → 4
输出: 1 → 1 → 2 → 3 → 4 → 4

    思路¶

    这就是归并排序里的 merge 步骤，只是在链表上做。

    用哑结点接管结果链表的头，再用一个 tail 指针不断把较小的节点接上去：

    1. 比较 l1.val 和 l2.val，把较小者接到 tail 后面，该指针前移；
    2. 循环直到其中一个链表为空；
    3. 把剩下的那一条整个接上去（不需要逐节点遍历，因为剩下的本来就是有序的）。

    哑结点在这里的价值：如果不用它，就必须写"结果链表的第一个节点是 l1 还是 l2"的特判，代码会多出好几个分支。

    解法推导与模式辨析¶

    有序性保证两条剩余链的全局最小节点必在两个头之一，因此只比较头值就覆盖全部候选。tail 指向结果链最后一个节点，每次接上较小节点后，必须同时推进该输入链头与 tail；前者消费输入，后者为下一次连接留位置。

    例如 1→4 与 2→3，先接 1，再接 2、3，最后把剩余 4 整段接上。这里复用输入节点并改写连接，不是复制数值到一条完全独立的新链。若要求保留原链结构，就需要新建输出节点，并重新核算空间；dummy 只统一空结果的入口，不会改变是否复制节点这一选择。

    代码¶

    解法一：迭代 + 哑结点（推荐）¶

    class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = tail = ListNode(0)
        l1, l2 = list1, list2

        while l1 and l2:
            if l1.val <= l2.val:      # 用 <= 保证稳定性
                tail.next = l1
                l1 = l1.next
            else:
                tail.next = l2
                l2 = l2.next
            tail = tail.next

        tail.next = l1 if l1 else l2  # 把剩下的整条接上
        return dummy.next

    解法二：递归（代码优雅，但有栈开销）¶

    class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        if not list1:
            return list2
        if not list2:
            return list1
        if list1.val <= list2.val:
            list1.next = self.mergeTwoLists(list1.next, list2)
            return list1
        else:
            list2.next = self.mergeTwoLists(list1, list2.next)
            return list2

    递归的优雅之处在于：它把"接剩下的部分"交给了下一层递归，不需要写收尾逻辑。

    解法三：原地插入（不推荐，但可以理解）¶

    class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0)
        dummy.next = list1
        prev, cur = dummy, list2          # 把 l2 的节点逐个插入 l1
        while prev.next and cur:
            if prev.next.val <= cur.val:
                prev = prev.next
            else:
                nxt = cur.next
                cur.next = prev.next
                prev.next = cur
                prev = cur
                cur = nxt
        if cur:
            prev.next = cur
        return dummy.next

    比解法一复杂得多，还容易出错——这正是"用哑结点 + 简单归并"的优越之处。

    复杂度¶

    解法 时间 空间
    迭代 O(n + m) O(1)
    递归 O(n + m) O(n + m)（递归栈）

    易错点与面试追问¶

    • 收尾别忘了 tail.next = l1 if l1 else l2，否则后半段会丢。
    • 比较用 <= 才能保证"相等时先取 l1"，这是一种稳定性，题目不要求但值得说明。
    • 空链表的处理：如果一个为空，直接返回另一个（上面的写法天然正确）。
    • 追问：合并 k 个有序链表？ → 23 Merge k Sorted Lists，用最小堆或分治归并。
    • 追问：如果要求不修改原链表（深拷贝）？ → 需要新建节点。
    • 追问：如果是归并排序链表？ → 148 Sort List，快慢指针找中点 + 本题的合并 + 递归，就能实现 O(n log n) 的链表排序。
    • 追问：如果两个链表长度差距极大？ → 复杂度仍是 O(n + m)，因为必须走完较长的那条。
