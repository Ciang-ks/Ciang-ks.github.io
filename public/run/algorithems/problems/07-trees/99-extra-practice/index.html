    1. 101 Symmetric Tree¶

    LeetCode 101 ｜ Easy

    题目：判断二叉树是否轴对称（左右镜像）。

    为什么放这里：Same Tree 的镜像版本，考察"递归时参数怎么配对"。

    思路提示：判断左右两棵子树是否互为镜像：a.val == b.val，且 a.left 与 b.right 镜像、a.right 与 b.left 镜像。注意是交叉比较，不是同侧比较。

    方法辨析：镜像关系按对应位置交叉比较，单独比较左右各自的中序值序列可能丢结构。空与非空不匹配，两个空匹配；这一基线同时覆盖缺失孩子的位置。

    class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        def mirror(a, b) -> bool:
            if not a and not b:
                return True
            if not a or not b:
                return False
            return (a.val == b.val
                    and mirror(a.left, b.right)      # 交叉！
                    and mirror(a.right, b.left))

        return mirror(root, root) if root else True

    易错点：把 mirror(a.left, b.right) 写成 mirror(a.left, b.left) 就成了 Same Tree，不再是镜像判断。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(h)\)。

    2. 111 Minimum Depth of Binary Tree¶

    LeetCode 111 ｜ Easy

    题目：求从根到最近的叶子节点的节点数。

    为什么放这里：与 104 对比，专门用来理解"叶子节点"的定义陷阱，以及 BFS 的提前终止优势。

    思路提示

    不能写 \(1 + \min (\mathrm{left}, \mathrm{right})\)！ 因为只有一个孩子时，另一个孩子的深度是 0，会把答案算成 1。正确的递归是：

    • 左右都为空 → 是叶子，深度 1；
    • 只有一边为空 → 走非空的那一边；
    • 两边都非空 → \(1 + \min (左, 右)\)。

    更漂亮的做法是 BFS：层序遍历，遇到第一个叶子就返回当前层号。

    方法辨析：深度路径必须在叶子结束，空孩子不提供一条深度为零的候选路径。BFS 首次遇到叶子即可返回，因为更深层不可能改善最小深度；遇到只有一个孩子的节点还不能停。

    from collections import deque

class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        q = deque([(root, 1)])
        while q:
            node, depth = q.popleft()
            if not node.left and not node.right:      # 找到最近的叶子
                return depth
            if node.left:
                q.append((node.left, depth + 1))
            if node.right:
                q.append((node.right, depth + 1))
        return 0

    易错点：递归版的 min(left, right) 陷阱；BFS 版必须在出队时判断叶子（入队时判断会漏掉"根就是叶子"的情况，或者需要额外处理）。

    复杂度：BFS 最坏 \(\mathcal{O}(n)\) 时间，但遇到浅叶子时可以提前结束；空间 \(\mathcal{O}(w)\)。

    3. 112 Path Sum¶

    LeetCode 112 ｜ Easy

    题目：判断是否存在一条从根到叶子的路径，使路径上节点值之和等于 targetSum。

    为什么放这里：最典型的"自顶向下传状态"——把"剩余需要的和"沿着路径往下传。

    思路提示：递归函数带参数 targetSum，表示"从当前节点出发还需要凑够多少"。

    • 空节点 → False；
    • 是叶子节点（左右都空） → 判断 targetSum == node.val；
    • 否则 → 递归左右孩子，把目标减去当前值再传下去。

    关键点：必须到叶子才算数。 中途某条路径凑够了不构成答案。

    方法辨析：剩余目标随当前路径向下传，不受兄弟分支影响。只有叶子才可判断是否恰好耗尽目标；含负值时目标暂时为负也可能再补回，不能照搬正数求和的超限剪枝。

    class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        if not root:
            return False
        if not root.left and not root.right:
            return targetSum == root.val              # 到叶子，判断是否恰好用完
        rest = targetSum - root.val
        return (self.hasPathSum(root.left, rest)
                or self.hasPathSum(root.right, rest))

    class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        if not root:
            return False
        if not root.left and not root.right:
            return targetSum == root.val              # 到叶子，判断是否恰好用完
        rest = targetSum - root.val
        return (self.hasPathSum(root.left, rest)
                or self.hasPathSum(root.right, rest))

    易错点：忘记"必须是叶子"这个条件；空树直接返回 False（不存在任何路径）。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(h)\)。

    变体：113 Path Sum II 要返回所有满足条件的路径，需要回溯记录路径；437 Path Sum III 不要求从根开始，需要用前缀和 + 哈希表。

    4. 108 Convert Sorted Array to BST¶

    LeetCode 108 ｜ Easy

    题目：把升序数组转换成一棵高度平衡的 BST。

    为什么放这里：分治构造的入门题，与 105 的"用序列重建树"同源，但更简单。

    思路提示：为了让树平衡，每个子区间都取中点作为根，然后递归构造左右子树。

    方法辨析：中点分割让左右节点数至多差一，且有序数组天然给出左右大小范围，二者共同保证生成高度平衡的 BST。要避免重复切片，可传左右边界；否则原地索引版与切片版空间不能混记。

    class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        def build(lo: int, hi: int) -> Optional[TreeNode]:
            if lo > hi:
                return None
            mid = (lo + hi) // 2                  # 取中点保证平衡
            node = TreeNode(nums[mid])
            node.left = build(lo, mid - 1)
            node.right = build(mid + 1, hi)
            return node

        return build(0, len(nums) - 1)

    易错点：区间是闭区间 \([\mathrm{lo}, \mathrm{hi}]\)，终止条件 \(lo > hi\)；取 (lo+hi)//2 或 (lo+hi+1)//2 都能得到合法的平衡 BST，只是偶数长度时根的选取不同。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(\log n)\)（递归栈）。

    5. 236 Lowest Common Ancestor of a Binary Tree¶

    LeetCode 236 ｜ Medium

    题目：普通二叉树（不是 BST）中两个节点的最近公共祖先。

    为什么放这里：235 的通用版本，也是后序递归的最佳范例之一：先拿到左右子树的"查找结果"，再决定当前节点是不是答案。

    思路提示：递归函数返回"在当前子树中找到的目标节点"：

    • 空节点 → None；
    • 当前节点就是 p 或 q → 返回当前节点；
    • 递归左右，分别得到 left、right；
    • left 和 right 都非空 → p、q 分居两侧，当前节点就是 LCA；
    • 否则返回非空的那一个（或 None）。

    方法辨析：返回值可能是找到的单个目标，也可能已经是子树内的 LCA，父节点只需知道该子树是否含目标证据。算法依赖 p、q 都存在；若取消保证，返回一个目标不足以证明另一个也在树中，需要额外计数或存在性验证。

    class Solution:
    def lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        if not root or root is p or root is q:
            return root
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left and right:
            return root              # 两侧各找到一个 → root 是分岔点
        return left or right

    易错点：比较用 root is p（节点身份）；返回 left or right 的写法依赖 None 是假值；递归必须在后序位置做判断。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(h)\)。

    6. 103 Binary Tree Zigzag Level Order Traversal¶

    LeetCode 103 ｜ Medium

    题目：层序遍历，但方向交替——第 1 层从左到右，第 2 层从右到左，第 3 层又从左到右……

    为什么放这里：102 的直接变体，考查"层序 + 一个方向变量"的组合。

    思路提示：102 的框架不变，只是偶数层把结果反转（或者用双端队列从两端交替插入）。

    方法辨析：改变的是输出这一层的方向，不必改变下一层节点的正常入队次序。先按普通层序收集，再按层号反转最易核对；若首层编号为 0，则反转奇数层，文字中的偶奇应与编号一致。

    from collections import deque

class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        res = []
        q = deque([root])
        left_to_right = True

        while q:
            level = []
            for _ in range(len(q)):
                node = q.popleft()
                level.append(node.val)
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            res.append(level if left_to_right else level[::-1])
            left_to_right = not left_to_right

        return res

    易错点：方向变量每层都要翻转；用 level[::-1] 比双端队列插入更易读，代价是多一次 \(\mathcal{O}(层宽)\) 的反转。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(w)\)。

    7. 863 All Nodes Distance K in Binary Tree¶

    LeetCode 863 ｜ Medium

    题目：给定二叉树和目标节点 target，找出所有与 target 距离为 k 的节点。

    为什么放这里："树转图"的思想转折点——树上不能往上走，但只要给每个节点加上指向父节点的边，树就变成了无向图，问题就退化成标准的 BFS。

    思路提示

    1. 用一次 DFS 建立 父节点 映射（parent[node] = 它的父节点）；
    2. 从 target 出发做 BFS，每轮同时向三个方向扩展：左孩子、右孩子、父节点；
    3. BFS 走 k 步，此时队列里的所有节点就是答案。

    必须记录 visited，否则会在"父↔子"的边上无限往返。

    方法辨析：加入父边后树成为双向可走的图，从 target 的距离才能覆盖祖先一侧。visited 按节点身份登记，并在发现时标记；走完恰好 k 层时返回整层，不能将这期间访问过的全部节点都输出。

    from collections import deque

class Solution:
    def distanceK(self, root: TreeNode, target: TreeNode, k: int) -> List[int]:
        parent = {}
        def build_parent(node, par):
            if not node:
                return
            parent[node] = par
            build_parent(node.left, node)
            build_parent(node.right, node)
        build_parent(root, None)

        q = deque([target])
        visited = {target}
        for _ in range(k):
            for _ in range(len(q)):
                node = q.popleft()
                for nxt in (node.left, node.right, parent[node]):
                    if nxt and nxt not in visited:
                        visited.add(nxt)
                        q.append(nxt)

        return [node.val for node in q]

    易错点：忘记 visited 会死循环；parent[root] 是 None，要用 if nxt 过滤；BFS 的层数控制用 for _ in range(k) 外层循环。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(n)\)。

    这个"树 → 加父指针 → 图 BFS"的思路非常重要，很多"树上距离"类问题都靠它转化。做完这题再回头看 199、102，会发现自己对"树就是图的一种特例"有了更统一的理解。
