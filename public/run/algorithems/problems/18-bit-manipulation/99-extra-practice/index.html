    1. 231 Power of Two¶

    LeetCode 231 ｜ Easy

    题目：判断一个整数是否是 2 的幂。

    为什么放这里：n & (n - 1) 最经典的应用，一行就能解决。

    思路提示：2 的幂的二进制里只有一个 1，所以 n & (n - 1) 会把它变成 0。

    方法辨析：正整数只有一位 1 当且仅当它是 2 的幂；零虽也满足 n&(n−1)==0，却不是幂，因此 n>0 是数学条件。不要把这个判断直接扩成任意底数的幂。

    class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        return n > 0 and (n & (n - 1)) == 0

    n > 0 这个条件不能省：n = 0 时 0 & -1 == 0 也成立，但 0 不是 2 的幂；负数也有问题。

    易错点：n > 0 必须放前面；Python 中 & 的优先级高于 ==，此处括号有助于阅读，并非语法必需；其他语言应查各自优先级。

    复杂度：时间 O(1)，空间 O(1)。

    变体：342 Power of Four 需要在 2 的幂的基础上再加一个条件（1 出现在奇数位上，用 n & 0xAAAAAAAA == 0 判断）。

    2. 461 Hamming Distance¶

    LeetCode 461 ｜ Easy

    题目：求两个整数二进制表示中不同位的个数。

    为什么放这里：异或 + 数 1 的组合，把本模块的两个核心技巧串在一起。

    思路提示

    1. 异或：x ^ y 的结果里，为 1 的位正好是两个数不同的位；
    2. 数 1：用 x & (x - 1) 统计（就是 191 题）。

    方法辨析：异或把对应位不同转成 1，问题随即变为一个整数的置位数。按位比较的是同一固定编码位置，若是任意字符串相似度或允许插删，不能再用这个简单汉明距离模型。

    class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        diff = x ^ y
        count = 0
        while diff:
            diff &= diff - 1        # 消掉一个 1
            count += 1
        return count

    易错点：diff=x ^ y 的 1 表示不同位；随后反复执行 diff &= diff-1 计数。

    复杂度：时间 O(1)（最多 32 轮），空间 O(1)。

    应用：汉明距离在纠错码（Hamming Code）、相似性搜索、DNA 序列比对中都有应用。能说出这个背景很加分。

    3. 137 Single Number II¶

    LeetCode 137 ｜ Medium

    题目：数组中除了一个元素只出现一次，其他元素都出现三次。找出那个元素。

    为什么放这里：异或不再适用时的"降级方案"——按位统计。它说明了"位运算是逐位独立的"这个重要性质。

    思路提示

    核心观察：每一位是相互独立的。

    对所有数的第 i 位统计 1 的个数：

    • 如果某个元素出现了 3 次，它在第 i 位上贡献的 1 的个数一定是 3 的倍数；
    • 所以 count % 3 剩下的就是"只出现一次的那个元素"在第 i 位的值。

    于是对 32 个位分别统计，再把结果拼起来就是答案。

    方法辨析：逐位把所有输入的 1 数量对三取模，三份相同值的贡献都消失。固定 32 位恢复负数时，最高位为 1 需减 2³²；直接把累积位模式当 Python 正整数，会把负答案解释错。

    class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        result = 0
        for i in range(32):                     # 逐位处理
            bit_sum = sum((x >> i) & 1 for x in nums)
            if bit_sum % 3:
                result |= (1 << i)

        # Python 的负数处理：如果符号位是 1，要转回负数
        return result if result < (1 << 31) else result - (1 << 32)

    易错点：负数要特殊处理（最高位是符号位）；result |= (1 << i) 用来设置第 i 位。

    复杂度：时间 O(32n) = O(n)，空间 O(1)。

    一个更漂亮的解法（不需要逐位循环）是用两个变量模拟三进制计数器，能在一次遍历中完成。面试中提一句它的存在很加分。

    4. 260 Single Number III¶

    LeetCode 260 ｜ Medium

    题目：数组里有两个元素各出现一次，其他元素都出现两次。找出这两个元素。

    为什么放这里：异或 + lowbit 的分组技巧，是 136 的直接升级，也是本模块最精彩的一道题。

    思路提示

    分为三步：

    1. 把所有数异或起来，得到 a ^ b（两个目标元素的异或值，因为其他元素都抵消了）；
    2. 找出 a ^ b 里最低位的 1（用 diff & (-diff) 取 lowbit）——这一位在 a 和 b 里必定不同；
    3. 按这一位把数组分成两组：这一位是 1 的一组、是 0 的一组。a 和 b 一定被分到了不同组，而其他元素（成对出现）也会被分到同一组；
    4. 对每组内部做一次异或，就分别得到了 a 和 b。

    为什么"按 lowbit 分组"能保证 a 和 b 分开？ 因为 diff = a ^ b 的第 i 位是 1，说明 a 和 b 的第 i 位不同，所以它们必然落在不同的组里。

    方法辨析：所有数异或得到的 diff 非零，因为两个单独值不同；任选其中一位 1 都能分开它们，lowbit 只是方便选一位。成对元素在该位总相同，因此进入同一组继续抵消。

    class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        diff = 0
        for x in nums:
            diff ^= x                       # 得到 a ^ b

        lowbit = diff & (-diff)             # 取出最低位的 1

        a = b = 0
        for x in nums:
            if x & lowbit:                  # 按这一位分组
                a ^= x
            else:
                b ^= x
        return [a, b]

    易错点：diff & (-diff) 是取 lowbit（不是 diff & (diff-1)，那是清除 lowbit）；分组的依据是"这一位是不是 1"。

    复杂度：时间 O(n)，空间 O(1)。

    这道题把本模块的三个核心式子全用上了：异或抵消、x & (-x) 取 lowbit、按位分组。做完它，位运算的基本功就过关了。

    5. 201 Bitwise AND of Numbers Range¶

    LeetCode 201 ｜ Medium

    题目：求 [left, right] 范围内所有数的按位与结果。

    为什么放这里："找公共前缀"这一类位运算题的经典，思路非常巧妙。

    思路提示

    关键观察：区间内所有数的按位与 = 它们的"公共前缀"（后面不同的位全部变成 0）。

    为什么？因为区间内的数连续，所以低位一定会经历"0 和 1 的各种组合"，只要某一位上出现过 0，这一位的按位与结果就是 0。

    于是做法是：不断把 left 和 right 右移，直到它们相等，然后把这个公共前缀再左移回去：

    方法辨析：从最高不同位向下，连续区间必跨过某个该位为零的数，使这些低位在按位与中全部清零；高位公共前缀则从未改变。仅对任意两端数字做与不够，例如 5&7=5，但 5&6&7=4。

    class Solution:
    def rangeBitwiseAnd(self, left: int, right: int) -> int:
        shift = 0
        while left < right:
            left >>= 1
            right >>= 1
            shift += 1
        return left << shift

    另一个等价技巧：right &= right - 1 会清除 right 最低位的 1，不断执行直到 right <= left，此时 right 就是答案。

    易错点：返回时要左移回原来的位数（left << shift）；循环条件是 left < right。

    复杂度：时间 O(32) 最坏，空间 O(1)。

    6. 318 Maximum Product of Word Lengths¶

    LeetCode 318 ｜ Medium

    题目：给定一组单词，找出两个不含相同字母的单词，使它们的长度乘积最大。

    为什么放这里：用位掩码表示"字符集合" 的经典应用，也是本模块"类型 3"的代表。

    思路提示

    1. 对每个单词，用 26 个 bit 表示"它包含哪些字母"（第 i 位表示字母 'a'+i 是否出现）；
    2. 检查两个单词是否含相同字母，只需 mask1 & mask2 == 0（O(1) 而不是 O(26) 或 O(单词长度)）；
    3. 两两比较取最大乘积。

    这个"用整数当集合"的技巧非常实用——元素种类较少时，位掩码通常紧凑且便于集合运算；实际性能仍取决于位宽、操作与运行环境。

    方法辨析：掩码只表达字符是否出现，不保存顺序或频次，恰与“无共同字母”的约束匹配。两个含相同字母集合但不同长度的词可只保留最大长度以减少候选，但不能用于要求频次相同的异位词判断。

    class Solution:
    def maxProduct(self, words: List[str]) -> int:
        masks = []
        for w in words:
            mask = 0
            for c in w:
                mask |= 1 << (ord(c) - ord('a'))
            masks.append(mask)

        best = 0
        for i in range(len(words)):
            for j in range(i + 1, len(words)):
                if masks[i] & masks[j] == 0:          # 没有共同字母
                    best = max(best, len(words[i]) * len(words[j]))
        return best

    易错点：可写 (masks[i] & masks[j]) == 0 清楚表达先求交再判空；Python 中 & 实际比 == 优先级高；1 << (ord(c) - ord('a')) 的偏移。

    复杂度：时间 O(n² + 总字符数)，空间 O(n)。

    7. 29 Divide Two Integers¶

    LeetCode 29 ｜ Medium

    题目：实现整数除法，不能使用乘法、除法和取模运算。结果需要截断到 32 位有符号整数范围。

    为什么放这里：用位移实现乘法/除法的经典——它展示了"二进制竖式除法"，也是位运算能提高效率的本质原因。

    思路提示

    核心思想是用 2 的幂去"逼近"被除数：

    1. 处理符号：把两个数都转成正数，记录结果的正负
2. 反复找"最大的 k" 使得 divisor << k <= dividend：
       result += 1 << k
       dividend -= divisor << k
3. 处理溢出：如果结果超出 32 位有符号范围，返回 2^31 - 1

    为什么这样是对的？ 因为除法本质上就是"把被除数分解成若干个 divisor × 2^k 的和"，而"乘以 2 的幂"就是左移。

    方法辨析：每轮减去不超过余数的最大 divisor×2ᵏ，并给商加对应 2ᵏ，相当于逐步确定二进制商位。商向零截断，最后按原符号恢复；−2³¹ 除以 −1 的数学结果超界，需按题目截为最大正数。

    class Solution:
    def divide(self, dividend: int, divisor: int) -> int:
        INT_MAX = 2**31 - 1
        if dividend == -2**31 and divisor == -1:
            return INT_MAX                       # 唯一会溢出的情况

        negative = (dividend < 0) != (divisor < 0)
        a, b = abs(dividend), abs(divisor)
        result = 0

        while a >= b:
            shift = 0
            while a >= (b << (shift + 1)):       # 找最大的可左移位数
                shift += 1
            result += 1 << shift
            a -= b << shift

        return -result if negative else result

    易错点：dividend = -2³¹ 且 divisor = -1 时结果会溢出（这是唯一的特殊情况，必须单独处理）；符号判断用"异或"式的 !=；1 << shift 是 2 的 shift 次幂。

    复杂度：时间 O((log n)²)（外层循环最多 log n 次，内层找 shift 也是 log n），空间 O(1)。

    优化：内层的"找最大 shift"可以用二分搜索降到 O(log n)，总复杂度变成 O(log² n) 的常数更小版本；也可以用"从高位往低位试"的一次遍历做到 O(log n)。
