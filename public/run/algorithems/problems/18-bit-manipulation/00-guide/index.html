    Bit Manipulation · 解题手册¶

    位运算的题目看起来"魔法"，但真正需要背的式子只有五六个。把它们记熟，剩下的就是"看出来该用哪个"。

    一、从题面提出候选，再核对条件¶

    已学基础：27-位运算。下面将讲义中的结构性质用于选择解法。

    位运算利用的是明确的编码和代数性质。先确认整数宽度、符号、数值范围以及重复次数，再选择消去、掩码或逐位统计。

    题目特征 需要验证的依据 迁移边界与反例
    成对抵消或缺一项 异或，先核对每个非答案值确实出现偶数次 两项缺失只会得到混合值，不能直接返回
    清最低 1 或批量统计 n&(n-1) 或依赖更小下标的递推 对负整数需先明确有限宽度
    位反转或位模拟加法 按题目位宽固定轮数或用掩码截断 非负右移会归零，固定轮数是为保留全部零位
    小范围集合 位 i 表示元素 i，交并与差对应不同运算 异或是对称差，不是一般集合差

    先用 4 位或 8 位手算验证，再推广到 32 位。Python 的无限符号扩展与固定宽度机器整数不同；固定宽度下的模运算结果还需按题意解释成有符号或无符号数。

    二、必背的位运算式子¶

    表达式 含义 典型用途
    x & 1 取最低位 判断奇偶
    x >> i & 1 取第 i 位（从 0 开始） 逐位检查
    x \| (1 << i) 把第 i 位置 1 打标记
    x & ~(1 << i) 把第 i 位清 0 清除标记
    x & (x - 1) 清除最低位的 1 数 1 的个数、判断 2 的幂
    x & (-x) 取出最低位的 1（lowbit） 树状数组、按位分组
    \(x ^ x = 0\) / \(x ^ 0 = x\) 异或的抵消性 找唯一出现一次的数

    最值得反复体会的是那两个加粗的式子：

    • x & (x - 1) 清除最低位的 1：例如 \(\mathtt{1100}_2\mathbin{\&}\mathtt{1011}_2=\mathtt{1000}_2\)。所以"不断执行直到 0"的循环次数就是 1 的个数；
    • x & (-x) 取出最低位的 1：例如 \(\mathtt{1100}_2\mathbin{\&}\mathtt{0100}_2=\mathtt{0100}_2\)。它是树状数组的核心，也是"按位分组"的关键。

    这两个式子看起来像，含义完全不同，一定要分清。

    三、三条常用模板与使用条件¶

    模板 1 异或找唯一元素¶

    def single_number(nums):
    result = 0
    for x in nums:
        result ^= x          # 成对出现的会互相抵消
    return result

    为什么能抵消？ 因为异或满足交换律、结合律，且 \(a \oplus a = 0\)。一旦题目出现"只出现一次，其余出现两次"，候选思路异或。

    模板 2 数 1 的个数（Brian Kernighan）¶

    def hamming_weight(n: int) -> int:
    count = 0
    while n:
        n &= n - 1           # 每次消掉最低位的 1
        count += 1
    return count

    循环次数等于 1 的个数（不是固定的 32 次），所以 1 很少时非常快。这是本题最重要的技巧。

    模板 3 位运算做加法¶

    def get_sum(a: int, b: int) -> int:
    MASK = 0xFFFFFFFF
    a, b = a & MASK, b & MASK
    while b:
        carry = ((a & b) << 1) & MASK    # 进位
        a = (a ^ b) & MASK               # 无进位和
        b = carry
    return a if a < (1 << 31) else a - (1 << 32)

    原理：对照二进制加法真值表，\(a \oplus b\) 恰好是"不含进位的结果"，(a & b) << 1 恰好是"进位"。这就是硬件全加器的逻辑。

    四、Python 的特别注意事项（做位运算题必看）¶

    Python 的整数是任意精度的，没有"32 位溢出"的概念。所以在模拟 32 位整数时（190、371、7）必须手动限制位数：

    需求 写法
    取低 32 位 x & 0xFFFFFFFF
    把 32 位无符号数解释为有符号 x - (1 << 32) if x >= (1 << 31) else x
    设置 / 判断某位 用掩码 & / \|，不要依赖溢出行为

    另一个需要核对的是运算符优先级：Python 的 & 优先级高于 ==，因此下面两行等价；加括号能让读者更容易看清意图，不能混用其他语言的优先级规则。

    n & 1 == 0        # Python 解析为 (n & 1) == 0
(n & 1) == 0      # 同样正确，分组更明确

    五、从读题到写码：四步流程¶

    1. 先问"这题的位有没有独立的意义"（奇偶、出现次数、集合成员）——位运算题几乎都是"逐位独立"的。
    2. 确定用哪种性质：抵消（异或）、计数（x&(x-1)）、分组（lowbit）、掩码（集合）。
    3. 如果是 32 位模拟题，先想好掩码和符号转换。
    4. 写完后用一个小例子逐位验证。

    六、逐题推演：从题面到思路¶

    1. Single Number（136）¶

    题面信号："一个元素只出现一次，其余都出现两次，要求 \(\mathcal{O}(1)\) 空间"。

    候选思路：\(\mathcal{O}(1)\) 空间排除了哈希集合；异或的抵消性正好满足——把所有数异或起来，成对的抵消，剩下的就是答案。

    走一遍示例：\(\mathrm{nums} = [4,1,2,1,2]\)

    4 ^ 1 = 5
5 ^ 2 = 7
7 ^ 1 = 6
6 ^ 2 = 4      ← 1 和 2 各抵消了一次，最后剩下 4

    （实际顺序无关，因为异或满足交换律和结合律。)

    关键细节：初始值必须是 0（\(0 ^ x = x\)）。

    追问准备："其余出现三次？" → 137，要按位统计 1 的个数模 3；"两个元素只出现一次？" → 260，先异或得到 \(a\oplus b\)，再用 lowbit 分组。

    2. Number of 1 Bits（191）¶

    题面信号："统计二进制里 1 的个数"。

    候选思路：分界线是 n & (n-1) 消掉最低位的 1——循环次数等于 1 的个数，比逐位检查（固定 32 次）更省。

    走一遍示例：n = 11（二进制 1011）

    1011 & 1010 = 1010   count=1
1010 & 1001 = 1000   count=2
1000 & 0111 = 0000   count=3

    关键细节：n = 0 返回 0；运算符优先级（(n & 1) == 0 要加括号）。

    3. Counting Bits（338）¶

    题面信号："返回 0..n 每个数的 1 的个数"，要求 \(\mathcal{O}(n)\)。

    候选思路：逐个调用 191 的函数是 \(\mathcal{O}(n \log n)\)，不满足要求。要用递推：dp[i] 可以从更小的数推出来。

    两个递推式：

    dp[i] = dp[i >> 1] + (i & 1)        # 右移一位的答案 + 最低位
dp[i] = dp[i & (i - 1)] + 1         # 去掉一个 1 之后的数量 + 1

    走一遍示例：n = 5，用第一个递推式

    i 二进制 i>>1 dp[i>>1] i&1 dp[i]
    0 0 —— —— —— 0
    1 1 0 0 1 1
    2 10 1 1 0 1
    3 11 1 1 1 2
    4 100 2 1 0 1
    5 101 2 1 1 2

    结果 [0,1,1,2,1,2] ✓

    关键细节：ans 长度是 \(n + 1\)（要包含 0）；题目明确要求 \(\mathcal{O}(n)\)，所以要主动说明"逐个调用 191 是 \(\mathcal{O}(n \log n)\)，不够好"。

    4. Reverse Bits（190）¶

    题面信号："颠倒 32 位无符号整数的二进制位"。

    候选思路：逐位搬移——从右往左取出 n 的最低位，放到结果的从左往右对应位置：

    def reverse_bits(n: int) -> int:
    result = 0
    for _ in range(32):                  # 固定 32 次
        result = (result << 1) | (n & 1) # 结果左移腾出最低位，填入 n 的最低（bitwise）
        n >>= 1
    return result

    "结果的左移"和"输入的右移"合起来就是颠倒——这是本题最简洁的理解方式。

    走一遍示例：n = 0b110

    轮 1: result = 0<<1 | 0 = 0，n → 0b11
轮 2: result = 0<<1 | 1 = 1，n → 0b1
轮 3: result = 1<<1 | 1 = 0b11，n → 0
之后 29 轮补齐高位 0 → 结果高位是 11，正好是 0b110 的逆序

    关键细节：必须固定循环 32 次（Python 的整数不会自动截断到 32 位）；结果要 & 0xFFFFFFFF；分治版（交换 16/8/4/2/1 位两半）固定 5 步，可以提一句。

    5. Missing Number（268）¶

    题面信号："从 0..n 里少了一个数，找出来"。

    候选思路：两种思路都能秒杀。

    思路 A 异或：把 0..n 和 nums 全部异或起来，出现过的互相抵消，剩下就是缺失的。

    def missing_number(nums):
    result = len(nums)                # n 只出现在完整序列里
    for i, x in enumerate(nums):
        result ^= i ^ x               # 下标和值一起异或
    return result

    思路 B 求和：n*(n+1)//2 - sum(nums)（注意溢出，Python 无所谓，但 C++/Java 要用 long）。

    走一遍示例：\(\mathrm{nums} = [3,0,1]\)

    result 初值 = 3（n）
i=0,x=3: 3 ^ 0 ^ 3 = 0
i=1,x=0: 0 ^ 1 ^ 0 = 1
i=2,x=1: 1 ^ 2 ^ 1 = 2
答案 2 ✓

    关键细节：异或版的初值是 len(nums)（即 n），不能写 0。这题和 136 的关系是：136 是"数组内部两两抵消"，本题是"数组与完整序列相互抵消"。

    6. Sum of Two Integers（371）¶

    题面信号："不用 + 和 - 计算两数之和"。

    候选思路：加法可以拆成"无进位和"+"进位"：

    a ^ b            = 无进位和
(a & b) << 1     = 进位
反复迭代，直到进位为 0

    走一遍示例：a = 1（01），b = 2（10）

    carry = (01 & 10) << 1 = 00，a = 01 ^ 10 = 11（十进制的 3），b = 0
循环结束，返回 3 ✓

    为什么 Python 需要特殊处理？ 因为 Python 的负数是"无限位补码"（-1 是无限个 1），<< 会让位数无限增长，循环永远不会结束。必须用掩码把结果限制在 32 位，最后再把符号位解释回 Python 的负数。

    关键细节：carry 要 & MASK；a 和 b 进入循环前就要掩码；最后 a if a < (1 << 31) else a - (1 << 32)。

    加分回答："这正是硬件全加器的逻辑——一个异或门算本位、一个与门算进位。"

    7. Reverse Integer（7）¶

    题面信号："反转整数的各位数字，溢出则返回 0"。

    候选思路：逐位取模 + 逐位构造：\(\mathrm{result} = \mathrm{result} * 10 + x \% 10\)。难点在于溢出判断：结果必须落在 \([-2^{31},2^{31}-1]\) 内。

    两种处理方式：

    语言 做法
    Python 先算完完整结果，再判断是否越界（大整数不溢出）
    C++ / Java 必须在计算过程中预判：result > INT_MAX // 10 或 result == INT_MAX // 10 and digit > 7 
    def reverse(x: int) -> int:
    sign = -1 if x < 0 else 1
    x = abs(x)
    result = 0
    while x:
        result = result * 10 + x % 10
        x //= 10
    result *= sign
    return result if -(2**31) <= result <= 2**31 - 1 else 0

    为什么是 \(> 7\)？ 因为 INT_MAX = 2147483647 的末位是 7；INT_MIN = -2147483648 的末位是 8。能说出这个细节很能体现对边界值的熟悉。

    关键细节：Python 对正除数 10 取模得到 0..9 的余数（\(-123 \% 10 = 7\)），所以先取绝对值、最后补符号最稳；溢出必须返回 0（不是 INT_MAX）。

    七、复杂度速查¶

    题目 关键技巧 时间 空间
    Single Number 异或抵消 \(\mathcal{O}(n)\) \(\mathcal{O}(1)\)
    Number of 1 Bits n & (n-1) \(\mathcal{O}(k)\)，k 为 1 的个数 \(\mathcal{O}(1)\)
    Counting Bits 递推 \(\mathcal{O}(n)\) \(\mathcal{O}(n)\)
    Reverse Bits 逐位搬移 \(\mathcal{O}(1)\)（32 次） \(\mathcal{O}(1)\)
    Missing Number 异或 / 求和 \(\mathcal{O}(n)\) \(\mathcal{O}(1)\)
    Sum of Two Integers ^ 与 & << 1 \(\mathcal{O}(1)\)（不大于32 轮） \(\mathcal{O}(1)\)
    Reverse Integer 取模构造 \(\mathcal{O}(\log x)\) \(\mathcal{O}(1)\)

    八、易错点速查¶

    1. 判断 2 的幂忘记排除 \(n \le 0\)。
    2. x & (x-1)（清除）和 x & (-x)（取出）搞混。
    3. 忘记加 32 位掩码，负数结果错误。
    4. 运算符优先级：n & 1 == 0 会被解析成 n & (1 == 0)。
    5. Python 的 >> 是算术右移（负数补 1），和 C++/Java 的无符号右移不同。
    6. 左移溢出没有提前判断（C++/Java）。
    7. 异或找唯一元素时初始值写错（必须是 0）。

    九、面试话术¶

    "这题可以用异或的性质：\(a \oplus a = 0\)、\(a ^ 0 = a\)，而且异或满足交换律和结合律。所以把所有元素异或起来，成对出现的互相抵消，剩下的就是只出现一次的那个。时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(1)\)。"
