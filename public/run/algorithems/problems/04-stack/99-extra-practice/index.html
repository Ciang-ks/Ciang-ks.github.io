    1. 1047 Remove All Adjacent Duplicates In String¶

    LeetCode 1047 ｜ Easy

    题目：反复删除字符串中相邻且相同的两个字符，直到无法继续，返回结果。

    为什么放这里：栈的最基础用法——"新元素与栈顶相同就消掉"，一次遍历就等价于"反复删除"。

    思路提示：栈顶与当前字符相同则弹出，否则压入。遍历结束后栈中内容就是答案。

    方法辨析：栈保存已处理前缀经过全部相邻抵消后的结果。新字符只可能与这个结果末尾构成新的一对，因此弹出后暴露的更早字符可继续与后续输入抵消，无需从头重复扫全串。

    class Solution:
    def removeDuplicates(self, s: str) -> str:
        stack = []
        for c in s:
            if stack and stack[-1] == c:
                stack.pop()          # 消掉一对
            else:
                stack.append(c)
        return "".join(stack)

    易错点：不需要真的循环删除——一次遍历就等价（想想 "abba"：处理完 bb 后 aa 会再次相遇，这正是栈的天然行为）。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(n)\)。

    变体：1209 Remove All Adjacent Duplicates in String II 要求消除连续 k 个相同字符，栈里改存 (字符, 连续个数)。

    2. 496 Next Greater Element I¶

    LeetCode 496 ｜ Easy

    题目：给定两个数组 nums1（nums2 的子集）和 nums2，对 nums1 中每个元素，找出它在 nums2 中右边第一个更大的元素，不存在返回 -1。

    为什么放这里：739 的"找下一个更大元素"直接复用，加上哈希做映射。

    思路提示：先对 nums2 跑一遍单调栈，得到每个元素的"下一个更大元素"存进字典；再查 nums1。

    方法辨析：本题 nums2 中值互异，所以可以将“值”直接映射到其下一更大值。若允许同值出现在不同位置，它们右边答案可能不同，按值存一个字典就会覆盖信息，必须回到按下标保存答案。

    class Solution:
    def nextGreaterElement(self, nums1: List[int], nums2: List[int]) -> List[int]:
        nxt = {}
        stack = []
        for x in nums2:
            while stack and stack[-1] < x:
                nxt[stack.pop()] = x     # x 就是它们的下一个更大元素
            stack.append(x)
        return [nxt.get(x, -1) for x in nums1]

    易错点：栈里剩下未匹配的元素不需要处理，get(x, -1) 自动兜底。

    复杂度：时间 \(\mathcal{O}(n + m)\)，空间 \(\mathcal{O}(m)\)。

    3. 71 Simplify Path¶

    LeetCode 71 ｜ Medium

    题目：化简 Unix 风格的绝对路径。

    规则：.. 回退到上一级（已在根目录则忽略），. 表示当前目录（忽略），多个连续 \(/\) 视为一个，结果必须以 \(/\) 开头且不含多余的 \(/\)。

    为什么放这里：栈处理"层级结构"的代表题，和括号匹配是同一类思维。

    思路提示：按 \(/\) 切分，过滤掉空串和 "."；遇到 ".." 且栈非空就弹出；其余入栈。最后用 "/" 连接。

    方法辨析：栈项是路径分量，不是单个字符；.. 撤销一个已有分量，... 则是普通文件名。这里处理绝对路径，根目录再遇 .. 保持根；相对路径的 .. 语义不同，不能无条件用同一规则。

    class Solution:
    def simplifyPath(self, path: str) -> str:
        stack = []
        for part in path.split('/'):
            if part == '' or part == '.':
                continue
            if part == '..':
                if stack:
                    stack.pop()
            else:
                stack.append(part)
        return '/' + '/'.join(stack)

    易错点："..".startswith(".") 之类的模糊判断会出错，必须精确比较；根目录下 .. 要忽略而不是报错；最后一定要以 \(/\) 开头。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(n)\)。

    4. 394 Decode String¶

    LeetCode 394 ｜ Medium

    题目：解码形如 k[encoded_string] 的字符串，支持嵌套。

    输入: "3[a2[c]]"     输出: "accaccacc"

    为什么放这里：栈处理嵌套结构的经典题，比括号匹配多了"携带数据"的维度。

    思路提示：维护两个栈——count_stack 存重复次数，str_stack 存"进入括号前已经累积的字符串"。

    • 遇到数字：读出完整的数字（可能多位），压入 count_stack；
    • 遇到 [：把当前累积的串压入 str_stack，重置当前串和计数；
    • 遇到 ]：把 str_stack 弹出的前缀，与重复指定次数的当前串拼接；
    • 遇到字母：追加到当前串。

    方法辨析：左括号暂停外层构造，栈保存外层前缀与重复次数；右括号把完整内层展开结果交回父层，因此嵌套次序符合后进先出。多位次数必须逐位累积，输出长度也可能远大于输入，时间与内存至少要计入展开结果。

    class Solution:
    def decodeString(self, s: str) -> str:
        count_stack = []
        str_stack = []
        cur = ''
        num = 0

        for c in s:
            if c.isdigit():
                num = num * 10 + int(c)          # 处理多位数
            elif c == '[':
                count_stack.append(num)
                str_stack.append(cur)
                num, cur = 0, ''
            elif c == ']':
                cur = str_stack.pop() + cur * count_stack.pop()
            else:
                cur += c

        return cur

    易错点：数字可能是多位（"12[a]"），不能只取一位；[ 时要保存"进入前的字符串"而不是清空丢弃。

    复杂度：时间 \(\mathcal{O}(输出长度)\)，空间 \(\mathcal{O}(嵌套深度 + 输出长度)\)。

    5. 227 Basic Calculator II¶

    LeetCode 227 ｜ Medium

    题目：实现一个支持 \(+ - * /\) 和空格的整数表达式求值（无括号），除法向零截断。

    为什么放这里：表达式求值的标准套路，也是 150 题的自然延伸。

    思路提示：扫描字符串，用 num 累积当前数字，用 op 记住上一个运算符：

    • 遇到 \(+\) / -：把 +num / -num 直接压栈（延迟到后面处理乘除）；
    • 遇到 \(*\) / \(/\)：立刻和栈顶结算（因为乘除优先级高），把结果压栈；
    • 结束后把栈内所有元素相加。

    这个"把加减变成带符号入栈、乘除即时结算"的技巧，可以一次性解决优先级问题，不需要真正实现优先级的比较。

    方法辨析：上一个运算符决定当前读完的数怎样参与表达式；当前符号只是触发结算并留给下一数。乘除先合并栈顶，使最终栈中只剩可相加的带符号项；除法要向零截断，负数不能直接用 Python //。

    class Solution:
    def calculate(self, s: str) -> int:
        stack = []
        num = 0
        op = '+'
        for i, c in enumerate(s):
            if c.isdigit():
                num = num * 10 + int(c)
            if c in '+-*/' or i == len(s) - 1:      # 遇到运算符或到达末尾
                if op == '+':
                    stack.append(num)
                elif op == '-':
                    stack.append(-num)
                elif op == '*':
                    stack.append(stack.pop() * num)
                else:
                    stack.append(int(stack.pop() / num))   # 向零截断
                op = c
                num = 0
        return sum(stack)

    易错点：末尾的数字必须被结算（所以判断里有 i == len(s) - 1）；空格需要跳过（c in '+-*/' 天然不匹配空格）；除法截断方向。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(n)\)。

    6. 32 Longest Valid Parentheses¶

    LeetCode 32 ｜ Hard

    题目：给定只含 ( 和 ) 的字符串，求最长合法括号子串的长度。

    为什么放这里：验证括号（20 题）的进阶版，考察"栈里存下标"这一关键技巧。

    思路提示：栈里存下标，并预先压入 -1 作为"上一个未被匹配的位置"。

    • 遇到 (：压入下标；
    • 遇到 )：弹出一个下标。若栈变空（说明这个 ) 多余），把当前下标压入作为新的基准；否则当前合法长度就是 i - stack[-1]。

    另一个等价解法是正向反向各扫一遍、用计数器判断（空间 \(\mathcal{O}(1)\)），可以当作加分答案。

    方法辨析：栈底下标表示当前可用区间之前最近的断点，其余项是未匹配左括号的位置。匹配后距离最近未匹配位置，才是一整段有效括号长度；栈清空时重置基准，避免跨过一个多余右括号。

    class Solution:
    def longestValidParentheses(self, s: str) -> int:
        stack = [-1]                      # 基准位
        best = 0
        for i, c in enumerate(s):
            if c == '(':
                stack.append(i)
            else:
                stack.pop()
                if not stack:
                    stack.append(i)       # 这个 ) 无法匹配，成为新基准
                else:
                    best = max(best, i - stack[-1])
        return best

    易错点：初始的 -1 不能省；栈空时的处理（把当前下标作为新基准）是关键；注意答案是长度而不是下标差。

    复杂度：时间 \(\mathcal{O}(n)\)，空间 \(\mathcal{O}(n)\)。

    7. 85 Maximal Rectangle¶

    LeetCode 85 ｜ Hard

    题目：给定只含 '0' 和 '1' 的二维矩阵，求只含 '1' 的最大矩形面积。

    为什么放这里：84 题的二维推广。把它看成"逐行的直方图"是唯一顺畅的思路。

    思路提示：对每一行，把"从这行往上连续 1 的个数"当作该列的直方图高度；每处理一行就对高度数组跑一次 84 题的单调栈算法。

    关键点是理解：以第 r 行为底边的任何矩形，其每列的高度都不能超过"从 r 往上连续 1 的数量"，所以逐行直方图不会漏解也不会多解。

    方法辨析：按每个矩形的底边行分类，其顶部连续 1 高度给出每列能用的上界，便能转成直方图。遇到 0 必须将该列高度归零，不能沿用上一行；每个矩形都有某一底边，因此逐行计算不会漏掉最优。

    class Solution:
    def maximalRectangle(self, matrix: List[List[str]]) -> int:
        if not matrix or not matrix[0]:
            return 0
        cols = len(matrix[0])
        heights = [0] * cols
        best = 0

        def largest(hist: List[int]) -> int:
            hist = [0] + hist + [0]
            stack = [0]
            area = 0
            for i in range(1, len(hist)):
                while hist[stack[-1]] > hist[i]:
                    h = hist[stack.pop()]
                    area = max(area, h * (i - stack[-1] - 1))
                stack.append(i)
            return area

        for row in matrix:
            for j in range(cols):
                heights[j] = heights[j] + 1 if row[j] == '1' else 0
            best = max(best, largest(heights))

        return best

    易错点：遇到 '0' 时高度必须清零（不能沿用上一行的值）；矩阵元素是字符 '1' 而不是整数；每次都重新调用一次 largest。

    复杂度：时间 \(\mathcal{O}(mn)\)，空间 \(\mathcal{O}(n)\)。

    变体：221 Maximal Square 把"矩形"换成"正方形"，用朴素 DP 更简单；1504 Count Submatrices With All Ones 则是计数版本。
