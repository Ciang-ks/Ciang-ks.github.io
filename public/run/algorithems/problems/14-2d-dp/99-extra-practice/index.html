    1. 64 Minimum Path Sum¶

    LeetCode 64 ｜ Medium

    题目：从网格左上走到右下（只能向右、向下），使路径上数字之和最小。

    为什么放这里：62 Unique Paths 的"求最优值"版本——把 + 换成 min + 加法，网格 DP 的框架完全不变。

    思路提示：dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])。

    方法辨析：路径每步只能右或下，所以最后一步来自上或左，两种前驱取较小再加当前格。首行首列只有一条路径，须逐项累加；有负格也不妨碍这个无环依赖，但允许回头后就不能原样递推。

    class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        ROWS, COLS = len(grid), len(grid[0])
        dp = [[0] * COLS for _ in range(ROWS)]
        dp[0][0] = grid[0][0]

        for i in range(1, ROWS):              # 第一列只能从上边来
            dp[i][0] = dp[i - 1][0] + grid[i][0]
        for j in range(1, COLS):              # 第一行只能从左边来
            dp[0][j] = dp[0][j - 1] + grid[0][j]

        for i in range(1, ROWS):
            for j in range(1, COLS):
                dp[i][j] = grid[i][j] + min(dp[i - 1][j], dp[i][j - 1])

        return dp[ROWS - 1][COLS - 1]

    易错点：第一行和第一列是累加（只有一条路可达），不能初始化成 0。

    复杂度：时间 O(mn)，空间 O(mn)（可以压到 O(n)）。

    2. 63 Unique Paths II¶

    LeetCode 63 ｜ Medium

    题目：62 题加上障碍物（1 表示障碍），求路径数。

    为什么放这里：网格 DP 加一个"不可达"的约束，训练"边界初始化 + 状态转移"的完整处理。

    思路提示：障碍物位置的路径数为 0；其他位置按常规转移。注意第一行/第一列被障碍物"截断"后，后面全都不可达。

    方法辨析：障碍格无论上左有多少路径都必须清零。第一行若前面遇障碍，后续不能凭“边界原本全 1”继续可达；一行压缩版遇障碍设 dp[j]=0 正好阻断这条方向。

    class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        ROWS, COLS = len(obstacleGrid), len(obstacleGrid[0])
        if obstacleGrid[0][0] == 1:
            return 0

        dp = [[0] * COLS for _ in range(ROWS)]
        dp[0][0] = 1

        for i in range(ROWS):
            for j in range(COLS):
                if obstacleGrid[i][j] == 1:
                    dp[i][j] = 0                       # 障碍物不可达
                    continue
                if i > 0:
                    dp[i][j] += dp[i - 1][j]
                if j > 0:
                    dp[i][j] += dp[i][j - 1]

        return dp[ROWS - 1][COLS - 1]

    易错点：起点有障碍时返回 0；不能像 62 那样把第一行/第一列全初始化为 1，因为障碍物后面的格子不可达。

    复杂度：时间 O(mn)，空间 O(mn)。

    3. 221 Maximal Square¶

    LeetCode 221 ｜ Medium

    题目：在只含 '0'/'1' 的矩阵中找最大的全 '1' 正方形，返回面积。

    为什么放这里：状态定义非常巧妙的网格 DP——它展示了"dp 的含义可以不是直接的答案，而是便于递推的中间量"。

    思路提示：dp[i][j] = 以 (i, j) 为右下角的最大正方形的边长。

    如果 grid[i][j] == '1':
    dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
否则:
    dp[i][j] = 0

    为什么是 min 三项 + 1？ 因为要以 (i,j) 为右下角构成边长 k 的正方形，就必须同时满足"左边、上边、左上角都能构成边长 k-1 的正方形"，取三者的最小即可。

    方法辨析：以某格为右下角的最大边长必须同时满足左、上、左上的支持，缺一方向会漏掉内部零。dp 存边长，最终返回面积 best²；若存面积直接 min+1，单位就不一致。

    class Solution:
    def maximalSquare(self, matrix: List[List[str]]) -> int:
        ROWS, COLS = len(matrix), len(matrix[0])
        dp = [[0] * (COLS + 1) for _ in range(ROWS + 1)]   # 多一行一列，省掉边界判断
        best = 0

        for i in range(1, ROWS + 1):
            for j in range(1, COLS + 1):
                if matrix[i - 1][j - 1] == '1':
                    dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
                    best = max(best, dp[i][j])

        return best * best                     # 返回面积

    易错点：返回的是面积（边长平方）；用"多一行一列的 dp"可以省掉所有边界判断（这是处理网格 DP 边界的常用技巧）。

    复杂度：时间 O(mn)，空间 O(mn)。

    4. 516 Longest Palindromic Subsequence¶

    LeetCode 516 ｜ Medium

    题目：求最长回文子序列的长度（可以不连续）。

    为什么放这里：区间 DP 的入门题，它和 312 Burst Balloons 的结构一致，但转移更简单，适合先掌握。

    思路提示：dp[i][j] = s[i..j] 中最长回文子序列的长度。

    如果 s[i] == s[j]:   dp[i][j] = dp[i+1][j-1] + 2
否则:                dp[i][j] = max(dp[i+1][j], dp[i][j-1])

    按区间长度递增遍历（因为依赖更短的区间）。

    方法辨析：回文子序列可跳过字符，末端相同可同时收下，两端不同则尝试各跳过一侧。它与最长回文子串的布尔区间表不同，字符不相同时并非直接 False，而是保留更短区间的最优长度。

    class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        for i in range(n):
            dp[i][i] = 1                       # 单字符是长度 1 的回文

        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1] + 2
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])

        return dp[0][n - 1] if n else 0

    易错点：dp[i][i] = 1；length = 2 时 dp[i+1][j-1] 是空区间，因为初始化为 0 所以正确；遍历顺序必须按长度递增。

    复杂度：时间 O(n²)，空间 O(n²)。

    有趣的事实：最长回文子序列长度 = len(s) - LCS(s, reverse(s))。这个等价关系很值得玩味。

    5. 1039 Minimum Score Triangulation of Polygon¶

    LeetCode 1039 ｜ Medium

    题目：把凸多边形三角化，每个三角形的分数是三顶点值之积，求最小总分。

    为什么放这里：和 312 Burst Balloons 完全同一套区间 DP 模板，只是"最后一个"换成了"选哪个三角形作为分割"。

    思路提示：dp[i][j] = 顶点 i..j 组成的多边形三角化的最小分数。枚举中间顶点 k，把多边形分成两个子多边形：

    dp[i][j] = min over k in (i,j) of:
    dp[i][k] + dp[k][j] + values[i] * values[k] * values[j]

    注意：它和 312 的转移方程长得一模一样，这不是巧合——两者都在"选一个分割点把区间分成两部分"。

    方法辨析：固定多边形的一条边 (i,j)，任何三角化中这条边恰属于一个三角形 (i,k,j)，其余区域分成两块独立子多边形。此处 k 是贴边三角形的第三顶点，不是气球的最后戳破位置；状态依赖相似，几何证明不同。

    class Solution:
    def minScoreTriangulation(self, values: List[int]) -> int:
        n = len(values)
        dp = [[0] * n for _ in range(n)]

        for length in range(2, n):              # 区间长度递增
            for i in range(n - length):
                j = i + length
                dp[i][j] = float('inf')
                for k in range(i + 1, j):
                    dp[i][j] = min(dp[i][j],
                                   dp[i][k] + dp[k][j] + values[i] * values[k] * values[j])

        return dp[0][n - 1]

    易错点：dp[i][j] 要初始化为 inf（因为求最小值）；按长度递增遍历。

    复杂度：时间 O(n³)，空间 O(n²)。

    6. 44 Wildcard Matching¶

    LeetCode 44 ｜ Hard

    题目：实现支持 '?'（匹配任意单个字符）和 '*'（匹配任意字符串，包括空串）的匹配。

    为什么放这里：和 10 Regular Expression Matching 是同一类但语义不同的题，对比做一遍能彻底搞清 * 的两种语义。

    关键区别：

    10 Regex 44 Wildcard
    * 的语义 修饰前一个字符，匹配零次或多次 独立匹配任意字符串
    ? 不存在（用 . 代替） 匹配任意单个字符

    思路提示：dp[i][j] = s 的前 i 个字符能否被 p 的前 j 个字符匹配。

    如果 p[j-1] == '*':
    dp[i][j] = dp[i-1][j]        # * 继续匹配一个字符
             or dp[i][j-1]       # * 匹配空串（跳过）
如果 p[j-1] == '?' 或 p[j-1] == s[i-1]:
    dp[i][j] = dp[i-1][j-1]
否则:
    dp[i][j] = False

    方法辨析：本题 * 自身代表任意长度字符序列，? 代表任意单字符，与正则 x 修饰前一元素的规则不同。零字符分支只跳过一个 ，多字符分支保留该 * 并消费一字符；不能直接照抄正则中的 j−2。

    class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m, n = len(s), len(p)
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = True

        for j in range(1, n + 1):              # 空串只能被全 * 的模式匹配
            if p[j - 1] == '*':
                dp[0][j] = dp[0][j - 1]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if p[j - 1] == '*':
                    dp[i][j] = dp[i - 1][j] or dp[i][j - 1]
                elif p[j - 1] == '?' or p[j - 1] == s[i - 1]:
                    dp[i][j] = dp[i - 1][j - 1]

        return dp[m][n]

    易错点：* 的两个分支（继续匹配 / 匹配空串）；空串的边界（只有 * 能匹配空串）。

    复杂度：时间 O(mn)，空间 O(mn)。

    7. 1547 Minimum Cost to Cut a Stick¶

    LeetCode 1547 ｜ Hard

    题目：一根长度为 n 的木棍，要按给定的位置切开，每次切割的费用是当前木棍的长度。求完成所有切割的最小总费用。

    为什么放这里：区间 DP 的第三个成员（312、1039、1547 是同一套模板的三道题）。这里应枚举当前段的第一次切割，使它被切成两个独立子段；与戳气球选最后一次的证明不同。

    思路提示

    1. 在切割位置列表两端加上 0 和 n 作为哨兵；
    2. 排序后，dp[i][j] = 把区间 (cuts[i], cuts[j]) 内的所有位置都切开的最小费用；
    3. 枚举“当前木棍段第一次切的位置 k”，切完后左右两段独立：
    dp[i][j] = min over k in (i,j) of:
    dp[i][k] + dp[k][j] + (cuts[j] - cuts[i])

    注意费用是当前木棍的长度，也就是 cuts[j] - cuts[i]。

    方法辨析：当前段第一次切 k 时费用固定为两端距离，切开后左右段才独立。若把 k 当最后一刀，届时木棍早已分成其他长度，费用便不再是整个区间长；先把操作时刻说清，才能使用看似相同的区间转移。

    class Solution:
    def minCost(self, n: int, cuts: List[int]) -> int:
        cuts = [0] + sorted(cuts) + [n]
        m = len(cuts)
        dp = [[0] * m for _ in range(m)]

        for length in range(2, m):              # 区间长度递增
            for i in range(m - length):
                j = i + length
                dp[i][j] = float('inf')
                for k in range(i + 1, j):
                    dp[i][j] = min(dp[i][j],
                                   dp[i][k] + dp[k][j] + cuts[j] - cuts[i])

        return dp[0][m - 1]

    易错点：哨兵 0 和 n 必须加；求最小值要初始化为 inf；费用只和区间端点有关（因为每次切割的费用是"当前木棍的长度"）。

    复杂度：时间 O(m³)，空间 O(m²)。

    区间 DP 三兄弟对照记忆：312 Burst Balloons、1039 Polygon Triangulation、1547 Cut a Stick —— 转移方程的形状完全一致，只是"收益/代价的计算方式"不同。把这三题的代码放在一起看，区间 DP 的套路就彻底内化了。
