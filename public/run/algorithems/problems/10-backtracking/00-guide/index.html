    Backtracking · 解题手册¶

    回溯就是"在决策树上做深度优先搜索"：每层做一个选择，做完往下递归，返回时撤销。写回溯的重点不是递归本身，而是想清楚三件事：这一层有多少个选择、怎么做选择、什么时候停。

    一、从题面提出候选，再核对条件¶

    已学基础：15-图与图搜索、20-动态规划入门、28-计算复杂度与NP。下面将讲义中的结构性质用于选择解法。

    回溯把候选答案分解为一连串决策。先明确什么算不同答案、每层决定什么，再设计剪枝和撤销；并不是所有枚举都只能用同一模板。

    题目特征 需要验证的依据 迁移边界与反例
    子集、组合 用 start 使选择下标递增，避免排列重复 是否允许复用决定递归传 i 还是 i+1
    排列 每层填一个位置，枚举全部未使用下标 start 递增会漏掉不同顺序
    输入重复但输出按值去重 排序后同层跳过等值选择，保留跨层不同副本 不能把多个相同值一律删掉
    路径或约束放置 保存当前路径使用状态，返回后撤销 连通块遍历的永久 visited 含义不同

    记录解的时机由完成条件决定：子集每层都合法，组合和需 remaining==0，分割需覆盖全串。只求可行性也可能需要回溯；可合并重复状态时再考虑 DP，不能仅由输出类型断定算法。

    二、回溯的三要素¶

    def backtrack(路径, 选择列表):
    if 满足结束条件:
        记录结果
        return
    for 选择 in 选择列表:
        做选择                      # 修改路径、打标记
        backtrack(路径, 新的选择列表)
        撤销选择                    # 恢复现场
    1. 路径：已经做出的选择（通常是一个列表）；
    2. 选择列表：当前还能做什么（由 start 索引或 used 数组界定）；
    3. 结束条件：什么时候记录结果。

    "撤销选择"最容易忘，忘了就会污染后续分支，结果全错。

    三、三种母题模板（其余全是变体）¶

    母题 1 子集型¶

    def subsets(nums):
    res, path = [], []

    def backtrack(start):
        res.append(path[:])              # 每个节点都是一个合法子集
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1)             # 传 i+1：每个元素只用一次
            path.pop()

    backtrack(0)
    return res

    在进入函数时就记录结果（包括空集），而不是等到叶子。

    母题 2 组合型¶

    def combination_sum(candidates, target):
    candidates.sort()                    # 排序后才能 break 剪枝
    res, path = [], []

    def backtrack(start, remaining):
        if remaining == 0:
            res.append(path[:])
            return
        for i in range(start, len(candidates)):
            if candidates[i] > remaining:
                break                    # 剪枝：后面的只会更大
            path.append(candidates[i])
            backtrack(i, remaining - candidates[i])   # 传 i：可重复选
            path.pop()

    backtrack(0, target)
    return res

    "传 i 还是 \(i + 1\)"决定元素能不能复用——这是 39 和 40 的核心差异。

    母题 3 排列型¶

    def permute(nums):
    res, path = [], []
    used = [False] * len(nums)

    def backtrack():
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):       # 每层都从头扫（排列关心顺序）
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack()
            path.pop()
            used[i] = False              # 撤销标记

    backtrack()
    return res

    四、去重：\(i > \mathrm{start}\) 与 not used[i-1]¶

    当输入含重复元素时，标准做法是"排序 + 同层跳过"。

    子集 / 组合去重¶

    nums.sort()
for i in range(start, len(nums)):
    if i > start and nums[i] == nums[i - 1]:
        continue                          # 同一层里，跳过重复的兄弟
    ...

    为什么是 \(i > \mathrm{start}\) 而不是 \(i > 0\)？

    • \(i > \mathrm{start}\) 判断的是"同一层"：前面已经用相同的值做过分岔，整个子树都是重复的 → 跳过；
    • 写成 \(i > 0\) 会误伤"上一层选了 nums[i-1]、这一层选 nums[i]"这种合法的跨层选择。以 [1,2,2] 为例，正确答案 [2,2] 正是这种跨层选择。

    口诀：同层去重看 start，跨层允许重复选。

    排列去重（条件更绕）¶

    for i in range(len(nums)):
    if used[i]:
        continue
    if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
        continue                          # 同一层的重复值，跳过
    # ... 做选择、递归、撤销

    排列没有 start，所以用 not used[i-1] 来间接判断"是否同层"：如果 nums[i-1] 还没被用过，说明 i-1 和 i 在同一层（都不是上一层选中的）→ 跳过。

    五、从读题到写码：五步流程¶

    1. 明确输出全部方案、一个方案、可行性还是计数，判断是否需要搜索及能否合并重复状态。
    2. 判断是哪一型：子集（每个节点都记录）/ 组合（选够条件就记录）/ 排列（长度够就记录）/ 分割（切完整个输入才记录）。
    3. 确定"选择"的边界：start 索引还是 used 数组？
    4. 决定是否可重复选取：传 i 还是 \(i + 1\)。
    5. 加剪枝：排序后能 break 的就 break；能用集合 \(\mathcal{O}(1)\) 判定冲突的就别遍历。

    六、逐题推演：从题面到思路¶

    1. Subsets（78）¶

    题面信号："返回所有子集（幂集）"。

    候选思路：子集 = 对每个元素做"选或不选"的二元决策 → 决策树有 \(2^{n}\) 个叶子。

    走一遍示例：\(\mathrm{nums} = [1,2,3]\)

    path=[]        → 记录 []
 选 1 → [1]    → 记录 [1]
   选 2 → [1,2] → 记录；选 3 → [1,2,3] 记录
   不选 2 → 选 3 → [1,3] 记录
 不选 1 → 选 2 → [2] 记录 …… 依此类推

    关键细节：记录位置在函数开头（不是循环结束后）；res.append(path[:]) 必须切片——写成 path 会记录引用，最终全是空列表。这是本题最经典的错误。

    2. Combination Sum（39）¶

    题面信号："和为 target 的所有组合，同一个数可以重复选"。

    候选思路：组合型模板 + start 保证不回头（否则 [2,2,3] 和 [2,3,2] 会重复）+"可重复选"这件事体现在递归传 i。

    走一遍示例：candidates = [2,3,6,7]（已排序），target = 7

    选 2 → remaining 5 → 再选 2 → remaining 3 → 再选 2 → 超出 → 回退
                  → 改选 3 → remaining 0 → 记录 [2,2,3]
选 3 → remaining 4 → 只能选 3（超）→ 回退
选 6 → remaining 1 → 超 → 回退
选 7 → remaining 0 → 记录 [7]

    关键细节：必须先排序，break 剪枝才成立；所有候选都是正数所以 remaining 单调递减，递归必然终止（若允许 0 或负数，可能不终止，需另加长度限制或重设状态）。

    3. Permutations（46）¶

    题面信号："所有排列（元素互不相同）"。

    候选思路：排列关心顺序，所以每层都要从头扫描，用 used 标记已用元素。

    和组合的本质区别：组合用 start 限制"只往后选"；排列必须扫描全数组，靠 used 去重。

    关键细节：used[i] = False 的撤销不能忘；结果个数是 \(n!\)，这是问题本身的下界。

    4. Subsets II（90）¶

    题面信号："数组可能含重复元素，返回所有不重复子集"。

    候选思路：母题 1 + 去重。先排序，再加一行 if i > start and nums[i] == nums[i-1]: continue。

    走一遍示例：\(\mathrm{nums} = [1,2,2]\)（已排序）

    第一层 i=0 选 1 → 后面处理 [2,2]
第一层 i=1 选 2 → 后面处理 [2] → 得到 [2,2] ✓
第一层 i=2 时 nums[2]==nums[1] 且 i>start → 跳过（否则会重复产出以第二个 2 开头的全部子树）

    关键细节：\(i > \mathrm{start}\) 的写法见第四节；另一种更彻底的写法是"按每个不同值取几个"来决策，搜索树上不会产生任何重复分支。

    5. Combination Sum II（40）¶

    题面信号："数组可能含重复，每个元素只能用一次，求所有和为 target 的组合"。

    候选思路：39 和 90 的合体——传 \(i + 1\)（不可重复选）+ 同层去重那行 continue。

    对比项 39（可重复选） 40（不可重复选）
    递归传参 backtrack(i, ...) backtrack(i + 1, ...)
    去重 不需要（候选互不相同） 需要 i > start and nums[i] == nums[i-1]

    关键细节：break（值超过剩余目标）要放在去重判断之前；误传 i 会跑出 [2,2,2,2] 这类错误组合。

    6. Word Search（79）¶

    题面信号："网格中是否存在一条路径拼出单词，同一格不能重复使用"。

    候选思路：网格回溯。访问状态直接标在网格上（改成 '#'），省掉 visited 数组。

    走一遍示例：在 \(3\times4\) 网格里找 "ABCCED"

    从 (0,0)='A' 出发 → 右到 'B' → 右到 'C' → 下到 'C' → 下到 'E' → 左到 'D'
途中每个格子都先改成 '#'，回溯时恢复

    关键细节：成功条件 i == len(word) 要放在边界检查之前；标记与恢复必须成对；两个实用剪枝是"字符计数不够直接返回"和"从更稀有的那个端点开始搜"。

    7. Palindrome Partitioning（131）¶

    题面信号："把字符串切成若干回文子串，返回所有切法"。

    候选思路：分割型回溯——选择是"下一刀切在哪里"，用 start 表示当前段的起点。

    走一遍示例：s = "aab"

    start=0: 切 "a"（回文）→ start=1
          切 "a" → start=2 → 切 "b" → 得到 ["a","a","b"] ✓
          切 "ab"（非回文）→ 剪掉
        切 "aa"（回文）→ start=2 → 切 "b" → 得到 ["aa","b"] ✓
        切 "aab"（非回文）→ 剪掉

    关键细节：end 的范围是 \(\mathrm{start}+1\) 到 len(s)；先用 DP 预处理回文表可以把每次回文判断从 \(\mathcal{O}(n)\) 降到 \(\mathcal{O}(1)\)，整体从 \(\mathcal{O}(n\cdot 2^{n})\) 降到 \(\mathcal{O}(n^{2} + 方案数\cdot n)\)。

    对照：132 题求最少回文分割次数，可把到同一边界的多种路径合并，只保留最少次数；本题输出所有分割，不能只保留最优一份。输出要求会影响状态内容，但不是唯一的算法选择条件。

    8. Letter Combinations of a Phone Number（17）¶

    题面信号："电话号码能拼出哪些字母组合"。

    候选思路：这是笛卡尔积，不是排列也不是组合——每一层的选择集合都不一样（由当前数字决定）。

    走一遍示例：digits = "23"

    第 0 层（数字 2 → "abc"）：依次选 a / b / c
  选 a 后，第 1 层（数字 3 → "def"）：ad / ae / af
  选 b：bd / be / bf
  选 c：cd / ce / cf

    关键细节：空输入要返回 [] 而不是 [""]（高频失分点）；数字 7 和 9 对应 4 个字母。

    9. N-Queens（51）¶

    题面信号："n 皇后，互不攻击"。

    候选思路：一行一行放，这样自动消除了行冲突，只剩列和两条对角线三种约束。

    用三个集合做 \(\mathcal{O}(1)\) 冲突检测：

    列冲突    → 列号 col
主对角线  → row - col（沿 ↘ 走一步，这个值不变）
副对角线  → row + col（沿 ↙ 走一步，这个值不变）

    走一遍示例：n = 4，第一行放在第 1 列

    row=0, col=1 → cols={1}, diag1={-1}, diag2={1}
row=1 尝试 col=0/1/2/3：col=3 不冲突 → 继续
row=2 只剩 col=0 → 继续
row=3 可选 col=2 → 四行均已放置，记录一个解
... 最终得到 ".Q..","...Q","Q...","..Q."

    关键细节：row - col 用数组实现时要加偏移 n - 1 防负下标；撤销操作必须完整（棋盘 + 三个集合都恢复）。

    追问准备："只要方案数？" → 52 题，把"构造棋盘"改成计数，省掉大量字符串开销。

    七、复杂度速查¶

    题型 结果数量 时间
    子集 \(2^{n}\) \(\mathcal{O}(n \cdot 2^{n})\)
    排列 n! \(\mathcal{O}(n \cdot n!)\)
    组合总和（可复用正数） 取决于候选数与 target/min值 递归深度至多 target/min值，不能仅按输入长度套 \(2^{n}\)
    生成括号 卡特兰数 \(C_{n}\) \(\mathcal{O}(C_{n} \cdot n)\)
    N 皇后 约 n! \(\mathcal{O}(n!)\)

    八、易错点速查¶

    1. 忘记撤销选择（path.pop() / used[i] = False / 恢复网格）。
    2. res.append(path) 而不是 path[:]（最高频错误）。
    3. 去重条件用 \(i > 0\) 而不是 \(i > \mathrm{start}\)。
    4. 可重复选 vs 不可重复选传参写错（i vs \(i + 1\)）。
    5. 剪枝前忘记排序（break 只有在有序时才正确，否则要用 continue）。
    6. 131 的回文检查与预处理成本要分别计入；可先写直接检查，再按需要优化。
    7. N 皇后的对角线索引搞错（是 r - c 与 \(r + c\)）。

    九、面试话术¶

    "这是一个枚举所有方案的问题，我用回溯。每一层决定一个位置放什么，用 start 索引保证不重复枚举同一种组合。进入递归前做选择，返回后撤销。输入有重复元素时我会先排序，然后同一层跳过相同值——条件是 i > start and nums[i] == nums[i-1]。我会按这道题的分支数、递归深度与输出复制成本估算复杂度；子集、排列和可复用组合的规模不能混算。"

    十、30 秒自测¶

    1. 子集、组合、排列三者的递归模板差在哪一行？
    2. 去重为什么必须先排序？条件为什么是 \(i > \mathrm{start}\)？
    3. 为什么 res.append(path[:]) 不能写成 res.append(path)？
    4. 什么情况下应该用 DP 而不是回溯？
    5. N 皇后的两条对角线分别用什么量来表示？
