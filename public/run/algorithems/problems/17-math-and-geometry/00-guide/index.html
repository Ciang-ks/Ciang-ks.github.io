    Math & Geometry · 解题手册¶

    这个模块没有统一的套路，但它们共享一种能力：把问题翻译成数学表达式或几何坐标，然后用一次扫描/一次运算解决。真正需要背的东西不多，关键是"想到"。

    一、从题面提出候选，再核对条件¶

    已学基础：26-数学与几何。下面将讲义中的结构性质用于选择解法。

    先用位权、坐标或不变量把模拟规则写清楚，再安排循环。数学题型并不意味着可以跳过输入含义与正确性推导。

    题目特征 需要验证的依据 迁移边界与反例
    十进制数位操作 确认高低位方向，正数取模整除，再处理符号 Python 负数整除可能使循环无法归零
    矩阵旋转或分层遍历 先写坐标映射或未访问区域边界 方阵旋转与非方阵的存储需求不同
    原地更新规则 先保留旧信息，再产生新状态 置零用首行首列，生命游戏可用位编码，不能混为同一模板
    几何计数 先固定足以确定图形的点，再查其余坐标 重复点按实例计数，方向与退化情况需排除

    挑最小的非平凡例子跟踪一轮：两位进位、2×2 旋转、单行螺旋、一个重复坐标。说明循环前仍保留哪些原始信息，以及何时可以覆盖它。

    二、四类问题的核心技巧¶

    类型 1 数位操作¶

    def digit_sum(x: int) -> int:
    """取各位数字之和（x >= 0）"""
    total = 0
    while x:
        total += x % 10
        x //= 10
    return total

    Python 的取模特例：-123 % 10 = 7（总是非负），和 C++/Java 不同。处理负数时先取绝对值、最后再补符号，最不容易出错。

    类型 2 矩阵的原地变换¶

    顺时针旋转 90° = 转置 + 左右翻转：

    def rotate(matrix):
    n = len(matrix)
    for i in range(n):                        # 第一步：沿主对角线转置
        for j in range(i + 1, n):             # 只遍历上三角，否则会换回来
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for i in range(n):                        # 第二步：每行左右翻转
        for j in range(n // 2):
            matrix[i][j], matrix[i][n - 1 - j] = matrix[i][n - 1 - j], matrix[i][j]

    怎么验证组合是对的？ 追踪一个点：(i, j) 转置后变成 (j, i)，再左右翻转变成 (j, n-1-i)——这正是顺时针 90° 的映射。

    逆时针 90° = 转置 + 上下翻转。方向说反是本题最常见的错误。

    螺旋遍历 = 四边界收缩：

    def spiral_order(matrix):
    if not matrix or not matrix[0]:
        return []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    res = []
    while top <= bottom and left <= right:
        for j in range(left, right + 1):          # 左 → 右
            res.append(matrix[top][j])
        top += 1
        for i in range(top, bottom + 1):          # 上 → 下
            res.append(matrix[i][right])
        right -= 1
        if top <= bottom:                         # 必须重新判断
            for j in range(right, left - 1, -1):
                res.append(matrix[bottom][j])
            bottom -= 1
        if left <= right:                         # 必须重新判断
            for i in range(bottom, top - 1, -1):
                res.append(matrix[i][left])
            left += 1
    return res

    那两个 if 判断不能省：因为前面的边界收缩可能已经让区间变空（只剩一行或只剩一列时，不判断就会重复输出）。

    类型 3 快速幂¶

    def my_pow(x: float, n: int) -> float:
    if n < 0:
        x = 1 / x
        n = -n
    result = 1.0
    base = x
    while n > 0:
        if n & 1:                 # 当前二进制位是 1，就把这一份乘进来
            result *= base
        base *= base              # 底数平方（对应指数右移一位）
        n >>= 1
    return result

    核心恒等式：x^n = (x^(n/2))²（n 为偶数）或 x · (x^((n-1)/2))²（n 为奇数）——每一步把指数减半，所以是 O(log n)。

    类型 4 几何与哈希¶

    from collections import defaultdict

class DetectSquares:
    def __init__(self):
        self.cnt = defaultdict(int)

    def add(self, point) -> None:
        self.cnt[tuple(point)] += 1

    def count(self, point) -> int:
        x, y = point
        total = 0
        for (px, py), c in list(self.cnt.items()):
            # 以 (px, py) 为"对角顶点"，检查它和给定点能否构成正方形的对角线
            if abs(px - x) == abs(py - y) and px != x and py != y:
                total += c * self.cnt[(px, y)] * self.cnt[(x, py)]
        return total

    正方形的对角线端点满足 |dx| == |dy|——这个性质让"枚举对角顶点"成为最简洁的做法，另外两个角就是 (px, y) 和 (x, py)。

    三、从读题到写码：四步流程¶

    1. 先判断属于哪一类：数位 / 矩阵 / 几何 / 数值溢出。
    2. 数位类：想清楚"循环条件"和"边界值"（0、负数、末位为 0）。
    3. 矩阵类：先在纸上画一个 3×3 的例子，写出下标变换公式。
    4. 几何类：用哈希表把点编码；避免浮点比较（斜率用约分后的整数对）。

    四、逐题推演：从题面到思路¶

    1. Happy Number（202）¶

    题面信号："反复把各位数字平方求和，判断能否到 1"。

    候选思路：这个过程一定会进入循环——因为平方和把数映射到有限范围内（例如三位数最大是 3 × 9² = 243），有限集合上的迭代必然出现重复。于是问题变成"判环"，可以用哈希集合或快慢指针。

    走一遍示例：n = 19

    19 → 1+81 = 82 → 64+4 = 68 → 36+64 = 100 → 1 ✓

    关键细节：哨兵写法是"遇到 1 就返回 True，遇到已见过的数就返回 False"；这题和 141 Linked List Cycle 是同一个数学模型（把 next 换成"平方和函数"）。

    2. Plus One（66）¶

    题面信号："数组表示的大整数加一"。

    候选思路：手算加法的过程——从最低位开始加 1，遇到 9 就置 0 继续进位。

    走一遍示例：digits = [1,2,9]

    i=2: 9 不小于 9 → 置 0，继续进位
i=1: 2 < 9 → 加 1 变 3 → 返回 [1,3,0]

    对比 [9,9,9]：循环结束仍没返回 → 需要返回 [1,0,0,0]（长度加一）。

    关键细节：全 9 的情况必须处理；不要用 int(''.join(...)) 转换（题目特意说数字可能非常大，在 C++/Java 里会溢出）。

    3. Rotate Image（48）¶

    题面信号："矩阵顺时针旋转 90°，原地修改"。

    候选思路：转置 + 左右翻转（两步都是原地操作，空间 O(1)）。

    走一遍示例：[[1,2,3],[4,5,6],[7,8,9]]

    转置后:      [[1,4,7],[2,5,8],[3,6,9]]
左右翻转后:  [[7,4,1],[8,5,2],[9,6,3]] ✓

    关键细节：转置只遍历上三角（j 从 i+1 开始），否则每个元素会被换两次等于没动；顺时针是"左右翻转"，逆时针是"上下翻转"。

    4. Spiral Matrix（54）¶

    题面信号："按螺旋顺序遍历矩阵"。

    候选思路：用四个边界 top / bottom / left / right 表示尚未遍历的区域，每走完一条边就收缩一格。

    走一遍示例：[[1,2,3],[4,5,6],[7,8,9]]

    第 1 步（左→右，top=0）: 1,2,3 → top=1
第 2 步（上→下，right=2）: 6,9 → right=1
第 3 步（右→左，bottom=2）: 8,7 → bottom=1
第 4 步（下→上，left=0）: 4 → left=1
第 5 步（左→右，top=1）: 5 → top=2，越界结束
结果 [1,2,3,6,9,8,7,4,5] ✓

    关键细节：第 3、4 步前必须重新检查 top <= bottom 和 left <= right；单行、单列、单元素都靠这两个判断正确工作。

    5. Set Matrix Zeroes（73）¶

    题面信号："含 0 的行列全部置零，原地修改"。

    候选思路：不能用额外的标记数组的话，就用第一行和第一列当标记——但这样会破坏首行首列本身的信息，所以需要两个布尔变量先记录"首行/首列原本是否有 0"。

    走一遍示例：[[1,1,1],[1,0,1],[1,1,1]]

    先检查首行、首列：都没有 0 → row0_has_zero = False, col0_has_zero = False
遍历内部区域（i,j >= 1）：matrix[1][1] == 0 → 标记 matrix[1][0] = 0、matrix[0][1] = 0
再遍历内部区域：matrix[1][j] 因为 matrix[1][0]==0 全部置 0；matrix[i][1] 因为 matrix[0][1]==0 全部置 0
首行首列不需要处理
结果 [[1,0,1],[0,0,0],[1,0,1]] ✓

    关键细节：顺序不能变——先记首行首列、再标记内部、最后处理首行首列（提前处理会被标记冲掉）。

    这个技巧的本质：matrix[i][0] 这一格本来就有值，但它只需要承担 1 bit 的标记功能——"用已有空间存标记"和 41 题的原地哈希同源。

    6. Pow(x, n)（50）¶

    题面信号："计算 x 的 n 次幂"。

    候选思路：朴素连乘是 O(n)，当 n = 2³¹-1 时不可接受 → 快速幂 O(log n)。

    递归写法：

    def my_pow_recursive(x: float, n: int) -> float:
    if n == 0:
        return 1.0
    if n < 0:
        return 1.0 / my_pow_recursive(x, -n)
    half = my_pow_recursive(x, n // 2)      # 关键：只算一次一半
    if n % 2 == 0:
        return half * half
    return half * half * x

    最容易写错的一点：不能写成 my_pow_recursive(x, n//2) * my_pow_recursive(x, n//2)——那样会重复计算，退化成 O(n)。

    关键细节：n = 0 返回 1.0（包括 x = 0 的情况，题目约定 0^0 = 1）；负指数先取倒数。

    7. Multiply Strings（43）¶

    题面信号："两个大整数字符串相乘"。

    候选思路：竖式乘法。关键是算清"乘积落在结果数组的哪一位"：num1[i] 和 num2[j] 的乘积落在第 i+j 位（进位）和第 i+j+1 位（低位）。

    怎么推出来的？ num1[i] 的权重是 10^(m-1-i)，num2[j] 的权重是 10^(n-1-j)，乘积权重是 10^(m+n-2-i-j)；而结果数组下标 k 的权重是 10^(m+n-1-k)。令两者相等得 k = i+j+1。能从权重推出下标，这题才算真懂。

    走一遍示例：num1 = "123"，num2 = "456" → "56088"

    从右往左逐位相乘，累加到 res[i+j+1]，进位加到 res[i+j]
最后去掉前导零

    关键细节：结果数组长度是 m + n；下标 i+j+1（低位）和 i+j（进位）不能写反；"10" × "10" 会产生前导零，必须去掉。

    进阶追问："能不能更快？" → FFT 做多项式乘法，O(n log n)，但远超面试范围（提一句就够）。

    8. Detect Squares（2013）¶

    题面信号："加点、查询能与给定点组成正方形的三元组数量"。

    候选思路：几何 + 哈希。关键转化：给定点 (x, y) 作为正方形的一个角时，如果另一个角是 (px, py)，那么两者构成对角线 ⟺ |px - x| == |py - y|；此时另外两个角就是 (px, y) 和 (x, py)。

    走一遍示例：已有 (3,10)、(11,2)、(3,2)，查询 (11,10)

    枚举已有点作为对角顶点：
(3,2): |3-11| = 8 == |2-10| = 8 ✓，且 3≠11、2≠10
   另外两个角是 (3,10) 和 (11,2) → 两者都存在 ✓
   贡献 = cnt[(3,2)] × cnt[(3,10)] × cnt[(11,2)] = 1 × 1 × 1 = 1
其他点：不满足 |dx| == |dy|
答案 1 ✓

    关键细节：重复加入同一个点要计数（用 defaultdict(int) 而不是 set）；方案数要相乘；不能把给定点自身算进去（排除 px == x 或 py == y）。

    五、复杂度速查¶

    题目 核心技巧 时间
    Happy Number 判环 O(log n)
    Plus One 从后往前处理进位 O(n)
    Rotate Image 转置 + 左右翻转 O(n²)
    Spiral Matrix 四边界收缩 O(mn)
    Set Matrix Zeroes 首行首列当标记 O(mn)
    Pow(x, n) 快速幂 O(log n)
    Multiply Strings 竖式乘法 O(mn)
    Detect Squares 哈希 + 枚举对角顶点 O(n) 每次查询

    六、易错点速查¶

    1. 矩阵下标变换写错（旋转、转置）。
    2. 原地操作时被覆盖的数据没保存。
    3. Spiral Matrix 漏掉那两个 if 判断。
    4. Python 的 % 与 C++/Java 不同（负数取模得非负数）。
    5. 浮点误差：涉及开方/对数优先用整数运算（比较平方和而不是距离）。
    6. 整数溢出：Python 无所谓，但要能说出其他语言的限制。
    7. n = 0、负数、末位为 0 的边界。
    8. Set Matrix Zeroes 的处理顺序搞反。

    七、面试话术¶
