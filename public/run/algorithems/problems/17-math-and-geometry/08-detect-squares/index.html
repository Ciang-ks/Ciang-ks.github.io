    2013. Detect Squares · 检测正方形¶

    Medium ｜ Geometry / 设计 ｜ LeetCode 2013 ｜ NeetCode

    题目大意¶

    设计一个数据结构，支持：

    • add(point)：加入一个点（重复加入同一个点要分别计数）；
    • count(point)：返回"能与该点一起构成轴对齐正方形的三元组数量"。
    DetectSquares()
add([3,10]), add([11,2]), add([3,2])
count([11,10])  → 1
count([14,8])   → 0

    思路¶

    关键：怎么枚举正方形¶

    把给定点看作正方形的一个角，枚举所有可能的边长。

    固定查询点 (x,y)，枚举所有同列点 (x,y1)，排除 y1==y：

    1. 边长 d=abs(y-y1)，同列点既可能在上方，也可能在下方；
    2. 另一侧列可为 x-d 或 \(x+d\)，分别检查 (x±d,y) 与 (x±d,y1)；
    3. 每种方向贡献三个已有角的数量乘积，查询点本身不参与这个乘积。

    枚举的是一条竖边的另一个端点；枚举对角点是另一种有效解法，不能把两种坐标推导混在一起。

    数据结构¶

    • cnt[(x, y)] = 数量：\(\mathcal{O}(1)\) 查询某个点的出现次数；
    • cols[x] = {该列所有出现过的 y}：快速枚举同列的点。

    解法推导与模式辨析¶

    正方形必须平行坐标轴且面积非零。固定查询点后，枚举同列另一个 y1不等于y 的点，就确定边长 |y-y1|；另两点可能在左侧或右侧，上下两种 y1 也都要遍历。查询点不要求事先加入集合，计数只乘另外三个角的实例数。

    例如查询 (0,0)，已有 (0,1) 两份、(1,0) 三份、(1,1) 一份，右上正方形贡献 \(2\times3\times1=6\)。相同坐标的实例形成多种选择，不能只用存在性布尔值。每个正方形只有唯一的同列伙伴和方向，因此不会因枚举而重计；若允许任意旋转的正方形，应改用向量旋转推导另外两角，当前只查水平偏移会漏解。

    代码¶

    解法一：哈希表 + 枚举同列的点（推荐）¶

    from collections import defaultdict

class DetectSquares:
    def __init__(self):
        self.cnt = defaultdict(int)          # (x, y) -> 数量
        self.cols = defaultdict(set)         # x -> 该列出现过的所有 y

    def add(self, point: List[int]) -> None:
        x, y = point
        self.cnt[(x, y)] += 1
        self.cols[x].add(y)

    def count(self, point: List[int]) -> int:
        x, y = point
        total = 0
        for y1 in self.cols[x]:              # 枚举与给定点同列的点
            if y1 == y:
                continue
            d = abs(y - y1)                  # 边长
            # 正方形可以在左边，也可以在右边
            total += (self.cnt[(x, y1)]
                      * self.cnt[(x - d, y)]
                      * self.cnt[(x - d, y1)])
            total += (self.cnt[(x, y1)]
                      * self.cnt[(x + d, y)]
                      * self.cnt[(x + d, y1)])
        return total

    注意要同时枚举 x - d 和 \(x + d\) 两个方向，因为正方形可能在给定点的左边或右边。

    解法二：枚举"对角顶点"（写法更直白）¶

    from collections import defaultdict

class DetectSquares:
    def __init__(self):
        self.cnt = defaultdict(int)

    def add(self, point: List[int]) -> None:
        self.cnt[tuple(point)] += 1

    def count(self, point: List[int]) -> int:
        x, y = point
        total = 0
        for (px, py), c in list(self.cnt.items()):
            # 以 (px, py) 为"对角顶点"，检查是否与给定点构成正方形的对角线
            if abs(px - x) == abs(py - y) and px != x and py != y:
                total += c * self.cnt[(px, y)] * self.cnt[(x, py)]
        return total

    这个版本利用了"正方形的对角线端点满足 \(\vert dx\vert = \vert dy\vert\)"这一性质：只需枚举所有已有点作为对角顶点，检查它们与给定点能否构成正方形，另外两个角就是 (px, y) 和 (x, py)。思路极其简洁，值得作为首选。

    复杂度¶

    操作 时间 空间
    add \(\mathcal{O}(1)\) \(\mathcal{O}(n)\)
    count（解法二） \(\mathcal{O}(已有点数)\) \(\mathcal{O}(1)\) 额外
    count（解法一） \(\mathcal{O}(同列点数)\) \(\mathcal{O}(1)\) 额外

    易错点与面试追问¶

    • 重复加入同一个点要计数，所以必须用 defaultdict(int) 而不是 set。
    • 方案数要用"数量相乘"（\(c1 * c2 * c3\)），不是相加或加 1。
    • 要枚举 x - d 和 \(x + d\) 两个方向（解法一）。
    • 不能把给定点自身算进去（在解法一里要跳过 \(y1 = y\)，在解法二里要排除 \(px = x\) 或 \(py = y\)）。
    • 坐标可能为负，哈希表天然支持。
    • 追问：如何降低 count 的复杂度？ → 解法一只枚举同列的点，通常远小于总点数；进一步可以用"x → (y → count)"的嵌套结构。
    • 追问：如果要求"矩形"而不是正方形？ → 需要枚举两对 x 和两对 y，复杂度上升。
    • 追问：cnt 的 key 为什么用元组？ → 元组可哈希；也可以用 \(x * M + y\) 的整数编码（需要足够大的 M）。
