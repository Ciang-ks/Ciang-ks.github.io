    项目 A：跨资产 Alpha 与组合研究¶

    这个项目围绕一个具体问题展开：只用过去价格形成的趋势分数，变成有约束的多空配置后，能否在同一资产集合上提供成本后的增量？ 我们不从最漂亮的收益曲线出发，而是追踪 2010 年 3 月 26 日这一笔目标是怎样形成、在哪一天进入收益、付了多少成本，以及最后的报告能证明什么。

    默认有八个资产标签：股票、债券、通胀债、黄金、商品、房地产、美元、加密。它们是确定性合成风险代理，不是这些资产真实历史上的可交易合同。生成器让它们共同受到三个随机因子影响，并加入不同噪声、漂移和一个很弱的前期收益项。这样既有相关性、趋势和反转，也能直接检查数据机制。它适合训练研究流程，不能证明真实市场存在同样的 alpha；资产名称也没有自动补齐债券现金流、期货换月或加密资金费率。

    交互入口是 project_lab.ipynb。它按“先看一日账，再看整段表现，再改变一个假设”的顺序展开。源码保持最小，数据、特征、权重、回测和指标分开，每个数字都有可以返回检查的上游对象。

    先读懂一笔真实代码中的目标¶

    默认价格从 2010-01-01 开始，窗口为 60 个工作日，每 20 行生成一次新目标。这里的工作日只是周一至周五，没有真实交易所假日规则。第 0、20、40 行还没有完整窗口；第 60 行是 2010-03-26，首次形成有效目标。它是一条很好的贯穿主线：看完它的构造，就能解释后面所有日期的同类计算。

    以 EQUITY 为例，起始价格约 100.078193，当日价格约 95.643664，所以 60 日动量（momentum） 是 95.643664 / 100.078193 - 1 ≈ -4.431064%。动量在这里指过去一段时间累计涨跌，不是未来收益预测本身。当日 60 日滚动日收益标准差乘 sqrt(252)，得到年化波动约 14.200537%。两者相除得到分数 -0.312035：过去下跌、波动越低，做空方向的相对分数越强。

    代码把八个分数的绝对值相加，当日约为 3.706140，再用每个分数除以这个和。于是股票权重为 -0.312035 / 3.706140 ≈ -0.084194，即以资本为分母的 -8.4194% 名义空头。归一化前后要分清：分数没有元的单位，权重则将分数变成持仓规模。

    最后逐项限制在 [-0.25, 0.25]。当日通胀代理触及 25% 上限，代码截断后不再重新归一化，因此总绝对权重约 0.954179，而不是必为 1；净权重约 -0.153115。总绝对权重衡量多空名义规模，净权重表示方向性金额差。单名限额没有让组合自动市场中性，也没有保证风险平均分配。

    下面是需要复算的三行，不要求记住数值，重要的是能解释每一列：

    日期 数据或计划 回测中的含义
    2010-03-26 用截至当日价格形成新目标 当日收益仍用前一天零仓位，所以毛收益为 0；目标从零变为非零，按 10 bps 计费用约 0.095418%
    2010-03-29 股票价格约 95.922607，股票单日收益约 +0.29165% 用 3 月 26 日股票空头权重，股票贡献约 -0.024555%；八项合计毛收益约 +0.167241%，目标未变则本日简化换手为 0
    2010-04-23 第 80 行，更新目标 用更新前计划解释当日毛收益，用新旧目标差计当日费用，随后新计划用于下一行收益

    这三行同时暴露模型边界。weights.shift(1) 避免了让当天新信号乘当天已经发生的收益，但仍把“当日收盘后算出目标”近似为可以按该收盘价建立仓位。实际下一开盘成交会遗漏隔夜段、引入跳空和滑点，不能仅凭一次 shift 就证明可成交。项目训练的是一个显式的收益近似，真实执行需要额外实现。

    数据怎样变成信号、权重和净值¶

    src/data.py 的输入是起止日期和 seed，输出正价格表。内部先生成带共同因子和弱自回归项的对数变化，再指数累计为价格。固定 seed 可以复现同一路径，但不等于换个 seed 还会得到相同结论。合成机制本身可检查，因此看到趋势表现时，要区分“恢复了生成器设定”与“发现了真实经济规律”。

    src/features.py 将价格转成每日简单收益、过去 60 行累计动量和过去 60 个有效日收益的年化波动。动量与年化波动的时间单位不同，所以二者相除只是一个风险缩放分数，不是预测的夏普比率。窗口不足保留缺失，在计划调仓日才生成新目标，随后向前延用该目标；向前延用表示沿用已知计划，不是用未来补齐过去。

    src/backtest.py 使用上一行计划乘本行资产收益，得到毛收益；新旧计划差的绝对值和作为换手，乘费率得到成本，再从毛收益扣出净收益。设目标计划为 w[t]、资产收益为 r[t]，则 gross[t] = sum(w[t-1] * r[t])，turnover[t] = sum(abs(w[t] - w[t-1]))，net[t] = gross[t] - turnover[t] * cost_bps / 10000。首行将前一期持仓视为全零，按初始目标总绝对权重计建仓换手。净值是 prod(1 + net)，初始为 1。

    目标固定时，代码每天按固定比例计算收益，却没有跟踪价格变化造成的实际权重漂移，也不计维持固定比例所需的交易。它不是恒份额买入持有，也不是第二章的完整金额自融资账本。趋势计划先为零，在首次非零目标日计建仓费；全程固定等权基准则在首行计建仓费，之后不再有计划变化成本。二者都未计漂移再平衡成本、现金利息、融资和借券。将来若扩展执行，应把这些作为需要重做的假设，当前报告必须如实注明。

    src/metrics.py 从净收益算复合年化增长、日标准差乘 sqrt(252) 的年化波动和路径回撤。输出字段 sharpe 为日均净收益乘 252 再除以年化波动，等价于日均净收益除以日标准差再乘 sqrt(252)；教学现金利率设为零，因此这里没有另减现金收益。复合年化增长来自财富连乘，夏普分子来自算术均值，两者有意区分。回撤将初始净值 1 纳入峰值，首期建仓费带来的净值损失也会正确计入。

    src/run.py 只是编排这些步骤，并输出同一配置下的价格、权重、四种成本、等权基准、指标和清单。数据与信号逻辑没有藏在入口里，因此当结果异常时，可以回到本节的 3 月 26 日逐层定位，而不必猜测整张净值图。

    固定研究合同，再改变一个假设¶

    主配置使用 60 行动量、20 行调仓间隔、25% 单名绝对权重上限，费用设为 0、10、25、50 个基点。一个基点等于比例数 0.0001；10 bps 费用意味着交易额 1000 元支付 1 元。费用是每单位证券买卖金额的单边线性近似，不是每次交易固定扣某个收益。

    等权基准在八个标签上每期使用 1/8 的固定权重，是本实现中的固定比例收益基准，计入首期建仓成本，但未计漂移再平衡成本。它帮助展示简单方向暴露，但多空趋势与长期全多头还可能有不同的市场 beta、波动和净暴露，比较时不能把任何差值都叫作独立 alpha。

    默认入口在整个合成区间生成一次回放，不会自动建立训练、验证和不可触碰的测试集。所以“样本外增量”是要检验的研究目标，并不是运行默认命令就完成的事实。若选择窗口或阈值，应先规定时间切分，只在训练与验证期做选择，固定规则后再展示后段结果；真实数据适配器也必须新增，不得悄悄替换默认路径。

    环境、运行与可观察产物¶

    从仓库中的 research 目录建立隔离环境；若已有满足依赖的 Python 环境，可直接使用。命令不假设环境已经安装：

    cd research
python -m venv .venv
.venv/bin/python -m pip install -r projects/alpha_research/requirements.txt
cd projects/alpha_research

    六个 milestone：沿着一笔目标逐层完成研究¶

    每个阶段先解释自己看到的账，再留下可追溯证据。时间安排按读者需要决定，不以几小时或几天完成作为质量标准。下面保留学习者要做的研究决策与代理可协助的范围；折叠答案帮助自查机制，不替代对新实验结果作判断。

    Milestone 0 — 研究合同和手工验算¶

    这一步先回到 3 月 26 日：价格已知后才形成目标，但代码把成交近似放在同一收盘。研究合同要把这个近似写明，而不是只画一条看似正确的箭头。如果选择下一开盘成交，就要重新定义收益区间，而非仅改文案。

    上下文：成熟团队在写代码前先冻结研究问题、交易时点、benchmark 和主指标。否则运行结果出来后会无意识地改问题。

    [STUDENT ACTION]

    1. 在 reports/memo.md 开头写出研究问题、经济直觉、universe、horizon、decision time、benchmark、成本区间和 primary metric。
    2. 画一条时间线：截至 t 的价格 → t 行形成目标并扣费 → t+1 行用该目标计算收益，并注明收盘成交近似。
    3. 手算三资产、两期的 turnover 和成本，并写出如果删除 weights.shift(1) 会产生什么前视偏差。
    4. 选择 daily/weekly/monthly rebalance 之一，写出响应速度、噪声、成本的取舍。

    [AGENT ACTION]

    • 解释 src/ 中每个模块的输入/输出和不变量，不替学习者选参数。
    • 检查 memo 是否把 signal、target position、order、fill 混为同一概念。

    参考答案：本阶段的关键机制

    若三资产计划由 [0.2, -0.1, 0.1] 变为 [0.1, -0.2, 0.0]，本实现换手为 0.3，10 bps 费用为收益比例 0.0003，即 3 个基点。删除 shift(1) 会让今天新目标乘今天已经发生的价格变化，信号直接使用了待解释收益。保留 shift 后，真实成交价问题仍未自动解决。

    Milestone 1 — 数据、单位和特征审计¶

    5. 记录至少三个真实数据会失效的假设：复权、退市、期货换月、时区、停牌或流动性。

    Milestone 2 — 信号、权重和暴露¶

    沿着 -0.312035 的股票分数检查，它先除以全资产分数绝对值和，再截断到单名上限。截断后没有重新分配余量，不能说权重始终满仓。随后每日复制的是一个目标比例计划，并非冻结不动的股份数量。

    上下文：同一 alpha 分数可以经过不同标准化、波动缩放和权重约束，变成完全不同的交易组合。

    [STUDENT ACTION]

    1. 逐行解释 momentum / volatility → normalized weights → cap → forward fill。
    2. 检查每个日期的单名权重是否满足 \(\vert w_i\vert \le 0.25\)，gross exposure、net exposure 和资产集中度如何变化。
    3. 比较 raw momentum、横截面 rank 和 inverse-vol 三种 mapping；一次只改一个因素。
    4. 对 rebalance_every=20 和 60 做 ablation，报告信号变化、换手和成本后的结果。
    5. 画目标权重、gross/net exposure 和各资产平均绝对权重。

    [AGENT ACTION]

    • 用小型三资产例子演示 cap 为什么可能改变权重和总 gross exposure。
    • 检查 weights 是 target/held position 还是 order，确认回测中的 shift 与定义一致。
    • 审阅实验是否保留了相同日期、资产和成本，避免“同时改了三件事”。

    完成证据：weights 审计表 + 两个窗口的对照表 + 暴露图。

    参考答案：本阶段的关键机制

    原始三项分数 [4, 1, -1] 归一化后为 [2/3, 1/6, -1/6]，若单名上限 0.25，截断后为 [0.25, 1/6, -1/6]，总暴露从 1 降为 7/12，净暴露为 0.25。若再归一化，总暴露改变，单名还可能再次超限；那已是另一个组合算法。

    Milestone 3 — 回测会计与成本压力¶

    3 月 26 日毛收益为零但净收益为负，是因为建立新计划当日发生了模型费用；3 月 29 日计划不变，简化换手为零但实际持仓比例会随价格漂移。这两个日期是区分时间规则与账户近似的最短例子。

    上下文：研究收益只有在说明成交时点、换手和成本后才具有交易含义。

    [STUDENT ACTION]

    1. 运行四种成本；确认成本提高不能提高净收益，且成本差异等于换手乘基点差再乘 \(10^{-4}\)。
    2. 同时报告 gross/net return、equity、最大回撤、恢复时间、平均和 P95 turnover。
    3. 写出 market order、limit order、TWAP、VWAP、POV、implementation shortfall 的适用条件。
    4. 增加一个简单的 order/ADV 非线性成本实验（可在新模块中实现），比较线性 bps 的偏差。
    5. 分别检查第一数据行、首次非零目标日和固定等权基准的换手；说明趋势初期空仓与基准首期建仓的区别，并解释仍未计入的漂移再平衡成本。

    [AGENT ACTION]

    • 逐项检查 backtest.py 的 previous-period weights、asset returns、cost 和 equity 公式。
    • 用 Almgren–Chriss 的临时/永久冲击直觉解释实验，不把线性成本称为最优执行。
    • 若结果异常，先检查索引、单位和交易时点，再讨论模型改进。

    完成证据：成本敏感性表、净值/回撤图、执行假设段落。

    参考答案：本阶段的关键机制

    保持权重不变时，两种成本的单期净收益差精确等于 turnover × bps差 / 10000，但累计净值差不是这些单期差简单相加。默认趋势第一行目标为零，所以无费用，在首次非零目标日计建仓费；固定等权基准首行换手为 1，之后计划差为零。二者仍未计实际持有比例漂移带来的再平衡成本。线性费用不含参与率、订单大小和盘口恶化，需要额外情景而非换个 bps 就当成完整执行模型。

    Milestone 4 — Benchmark、归因和失败状态¶

    合成趋势信号的默认 10 bps 年化结果可能落后基准；这种结果完全可以成为完整研究交付。先问是否只是净空头、资产选择或某些状态造成差异，再决定是否值得扩展，不能为了满足“有效策略”的预期持续调到正数。

    上下文：高 Sharpe 可能只是市场 beta、某个资产、某一年或低成本假设的产物。

    [STUDENT ACTION]

    1. 把趋势组合和等权 benchmark 放在同一张图和同一张指标表。
    2. 按年份、资产、趋势状态和波动状态拆分收益；报告每组样本量。
    3. 对策略净收益回归或相关分析至少两个简单风险因子，讨论 beta 与 alpha 的区别。
    4. 设计三个失败解释：趋势反转、流动性冲击、资产相关性上升；为每个解释写一个可执行的检查。
    5. 写出“结果不支持部署”的条件，例如成本超过 25 bps、回撤超过阈值或只剩单一资产贡献。

    [AGENT ACTION]

    • 防止把合成数据中的设定机制误写成真实市场规律。
    • 帮助区分 benchmark-relative alpha、absolute return 和风险溢价。
    • 审阅分组是否事后挑选；要求保留完整的失败分组。

    完成证据：benchmark/归因表、失败样本、停止/继续规则。

    参考答案：本阶段的关键机制

    先比较同日期净收益，再检查多空净暴露、股票等资产贡献以及状态样本数。趋势反转可查看变号前后损益；相关性上升可查看同时亏损的资产数及风险贡献；流动性冲击需提高成本或加入成交限制。历史数据没有真实流动性时，应把后者记作情景而非已观测事实。

    进一步诊断：仍然沿着同一条研究主线¶

    信号衰减（alpha decay） 问的是 3 月 26 日看到的分数，究竟对未来哪一段收益还有信息。可以固定一个主窗口，分别比较未来 1、5、20 行收益与当时分数的关系；若收益窗口重叠，统计误差不能按独立样本处理。不要把“事后选择最好持有期”与“预先定义的预测期限”混为一谈。

    信息系数（information coefficient，IC） 是分数与后续收益的相关程度；跨资产每日只有八个标签，横截面 IC 非常嘈杂，还可能只是共同因子作用。有效下注数（effective breadth） 关注相对独立的机会，而不是简单数资产。八种资产共享三个生成因子，不能自动当成八次独立证据。可以画分资产分数—收益关系和相关矩阵，说明哪些机会其实重复。

    交易成本分析（transaction cost analysis，TCA） 应区分费用、价差、冲击与延迟。按时间均匀拆单的 TWAP 适合控制时间分布，按市场量分布执行的 VWAP 追踪成交量加权价格，按成交量一定比例参与的 POV 则限制交易参与率；它们都是执行规则，不保证更好价格。执行缺口（implementation shortfall） 比较决策时的理想价值与真实完成结果，包含未成交机会成本。本项目没有订单和逐笔成交，所以这些只能作为新增模块的研究问题，不能从现有 bps 回测里反推出真实 TCA。

    若设计冲击实验，可从 订单金额 / 当日可交易金额 的参与比例出发；ADV 是平均日成交额或成交量，必须与订单单位匹配。成本随参与比例非线性上升的情景，比把所有订单统一扣同一个数更能揭示容量压力。但当前合成数据没有真实成交量，必须将量假设标成教学设定。

    研究交付还需要明确阶段边界：输入数据可信、信号能复现、配置与风险规则明确、历史回放通过，之后才是模拟成交、影子运行和监控。成本翻倍、字段覆盖下降或相关性突变时，应该先有可执行的减仓或停止条件。这些判断可以写入 memo，不需要把课堂源码包装成生产系统。

    交付与下一步¶

    完成项目时，运行现有不变量测试，并保留至少两个窗口或信号变体、四种费用、一个明确口径的基准。报告同时给出毛净收益、暴露、换手、回撤、分组或样本外结果；每个数字都能追溯到配置和 CSV/JSON，失败结果与近似限制也应留下。

    最自然的扩展顺序是先建立真实 ETF 数据适配器，确认身份、复权、时区和缺失，再增加漂移持仓、现金融资、非线性冲击与容量。随后可研究因子中性化和滚动时间验证。若标签或特征窗口跨越切分点，使用去除边界重叠样本的清除（purge）和隔离区（embargo）规则；它们针对信息重叠，不是所有简单日收益实验都必须机械加入的装饰。

    回到起点，只要你能从 2010-03-26 的价格变化一步步解释到下一行净值，并能清楚指出哪些损益与成交没有被模型覆盖，这个最小项目就已经提供了可靠的研究能力练习。复杂模型应在这些解释得到验证后再进入，而不是替代它们。
